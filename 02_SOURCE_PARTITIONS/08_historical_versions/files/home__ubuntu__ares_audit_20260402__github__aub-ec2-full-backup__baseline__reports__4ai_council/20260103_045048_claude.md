## 3. 성능 정체 원인 분해 프레임워크

```
성능 = 트리거 × 적용률 × 노출 × (1-비용) × 레짐적합
       ───────────────────────────────────────────────
       각 단계에서 손실 발생 가능

[1] 트리거 (Signal Fire Rate)
    - 시그널 발생 빈도 → 너무 희소하면 기회 손실
    - 점검: 일별 시그널 발생 카운트 시계열

[2] 적용률 (Execution Rate)
    - 시그널 → 실제 주문 비율 (유동성/슬리피지 필터)
    - 점검: 시그널 vs 체결 로그 diff

[3] 노출 (Position Sizing)
    - 사이징이 시그널 강도 반영하는지
    - 점검: 시그널 강도 vs 실제 weight 상관

[4] 비용 (Friction)
    - 슬리피지 + 수수료 + 스프레드
    - 점검: 백테스트 비용 vs 실제 비용 비교

[5] 레짐 (Regime Fit)
    - 현재 시장이 전략 설계 가정과 일치하는지
    - 점검: VIX 구간별 / 금리 방향별 성능 분해
```
