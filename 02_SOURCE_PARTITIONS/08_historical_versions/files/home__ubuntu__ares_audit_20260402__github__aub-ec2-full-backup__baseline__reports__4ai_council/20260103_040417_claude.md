### P2. Degenerate Fold 원인 분해
```
WHY: 4/10 폴드 degenerate = 특정 기간에 포지션 0 또는 단일종목 올인
     → 서바이버십 바이어스 or 시그널 과적합 의심
```

**체크리스트**
- [ ] 폴드 1,2,3,8의 기간 확인 (어떤 시장 레짐?)
- [ ] 해당 폴드에서 필터 통과 종목 수 확인
- [ ] 시그널 분포 히스토그램 생성

**실험**
| ID | 내용 | Gate | 기대 관측치 |
|----|------|------|------------|
| P2-A | 폴드별 `n_candidates` 로깅 추가 | 로그 확인 | 폴드별 종목 수 분포 |
| P2-B | degenerate 폴드만 시그널 임계값 -10% 완화 | OOS 변화 | degenerate 해소 or 악화 |
| P2-C | 폴드 1,2,3,8 기간에 VIX/SPY 레짐 태깅 | 레짐 매핑 | 특정 레짐 집중 여부 |

**PASS 조건**: Degenerate 폴드 ≤ 2개 AND OOS Mean ≥ 2.5 유지

```
WHY: max 83.8%인데 min 0% → 올인/제로 스윙
     → 운영 불가능한 변동성, 슬리피지 과소 추정
```

**체크리스트**
- [ ] 일별 exposure 시계열 추출
- [ ] exposure 급변 (>30%p/day) 횟수 카운트
- [ ] 해당 날짜의 거래비용 실제 반영 여부

**실험**
| ID | 내용 | Gate | 기대 관측치 |
|----|------|------|------------|
| P3-A | exposure 변화율 ≤ 20%/day 제약 추가 | 백테스트 | OOS Mean 변화 |
| P3-B | turnover 기반 비용 2x로 상향 | 비용 민감도 | OOS Mean -0.5 이상 하락 시 과최적화 |

**PASS 조건**: Exposure 일변화 std < 15%p AND OOS Mean > 2.0

| P5-B | degenerate 폴드 제외 OOS 별도 리포팅 | 리포트 추가 | 두 버전 병기 |

## 🔍 성능 미변화 원인 분해 트리

```
OOS 안 움직임
├─ 트리거 문제
│  ├─ 시그널 임계값 너무 높아 발동 안함
│  └─ 필터가 대부분 종목 제거
├─ 적용 문제
│  ├─ 포지션 사이징이 0에 수렴
│  └─ 리밸런싱 주기가 너무 김
├─ 노출 문제
│  ├─ 롱/숏 상쇄로 net exposure ≈ 0
│  └─ 현금 비중 과다
├─ 비용 문제
│  ├─ 거래비용이 알파를 상쇄
│  └─ 슬리피지 과소/과다 추정
└─ 레짐 문제
   ├─ 특정 레짐에서만 작동 (2020-2021 등)
   └─ 현재 폴드가 비작동 레짐에 집중
```

**진단 명령어**
```bash
# 트리거 진단
python3 -c "from backtest import *; print(signal_trigger_rate())"

# 노출 진단  
python3 -c "from backtest import *; print(daily_net_exposure().describe())"

# 비용 진단
python3 -c "from backtest import *; print(gross_return - net_return)"
```
