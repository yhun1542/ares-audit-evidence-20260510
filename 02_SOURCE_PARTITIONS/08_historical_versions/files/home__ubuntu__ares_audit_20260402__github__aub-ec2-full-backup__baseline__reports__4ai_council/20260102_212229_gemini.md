### 3) 성능 고착화(Stagnation) 시 원인 분해 트리거

성능 지표(OOS Mean 등)가 움직이지 않을 때 다음 순서로 디버깅:

1.  **트리거(Trigger) 불감증:**
    *   *현상:* 매매 신호 자체가 발생하지 않음.
    *   *점검:* 진입 조건(`threshold`)이 너무 높은지 확인 (예: RSI < 20은 너무 드묾). -> **Action: Threshold 완화.**
2.  **노출(Exposure) 제한:**
    *   *현상:* 신호는 뜨는데 포트폴리오에 편입 안 됨.
    *   *점검:* 현금 비중 고정 로직이나 `max_positions` 제한에 걸렸는지 확인. -> **Action: 슬롯 당 비중(alloc) 축소 후 종목 수 확대.**
3.  **비용(Cost) 잠식:**
    *   *현상:* Gross Return은 좋은데 Net Return이 0에 수렴.
    *   *점검:* 턴오버가 과도하게 높음. -> **Action: 리밸런싱 주기를 일간 -> 주간/월간으로 변경하거나 대기(Holding) 페널티 부여.**
4.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 년도(예: 2022)에만 박살 나고 나머지는 좋음.
    *   *점검:* 하락장에서 롱 온리 전략 고수 중. -> **Action: 시장 지표(SPY 200MA 등) 하회 시 현금 100% 전환(Market Timing) 로직 추가.**
