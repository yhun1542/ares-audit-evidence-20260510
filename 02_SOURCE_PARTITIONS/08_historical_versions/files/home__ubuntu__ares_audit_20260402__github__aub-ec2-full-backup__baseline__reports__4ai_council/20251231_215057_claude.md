## 2. 성능 정체 시 원인 분해 트리

```
성능 미변동
│
├─▶ [트리거 실패] 시그널이 발생 안 함
│   └─ 점검: 실험 기간 내 시그널 firing rate 계산
│       → < 5% 면 조건 과잉 엄격
│
├─▶ [적용 실패] 시그널 발생했으나 포지션 미반영
│   └─ 점검: 시그널 vs 실제 거래 일치율
│       → < 80% 면 execution layer 버그
│
├─▶ [노출 부족] 포지션 잡았으나 사이즈 미미
│   └─ 점검: 평균 position size / 목표 대비 %
│       → < 50% 면 sizing 로직 과보수적
│
├─▶ [비용 상쇄] 수익 발생했으나 비용으로 소멸
│   └─ 점검: gross return vs net return 차이
│       → > 30% 면 turnover 과다
│
└─▶ [레짐 불일치] 실험 기간이 전략 작동 안 하는 국면
    └─ 점검: 해당 기간 SPY 방향성/변동성 vs 전략 설계 가정
        → bear market에서 long-only 면 당연한 결과
```

## 3. 48h 자동화 명령 시퀀스

```bash
# ===== Phase 1: 진단 (0-8h) =====
# P1: 극단 fold 분석
python3 experiment_system/tools/fold_analyzer.py --find-worst --metric tuning_min --output reports/worst_fold.json

# P3: 비용 계산
python3 experiment_system/tools/turnover_calc.py --config baseline/champion_v5_20251231.json --output reports/turnover.json

# P5: 누수 체크
python3 experiment_system/tools/lookahead_bias_check.py --config baseline/champion_v5_20251231.json

# ===== Phase 2: 실험 실행 (8-40h) =====
# P1-EXP2: VIX 레짐 필터
python3 experiment_system/tools/aub_autopilot.py \
  --registry experiment_system/config/module_registry.yaml \
  --inject "regime_filter: {vix_threshold: 30, exposure_reduction: 0.5}" \
  --run --output candidate_P1_EXP2.json

# P3-EXP2: 10bp 슬리피지
python3 experiment_system/tools/aub_autopilot.py \
  --registry experiment_system/config/module_registry.yaml \
  --inject "cost_model: {slippage_bp: 10}" \
  --run --output candidate_P3_EXP2.json

# P4-EXP1: 헤지 해제 단축
python3 experiment_system/tools/aub_autopilot.py \
  --registry experiment_system/config/module_registry.yaml \
  --inject "hedge_exit: {vix_below: 20, consecutive_days: 3}" \
  --run --output candidate_P4_EXP1.json

# ===== Phase 3: 게이트 판정 (40-48h) =====
python3 experiment_system/tools/gate_evaluator.py \
  --candidates "candidate_P*.json" \
  --gates "tuning_min>=0.30,lockbox_mean>=1.75,worst_mdd>=-0.12" \
  --promote-if-pass
```
