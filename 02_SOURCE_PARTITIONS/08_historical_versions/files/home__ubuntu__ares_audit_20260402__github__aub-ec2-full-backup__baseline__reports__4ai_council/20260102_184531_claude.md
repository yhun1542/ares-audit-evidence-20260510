## 2. 성능 미변화 시 원인 분해 트리

```
성능 불변 (tuning_mean Δ < 0.05)
│
├─ [트리거] 시그널이 변경되었나?
│   └─ NO → 파라미터/피처 변경이 시그널까지 전파 안 됨 (코드 버그)
│
├─ [적용] 시그널 → 포지션 매핑 변경되었나?
│   └─ NO → 리밸런스 로직/임계값이 변화 흡수
│
├─ [노출] 실제 노출(섹터/팩터) 변화?
│   └─ NO → 유니버스 내 종목 상관관계 높아 대체 효과
│
├─ [비용] 회전율 증가로 수익 상쇄?
│   └─ YES → 비용 조정 후 재측정
│
└─ [레짐] 테스트 기간 레짐이 단일(예: bull only)?
    └─ YES → fold별 레짐 라벨 분포 확인 → 다양성 부족 시 fold 재설계
```

## 3. 48h 루프 자동 실행 순서

```bash
# ─────────────────────────────────────────
# STEP 1: 게이트 점검 (FAIL 시 중단)
python3 experiment_system/tools/gate_check.py --checks G1,G2,G3,G4

# STEP 2: P1~P3 실험 병렬 실행
python3 experiment_system/tools/run_experiment.py --id P1-A,P1-B,P3-A --parallel

# STEP 3: 결과 수집 & PASS 판정
python3 experiment_system/tools/evaluate.py --ids P1-A,P1-B,P3-A --gate-file gates.yaml

# STEP 4: PASS 후보 → Candidate 승격
python3 experiment_system/tools/promote.py --best --output baseline/candidate_$(date +%Y%m%d_%H%M%S).json

# STEP 5: HANDOFF 갱신
python3 experiment_system/tools/handoff.py --update
# ─────────────────────────────────────────
```
