[우선순위 제안 및 실행 체크리스트]

현재 시스템은 **"관측 불가능(MDD None, 로그 로딩 실패)"** 상태와 **"과적합 의심(OOS Mean 3.32, Degenerate Folds 4개)"** 상태가 공존하는 고위험 구간입니다. 새로운 알파 탐색보다 **시스템 정상화 및 검증**이 최우선입니다.

### 1. [INFRA] 로그/메트릭 무결성 확보 (긴급)
*   **이유:** `Worst MDD: None` 및 JSON 파싱 에러는 시스템이 리스크를 계산하지 못하고 있음을 의미. 맹목적 비행 상태.
*   **위험:** 실제 계좌 파산 위험을 백테스트상 'None'이나 '에러'로 덮어버릴 수 있음.
*   **실험 정의:**
    *   `FIX_LOGGER`: Rebalance 로거의 JSON 형식을 JSONL(Line delimited)로 강제 변환 및 Flush 주기 단축.
    *   `CALC_MDD_PATCH`: 수익률 곡선(Equity Curve)이 Flat(거래 없음)일 때도 0.0으로 MDD가 산출되도록 예외 처리 추가.
*   **Gate:** `oos_mdd`가 `None`이 아닐 것. Rebalance 로그가 파서(Parser)에서 정상 로드될 것.
*   **관측치:** 로그 파일 용량 증가 확인, Degenerate Fold의 구체적 에러 메시지 획득.

### 2. [STRATEGY] Degenerate Folds(1,2,3,8) 해결을 위한 Regime Filter
*   **이유:** 전체 Fold의 약 40%가 실패(Degenerate)한다는 것은 특정 시장 국면(급락장 등)에서 전략이 붕괴됨을 시사.
*   **위험:** 필터가 너무 강력하면(Over-filtering) 거래 기회를 모두 박탈하여 `Exposure = 0`이 지속됨.
*   **실험 정의:**
    *   `EXP_VIX_FILTER`: VIX(또는 ETF 'VIXY') 30 이상 시 매수 금지(Cash 100%).
    *   `EXP_MA_FILTER`: QQQ 200일 이동평균선 하회 시 Tech 섹터 비중 축소(0.5x) 또는 매매 중단.
    *   `EXP_RELAX_STOP`: 손절(Stop Loss) 범위를 현재보다 1.5배 넓혀 노이즈에 의한 조기 청산 방지.
*   **Gate:** Degenerate Folds 개수가 1개 이하로 감소.
*   **관측치:** OOS Mean은 다소 하락하더라도, OOS Min 값이 개선(상승)되어야 함.

### 3. [COST] 슬리피지/수수료 스트레스 테스트 (과최적화 감지)
*   **이유:** OOS Mean 3.32는 비현실적. 거래 비용이 과소평가되었거나, 유동성이 적은 종목(Biotech 소형주 등)에서 체결 오차가 발생했을 가능성 높음.
*   **위험:** 전략의 기대 수익률이 급감하여 폐기해야 할 수도 있음(그러나 이것이 Truth임).
*   **실험 정의:**
    *   `STRESS_COST_2X`: 수수료/슬리피지 설정을 현재의 2배(예: 10bps -> 20bps)로 설정 후 백테스트.
    *   `STRESS_OPEN_EXECUTION`: 종가(Close) 체결 대신 익일 시가(Open) 또는 시가+0.5% 체결 가정.
*   **Gate:** OOS Mean > 1.0 유지. (3.3 -> 1.0 이하로 떨어지면 기존 전략은 비용 과소평가된 것임).
*   **관측치:** 회전율(Turnover)이 높은 종목들의 수익률 기여도 급감 여부.

### 4. [UNIVERSE] 유동성/변동성 기반 Tech+Health 유니버스 압축
*   **이유:** Tech/Healthcare 8~14개 종목 제한 시, 개별 종목 리스크가 큼. 특히 바이오 섹터의 임상 실패 리스크 회피 필요.
*   **위험:** "대형주 편중"으로 인해 알파가 사라지고 벤치마크(QQQ/XLV)와 동조화될 수 있음.
*   **실험 정의:**
    *   `UNIV_LIQUID_CAP`: 시가총액 $5B 이상, 일평균 거래대금 $50M 이상 종목만 필터링.
    *   `UNIV_LOW_VOL`: 최근 6개월 변동성 상위 10% 종목 제외(급등락 바이오/밈 주식 배제).
*   **Gate:** 유니버스 내 종목 교체율(Universe Turnover) < 20% (월간).
*   **관측치:** 드로우다운(MDD)의 깊이 감소, 샤프지수 안정화.

### 5. [EXECUTION] 비중 조절 민감도(Scale) 튜닝
*   **이유:** 현재 `exposure_max: 0.83`임에도 `oos_min`이 매우 낮음. 베팅 크기가 너무 작거나, 잘못된 타이밍에 과소 베팅 중.
*   **위험:** 레버리지 증가 시 MDD 동반 상승.
*   **실험 정의:**
    *   `SCALE_TARGET_VOL`: 포트폴리오 타겟 변동성을 고정(예: 연 15%)하고 이에 맞춰 비중 역산.
    *   `SCALE_CONFIDENCE`: 모델 예측 확신도(Probability)가 0.6 미만인 경우 진입 포기(Threshold 상향).
*   **Gate:** Exposure 평균이 0.4~0.7 구간에 안착.
*   **관측치:** 승률(Win Rate) 상승 여부.

### [48시간 자동 루프 정의]

**1. 실험 정의 (JSON Config)**
```json
{
  "experiments": [
    {"id": "fix_infra", "type": "patch", "target": "logger_and_mdd_logic"},
    {"id": "regime_vix", "type": "logic", "param": "vix_threshold=30", "action": "cash_100"},
    {"id": "stress_cost", "type": "stress", "param": "slippage_bps=20"},
    {"id": "univ_qual",  "type": "filter", "param": "min_mkt_cap=5B"}
  ]
}
```

**2. 게이트 (Pass Condition)**
*   **MUST:** `Generate Folds` == 0 (모든 Fold 정상 종료).
*   **MUST:** `Worst MDD` != None.
*   **MUST:** `Rebalance Log` 파일 존재 및 파싱 성공.
*   **TARGET:** `OOS Mean` > 1.5 (비용 2배 적용 후에도).

**3. 기대 관측치 (Expected Observation)**
*   로그 수정 후 OOS Mean이 3.32에서 1.xx 대로 현실화될 것으로 예상.
*   Degenerate Folds가 VIX 필터 적용 시 정상화되는지 확인 (불안정성의 원인이 고변동성 장세인지 확인).

### [성능 정체 시 원인 분해 가이드]

성능 지표가 움직이지 않을 때(Flat) 다음 순서로 점검:

1.  **Trigger (신호 발생):** 예측 스코어가 임계값(Threshold)을 넘지 못하는가? -> *조치: Threshold 하향 조정.*
2.  **Exposure (포지션 크기):** 신호는 떴는데 변동성/Risk Parity 로직이 비중을 0에 가깝게 깎았는가? -> *조치: Risk Budget 상향.*
3.  **Execution (체결):** 주문은 나갔으나 시가/종가 차이, 혹은 거래 정지 등으로 체결 실패 처리되었는가? -> *조치: 거래 가능 유니버스 재점검.*
4.  **Cost (비용):** 수익이 발생했으나 잦은 매매(Churning)로 수수료가 이를 상쇄했는가? -> *조치: 최소 보유 기간(Holding Period) 설정.*
5.  **Regime (시장 국면):** 시스템이 현재 시장을 'Trading 금지 구간'으로 오인하고 있는가? -> *조치: Regime Filter 조건 완화.*
