## 2. 우선순위 TOP-5 제안 (48h 실험)

---

### P1. Degenerate Fold 원인 분해

**(a) 왜 필요한가**  
- 10 fold 중 4개가 degenerate → OOS 신뢰도 붕괴  
- 특정 레짐(2022 금리, 2020 코로나) 집중 가능성

**(b) 위험/부작용**  
- Fold 제외 시 survivorship bias 유입  
- 레짐 필터 과도 시 표본 부족

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P1-A | Fold 1,2,3,8의 시작/종료일, 종목별 승률 dump | 완료 | 공통 패턴 식별 (예: 특정 섹터/월) |
| P1-B | 해당 Fold만 `exposure_cap=0.5` 적용 재실행 | OOS>0 | Degenerate 해소 여부 |
| P1-C | 6-fold WalkForward (degenerate fold 제거) | OOS mean ≥ 2.5 & min > -0.01 | 안정성 확인 |

**PASS 조건**: Degenerate fold ≤ 1개 & OOS min > -0.02

---

### P2. MDD 계산 파이프 복구

**(a) 왜 필요한가**  
- `worst_mdd: None` → 리스크 게이트 무력화  
- 실제 MDD -30% 전략이 통과될 수 있음

**(b) 위험/부작용**  
- 계산 로직 수정 시 기존 결과 재현 불가 가능

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P2-A | `calc_mdd()` 함수에 `assert equity_curve is not None` 삽입 | 에러 위치 특정 | 예외 발생 라인 |
| P2-B | Champion v5 equity curve 수동 플롯 후 MDD 계산 | 값 산출 | MDD 수치 확보 |

**PASS 조건**: `worst_mdd` 필드에 float 값 출력 & MDD < -25%

---

### P3. OOS Mean 불일치 해소 (3.32 vs 2.63)

**(a) 왜 필요한가**  
- Handoff와 Diagnoser 값 충돌 → ONE TRUTH 위반  
- 잘못된 수치로 의사결정 시 전략 선택 오류

**(b) 위험/부작용**  
- 캐시/버전 차이일 경우 단순 해결  
- 계산 로직 차이일 경우 전면 재검증 필요

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P3-A | 두 스크립트의 `oos_mean` 계산 라인 diff | 차이점 특정 | 수식 or 입력 데이터 차이 |
| P3-B | 동일 JSON 파일 기준 양쪽 재실행 | 값 일치 | 3.32 or 2.63 중 하나로 통일 |

**PASS 조건**: 모든 리포트에서 동일 OOS Mean 표시

---

### P4. 트레이딩 비용 민감도 검증

**(a) 왜 필요한가**  
- 현재 비용 반영 여부 불명확  
- 고회전 전략일 경우 실제 수익 대폭 하락

**(b) 위험/부작용**  
- 비용 과대 적용 시 실행 가능 전략 사망

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P4-A | 현재 cost 파라미터 값 추출 (`grep -r "cost\|slippage"`) | 확인 | bps 단위로 문서화 |
| P4-B | cost=0 vs cost=15bps vs cost=30bps 3-way 비교 | 완료 | OOS 차이 ≤ 0.5 → 저회전 확인 |

**PASS 조건**: cost=30bps에서도 OOS mean ≥ 2.0

---

### P5. Hedge 파라미터 고정점 탐색

**(a) 왜 필요한가**  
- `exp_fsa_only_scale_090_hedge_025` 실험 존재 → 이미 탐색 중  
- 현재 결과와 연결 안 됨

**(b) 위험/부작용**  
- 파라미터 그리드 확장 시 과최적화  
- Hedge 비율 ↑ → Exposure ↓ → 수익 희석

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P5-A | `hedge=0.15/0.25/0.35` 3점 비교 (scale=0.90 고정) | OOS min 개선 | min > -0.01 |
| P5-B | Best hedge에서 `scale=0.85/0.90/0.95` 교차 | OOS mean ≥ 3.0 | 최적 조합 1개 |

**PASS 조건**: Degenerate fold ≤ 2 & OOS mean ≥ 3.0 & min > -0.015

## 3. 성능 정체 시 원인 분해 트리

```
OOS 안 움직임
│
├─ [트리거] 시그널 발생률 확인
│   └─ signal_count / total_bars < 5%? → 시그널 조건 완화
│
├─ [적용] 시그널 → 실제 포지션 전환율
│   └─ position_changes / signals < 50%? → rebalance 로직 점검
│
├─ [노출] 평균 exposure 수준
│   └─ mean_exposure < 0.3? → 현금 과다 → sizing 조정
│
├─ [비용] 회전율 × 단위비용
│   └─ turnover > 200%/yr? → cost drag 지배적
│
└─ [레짐] Fold별 분산
    └─ std(fold_oos) > mean? → 레짐 의존성 과다
```
