[우선순위 TOP 5 제안 (향후 24~48시간)]

1.  **Degenerate Folds (1, 2, 3, 8) 긴급 복구**: 전체 폴드의 40%가 유효하지 않음(Degenerate). 이는 과최적화(특정 구간만 작동) 또는 데이터 공백을 의미. 해당 구간 강제 백테스트 수행 필수.
2.  **MDD 계산 로직 수정**: `worst_mdd: None`은 리스크 관리 모듈의 치명적 오류. Drawdown 계산 시 NaN/Inf 처리 로직 점검 및 0으로 나누기 방지.
3.  **로깅 파이프라인 정상화**: `Rebalance Pinpoint` 실패(JSON 파싱 에러/파일 없음)는 "깜깜이 매매"를 의미. 체결 로그(rebalance.csv/jsonl) 기록 강제화.
4.  **비용 구조(Cost Model) 현실화**: OOS Mean 3.32는 비현실적. 슬리피지(10bps)+수수료(5bps) 적용 후에도 살아남는지 확인.
5.  **Universe Tech/Health 집중**: ETF 제외 및 섹터 집중도(Tech+Bio) 검증 로직 추가. 현재 `exposure_max: 0.83`이나 종목 구성 확인 불가.

[실행 가능한 Patch/실험 (3개)]

### EXPERIMENT 01: Degenerate Fold Rescue (안정성 확보)
*   **(a) 필요성**: 폴드 1, 2, 3, 8이 붕괴된 상태에서 OOS Mean 값은 생존 편향(Survivorship Bias) 덩어리임. 이 구간에서 전략이 매매를 포기했거나 솔버가 터짐.
*   **(b) 위험**: 해당 구간 포함 시 전체 평균 수익률 급락 가능성 (그러나 이것이 '진실'임).
*   **(c) 실험 정의**:
    1.  `fold_ids = [1, 2, 3, 8]`로 고정하여 백테스트 실행.
    2.  제약 조건 완화: `min_weights` 0.0 -> 0.05, `max_turnover` 제한 해제.
    3.  Solver Timeout 시간 2배 증액.
*   **(d) PASS 조건**:
    - 4개 폴드 모두에서 유효한 Sharpe/MDD 값 산출 (0.0 또는 None 제외).
    - 에러 로그 없이 종료.

### EXPERIMENT 02: Cost & MDD Reality Check (과최적화 방지)
*   **(a) 필요성**: `worst_mdd: None` 상태에서 운영 불가. 초고수익률(3.32)은 거래비용 0 가정일 확률 높음.
*   **(b) 위험**: 전략 폐기 수준으로 성능 하락 가능성.
*   **(c) 실험 정의**:
    1.  비용 모델 주입: `slippage=0.001` (10bps), `commission=0.0005`.
    2.  MDD 계산기 패치: Equity Curve가 `NaN`인 경우 직전 값 사용(Fill Forward) 후 계산.
    3.  대상 유니버스: US Tech/Healthcare Top 50 (유동성 기준)으로 제한.
*   **(d) PASS 조건**:
    - `worst_mdd`가 유효한 음수 값(예: -0.15)으로 기록됨.
    - Cost 적용 후 OOS Sharpe > 1.5 유지.

### EXPERIMENT 03: Sector Concentration Enforcer (규칙 준수)
*   **(a) 필요성**: "미국주식 Tech+Healthcare 8~14개" 규칙 강제. 현재 어떤 종목을 잡는지 불투명. ETF 매매 차단.
*   **(b) 위험**: 분산 효과 감소로 인한 변동성 증가.
*   **(c) 실험 정의**:
    1.  Universe 필터: GICS Sector 정보 기준 'Information Technology' 및 'Health Care'만 허용. (ETF 티커 블랙리스트 적용).
    2.  포트폴리오 제약: `target_n_positions` = 12 (Soft limit 8~14).
    3.  비중 제한: 개별 종목 Max 15% (집중 투자 유도).
*   **(d) PASS 조건**:
    - 리밸런싱 로그 상 보유 종목 수 8~14개 유지.
    - ETF 보유 비중 0%.

[성능 정체 시 원인 분해 아이디어]

자동화 루프에서 성능 지표가 움직이지 않을 때(Flatline) 체크리스트:

1.  **트리거(Trigger) 불발**:
    *   시그널 임계값(Threshold)이 너무 높아 매매가 발생하지 않음.
    *   *Action*: 임계값을 0.5배로 낮춰 거래량 발생 여부 확인.
2.  **노출(Exposure) 제약**:
    *   `exposure_max` 리밋에 걸려 현금 비중만 높음.
    *   *Action*: 현금 비중이 20% 이상인 날짜의 수 카운트.
3.  **데이터(Data) 누락**:
    *   특정 섹터(Tech/Bio) 데이터가 해당 기간에 NaN으로 처리되어 유니버스에서 탈락.
    *   *Action*: `Dropna` 전후의 유니버스 사이즈 비교 로그 출력.
4.  **레짐(Regime) 불일치**:
    *   현재 전략이 '추세 추종'인데 시장이 '횡보' 중일 때 손실 방지를 위해 포지션 청산 후 대기 중일 수 있음.
    *   *Action*: 시장 벤치마크(QQQ/XLV) 대비 베타(Beta)가 0에 수렴하는지 확인.
