## 1) 향후 24~48시간 우선순위 TOP 5 제안

현재 `degenerate_folds: [1, 2, 3, 8]` 상태는 모델이 특정 구간에서 완전히 실패하거나 계산 불능(NaN/Inf) 상태임을 시사합니다. 로그 파일 누락(`Errno 2`)으로 인해 실제 회전율과 비용이 블랙박스 상태입니다. 수익률(3.32)은 과최적화나 데이터 누수일 확률이 높습니다.

### P1. [Ops/Fix] Rebalance Logger 복구 및 포맷 통일
*   **Why:** `rebalance.csv` vs `.jsonl` 포맷 불일치로 비용 분석 불가. 실제 트레이딩 시 슬리피지로 인한 파산 위험 1순위.
*   **Risk:** 로깅 수정 자체는 모델 성능에 영향 없으나, 수정 후 백테스트 결과가 대폭 하락할 수 있음(현실화).
*   **Experiments:**
    1.  **[FIX_LOG]**: 로거 포맷을 `jsonl`로 단일화하고, 매 리밸런싱마다 `target_weight`, `actual_traded`, `estimated_cost` 강제 기록.
    2.  **[DRY_RUN]**: 최근 1개월 데이터로 Dry Run 수행하여 로그 파일 생성 여부 및 파싱 가능 여부 확인.
*   **PASS 조건:** `aub_rebalance_pinpoint.py`가 에러 없이 실행되고, Turnover가 0이 아님을 확인.

### P2. [Logic/Safety] Degenerate Folds(1,2,3,8) NaN/Inf 방어 로직 주입
*   **Why:** 전체 폴드의 40%가 망가짐. 0으로 나누기, 로그 음수 진입, 혹은 아웃라이어 데이터로 인한 가중치 폭발 가능성.
*   **Risk:** 신호 강도를 인위적으로 클리핑(Clipping)하여 잠재 수익률(Upside)이 일부 깎일 수 있음.
*   **Experiments:**
    1.  **[CLIP_SIG]**: 모든 시그널(Signal) 출력단에 `np.clip(signal, -3, 3)` 적용.
    2.  **[FILL_NA]**: Feature 전처리 단계에서 `ffill()` 후 남은 NaN을 0이 아닌 `median`으로 대체.
    3.  **[VOL_FLOOR]**: 변동성 스케일링 시 분모에 `max(std, 1e-6)` 적용하여 div-by-zero 방지.
*   **PASS 조건:** `degenerate_folds` 리스트가 비어 있거나 개수가 1개 이하로 감소.

### P3. [Universe] Tech/Healthcare 유동성 필터 및 서바이버십 제거
*   **Why:** `oos_mean` 3.32는 비정상적으로 높음. 거래량 없는 바이오/테크 소형주가 포함되었을 가능성 농후.
*   **Risk:** 유니버스 축소로 인한 분산 효과 감소 (8~14 종목 유지가 어려울 수 있음).
*   **Experiments:**
    1.  **[LIQ_FILTER]**: `DollarVolume` 상위 200위 내에서만 Tech/Healthcare 필터링 (ADT > $20M 강제).
    2.  **[CAP_FILTER]**: 시가총액 $5B 이상만 허용 (Micro-cap 바이오 펌핑 제거).
*   **PASS 조건:** 필터 적용 후에도 유니버스가 15종목 이상 유지되며, OOS Mean이 1.0~1.5 수준으로 '현실적으로' 하락.

### P4. [Strategy] 집중 투자 방지 (Max Weight Cap)
*   **Why:** `exposure_max` 0.83에 비해 `oos_min` -0.02는 특정 종목 몰빵 후 급락 가능성을 시사. 8~14개 종목이라면 개별 종목 Cap이 필수.
*   **Risk:** 승자 종목(Winner)의 비중을 강제로 줄여 모멘텀 효과 반감.
*   **Experiments:**
    1.  **[HARD_CAP]**: 개별 종목 최대 비중 15% (`1/N * 1.5` 수준) 강제 제한.
    2.  **[SFT_CAP]**: 특정 섹터(예: Biotech) 합산 비중 40% 제한.
*   **PASS 조건:** `worst_mdd`가 개선되고(수치 확인 필요), 특정 종목 비중이 20%를 넘지 않음.

### P5. [Cost] 수수료 민감도 테스트 (Stress Test)
*   **Why:** 현재 로그가 없어 회전율 모름. 고빈도 매매 전략일 경우 수수료 반영 시 마이너스일 수 있음.
*   **Risk:** 전략 폐기 가능성 높음.
*   **Experiments:**
    1.  **[FEE_10BPS]**: 편도 수수료 10bps 가정 후 백테스트.
    2.  **[FEE_20BPS]**: 편도 수수료 20bps 가정 후 백테스트 (최악의 시나리오).
*   **PASS 조건:** 20bps 가정 시에도 OOS Sharpe > 1.0 유지.

## 2) 48시간 자동 루프 정의 (Auto-Loop)

### Experiment A: [FIX_LOG] + [LIQ_FILTER]
1.  **실험 정의**: 리밸런싱 로그 포맷 수정 및 유니버스를 유동성 상위(ADT > $20M) Tech/HC 종목으로 제한.
2.  **게이트(Gate)**:
    *   `degenerate_folds` 감소 확인 (데이터 품질 이슈가 소형주 때문인지 확인).
    *   로그 파일 파싱 성공.
3.  **기대 관측치**:
    *   OOS Mean: 3.3 -> 1.2 내외 (정상화).
    *   Turnover: 연 500% 이상일 경우 [Cost] 문제로 직결됨을 인지.

### Experiment B: [CLIP_SIG] + [HARD_CAP]
1.  **실험 정의**: 시그널 ±3 클리핑 및 개별 종목 비중 15% 상한 적용.
2.  **게이트(Gate)**:
    *   `exposure_min` > 0.1 (0.0 노출 상황 방지).
    *   `oos_min` 상승 (하방 경직성 확보).
3.  **기대 관측치**:
    *   MDD 감소.
    *   폴드 간 성능 편차(Variance) 감소.

### Experiment C: [VOL_FLOOR] + [FEE_10BPS]
1.  **실험 정의**: 변동성 계산 시 최소값 보정 및 수수료 10bps 적용 테스트.
2.  **게이트(Gate)**:
    *   나머지 Degenerate Fold(수학적 에러) 해결 여부.
    *   Sharpe Ratio > 1.0 유지.
3.  **기대 관측치**:
    *   현실적인 OOS 수익률 곡선 확인.

## 3) 성능 정체(Stagnation) 시 원인 분해 아이디어

만약 위 패치 후에도 성능이 개선되지 않거나 0에 수렴할 경우 체크리스트:

1.  **트리거(Trigger) 실패**:
    *   *Check:* 시그널이 임계값(Threshold)을 넘지 못해 매매가 아예 안 일어나는지? (`exposure_min: 0.0`의 원인일 수 있음)
    *   *Action:* 강제 매매(Force Trade) 로직을 넣어 파이프라인 작동 확인.

2.  **적용(Application) 오류**:
    *   *Check:* 최적화 솔버(Solver)가 제약조건(Constraint) 충돌로 인해 `None`이나 `Initial Weights`를 반환하는지?
    *   *Action:* 제약조건 완화(Slack 변수 도입) 후 솔버 상태 로그 확인.

3.  **노출(Exposure) 왜곡**:
    *   *Check:* ETF 제외 규칙이 너무 강력하여 Tech/HC 유니버스가 공집합이 되는 구간이 있는지?
    *   *Action:* 유니버스 종목 수(`count`)를 시계열로 플롯팅.

4.  **비용(Cost) 잠식**:
    *   *Check:* 리밸런싱 주기가 너무 짧아(일간) 알파가 수수료로 삭제되는지?
    *   *Action:* 리밸런싱 주기를 주간(Weekly)으로 변경 실험.

5.  **레짐(Regime) 불일치**:
    *   *Check:* 학습 기간이 2020-2021(Bull)이고 테스트가 2022(Bear)인 구조적 문제인지?
    *   *Action:* `oos_mean`이 높은데 `degenerate`가 뜬다면, 특정 '하락장 폴드'에서만 파산하는지 폴드별 수익률 상세 확인.
