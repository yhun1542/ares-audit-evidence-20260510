## TOP 5 우선순위 액션

### 1️⃣ [CRITICAL] Degenerate Fold 근본 원인 분리

**왜 필요한지:**
- 4/8 폴드 퇴화 = 전략이 특정 레짐에서만 작동
- 이 상태로 실험 돌리면 모든 결과가 오염됨

**위험/부작용:**
- 폴드 제거 시 survivorship bias 발생
- 과도한 필터링 → 샘플 부족

**실험 체크리스트:**

```
□ EXP-1A: 퇴화 폴드 레짐 분석
  - 정의: 폴드 1,2,3,8의 기간별 VIX/금리/섹터모멘텀 분포 추출
  - 게이트: 비퇴화 폴드와 분포 차이 KS-test p<0.05
  - 기대 관측치: "고VIX+금리상승" 레짐에서 집중 퇴화 확인

□ EXP-1B: Fold-Aware 앙상블 가중치
  - 정의: 퇴화 폴드 가중치 0.3x, 정상 폴드 1.0x로 OOS 재계산
  - 게이트: oos_mean 변화 < 15% && oos_min > -1.5%
  - 기대 관측치: 분산 축소, mean 소폭 하락 수용

□ EXP-1C: 최소 노출 필터 추가
  - 정의: exposure < 0.05인 날 > 60% 시 폴드 자동 제외
  - 게이트: 유효 폴드 >= 5개 유지
  - 기대 관측치: degenerate 폴드 3개 이하로 감소
```

**PASS 조건:** `degenerate_folds <= 2 AND 유효폴드 >= 6`

### 2️⃣ [CRITICAL] MDD 게이트 복구 및 강제 측정

**왜 필요한지:**
- `worst_mdd: None` = 리스크 제어 없이 비행 중
- 실제 운용 시 -30% MDD 발생해도 탐지 불가

**위험/부작용:**
- MDD 계산 로직 버그 시 전체 파이프라인 중단
- 보수적 MDD 게이트 → 수익 기회 손실

**실험 체크리스트:**

```
□ EXP-2A: MDD 계산 파이프라인 디버그
  - 정의: champion_v5 equity curve에서 수동 MDD 계산 후 비교
  - 게이트: |자동MDD - 수동MDD| < 0.5%
  - 기대 관측치: None 원인 = 빈 equity curve 또는 타입 에러

□ EXP-2B: Rolling MDD 20일 윈도우 추가
  - 정의: worst_mdd 외에 rolling_mdd_20d 지표 추가
  - 게이트: rolling_mdd_20d < 12% (연속 3폴드)
  - 기대 관측치: 단기 급락 조기 탐지
```

**PASS 조건:** `worst_mdd != None AND worst_mdd < 18%`

### 3️⃣ [HIGH] 리밸런스/비용 추적 복구

**왜 필요한지:**
- rebalance.csv 로딩 실패 → 실제 회전율/슬리피지 미반영
- OOS 3.32%가 비용 전인지 후인지 불명

**위험/부작용:**
- 비용 과다 반영 시 모든 전략 사망
- JSON/CSV 포맷 불일치 → 파싱 지속 실패

**실험 체크리스트:**

```
□ EXP-3A: 리밸런스 로그 포맷 통일
  - 정의: rebalance 출력을 JSON Lines(.jsonl)로 강제 통일
  - 게이트: aub_rebalance_pinpoint.py 에러 0건
  - 기대 관측치: 정상 로딩, 회전율 통계 출력

□ EXP-3B: 비용 시나리오 테스트
  - 정의: 슬리피지 0bp/5bp/10bp 3단계로 OOS 재계산
  - 게이트: 10bp에서도 oos_mean > 2.0%
  - 기대 관측치: 비용 민감도 정량화 (현재 미지)

□ EXP-3C: 연간 회전율 상한 설정
  - 정의: turnover > 800%/yr 시 경고 플래그
  - 게이트: 현재 전략 turnover 측정 완료
  - 기대 관측치: 실제 회전율 400-600% 범위 확인
```

**PASS 조건:** `turnover_annual < 700% AND cost_adjusted_oos > 2.5%`

### 4️⃣ [MEDIUM] 노출 범위 정상화 (0.0 ~ 0.84 스프레드)

**왜 필요한지:**
- exposure_min=0.0 = 완전 현금 상태 발생
- 0.0↔0.84 급격한 변동 = 타이밍 의존도 과다

**위험/부작용:**
- 최소 노출 강제 시 하락장 손실 확대
- 노출 스무딩 → 반응 속도 저하

**실험 체크리스트:**

```
□ EXP-4A: 최소 노출 바닥 설정
  - 정의: exposure_floor = 0.15 (항상 15% 이상 투자)
  - 게이트: exposure_min >= 0.15 AND oos_mean 하락 < 0.5%
  - 기대 관측치: 변동성 장에서 안정성 확보

□ EXP-4B: 노출 변화율 제한
  - 정의: |Δexposure| <= 0.20/일 (급격한 변동 방지)
  - 게이트: 일간 노출 변화 분포 95% < 0.20
  - 기대 관측치: 회전율 자동 감소
```

**PASS 조건:** `exposure_min >= 0.10 AND exposure_std < 0.20`

### 5️⃣ [MEDIUM] OOS 분산 축소 (min -2.57% → -1.5% 이상)

**왜 필요한지:**
- oos_mean 3.32%지만 min -2.57% = 분산 과다
- 실제 운용 시 최악 시나리오가 현실화될 확률 존재

**위험/부작용:**
- 분산 축소 과정에서 mean도 같이 하락
- 과도한 헤지 → 수익 잠식

**실험 체크리스트:**

```
□ EXP-5A: Tail-Aware 손실 함수
  - 정의: loss = -mean + 0.5 * (min 폴드 수익률 < -1% 개수)
  - 게이트: oos_min > -1.5% AND oos_mean > 2.8%
  - 기대 관측치: 꼬리 리스크 20% 감소

□ EXP-5B: VIX 기반 동적 헤지
  - 정의: VIX > 25일 때 exposure * 0.7 적용
  - 게이트: 고VIX 기간 MDD 개선 > 3%p
  - 기대 관측치: 폴드 1,2,3,8 손실 완화
```

**PASS 조건:** `oos_min > -1.5% AND oos_mean > 2.5%`

## 48시간 자동 루프 형식

```yaml
# autopilot_20260103.yaml
experiments:
  - id: EXP-1A
    cmd: python3 tools/fold_regime_analyzer.py --folds 1,2,3,8
    gate: "ks_pvalue < 0.05"
    expect: "regime_diff_detected: true"
    timeout: 2h

  - id: EXP-2A  
    cmd: python3 tools/mdd_debug.py --champion champion_v5_latest.json
    gate: "mdd_value != None"
    expect: "worst_mdd in range [0.10, 0.25]"
    timeout: 30m

  - id: EXP-3A
    cmd: python3 tools/rebalance_format_fix.py --output jsonl
    gate: "parse_errors == 0"
    expect: "turnover_annual < 800"
    timeout: 1h

  - id: EXP-4A
    cmd: python3 backtest.py --exposure-floor 0.15
    gate: "exposure_min >= 0.15 AND oos_delta > -0.5"
    expect: "stability_score > 0.7"
    timeout: 4h

  - id: EXP-5A
    cmd: python3 backtest.py --loss tail_aware --tail-weight 0.5
    gate: "oos_min > -0.015 AND oos_mean > 0.025"
    expect: "tail_risk_reduction > 0.15"
    timeout: 4h

sequence: [EXP-2A, EXP-3A, EXP-1A, EXP-4A, EXP-5A]  # 의존성 순서
abort_on_fail: [EXP-2A, EXP-3A]  # 이것들 실패 시 전체 중단
```
