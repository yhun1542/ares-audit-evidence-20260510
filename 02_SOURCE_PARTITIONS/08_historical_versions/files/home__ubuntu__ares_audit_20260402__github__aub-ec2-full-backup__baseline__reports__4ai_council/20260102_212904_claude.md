## 1. 우선순위 TOP 5 액션

### P0. 관측 파이프라인 복구 (BLOCKER)

**(a) 왜 필요한지**
- `worst_mdd: None` → 리스크 게이트 작동 불가
- rebalance.csv 파싱 실패 → 포지션 변화 추적 불가
- 2개 OOS Mean 값 불일치 → 어떤 게 진실인지 모름

**(b) 위험/부작용**
- 복구 중 기존 아티팩트 덮어쓰기 → 백업 필수
- 포맷 변경 시 downstream 스크립트 전부 깨짐

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P0-1 | `aub_handoff.py`에서 MDD 계산 로직 단위테스트 | MDD ≠ None | float 반환 |
| P0-2 | rebalance 출력을 JSON → JSONL 통일, 스키마 검증 추가 | 파싱 성공률 100% | pinpoint 리포트 정상 생성 |
| P0-3 | OOS Mean 계산 지점 2곳 diff → 단일 소스화 | 값 일치 | delta < 0.01 |

**(d) PASS 조건**
```
✅ worst_mdd: float (not None)
✅ rebalance_pinpoint.md 정상 생성
✅ handoff OOS == diagnoser OOS (±0.01)
```

### P1. Degenerate Fold 원인 분리

**(a) 왜 필요한지**
- 4/10 fold 퇴화 = 전략이 **40% 시장 레짐에서 무력화**
- 과최적화 가능성 높음 (생존 fold만 보고 있음)

**(b) 위험/부작용**
- fold별 분석 시 case explosion → 대표 fold 2개로 제한
- 레짐 라벨링 주관적 → 사후 해석 편향

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P1-1 | Fold 1,3 (연속 퇴화) 구간 SPY/QQQ 레짐 라벨링 (bull/bear/chop) | - | 레짐 태그 |
| P1-2 | 퇴화 fold에서 시그널 firing rate 측정 | rate > 5% | 시그널 자체는 발생하는지 |
| P1-3 | 퇴화 fold only로 파라미터 re-fit → OOS 비교 | OOS > 0 | 해당 레짐 대응 가능 여부 |

**(d) PASS 조건**
```
✅ 퇴화 원인 분류: {시그널 미발생 | 시그널 역행 | 비용 초과}
✅ 최소 1개 fold에서 개선안 도출
```

### P2. Exposure 0% 구간 감사

**(a) 왜 필요한지**
- `exposure_min: 0.0` = 완전 현금 구간 존재
- 의도적 회피인지 버그인지 구분 필요
- 현금 구간이 드로우다운 회피에 기여했다면 → 진짜 알파
- 버그라면 → 누락 수익

**(b) 위험/부작용**
- 현금 구간 제거 시 MDD 급증 가능

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P2-1 | exposure=0 날짜 리스트 추출 + SPY 수익률 overlay | - | 현금이 회피한 날의 SPY 방향 |
| P2-2 | 강제 min_exposure=0.1 적용 후 OOS 비교 | OOS delta | 현금 가치 정량화 |

**(d) PASS 조건**
```
✅ exposure=0 구간 중 SPY 하락일 비율 > 60% → 의도적 회피로 인정
✅ 아니면 min_exposure 도입 검토
```

**(a) 왜 필요한지**

- 과도한 비용 가정 → 유효 전략도 기각

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |

**(d) PASS 조건**
```

✅ 비용 파라미터 config에 명시적 기록
```

## 2. 성능 미변동 시 원인 분해 트리

```
성능 안 움직임
│
├─ [1] 트리거 미발생
│   └─ 시그널 firing rate < 1%? → 조건 완화 필요
│
├─ [2] 트리거 발생 but 적용 안 됨
│   └─ 포지션 사이징 0으로 수렴? → scaler/risk 로직 점검
│
├─ [3] 적용됐지만 노출 미미
│   └─ max_exposure cap 너무 낮음? → 0.84 상한 검토
│
├─ [4] 노출됐지만 비용에 먹힘
│   └─ 회전율 과다? → holding period 연장 실험
│
└─ [5] 비용 후에도 수익 but 레짐 상쇄
    └─ 롱/숏 레짐 반대로 작동? → 레짐별 분리 OOS
```
