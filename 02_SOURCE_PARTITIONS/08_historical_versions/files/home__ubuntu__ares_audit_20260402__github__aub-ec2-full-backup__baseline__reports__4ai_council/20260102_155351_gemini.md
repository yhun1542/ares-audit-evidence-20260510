### 3. 성능 정체(Flat) 시 원인 분해 트리거

성능이 1.88 ~ 2.62 구간에서 횡보하거나 움직이지 않을 때 다음 순서로 점검하라.

1.  **트리거(Signal) 점검**:
    *   *Check*: 예측 스코어(Alpha)의 표준편차가 너무 낮은가? (0에 수렴하면 포지션 변경 없음)
    *   *Action*: 예측 모델의 Softmax Temperature를 높이거나, Rank Threshold를 좁힘.

2.  **적용(Allocation) 점검**:
    *   *Check*: 최적화(Optimizer)가 `Min Exposure 0.47` 제약 때문에 나쁜 주식도 강제로 사고 있는가?
    *   *Action*: Hard Constraint(0.47)를 Soft Constraint(Penalty)로 변경 테스트.

3.  **비용(Cost) 점검**:
    *   *Check*: 건당 기대 수익(Avg Profit per Trade)이 15bps(0.15%) 미만인가?
    *   *Action*: 슬리피지/수수료 고려 시 사실상 손실. 진입 장벽(Threshold) 상향.

4.  **레짐(Regime) 불일치**:
    *   *Check*: 최근 3개월 데이터가 훈련 데이터(Train) 분포와 완전히 다른가? (Covariate Shift)
    *   *Action*: 최근 6개월 데이터 가중치(Decay)를 높여 재학습(Retrain).

5.  **노출(Exposure) 누수**:
    *   *Check*: ETF 매매 제외 규칙에도 불구하고, 상관관계가 0.99인 개별주(예: 3배 레버리지 대용)를 담고 있는가?
    *   *Action*: 블랙리스트 업데이트.
