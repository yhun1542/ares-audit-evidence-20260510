## 1. 우선순위 TOP 5 (48h 실행 체크리스트)

### ☑️ P0. 인프라 버그 수정 (BLOCKER)

**(a) 필요성**
- MDD=None → 리스크 게이트 무력화
- rebalance.csv 파싱 실패 → 거래비용/슬리피지 미반영
- **현재 OOS 수치 자체가 신뢰 불가**

**(b) 위험/부작용**
- 수정 후 OOS가 급락할 가능성 (숨겨진 비용 노출)
- 챔피언 교체 필요할 수 있음

**(c) 실험 정의**

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P0-1 | `calculate_mdd()` 함수에 빈 리턴 케이스 추가 + 단위테스트 | MDD 값 != None | worst_mdd ∈ [-0.5, -0.05] |
| P0-2 | rebalance 로그를 JSON→CSV 듀얼 출력 | 파일 존재 & row_count > 0 | 최소 60일치 리밸런스 기록 |
| P0-3 | 비용 반영 백테스트 재실행 | OOS 재계산 완료 | OOS_new vs OOS_old delta 기록 |

**(d) PASS 조건**
```
worst_mdd != None AND 
rebalance_log.rows >= 60 AND
cost_reflected == True
```

## 2. 성능 미변동 시 원인 분해 트리

```
OOS 변화 없음
│
├─[1] 트리거 미발동
│   └─ 시그널 임계값 너무 높음 → exposure 로그 확인
│
├─[2] 포지션 적용 실패  
│   └─ 코드 버그/조건 충돌 → rebalance 로그 row 수 확인
│
├─[3] 노출 상쇄
│   └─ 롱/숏 헤지가 서로 상쇄 → net_exposure 분포 확인
│
├─[4] 비용 잠식
│   └─ 총수익 ≈ 거래비용 → turnover × cost 계산
│
└─[5] 레짐 불일치
    └─ 실험 기간이 특정 레짐에 편중 → VIX/금리 overlay 확인
```
