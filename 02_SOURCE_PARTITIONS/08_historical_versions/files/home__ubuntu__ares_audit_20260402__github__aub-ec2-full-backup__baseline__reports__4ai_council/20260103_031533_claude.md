## 성능 무변동 시 원인 분해 트리

```
성능 Δ ≈ 0
│
├─▶ [트리거 실패] 시그널이 발생 안 함
│   └─ 체크: 시그널 firing rate (일평균 몇 회?)
│
├─▶ [적용 실패] 시그널 → 주문 변환 안 됨
│   └─ 체크: rebalance 로그에 order 기록 있는지
│
├─▶ [노출 부족] 포지션 사이즈 너무 작음
│   └─ 체크: avg_exposure, position_concentration
│
├─▶ [비용 상쇄] 수익 < 슬리피지+수수료
│   └─ 체크: gross_return vs net_return 차이
│
└─▶ [레짐 불일치] 훈련 레짐 ≠ 테스트 레짐
    └─ 체크: 퇴화 폴드 시점 vs 시장 레짐 매핑
```
