### 4. 성능 정체 원인 분해 (Diagnosis Tree)

만약 위 조치 후에도 성능이 제자리라면 다음 트리거를 점검:

1.  **트리거 (Trigger)**:
    *   *Issue*: Alpha Signal의 변별력 상실.
    *   *Check*: 상위 Score 종목의 익일 수익률(IC)이 0에 수렴하는지 확인.
2.  **적용 (Application/Optimizer)**:
    *   *Issue*: 최적화 솔버(Solver)가 해를 찾지 못해 이전 포지션 유지 or 전량 매도 처리.
    *   *Check*: Solver Status Log 확인 (Optimal vs Infeasible).
3.  **노출 (Exposure)**:
    *   *Issue*: 리스크 모델(Covariance Matrix)이 시장 변동성을 과대평가하여 포지션 축소 강제.
    *   *Check*: VIX 지수와 Exposure 역상관 관계 확인.
4.  **레짐 (Regime)**:
    *   *Issue*: 금리 인상기(Fold 1,2 등)에 Tech/Bio가 전멸하는 구간.
    *   *Check*: 벤치마크(QQQ/XLV) 대비 Alpha가 존재하는지, 아니면 단순 Beta 추종 실패인지 확인.
