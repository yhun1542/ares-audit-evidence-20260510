### 2. 성능 정체 시 원인 분해 (Debugging Tree)

수익률이나 MDD 지표가 개선되지 않고 제자리걸음일 때, 다음 순서로 점검하라.

1.  **Trigger (신호 발생):**
    *   **증상:** 거래 횟수가 0이거나 매우 적음.
    *   **Action:** 필터 조건(RSI, 이평선 등)을 완화해본다. 유니버스 내 종목들이 필터에 모두 걸리고 있을 수 있음.
2.  **Application (사이징/자금 관리):**
    *   **증상:** 승률은 높은데 총 수익이 낮음.
    *   **Action:** 포지션 사이징이 너무 보수적인지 확인 (예: 전체 자산의 10%만 사용 중인지). 변동성 역가중 로직이 너무 작은 비중을 할당하는지 체크.
3.  **Exposure (상관관계):**
    *   **증상:** 시장 하락 시 모든 종목이 같이 손실 (MDD 급증).
    *   **Action:** Tech와 Healthcare가 동시에 무너지는 구간인지 확인. 이 경우 현금 비중(Cash buffering) 로직을 강화해야 함.
4.  **Cost (비용 민감도):**
    *   **증상:** Gross Profit은 우상향인데 Net Profit은 횡보/하락.
    *   **Action:** 평균 이익(Avg Profit per Trade)이 슬리피지보다 큰지 확인. 작다면 전략 폐기 또는 타임프레임 확장 필요.
5.  **Regime (시장 국면):**
    *   **증상:** 특정 연도/분기에는 잘 맞고, 다른 구간엔 전멸.
    *   **Action:** 현재 Champion 로직이 '상승장 전용'인지 확인. 하락장(2022년 등)에서의 성과만 분리해서 볼 것.
