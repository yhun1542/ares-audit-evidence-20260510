## 2. 성능 미변동 시 원인 분해 트리

```
OOS Mean 변화 없음
│
├─ [트리거] 시그널 발생 횟수 동일한가?
│   └─ YES → 파라미터가 시그널 생성에 영향 없음 (잘못된 레이어 수정)
│   └─ NO  → 다음 단계
│
├─ [적용] 시그널 → 포지션 전환 비율?
│   └─ 낮음 → 필터/리스크 게이트가 block
│   └─ 높음 → 다음 단계
│
├─ [노출] 평균 포지션 크기 변화?
│   └─ 없음 → sizing 로직 미영향
│   └─ 있음 → 다음 단계
│
├─ [비용] 거래 횟수 × 비용 변화?
│   └─ 상쇄 → 수익 증가분이 비용으로 소멸
│
└─ [레짐] OOS 기간 시장 상태?
    └─ 2022-type drawdown → 전략 한계 (개선 여지 제한)
```
