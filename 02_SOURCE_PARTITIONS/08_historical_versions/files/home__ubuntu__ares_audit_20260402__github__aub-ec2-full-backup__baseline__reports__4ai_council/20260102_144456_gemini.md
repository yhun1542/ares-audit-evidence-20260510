[성능 정체 시 원인 분해 (Diagnosis Logic)]

성능(OOS Mean)이 개선되지 않거나 횡보할 경우 다음 순서로 점검하십시오:

1.  **트리거(Trigger) 불발:**
    *   *체크:* Top 8~14 랭킹이 매일 고착화되어 있는가? (교체 매매가 안 일어남)
    *   *액션:* 랭킹 스코어의 표준편차(std)를 확인. 스코어 차이가 너무 미미하면 교체가 안 일어남. Score Scaling 강화.

2.  **노출(Exposure) 제약:**
    *   *체크:* `exposure_max`가 0.84인데 실제로 0.84를 채우는 날이 며칠인가?
    *   *액션:* 리스크 관리 모듈(Volatility Targeting 등)이 너무 보수적으로 포지션 사이즈를 줄이고 있는지 확인.

3.  **비용(Cost) 잠식:**
    *   *체크:* Gross Profit은 우상향이나 Net Profit이 횡보하는가?
    *   *액션:* 회전율(Turnover) 강제 제한 (예: 보유 기간 최소 3일).

4.  **레짐(Regime) 불일치:**
    *   *체크:* 벤치마크(QQQ/XLV) 상승 구간에서 모델이 Short/Cash 비중을 늘리는가?
    *   *액션:* ETF(XLK, XLV)의 200일 이평선 위에서는 `Long Only` 또는 `Min Exposure 0.8` 강제.

5.  **Data Quality (Survivor Bias):**
    *   *체크:* 상장폐지되거나 인수합병된 종목이 유니버스에 포함되어 수익을 왜곡하는가?
    *   *액션:* `tradable_universe` 필터에 `IsActive` 및 `Volume > $10M` 조건 강화.
