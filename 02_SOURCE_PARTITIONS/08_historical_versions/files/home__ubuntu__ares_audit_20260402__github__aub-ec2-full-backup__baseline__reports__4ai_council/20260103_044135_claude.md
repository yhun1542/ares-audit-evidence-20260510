### P1. Degenerate Fold 원인 분리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한가**
- 4/8 폴드 퇴화 = **50% 구간에서 시그널 무효**
- IS 과최적화 또는 레짐 불일치 강력 시사

**(b) 위험/부작용**
- 퇴화 폴드 제거 시 survivorship bias
- 폴드 재정의 시 전체 백테스트 재실행 필요

**(c) 최소 실험**

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 1-1 | 퇴화 폴드(1,2,3,8) 기간 추출 → VIX/SPY regime 매핑 | - | 공통 패턴 식별 (예: VIX>25) |
| 1-2 | 퇴화 폴드 IS vs OOS 수익 분포 비교 | IS Sharpe > 2 & OOS < 0 | 과적합 증거 |
| 1-3 | 정상 폴드(4,5,6,7)만으로 앙상블 재구성 | OOS mean ≥ 2.5 유지 | 4-fold stability |

**(d) PASS 조건**
```
□ 퇴화 원인 1개 이상 문서화 (regime / overfitting / data issue)
□ 4-fold 앙상블 OOS ≥ 2.0
□ 정상 폴드 간 상관 < 0.7
```

## 🔍 성능 미변동 시 원인 분해 트리

```
성능 Delta = 0 일 때 체크 순서:

1. [트리거 실패]
   └─ 시그널이 발생했는가?
      └─ signal_count == 0 → 조건 너무 strict
      
2. [적용 실패]  
   └─ 시그널 → 주문 전환되었는가?
      └─ order_count == 0 → 필터/리스크 체크에서 block
      
3. [노출 부족]
   └─ 포지션 보유 시간이 충분한가?
      └─ exposure_mean < 0.2 → 조기 청산 or 드문 진입
      
4. [비용 상쇄]
   └─ 수익 > 비용인가?
      └─ gross_return > 0, net_return ≈ 0 → 비용 과다
      
5. [레짐 불일치]
   └─ 해당 기간 시장 상태가 전략과 맞는가?
      └─ VIX regime 불일치 → 레짐 필터 추가 고려
```
