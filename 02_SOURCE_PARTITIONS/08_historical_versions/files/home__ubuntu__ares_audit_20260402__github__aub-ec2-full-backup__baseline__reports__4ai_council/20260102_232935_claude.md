## 1. 우선순위 TOP-5 체크리스트

### P1. 🔧 Degenerate Fold 원인 규명 (INFRA)

**왜 필요한지**
- 4/10 폴드가 퇴화 → OOS 평균이 나머지 6개에만 의존
- 서바이버십 바이어스: "잘 작동하는 폴드만" 결과에 반영
- 실제 라이브에서 해당 기간 진입 시 전략 무력화

**위험/부작용**
- 수정 후 OOS Mean 급락 가능 (진짜 성능 노출)
- 폴드 정의 변경 시 전체 백테스트 무효화

**최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P1-A | 퇴화 폴드 [1,2,3,8] 구간의 시장 레짐 분류 (VIX, SPY drawdown) | 로그 생성 완료 | 4개 폴드 모두 특정 레짐(예: VIX>25) 해당 여부 |
| P1-B | 퇴화 정의 기준 검토: exposure=0 연속일 > N일 vs 수익=0 | 기준 명문화 | 퇴화 판정 폴드 수 변화 |
| P1-C | 폴드별 signal 생성 로그 추가 → 신호 자체가 0인지 vs 필터에서 제거인지 | 로그 파싱 성공 | 원인 분류표 생성 |

**PASS 조건**
```
✅ 퇴화 원인 3가지 이상 식별 & 문서화
✅ 비퇴화 폴드 수 ≥ 8/10 달성 가능한 수정안 도출
```

### P2. 🔧 MDD 측정 파이프라인 복구 (INFRA)

**왜 필요한지**
- worst_mdd = None → 리스크 관리 지표 부재
- 운영 중 -15% 낙폭 발생해도 사전 인지 불가
- 백테스트 대비 실전 괴리의 핵심 원인

**위험/부작용**
- MDD 측정 시 champion 탈락 가능
- 계산 방식(일간/분간, 종가/고저가) 따라 값 2배 차이

**최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P2-A | equity curve에서 rolling peak 대비 drawdown 계산 로직 추가 | 코드 커밋 | worst_mdd 숫자 출력 |
| P2-B | 폴드별 MDD 분포 출력 | JSON 스키마 확장 | mdd_per_fold: [f1, f2, ...] |

**PASS 조건**
```
✅ worst_mdd ≠ None
✅ 모든 폴드에서 mdd < -25% (절대 게이트)
```

### P3. 🔧 Rebalance 로그 파싱 에러 해결 (INFRA)

**왜 필요한지**

- 비용(슬리피지, 수수료) 반영 여부 검증 불가

**위험/부작용**
- 로그 포맷 변경 시 기존 분석 스크립트 호환성 깨짐

**최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P3-A | champion 실행 시 rebalance.jsonl 강제 출력 플래그 추가 | 파일 존재 | rows > 0 |
| P3-B | aub_rebalance_pinpoint.py 에러 핸들링 개선 (파일 없음 vs 파싱 실패 분리) | 에러 메시지 명확화 | 원인별 exit code |

**PASS 조건**
```
✅ rebalance 로그 100% 파싱 성공

```

**위험/부작용**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P5-A | exposure=0 구간의 시장 수익률 계산 (놓친 수익 vs 피한 손실) | 리포트 | opportunity_cost, avoided_loss |
| P5-B | exposure 하한 10% 강제 실험 | OOS 재계산 | OOS mean 변화, MDD 변화 |

## 2. 성능 불변 시 원인 분해 트리

```
성능 안 움직임
│
├─ [트리거] 신호 자체가 생성 안 됨
│   ├─ 데이터 누락/지연
│   ├─ feature 계산 오류 (NaN 전파)
│   └─ 신호 임계값 도달 빈도 < 1%
│
├─ [적용] 신호 생성 → 포지션 미반영
│   ├─ 리스크 필터에서 전부 제거
│   ├─ rebalance 주기 불일치
│   └─ 최소 거래 단위 미충족
│
├─ [노출] 포지션 진입 → 시장 움직임 무관
│   ├─ 진입 후 즉시 청산 (holding < 1일)
│   ├─ 포지션 크기 미미 (weight < 1%)
│   └─ 롱/숏 상계로 순노출 ≈ 0
│
├─ [비용] 수익 발생 → 비용이 상쇄
│   ├─ 슬리피지 과소 추정
│   ├─ 수수료 미반영
│   └─ 세금/환전 비용
│
└─ [레짐] 특정 시장 구간만 작동
    ├─ 백테스트 기간 = 강세장 편중
    ├─ 변동성 레짐 불일치
    └─ 섹터 로테이션 미반영
```
