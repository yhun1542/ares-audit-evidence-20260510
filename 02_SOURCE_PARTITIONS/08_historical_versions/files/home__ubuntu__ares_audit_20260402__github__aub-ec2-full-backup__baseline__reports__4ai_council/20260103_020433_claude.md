## 📋 TOP 5 우선순위 (명령형 체크리스트)

### P1. OOS Mean 불일치 원인 규명 (데이터 누수 점검)
```
왜: 3.32 vs 2.63 = 26% 괴리 → 누수 또는 측정 버그 확정 필요
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| L1 | `--no-future` 플래그로 전체 재실행 | 완료 | OOS가 2.6 근처면 누수 확정 |
| L2 | fold별 학습/테스트 날짜 범위 덤프 | 완료 | 겹침 0일 확인 |
| L3 | feature timestamp vs target timestamp 교차검증 | 완료 | future_leak_count == 0 |

**PASS 조건:** `abs(rerun_oos - 2.63) < 0.1` AND `overlap_days == 0`

**위험:** 누수 확정 시 현재 champion 무효화 → 전략 재설계 필요

---

### P2. Degenerate Fold 원인 분석 (4/10 = 40%)
```
왜: fold 1,2,3,8 실패 → 특정 regime에서 전략 붕괴 또는 데이터 불균형
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| D1 | 각 fold의 날짜 범위 + VIX 평균 출력 | 완료 | regime 패턴 식별 |
| D2 | degenerate fold에서 exposure=0 비율 측정 | 완료 | >80%면 신호 미생성 확정 |
| D3 | threshold 0.5 → 0.3 완화 후 재측정 | OOS 저하 <15% | degenerate→2개 이하 |

**PASS 조건:** `degenerate_folds <= 2` AND `oos_mean >= 2.2`

**위험:** threshold 완화 시 노이즈 트레이드 증가 → 비용 악화

---

### P3. 비용/슬리피지 반영 검증
```
왜: rebalance.csv 파싱 실패 → 현재 수익이 gross인지 net인지 불명
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| C1 | rebalance 로그 경로 수정 및 재생성 | 파일 생성 | JSON lines 정상 파싱 |
| C2 | turnover 계산: `sum(abs(delta_weight))/periods` | 완료 | 연간 turnover 값 |
| C3 | `cost = turnover * 0.001` 차감 후 OOS 재계산 | 완료 | net_oos 값 |

**PASS 조건:** `net_oos >= gross_oos * 0.85` (비용 15% 이내)

**위험:** 실제 비용 반영 시 전략 수익성 소멸 가능

---

### P4. MDD 측정 파이프라인 복구
```
왜: worst_mdd=None → 리스크 관리 불가, 실전 배포 블로커
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| M1 | equity curve 생성 코드 디버그 | 완료 | daily_equity.csv 생성 |
| M2 | rolling MDD 계산 추가 | 완료 | worst_mdd 숫자 반환 |
| M3 | MDD > 25% fold 식별 | 완료 | 해당 fold 리스트 |

**PASS 조건:** `worst_mdd != None` AND `worst_mdd <= 0.30`

**위험:** MDD 측정 시 degenerate fold와 중복 가능 (같은 원인)

---

### P5. Exposure 상한 점검 (0.84 = 84%)
```
왜: max_exposure 84%는 양호하나 min=0% → 장기 현금 구간 존재
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| E1 | exposure=0 구간 날짜 + 기간 출력 | 완료 | 현금 구간 리스트 |
| E2 | 해당 구간 SPY 수익률 계산 | 완료 | 기회비용 측정 |
| E3 | min_exposure=0.2 강제 후 재실행 | OOS 비교 | delta 값 |

**PASS 조건:** `opportunity_cost <= 0.5%/month` OR `forced_exposure 개선`

**위험:** 강제 노출 시 하락장 손실 확대

```yaml

max_iterations: 8

  - name: "P1_leak_check"

    cmd: "python3 tools/mdd_calculator.py --output reports/"
    gate: "worst_mdd != None"
    on_fail: "DEBUG_equity_curve"
    
  - name: "P5_exposure_audit"
    cmd: "python3 tools/exposure_analyzer.py --min-check 0.2"
    gate: "zero_exposure_days <= 30"
```
