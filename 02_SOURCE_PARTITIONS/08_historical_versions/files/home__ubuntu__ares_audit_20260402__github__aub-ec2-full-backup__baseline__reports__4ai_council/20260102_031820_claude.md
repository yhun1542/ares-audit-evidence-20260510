## 1. 우선순위 TOP-5 제안

### 🔴 P1. Lockbox-Tuning Gap 축소 (Gap = 0.59 → 목표 < 0.3)

**(a) 왜 필요한가**
- Champion: tuning_mean 3.47 vs lockbox_mean 2.89 → **17% 성능 감소**
- 과최적화 신호. Lockbox가 더 떨어지면 실전은 더 나쁨

**(b) 위험/부작용**
- 정규화 과도 시 tuning도 동반 하락 → 전체 수익률 저하
- 파라미터 수 축소 시 표현력 손실

**(c) 최소 실험**

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| P1-E1 | L2 regularization λ=0.01 → 0.05 | lockbox_mean ≥ 2.8 | gap < 0.4 |
| P1-E2 | Feature 수 30% 축소 (importance 하위 제거) | tuning_mean ≥ 3.0 | gap < 0.35 |
| P1-E3 | Ensemble weight decay 0.1 적용 | worst_mdd 유지 | gap < 0.3 |

**(d) PASS 조건**
```
lockbox_mean ≥ 2.8 AND (tuning_mean - lockbox_mean) < 0.3
```
