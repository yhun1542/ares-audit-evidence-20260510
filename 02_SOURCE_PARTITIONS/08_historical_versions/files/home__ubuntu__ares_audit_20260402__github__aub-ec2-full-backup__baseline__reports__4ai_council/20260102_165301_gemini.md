[우선순위 분석]
현재 상태는 **'수치상 고성능이나 신뢰할 수 없는 상태(Blind Flying)'**입니다. `worst_mdd: None`과 `degenerate_folds: [1, 2, 3, 8]`(절반 가까운 폴드 파산/계산불가)은 치명적 버그이며, 로그 파일 로딩 실패는 비용 분석을 불가능하게 합니다. 알파 탐색보다 **시스템 정상화 및 리스크 현실화**가 최우선입니다.

### 1. [Critical Fix] Rebalance Logger 포맷 일치 및 MDD 계산 복구
**(a) 필요성:** 리밸런싱 로그(`csv` vs `jsonl` 불일치) 파싱 에러로 인해 턴오버/슬리피지 비용이 전혀 반영되지 않았을 가능성 높음. `worst_mdd: None`은 리스크 관리 모듈이 작동하지 않음을 의미.
**(b) 위험:** MDD가 정상 계산되면 현재의 높은 `oos_mean`이 실제로는 '파산' 상태로 판명될 수 있음(Sharpe 급락).
**(c) 실험 (Patch):**
1.  **EXP-01-LOG-FIX:** `experiment_system` 내 로거를 강제로 `jsonl`로 통일하고, `None` 값 처리 로직에 `fillna(0)` 또는 예외처리 추가.
2.  **EXP-01-MDD-RECALC:** 수익률 시계열에 `NaN`이 포함된 경우 0으로 치환 후 MDD 재계산 로직 배포.
**(d) PASS 조건:** `rebalance_pinpoint.py` 정상 실행 && `worst_mdd`가 수치(예: -0.15)로 출력됨.

### 2. [Logic] Tech/Healthcare 섹터 변동성 기반 노출(Exposure) 동적 조절
**(a) 필요성:** Degenerate Folds(1,2,3,8)는 특정 시장 충격 구간(Tech bubble burst 등)에서 전략이 전멸함을 시사. 개별 종목이 아닌 섹터 ETF(XLK, XLV)를 관측 지표로 사용하여 시스템 전체 노출을 제어해야 함.
**(b) 위험:** 상승장에서 조기 매도로 인한 수익률(Upside) 제한.
**(c) 실험 (Patch):**
1.  **EXP-02-VOL-TARGET:** XLK 또는 XLV의 20일 역사적 변동성(HV)이 상위 80% 위일 때, 전체 포트폴리오 Max Exposure를 0.84 → 0.50으로 축소.
2.  **EXP-02-CORR-CUT:** 포트폴리오 내 헬스케어 비중이 Tech와 상관계수 0.7 이상일 때, 헬스케어 비중 강제 축소 (Decorrelation 강제).
**(d) PASS 조건:** Degenerate Folds 개수가 4개 → 1개 이하로 감소 && OOS Mean 2.0 이상 유지.

### 3. [Universe] 유동성/비용 필터 강화 (Survivorship/Cost 방지)
**(a) 필요성:** 2026년 시점 시뮬레이션 중. 소형 바이오/테크주의 상장폐지나 유동성 부족이 반영되지 않았을 확률 높음. 8~14개 종목 집중 투자 시 1개 종목 사고가 치명적.
**(b) 위험:** 유니버스 축소로 인한 기회비용 발생, 알파 시그널 희석.
**(c) 실험 (Patch):**
1.  **EXP-03-LIQ-STRESS:** 슬리피지 비용 가정치를 현재의 3배(예: 5bps → 15bps)로 설정하여 백테스트 수행.
2.  **EXP-03-MIN-PRICE:** $10 미만 주식 거래 금지 및 일평균거래대금(ADTV) 하위 20% 컷오프 적용.
**(d) PASS 조건:** 비용 3배 적용 후에도 OOS Sharpe > 1.0 유지.

### 48시간 자동 루프 정의

#### (1) 실험 정의 (Experiment Definition)
*   **Target:** `run_champion_v5` 기반 브랜치 생성.
*   **Params:**
    *   `force_jsonl_logging`: True
    *   `mdd_calculation_safe_mode`: True
    *   `regime_indicator`: ["XLK", "XLV"]
    *   `max_sector_vol_threshold`: 0.025 (Daily)
    *   `exposure_limit_on_vol`: 0.5

#### (2) 게이트 (Gate - 48h Check)
1.  **Integrity Gate:** `rebalance_pinpoint.md` 파일이 생성되고 파일 크기가 1KB 이상인가? (Yes/No)
2.  **Risk Gate:** `worst_mdd` is not None AND `worst_mdd` > -0.30 (-30% 이하 손실 방어).
3.  **Performance Gate:** `degenerate_folds` 리스트 길이가 2 이하인가?

#### (3) 기대 관측치 (Expected Observation)
*   **관측 1:** 수정 후 `oos_mean`은 3.32에서 1.8~2.2 수준으로 **하락**할 것임 (비용 및 리스크 현실화).
*   **관측 2:** `degenerate_folds`가 사라지거나 특정 구간(2022년 등)으로 한정됨.
*   **관측 3:** 리밸런싱 로그에서 헬스케어/테크 간 교체 매매 빈도(Turnover)가 급증하는지 확인 (과최적화 징후).

### 성능 정체(Stagnation) 시 원인 분해 아이디어

성능 지표가 움직이지 않을 경우, 다음 순서로 코드를 점검하십시오:

1.  **트리거(Trigger) 불발:**
    *   시장 국면(Regime) 필터(XLK/XLV 변동성)가 너무 느슨하여(threshold high) 작동한 적이 없는가?
    *   *Check:* `regime_signal` 시계열 데이터의 0/1 변화율 확인.
2.  **적용(Apply) 실패:**
    *   최적화 엔진(Optimizer)의 `min_weight`/`max_weight` 제약조건이 너무 강력하여, 알파 시그널이 포트폴리오 비중 변화로 연결되지 못하는가? (Hard constraint 충돌)
    *   *Check:* 최적화 솔버의 `status` 로그(Infeasible 등) 확인.
3.  **노출(Exposure) 상쇄:**
    *   Tech Long / Healthcare Short가 동시에 발생하여 Net Exposure가 의도치 않게 중립화되는가?
    *   *Check:* Gross Exposure 대비 Net Exposure 비율 확인.
4.  **비용(Cost) 잠식:**
    *   알파 수익이 거래 비용(슬리피지)과 정확히 1:1로 상쇄되고 있는가?
    *   *Check:* Gross Return과 Net Return의 괴리율(Spread) 시계열 분석.
