### PATCH-1: Fold Concentration Breaker
```
┌─────────────────────────────────────────────────────┐
│ WHY: fold14_mdd가 champion/candidate 동일 = 해당   │
│      폴드에 overfitting, 다른 폴드 무시 가능성     │
└─────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | lockbox_min이 -0.053으로 고정 → 특정 레짐(폴드)만 최적화됨 |
| **(b) 위험** | 분산 강제 시 mean 하락 가능, 신호 희석 |
| **(c) 실험** | |

```yaml
EXP-1A:
  정의: fold별 MDD variance 페널티 추가 (σ_mdd < 0.02 강제)
  게이트: tuning_mean ≥ 1.065 AND fold_mdd_std < 0.02
  기대: lockbox_min 개선 -0.04 이상

EXP-1B:
  정의: worst 3 folds 가중치 2x로 loss 재계산
  게이트: worst_mdd ≥ -0.08 유지
  기대: fold간 편차 30% 감소
```

| **(d) PASS** | `fold_mdd_std < 0.015` AND `lockbox_mean ≥ 1.32` |

## 2. 48h 자동 루프 형식

```bash
# === CYCLE START ===
for PATCH in 1A 1B 2A 2B 3A 3B 4A 4B 5A 5B; do
  
  # (1) 실험 실행
  python3 run_experiment.py --exp $PATCH --output results/${PATCH}.json
  
  # (2) 게이트 체크
  python3 gate_check.py --result results/${PATCH}.json --spec gates/${PATCH}.yaml
  
  # (3) 관측치 기록
  python3 log_observation.py --exp $PATCH >> observations.log
  
done
# === CYCLE END ===
```

## 3. 성능 미이동 시 원인 분해 트리

```
성능 Δ < 1%
    │
    ├─► [트리거] 신호 자체가 발생 안 함?
    │       └─ 체크: daily_signal_count, active_days_ratio
    │
    ├─► [적용] 신호 → 포지션 전환 실패?
    │       └─ 체크: signal_to_trade_lag, execution_fill_rate
    │
    ├─► [노출] 포지션 있으나 시장과 무상관?
    │       └─ 체크: beta_to_SPY, sector_exposure_drift
    │
    ├─► [비용] 수익 있으나 비용이 상쇄?
    │       └─ 체크: gross_vs_net_return, turnover_spike
    │
    └─► [레짐] 현재 시장이 전략 무효 구간?
            └─ 체크: VIX_regime, correlation_regime, trend_strength
```
