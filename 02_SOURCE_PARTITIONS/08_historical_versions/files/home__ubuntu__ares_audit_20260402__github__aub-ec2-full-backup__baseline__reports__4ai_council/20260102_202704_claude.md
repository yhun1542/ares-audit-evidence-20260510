## 1. 우선순위 TOP 5 PATCHES

### PATCH-1: Tuning 음수 Fold 격리 및 원인 분해

**WHY**
- Champion tuning_min = -0.026 → 최소 1개 fold에서 손실
- 해당 fold가 특정 레짐(금리급등/VIX스파이크)일 가능성
- 이 fold에서 어떤 종목/시그널이 실패했는지 모르면 lockbox 신뢰 불가

**위험/부작용**
- Fold 특화 패치 시 다른 fold 성능 저하 가능
- 분석 시간 소모 (자동화 안 되어 있으면)

**최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 1a | `--audit-fold` 플래그로 음수 fold 식별, 해당 구간 시장 레짐 태깅 | 자동완료 | fold_id, 날짜범위, VIX/금리 상태 |
| 1b | 해당 fold에서 loss 기여 상위 3종목 추출 | 자동완료 | ticker별 PnL breakdown |
| 1c | 해당 종목 제외 시 fold 수익 변화 측정 (shadow run) | tuning_min ≥ 0 | delta PnL ≥ +0.05 |

**PASS 조건**: 음수 fold 원인 ticker/signal 특정 + 제외 시 tuning_min ≥ 0 유지하며 tuning_mean 하락 < 10%

### PATCH-2: Lockbox 고수익 서바이버십 검증

**WHY**
- lockbox_mean 4.01은 tuning 대비 1.7× → 비정상적 점프
- 가능 원인: (1) lockbox 기간에 운좋게 빅테크 랠리 (2) 데이터 누수 (3) 실제 알파
- 검증 없이 프로덕션 배포 시 실망 리스크

**위험/부작용**
- 검증 결과 "운" 판정 시 전략 신뢰도 급락
- 추가 검증 시간 필요

**최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 2a | Lockbox 기간 SPY/QQQ 벤치마크 대비 초과수익 계산 | 자동완료 | alpha = return - beta×benchmark |
| 2b | Lockbox 기간 상위 기여 3종목 추출, 해당 종목 tuning 성과 비교 | 자동완료 | 종목별 sharpe consistency |
| 2c | 랜덤 8종목 포트폴리오 1000회 시뮬, lockbox 수익 분포 생성 | p-value < 0.05 | champion이 상위 5% 이내 |

**PASS 조건**: 벤치마크 대비 alpha > 1.5 AND 상위 기여 종목이 tuning에서도 sharpe > 1.0
