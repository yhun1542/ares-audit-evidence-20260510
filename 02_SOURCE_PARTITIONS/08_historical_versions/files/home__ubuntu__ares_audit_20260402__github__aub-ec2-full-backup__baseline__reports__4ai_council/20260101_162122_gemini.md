### 2. 실행 가능한 Patch / 실험 제안 (3건)

`exp_mrd_fsa`가 평균 성능은 높였으나 하방 경직성을 확보하지 못했으므로, 아래 3가지 실험을 병렬 수행하십시오.

#### [실험 A] Sector Trend Overlay (거시 필터링)
*   **목적**: 섹터 전체가 하락세일 때 개별 종목의 '가짜 반등'에 속아 손실을 키우는 것(Bull trap) 방지.
*   **위험/부작용**: 강한 반등(V자 반등) 초기 진입 실패로 인한 기회비용 발생.
*   **정의 (실험 내용)**:
    ```python
    # Logic: XLK(Tech)와 XLV(Health) ETF의 가격 데이터를 관측 지표로 사용
    if sector_etf_price < sector_etf_ma60:
        signal = 0  # 진입 금지
    else:
        signal = original_strategy_signal
    ```
*   **PASS 조건 (Gate)**:
    *   Tuning Min > -1.0 (최악의 Fold 손실 폭 축소)
    *   Total Trades 감소율 < 30% (과도한 거래 위축 방지)
*   **기대 관측치**: Lockbox Mean은 소폭 하락하더라도, Worst MDD와 Tuning Min이 현저히 개선됨.

#### [실험 B] Earnings Gap Avoidance (이벤트 회피)
*   **목적**: Tech/Healthcare 특유의 실적 발표일 ±1일간 발생하는 20% 이상의 Gap 하락 회피. 현재 -1.35 Min의 주원인으로 추정.
*   **위험/부작용**: 어닝 서프라이즈로 인한 점프 수익(Gap Up) 포기.
*   **정의 (실험 내용)**:
    *   Earnings Date 데이터 로드.
    *   `if (today + 1_day) == earnings_date: exit_all_positions()`
    *   (데이터가 없을 경우) 실적 발표 시즌(1, 4, 7, 10월)의 변동성 상위 종목 제외.
*   **PASS 조건 (Gate)**:
    *   Worst MDD 개선 (> -0.08)
    *   Sharpe Ratio 상승 (변동성 제거 효과)
*   **기대 관측치**: 승률(Win Rate) 상승, 손익비(Profit Factor) 개선.

#### [실험 C] Dynamic Position Sizing by Volatility (비중 조절)
*   **목적**: 변동성이 큰 소형 Tech/Bio 종목에 동일 비중 진입 시 계좌 전체 타격 방지.
*   **위험/부작용**: 주도주(보통 변동성이 큼)의 비중이 줄어들어 총수익(Total Return) 감소.
*   **정의 (실험 내용)**:
    *   기존: `weight = 1 / N` (Equal Weight)
    *   변경: `weight = (1 / ATR_14) / sum(1 / ATR_14_all)` (Inverse Volatility)
*   **PASS 조건 (Gate)**:
    *   Tuning Min -1.35 → -1.20 이상으로 완화.
    *   Lockbox Performance 유지 (오차범위 5% 이내).
*   **기대 관측치**: 수익 곡선(Equity Curve)의 부드러움(Smoothness) 개선.

### 3. 성능 정체 시 원인 분해 아이디어 (Debug Tree)

만약 위 실험 후에도 성능(특히 Tuning Min/Worst MDD)이 요지부동이라면, 다음 순서로 원인을 분해하십시오.

1.  **트리거(Trigger) 확인**:
    *   매매 신호가 발생했음에도 `Volume=0`이거나 `Limit Up/Down`으로 체결되지 않은 가상의 거래가 포함되었는가? (유령 거래 체크)
2.  **비용(Cost) 민감도**:
    *   Spread 비용을 0bp에서 10bp로 올렸을 때 수익이 마이너스로 전환되는가? (만약 그렇다면 전략은 노이즈를 거래 중임)
3.  **레짐(Regime) 불일치**:
    *   Champion 모델이 학습한 기간(In-sample)과 Tuning Min이 발생한 기간의 시장 상관계수(Correlation)가 정반대인가? (예: 금리 인상기 vs 인하기) -> 이 경우, `Regime Classifier` 모듈을 최상단에 배치해야 함.
4.  **노출(Exposure) 집중**:
    *   14개 종목 중 특정 1개 종목이 전체 손실의 80%를 차지하는가? -> 해당 종목 블랙리스트 처리 후 재학습.
