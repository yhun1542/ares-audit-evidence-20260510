### 1. Degenerate Folds(1,2,3,8) 강제 복구 및 페널티 부여
*   **(a) 필요성:** 현재 `degenerate_folds`가 4개나 발생함. 이는 특정 구간(Fold)에서 거래가 전무하거나, 수익률 계산이 불가능(NaN)함을 의미. 현재 `oos_mean: 3.32`는 생존한 Fold들의 과적합된 결과일 가능성이 매우 높음(Survivorship Bias).
*   **(b) 리스크:** 페널티 적용 시 겉보기 성과(Mean)가 급락하여 현재 챔피언 모델이 폐기될 수 있음. 그러나 이는 거품을 걷어내는 과정임.
*   **(c) 실험 (Experiments):**
    *   `EXP-01 (Non-Zero Force)`: Entry Threshold를 0.9 → 0.6으로 낮추어 강제로 거래 발생 유도.
    *   `EXP-02 (Degenerate Penalty)`: Degenerate Fold의 Sharpe/Mean 값을 `None`에서 `-1.0`으로 치환하여 Optimizer가 해당 파라미터를 회피하도록 수정.
*   **(d) PASS 조건:** `degenerate_folds` 개수 = 0. `oos_min` > -0.5.

### 2. 로깅 파이프라인(Rebalance Pinpoint) 긴급 수리
*   **(a) 필요성:** `Error loading... No such file` 에러 발생 중. 백테스트 상에서 실제 어떤 종목이 체결되었는지 추적 불가능(Blind Optimizing). Tech/Healthcare 비중이 지켜지는지 확인 불가.
*   **(b) 리스크:** 코드 수정 중 실행 경로 꼬임 발생 가능.
*   **(c) 실험:**
    *   `EXP-03 (Path Fix)`: `rebalance.csv` 생성 경로를 절대 경로(`/home/ubuntu/AUB/artifacts/...`)로 하드코딩하여 출력 강제화.
    *   `EXP-04 (JSONL Dump)`: CSV 파싱 실패 대비, 모든 거래 로그를 JSONL 포맷으로 이중 저장.
*   **(d) PASS 조건:** `rebalance_pinpoint.md` 리포트가 정상 생성되고 파일 사이즈 > 0KB.

### 3. Universe 유동성 필터 강화 (Tech+Healthcare Focus)
*   **(a) 필요성:** Tech/Bio 섹터는 변동성이 커서 슬리피지가 큼. `worst_mdd: None`은 데이터 누락 혹은 비유동성 자산 거래 시도일 수 있음.
*   **(b) 리스크:** 유니버스 축소로 인한 분산 효과 감소.
*   **(c) 실험:**
    *   `EXP-05 (Volume Filter)`: 최근 20일 평균 거래대금 하위 30% 종목 제외(Hard Filter).
    *   `EXP-06 (Sector Lock)`: 포트폴리오 내 Tech:Healthcare 비율을 6:4 또는 5:5로 강제하는 Constraint 추가.
*   **(d) PASS 조건:** Backtest 로그 상 거래된 종목의 Avg Daily Volume > $50M.

### 4. 비용 구조(Cost Model) 현실화
*   **(a) 필요성:** 2026년 시점 시뮬레이션에서 고빈도 매매가 발생할 경우 수수료/슬리피지가 수익을 잠식함. 현재 높은 Mean 값은 비용 미반영일 확률 높음.
*   **(b) 리스크:** 기대 수익률(CAGR) 대폭 하락.
*   **(c) 실험:**
    *   `EXP-07 (Bps Penalty)`: 매매당 10bps(0.1%) 강제 차감 적용 후 재평가.
*   **(d) PASS 조건:** 비용 적용 후에도 `oos_mean` > 1.5 유지.

### 5. 레짐 기반 노출(Exposure) 동적 조절
*   **(a) 필요성:** 현재 `exposure_max: 0.83`이나 MDD 정보 없음. ETF(QQQ, XLV)의 변동성을 관측지표로 삼아 현금 비중을 조절해야 함.
*   **(b) 리스크:** 잦은 포지션 변경으로 인한 비용 증가, 상승장 소외(Underperformance).
*   **(c) 실험:**
    *   `EXP-08 (Vix-Gating)`: QQQ의 20일 변동성이 상위 20%일 때, 전체 Exposure를 0.5로 제한.
*   **(d) PASS 조건:** MDD가 기존 대비 10% 이상 개선 (수치 확인 필요).
