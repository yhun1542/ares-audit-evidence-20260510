## 2. 성능 미동 시 원인 분해 트리

```
성능 변화 없음
│
├─ [트리거] 신호 자체가 안 바뀜?
│   └─ 점검: signal diff between runs → 변화율 < 1%면 트리거 문제
│
├─ [적용] 신호 → 포지션 전환 안 됨?
│   └─ 점검: rebalance 횟수/크기 → 월 평균 < 2회면 적용 문제
│
├─ [노출] 포지션은 바뀌나 exposure 고정?
│   └─ 점검: exposure_min ≈ exposure_max → 범위 < 5%p면 노출 문제
│
├─ [비용] 수익 발생하나 비용에 상쇄?
│   └─ 점검: gross vs net return 차이 → 차이 > 30%면 비용 문제
│
└─ [레짐] 특정 기간만 작동?
    └─ 점검: fold별 OOS 분산 → CV > 0.5면 레짐 의존 문제
```
