#### 1. 실험 ID: `EXP_LEAK_HUNTER_SHIFT`
*   **목적**: Lockbox 성과(4.01)의 허구성 검증. Feature 생성 시점에 미래 데이터가 섞였는지 확인하기 위해 모든 Input Feature에 강제로 1일 지연(Lag)을 추가.
*   **위험/부작용**: 실제 예측력이 있는 단기 시그널까지 뭉개질 수 있음. 성과 대폭 하락 예상.
*   **실행 정의**:
    1.  모든 Feature Engineering 파이프라인 마지막에 `.shift(1)` 강제 적용.
    2.  대상: `champion_v5` 로직 그대로 사용.
*   **게이트 (PASS 조건)**:
    *   `Lockbox Mean` > 1.5 (4.01에서 급락하더라도 양수 유지 필수).
    *   `Lockbox Min` > -0.5 (파산하지 않아야 함).
*   **기대 관측치**:
    *   만약 성과가 0.5 이하로 떨어지면 기존 Champion은 폐기(데이터 누수 확정).
    *   성과가 유지된다면 현재 Champion은 '운이 좋았거나' 진짜 강력한 모델임.

#### 2. 실험 ID: `EXP_SECTOR_VOL_TARGETING`

    *   수익률(Mean)은 다소 감소하더라도 MDD의 유의미한 개선 확인.

#### 3. 실험 ID: `EXP_STRICT_COST_REALITY`
*   **목적**: 실제 운영 리스크 반영. `tuning_min`(-0.02)이 매우 낮으므로 비용 증가 시 손실 전환 가능성 체크.

### [성능 정체 시 원인 분해 (Root Cause Analysis Ideas)]

성능 지표가 횡보하거나 개선되지 않을 때 다음 트리를 따라 점검:

1.  **Trigger Failure (신호 부재)**
    *   *증상*: 거래 횟수가 0에 수렴하거나 매우 적음.
    *   *원인*: 필터 조건(예: RSI < 30 AND PBR < 1)이 너무 엄격(And 조건 과다).
    *   *액션*: 필터 중 하나를 OR 조건으로 완화하거나 임계값 넓히기.

2.  **Exposure Mismatch (방향성 오류)**
    *   *증상*: 승률(Win Rate)이 50% 미만이나, 손익비(P/L Ratio)로 버티는 중.
    *   *원인*: Tech/Healthcare 간의 역상관 관계 발생 시 헷지 로직 없이 양쪽 다 롱 포지션 진입.
    *   *액션*: Tech와 Healthcare의 상관계수가 음수일 때는 Beta가 낮은 섹터 비중 축소.

3.  **Cost Drag (비용 잠식)**
    *   *증상*: Gross Return은 우상향이나 Net Return은 횡보/하락.
    *   *원인*: 평균 보유 기간이 너무 짧음 (Intraday or 1-2 days).
    *   *액션*: 최소 보유 기간(Minimum Holding Period) 3일 강제 또는 진입 임계값을 높여 노이즈 거래 차단.

4.  **Regime Incompatibility (레짐 불일치)**
    *   *증상*: 특정 연도(Fold)에서는 압도적이나 다른 연도에서는 처참함. (현재 Champion의 Lockbox 괴리가 이 경우일 수 있음)
    *   *원인*: 전략이 '저금리 성장주 장세'에만 최적화됨.
    *   *액션*: 금리(TNX) 상승 구간만 따로 떼어내어 백테스트 수행 후, 해당 구간 방어 로직(현금 비중 조절) 추가.
