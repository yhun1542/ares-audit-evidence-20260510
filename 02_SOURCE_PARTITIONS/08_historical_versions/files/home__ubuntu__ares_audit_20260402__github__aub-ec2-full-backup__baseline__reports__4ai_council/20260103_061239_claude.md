## 🔬 TOP 5 실험 제안

### #1. Degenerate Fold 원인 분해 (최우선)

**(a) 왜 필요한가**
- 40% fold가 degenerate = 특정 시장 레짐에서 전략이 작동 안 함
- 이 상태로 실전 투입 시 해당 레짐 재현 → 대형 손실

**(b) 위험/부작용**
- 원인이 데이터 품질이면 → 전체 백테스트 재실행 필요
- 원인이 전략 구조면 → Champion 교체 필요

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| D1 | Fold 1,2,3,8 기간 식별 → 해당 기간 시장 레짐 태깅 | 완료 여부 | 레짐 클러스터 3개 이내 |
| D2 | Degenerate 기준 완화 (exposure_min=0.05) 재측정 | degenerate ≤ 2 | Fold 복구 수 |
| D3 | 해당 Fold만 signal histogram 출력 | 분포 확인 | signal 0 집중도 < 80% |

**(d) PASS 조건**
```
degenerate_folds ≤ 2 AND 원인 문서화 완료
```

### #2. OOS Mean 3.32 과최적화 검증

**(a) 왜 필요한가**
- 기존 2.63 → 3.32 (26% 상승)는 비정상적
- Look-ahead leak 또는 IS/OOS 경계 오염 의심

**(b) 위험/부작용**
- 실제 alpha 발견이면 버리는 손실
- 검증에 24시간 소요 가능

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| O1 | IS와 OOS 수익률 상관계수 계산 | corr < 0.7 | IS-OOS 독립성 확인 |
| O2 | OOS 기간 1개월 shift 후 재측정 | OOS Mean 변동 < 20% | 시점 민감도 |
| O3 | Feature importance 상위 3개 → 미래 데이터 의존성 감사 | leak 0건 | 변수명 리스트 |

**(d) PASS 조건**
```
(O1.corr < 0.7) AND (O2.변동 < 20%) AND (O3.leak == 0)
```

**(b) 위험/부작용**

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| M1 | equity curve에서 MDD 계산 로직 구현 | 값 출력 | -15% ~ -40% 범위 |

| M3 | 연도별 MDD 분해 | 출력 완료 | worst year 식별 |

**(d) PASS 조건**

```
worst_mdd 계산 완료 AND worst_mdd > -30%
```

### #4. Exposure 불균형 정상화

**(a) 왜 필요한가**
- exposure_min=0.0 = 현금 100% 구간 존재
- exposure_max=0.84 vs min=0.0 → 레버리지 변동 극심

**(b) 위험/부작용**
- 강제 최소 exposure 시 손실 구간 강제 진입

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| E1 | exposure=0 구간 날짜 추출 | 리스트 출력 | degenerate fold와 겹침 확인 |
| E2 | min_exposure=0.2 강제 후 OOS 재측정 | OOS Mean > 2.0 | 성능 저하폭 |
| E3 | exposure 변동성 (std) 계산 | std < 0.25 | 안정성 지표 |

**(d) PASS 조건**
```
exposure_min ≥ 0.1 OR exposure=0 구간이 명확한 레짐 기반
```

## 🌲 성능 미동 원인 분해 트리

```
OOS 성능 변동 없음
├── [1] 트리거 미발동
│   ├── signal threshold 너무 높음 → histogram 확인
│   └── 조건 AND 과다 → 개별 조건 발동률 측정
├── [2] 적용 오류
│   ├── position sizing 0 강제 → sizing 로직 감사
│   └── 코드 버그 (if/else 분기) → unit test 추가
├── [3] 노출 상쇄
│   ├── long/short 동시 진입 → net exposure 확인
│   └── 섹터 내 상쇄 (AAPL long, MSFT short) → 종목별 분해
├── [4] 비용 소멸
│   ├── gross return 양수, net return 0 → 비용 로그 확인
│   └── slippage 과대 설정 → 시장가 vs 지정가 검증
└── [5] 레짐 불일치
    ├── 학습 기간 bull only → bear 기간 OOS 확인
    └── 변동성 레짐 shift → VIX 구간별 성능 분해
```
