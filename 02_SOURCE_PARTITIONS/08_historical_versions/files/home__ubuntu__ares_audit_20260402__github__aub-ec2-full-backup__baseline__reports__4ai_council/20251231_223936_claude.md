### P1. MDD 클러스터 분석 및 방어 로직
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(b) 위험/부작용**
- 방어 로직 과잉 → 정상 구간 수익 훼손

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |

| P1-B | 해당 구간 VIX>25 시 현금비중 +20% 룰 추가 | lockbox_mdd 개선 ≥0.5%p | worst_mdd → -10.5% 이하 |
| P1-C | 단일종목 손실 -7% 시 강제청산 룰 (stop-loss) | tuning_mean 하락 <3% | worst_mdd → -10.0% 이하 |

worst_mdd ≥ -0.105 AND lockbox_mean ≥ 1.79 AND tuning_mean ≥ 1.75

**(b) 위험/부작용**
- 최악 폴드 맞춤 시 전체 mean 하락
- 레짐 특수성 무시하면 일반화 실패

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|

| P2-C | 포트폴리오 종목 수 8→10 분산 (해당 폴드만 테스트) | mean 하락 <5% | min 폴드 안정화 |

**(d) PASS 조건**

tuning_min ≥ 0.30 AND tuning_mean ≥ 1.70 AND lockbox_mean 변동 <2%

### P4. 시그널 기여도 분해 (Ablation)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한가**
- 복합 시그널 중 어떤 것이 실제 기여인지 불명
- 불필요 시그널 = 노이즈 + 과적합 경로

**(b) 위험/부작용**
- Ablation 과잉 시 조합 폭발
- 단일 제거가 비선형 효과 놓칠 수 있음

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P4-A | 시그널 1개씩 OFF → lockbox 재측정 (상위 3개만) | 각각 완료 | 기여도 순위: Sig_A > Sig_B > Sig_C |
| P4-B | 기여도 0 또는 음수 시그널 제거 | lockbox_mean 유지 | 복잡도 감소, 동일 성능 |
| P4-C | 상위 2개 시그널만으로 단순화 버전 | mean ≥ 1.6 | 오컴 면도날 버전 확보 |

**(d) PASS 조건**
```
시그널 수 감소 AND lockbox_mean ≥ 1.75
```

## 2. 성능 미동작 시 원인 분해 트리

```
성능 변화 없음
│
├─[1] 트리거 미발동
│   └─ 실험 조건이 백테스트 기간 내 발생 안 함
│   └─ 확인: 룰 발동 횟수 로깅 → 0회면 무의미 실험
│
├─[2] 적용되었으나 노출 부족
│   └─ 포지션 비중이 너무 작아 전체 영향 미미
│   └─ 확인: 변경 종목의 평균 비중 × 발동일수
│
├─[3] 양방향 상쇄
│   └─ 개선 구간 + 악화 구간이 상쇄
│   └─ 확인: 폴드별 분해 → 일부는 +, 일부는 -
│
├─[4] 비용이 이득 상쇄
│   └─ 회전율 증가로 거래비용 > 수익개선
│   └─ 확인: 비용 전/후 비교
│
└─[5] 레짐 불일치
    └─ 실험 타겟 레짐이 lockbox 기간에 부재
    └─ 확인: lockbox 기간 내 해당 레짐 일수 비율
```
