[진단: ONE TRUTH 분석]
- **심각한 과적합/데이터 희소성 의심:** `degenerate_folds: [1, 2, 3, 8]`은 전체 폴드의 절반 가량이 통계적 유의성을 확보하지 못했거나 거래가 '0'에 수렴했음을 의미함.
- **비정상적 성능 지표:** `oos_mean: 3.32`는 현실적이지 않음(Look-ahead Bias 강력 의심). `worst_mdd: None`은 데이터 결측 혹은 수익 곡선 계산 로직 파탄 상태.
- **결론:** 현재 챔피언은 폐기 대상이며, 즉각적인 '데이터 정합성' 및 'Look-ahead' 감사가 필요함.

### 1) 다음 24~48시간 우선순위 TOP 5 제안

#### P1. [Integrity] 거래 희소성 및 MDD 계산 로직 수정
*   **(a) 이유:** `worst_mdd: None`과 4개의 퇴행 폴드(degenerate folds)는 전략이 특정 구간에서 전혀 작동하지 않거나 로직이 깨졌음을 의미. 이를 해결하지 않으면 어떤 실험도 무의미.
*   **(b) 위험:** 강제로 거래를 유발할 경우 수익률 급락 가능성(False Positive 증가).
*   **(c) 실험 정의:**
    *   `Exp_Fix_Sparsity`: 최소 거래 횟수 제약(Min_Trades > 30 per fold) 추가.
    *   `Exp_Debug_MDD`: 수익 곡선(Equity Curve) 계산 시 NaN 발생 구간을 0으로 채우거나(fill) 드롭하는 전처리 로직 강화.
*   **(d) PASS 조건:** 모든 폴드에서 `degenerate` 상태 해제, `worst_mdd`가 유효한 음수 값으로 산출될 것.

#### P2. [Universe] Tech/Health 12개 종목 고정 및 유동성 필터
*   **(a) 이유:** 8~14개 종목 제한 조건 충족 및 서바이버십 바이어스 제거. Tech(XLK 구성종목), Health(XLV 구성종목) 내 대형주 위주로 압축하여 데이터 퀄리티 확보.
*   **(b) 위험:** 소형주 폭발력 제외로 인한 잠재 수익률 하락.
*   **(c) 실험 정의:**

*   **(d) PASS 조건:** 고정된 유니버스 내에서 백테스트 구동 성공, 데이터 결측치(Null) 0건.

#### P3. [Bias Audit] 1일 강제 Lag 및 타임스탬프 검증
*   **(a) 이유:** `oos_mean: 3.32`는 미래 데이터를 참조했을 확률 99%. Feature 생성 시점과 체결 시점의 불일치(Look-ahead)를 물리적으로 차단해야 함.
*   **(b) 위험:** 실제 예측력이 사라져 성능이 0 또는 마이너스로 수렴할 가능성(오히려 이것이 정상).
*   **(c) 실험 정의:**

    *   `Exp_Shuffle_Time`: 타임스탬프를 랜덤 셔플 후 학습 시 성능이 급락하는지 확인(성능 유지 시 로직 오류).
*   **(d) PASS 조건:** `oos_mean`이 0.5~1.5 범위로 하락하더라도 `oos_min`이 방어적 수준(-0.05 이상) 유지.

#### P4. [Cost Model] 현실적 비용(Slippage/Comm) 주입
*   **(a) 이유:** 초과 수익이 비용 미반영에서 올 수 있음.
*   **(b) 위험:** 샤프 비율 급락으로 인한 전략 폐기 압박.

### 3) 성능 정체 시 원인 분해 (Debugging Tree)

성능이 움직이지 않거나(0 근처) 개선되지 않을 때 다음 순서로 점검하십시오.

1.  **트리거(Trigger) 확인:**
    *   *신호가 발생하는가?* -> Raw Prediction 값의 분포 확인 (모두 0.5 근처인지, 0/1로 쏠려있는지).
    *   *해결:* Feature Scaling (Z-score) 재점검, 모델의 Variance 높이기.

2.  **적용(Application) 확인:**
    *   *주문이 나가는가?* -> 신호는 있는데 현금 부족/레버리지 제한으로 주문 거부(Reject) 되는지 로그 확인.
    *   *해결:* `exposure_limit` 확인, 초기 자본금 설정 확인.

3.  **노출(Exposure) 확인:**
    *   *베팅 사이즈가 유의미한가?* -> 포트폴리오 내 비중이 너무 작아(예: 1%) 수익 기여가 없는지.
    *   *해결:* 변동성 타겟팅(Target Vol) 로직으로 포지션 사이징 동적 조절.

4.  **비용(Cost) 확인:**
    *   *벌어서 비용으로 다 나가는가?* -> Gross Profit은 우상향인데 Net Profit이 횡보/하락인지.
    *   *해결:* 회전율(Turnover) 강제 제한, 진입 임계값(Threshold) 상향.

5.  **레짐(Regime) 확인:**
    *   *시장의 성격이 변했는가?* -> 특정 연도(예: 2022)에만 손실이 집중되는지.
    *   *해결:* ETF(XLK, XLV) 모멘텀을 Feature가 아닌 'Hard Rule Filter'로 격상 적용.
