[우선순위 분석]
현재 Champion(v5)의 Lockbox 성과(4.01)가 Tuning(2.32)보다 월등히 높은 현상은 **'미래 참조(Look-ahead Bias)'** 또는 **'극단적인 특정 종목(NVIDIA 등) 의존'**일 확률이 90% 이상임. 따라서 성과 개선보다는 **Champion의 유효성 검증(Audit)**과 **Candidate의 안정성 강화**에 자원을 집중해야 함.

### 1. 24~48시간 우선순위 TOP 5 제안 (명령형 체크리스트)

#### [AUDIT] 1. Champion 데이터 누수(Leakage) 강제 검증
*   **(a) 이유:** Tuning 대비 Lockbox 성과가 1.7배 높은 것은 통계적으로 이례적임. `Close` 가격으로 시그널을 만들고 당일 `Close`로 진입하는 오류가 있는지 확인 필수.
*   **(b) 위험:** 챔피언 폐기 가능성 높음(그러나 리소스 낭비 방지를 위해 필수).
*   **(c) 실험 정의:**
    *   **Exp 1-1 (Lag Shift):** 모든 Feature 생성 로직에 `shift(1)`을 강제 적용 후 재학습 없이 Backtest 수행.
    *   **Exp 1-2 (Execution Delay):** 진입 시점을 `Signal Day Close`에서 `Next Day Open`으로 변경.
*   **(d) PASS 조건:**
    *   Exp 1-1: 기존 성과 대비 하락폭이 30% 이내일 것 (90% 이상 폭락 시 즉시 폐기).
    *   Exp 1-2: 기존 성과 대비 하락폭이 15% 이내일 것.

#### [ROBUSTNESS] 2. Tech/Bio 유니버스 편중(Bias) 제거 실험
*   **(a) 이유:** 8~14개 종목 제한 시, 특정 '슈퍼 스톡(LLY, NVDA)' 하나가 전체 성과를 왜곡했을 가능성(Survivorship Bias) 존재.
*   **(b) 위험:** 성과 수치가 대폭 하락하여 '실패'로 보일 수 있음.
*   **(c) 실험 정의:**
    *   **Exp 2-1 (Kill-Top2):** 유니버스 내 수익 기여도 상위 2개 종목(예: NVDA, LLY)을 제외하고 나머지로만 포트폴리오 구성.
    *   **Exp 2-2 (Sector Equalizer):** Tech(XLK 구성종목)와 Healthcare(XLV 구성종목)의 비중을 강제로 50:50으로 고정(리밸런싱 주기 단축).
*   **(d) PASS 조건:**
    *   Exp 2-1: `Lockbox Mean` > 1.2 유지, `Worst MDD` 악화 < 5%pt.
    *   Exp 2-2: `Sharpe Ratio` > 1.5 유지.

#### [REALITY] 3. 비용 구조 현실화 (Slippage/Commision Stress Test)
*   **(a) 이유:** Tech/Bio 고변동성 종목은 슬리피지가 큼. 현재 '비용 미반영' 리스크가 최우선 점검 사항임.
*   **(b) 위험:** 잦은 매매(High Turnover) 전략일 경우 수익 곡선이 우하향으로 반전될 수 있음.
*   **(c) 실험 정의:**
    *   **Exp 3-1 (High Friction):** 왕복 수수료+슬리피지를 15bps(0.15%)로 설정 후 `candidate_macro_alpha_shadow` 재검증.
    *   **Exp 3-2 (Turnover Constraint):** 일일 회전율(Turnover)이 10%를 초과하지 않도록 페널티 항 추가.
*   **(d) PASS 조건:**
    *   Exp 3-1: 연환산 수익률(CAGR) > 15% 유지.
    *   Exp 3-2: `Avg Transaction per Day` 감소, 그러나 `Total Return` 감소폭 < 10%.

#### [LOGIC] 4. 변동성 돌파 + Mean Reversion 하이브리드 (Candidate 개선)
*   **(a) 이유:** `candidate_macro_alpha_shadow`의 MDD(-11%) 방어를 위해, Tech 섹터의 추세 추종과 Bio 섹터의 평균 회귀 성향을 분리 적용.
*   **(b) 위험:** 로직 복잡도 증가로 인한 과최적화(Overfitting).
*   **(c) 실험 정의:**
    *   **Exp 4-1 (Sector Split Logic):** Tech 종목은 Breakout(20일 신고가) 진입, Healthcare 종목은 RSI(30) 역추세 진입으로 로직 이원화.
    *   **Exp 4-2 (VIX Filter):** VIX > 25 구간에서는 Tech 비중 0, Healthcare 비중 확대(방어적 로테이션).
*   **(d) PASS 조건:**
    *   Exp 4-1: `Fold14 MDD` > -7% (개선), `Win Rate` > 55%.
    *   Exp 4-2: `Lockbox Min` 수익률 > 0.5 (하방 경직성 확보).

#### [EXECUTION] 5. 베팅 사이즈 동적 조절 (Kelly Criterion Lite)
*   **(a) 이유:** 단순히 종목을 n등분 하는 것이 아니라, 시그널 강도나 변동성에 따라 비중을 조절하여 MDD 관리.
*   **(b) 위험:** 레버리지 효과로 MDD가 오히려 커질 수 있음(변동성 역가중 필요).
*   **(c) 실험 정의:**
    *   **Exp 5-1 (Inv-Vol Weighting):** (1/개별종목 20일 변동성) 비례하여 비중 할당.
    *   **Exp 5-2 (Signal Scaling):** 모델 예측 확률(Confidence)이 0.7 이상일 때만 진입 비중 100%, 그 외 50%.
*   **(d) PASS 조건:**
    *   Exp 5-1: `Worst MDD` -8% 이내 진입.
    *   Exp 5-2: `Profit Factor` > 2.0 달성.

### 3. 성과 정체(Stagnation) 시 원인 분해 & 해결 아이디어

만약 위 실험 후에도 성능 지표(Sharpe, MDD)가 개선되지 않거나 횡보할 경우 아래 트리거를 점검:

1.  **트리거(Trigger) 빈도 부족:**
    *   *현상:* 매매 횟수가 너무 적음 (월 1~2회).
    *   *원인:* 진입 조건(Threshold)이 너무 엄격함.
    *   *해결:* 진입 임계값을 완화(예: `prob > 0.8` → `prob > 0.6`)하되, 포지션 사이즈를 줄여 리스크 분산.

2.  **노출(Exposure) 왜곡:**
    *   *현상:* 승률은 좋은데 계좌 수익은 제자리.
    *   *원인:* 이기는 거래엔 비중이 적고, 지는 거래에 비중이 큼 (역-Kelly).
    *   *해결:* 최근 5일 변동성이 낮은 종목에 더 큰 비중을 싣는 'Risk Parity' 로직 적용.

3.  **비용(Cost) 잠식:**
    *   *현상:* Gross Return은 우상향이나 Net Return은 횡보.
    *   *원인:* 잦은 리밸런싱으로 슬리피지 누적.
    *   *해결:* '버퍼 룰' 도입 (목표 비중과 현재 비중 차이가 10% 이상일 때만 리밸런싱).

4.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 분기(예: 2022 Q2)에 MDD가 집중됨.
    *   *원인:* 금리 인상기 등 매크로 변수에 취약.
    *   *해결:* ETF(TLT, UUP)를 관측 지표로 삼아, 금리 급등 구간에서는 현금 비중 100% 강제(Cash Protection).
