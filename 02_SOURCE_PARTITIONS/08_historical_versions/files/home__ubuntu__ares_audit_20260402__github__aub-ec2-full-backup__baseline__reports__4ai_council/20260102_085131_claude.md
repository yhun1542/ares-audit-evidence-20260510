| 구분 | 내용 |
|------|------|

| **(b) 위험** | 계산 로직 오류 시 false safety; 시간 해상도(daily vs intraday) 불일치 |

```

GATE: worst_mdd != None AND worst_mdd < 0.25
OBSERVE: mdd_daily, mdd_rolling_63d
```
