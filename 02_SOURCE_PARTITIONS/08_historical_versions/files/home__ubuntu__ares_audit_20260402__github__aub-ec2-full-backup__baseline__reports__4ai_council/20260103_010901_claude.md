## TOP 5 우선순위 패치 (24-48H)

### P1. 파이프라인 무결성 복구 (즉시)

| 항목 | 내용 |
|------|------|
| **왜 필요** | MDD=None, rebalance 파싱 실패 → 실험 비교 자체 불가능. 성능 0 움직임의 원인이 측정 오류일 가능성 |
| **위험** | 수정 중 기존 로그 포맷 깨뜨릴 수 있음 |

**실험 체크리스트:**
```bash
# EXP-P1a: MDD 계산 복구
□ worst_mdd 계산 로직에 division-by-zero / empty array 방어 추가
□ Gate: worst_mdd ≠ None for all folds
□ 기대치: MDD 값 -5% ~ -25% 범위 출력

# EXP-P1b: Rebalance 로그 포맷 통일
□ rebalance.csv vs .jsonl 포맷 일치 확인
□ Gate: aub_rebalance_pinpoint 에러 없이 완료
□ 기대치: trade_count, turnover 정상 출력

# EXP-P1c: Fold 퇴화 원인 로깅
□ degenerate_fold 정의 조건 출력 (exposure<1%? zero trades?)
□ Gate: 4개 fold별 퇴화 사유 명시
□ 기대치: 원인 분류 → {no_signal, filter_block, position_cap}
```

**PASS 조건:** 3개 모두 에러 없이 리포트 생성, MDD/turnover 숫자 확인

### P2. Degenerate Fold 긴급 분석

| 항목 | 내용 |
|------|------|
| **왜 필요** | Fold 1,2,3,8 퇴화 = 특정 시장 레짐에서 신호 전무. 과최적화 또는 필터 과잉 |
| **위험** | 필터 완화 시 노이즈 트레이드 증가 → 비용 폭증 |

**실험 체크리스트:**
```bash
# EXP-P2a: 퇴화 fold 시장환경 매핑
□ fold 1,2,3,8 기간의 VIX/SPY 레짐 태깅
□ Gate: 퇴화 fold ≥3개가 동일 레짐이면 레짐필터 문제
□ 기대치: {high_vol: 2, low_vol: 1, sideways: 1} 형태 출력

# EXP-P2b: 필터 완화 ablation
□ entry_filter threshold 10% 완화 (현재값 × 0.9)
□ Gate: degenerate_fold ≤ 2 AND oos_mean ≥ 2.5
□ 기대치: exposure_min 0.05+ 로 상승

# EXP-P2c: Minimum position size 하한 강제
□ 신호 발생 시 min_weight = 2% 강제
□ Gate: zero-exposure day < 30%
□ 기대치: fold별 trade_count 균등화
```

**PASS 조건:** degenerate_fold ≤ 2개로 감소 + oos_mean 유지

## 48H 자동루프 실행 명령

```yaml
# autopilot_48h_config.yaml
loop_interval: 4h
experiments:
  - id: P1a_mdd_fix
    script: fix_mdd_calculation.py
    gate: worst_mdd != None
    
  - id: P1b_log_format
    script: unify_rebalance_format.py
    gate: rebalance_pinpoint_success == True
    
  - id: P2b_filter_relax
    script: run_backtest.py --filter_mult=0.9
    gate: degenerate_folds <= 2 AND oos_mean >= 2.5
    
  - id: P3a_cost_audit
    script: audit_transaction_costs.py
    gate: cost_variance < 1bps
    
  - id: P4a_exposure_cap
    script: run_backtest.py --max_exposure=0.7
    gate: mdd_improvement > 10% AND sharpe_loss < 10%

stop_condition: 
  - all_gates_pass
  - OR iteration >= 12
```
