# AUB 48H 자동 루프 패치 제안

## 🔴 Critical Issue 진단

현재 상태에서 **심각한 문제점**:
1. **degenerate_folds: [1,2,3,8]** → 10개 중 4개 폴드 붕괴 = 40% 실패율
2. **worst_mdd: None** → MDD 계산 자체가 안 됨 (코드 버그 또는 데이터 누락)
3. **rebalance.csv 파싱 에러** → 리밸런스 로그 손상/포맷 불일치
4. **oos_min: -2.57%** vs **oos_mean: 3.32** → 폴드 간 분산 극심

## 📋 TOP 5 우선순위 패치 (48H)

### PATCH 1: Degenerate Fold 원인 분리
| 항목 | 내용 |
|------|------|
| **왜 필요** | 4/10 폴드 붕괴 = OOS 신뢰도 0. 원인 미분리 시 모든 실험 무의미 |
| **위험/부작용** | 폴드 정의 변경 시 과거 비교 불가 |
| **게이트** | `degenerate_folds ≤ 1` 달성 전까지 다른 실험 중단 |

```yaml
# 실험 정의
EXP-1A:
  name: "fold_regime_map"
  action: |
    각 폴드(1,2,3,8)의 시작/종료 날짜 + 시장 레짐(VIX>25, SPY DD>10%) 매핑
  gate: fold별 레짐 라벨 출력
  expect: 붕괴 폴드가 특정 레짐(예: 2022Q1 금리쇼크)에 집중되는지 확인

EXP-1B:
  name: "signal_coverage_by_fold"
  action: |
    붕괴 폴드에서 signal != 0 인 날짜 비율 계산
  gate: coverage_ratio >= 0.3 (정상 폴드 평균 대비)
  expect: 붕괴 원인이 "신호 미발생" vs "신호 발생했으나 손실"인지 분리

EXP-1C:
  name: "min_holding_relaxation"
  action: |
    min_holding: 5 → 3 으로 완화 후 붕괴 폴드 재실행
  gate: degenerate_folds 개수 변화 관측
  expect: 2개 이상 폴드 복구 시 holding constraint 과적합 확정
```

  gate: 단위테스트 PASS
  expect: 버그 위치 특정 (입력 누락 vs 계산 로직)

EXP-2B:
  name: "equity_curve_integrity"
