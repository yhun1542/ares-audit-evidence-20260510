## TOP 5 우선순위 액션

---

### P1. 🔧 파이프라인 복구 + MDD 측정 활성화

#### (a) 왜 필요한지
- `worst_mdd: None` → 리스크 블라인드 상태로 운영 중
- `rebalance.csv` 로드 실패 → 비용/슬리피지 미반영 가능성
- 진짜 성능을 모르면 모든 실험이 의미 없음

#### (b) 위험/부작용
- 파이프라인 수정 시 기존 결과와 비교 불가능해질 수 있음
- MDD 계산 로직에 따라 결과 해석 달라짐

#### (c) 최소 실험

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P1-A | `backtest.py`에 MDD 계산 추가, per-fold + aggregate | 코드 실행 성공 | MDD 값 출력 (예상: -15%~-35%) |
| P1-B | rebalance 로거 JSON→CSV 호환 확인 | 파일 생성 + 파싱 성공 | 최소 100행 rebalance 기록 |
| P1-C | Champion 재실행 with full logging | OOS Mean ±0.1 이내 재현 | MDD, turnover, cost 모두 채워짐 |

#### (d) PASS 조건
```
worst_mdd != None AND rebalance_rows > 0 AND oos_mean 재현오차 < 5%
```

### P2. 🔬 Degenerate Fold 원인 분해

#### (a) 왜 필요한지
- 4/10 폴드 사망 = 신호가 특정 시장 레짐에서만 작동
- 이 상태로 라이브 가면 **40% 확률로 손실 구간** 진입

#### (b) 위험/부작용
- 레짐 필터 추가 시 → 신호 발생 빈도 급감 가능
- 폴드별 튜닝 시 → 과최적화 위험

#### (c) 최소 실험

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P2-A | Degenerate 폴드 날짜 범위 추출 → VIX/SPY 레짐 매핑 | 스크립트 완료 | "폴드1,2,3,8 = 고VIX 구간" 등 패턴 |
| P2-B | 해당 구간에서 exposure=0 강제 (레짐 오버레이) | degenerate 폴드 수 감소 | 4개 → 2개 이하 |
| P2-C | 폴드별 개별 종목 기여도 분해 | 리포트 생성 | 특정 종목이 손실 주범인지 확인 |

#### (d) PASS 조건
```
degenerate_folds ≤ 2 AND oos_mean 하락 < 20%
```

### P3. 📊 OOS Mean 불일치 해소 (3.32 vs 2.63)

#### (a) 왜 필요한지
- 핸드오프(3.32) vs 진단(2.63) = **25% 괴리**
- 둘 중 하나는 틀림 → 의사결정 기반 자체가 불안정

#### (b) 위험/부작용
- 낮은 숫자가 진짜면 전략 자체 재검토 필요
- 계산 로직 차이면 표준화 작업 필요

#### (c) 최소 실험

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P3-A | 두 스크립트의 OOS 계산 로직 diff | 차이점 문서화 | "A는 mean(folds), B는 weighted" 등 |
| P3-B | 동일 데이터로 양쪽 실행, 중간값 로깅 | 불일치 지점 특정 | 어느 폴드에서 갈리는지 |
| P3-C | 표준 계산 함수 1개로 통일 | 양쪽 결과 일치 | 오차 < 1% |

#### (d) PASS 조건
```
|handoff_oos - diagnoser_oos| < 0.1
```

#### (b) 위험/부작용
- 비용 반영 시 OOS 급락 → 전략 폐기 가능성
- 과도한 비용 가정 시 좋은 전략도 사장

## 성능 안 움직일 때 원인 분해 트리

```
OOS 변화 없음
├─ [트리거] 신호 자체가 안 바뀜
│   ├─ 파라미터 변경이 임계값 이하
│   └─ 데이터 윈도우가 동일 구간만 커버
│
├─ [적용] 신호 → 포지션 변환 병목
│   ├─ Position sizing이 floor/cap에 걸림
│   └─ 동일 종목이 항상 max weight
│
├─ [노출] 실제 exposure가 거의 동일
│   ├─ 레버리지 캡에 걸려서 포화
│   └─ 롱숏 상쇄로 net exposure ~0
│
├─ [비용] 비용 모델 미반영
│   └─ gross return은 바뀌지만 net은 동일 (비용이 0이면)
│
└─ [레짐] 특정 구간에서만 차이
    └─ 테스트 기간의 레짐 구성이 우연히 동일
```
