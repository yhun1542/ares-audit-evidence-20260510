3. **자산 배분 미작동:** Tech/Healthcare 중심임에도 Exposure Min 0.0은 전략이 현금에 숨어버리는 현상(Degenerate)을 방증.

### 2. 제안별 실행 계획 (Action Plan)

#### 제안 A: [Critical Fix] Metric & Log Recovery
*   **Why:** `MDD: None` 상태에서는 리스크 관리가 불가능하며, `degenerate_folds`의 원인을 파악할 로그가 없음.
*   **Risks:** 코드 수정 중 실행 에러 발생 가능성 (Syntax error).
*   **Experiments (Patch):**
    1.  `exp_fix_logger`: 거래 로그 저장 시 `flush()` 강제 호출 및 JSON 형식 유효성 검사 추가.
    2.  `exp_calc_mdd_safe`: MDD 계산식에서 `NaN` 또는 `ZeroDivision` 예외 처리 추가 (초기 자산 대비 0이 될 경우 강제 -1.0 처리).
    3.  `exp_force_trade`: 첫 10틱 이내 무조건 1주 매수하여 `No Trade`로 인한 Null Metric 방지.
*   **PASS 조건:**
    *   `worst_mdd`가 숫자(float)로 출력될 것.
    *   `rebalance_pinpoint.py`가 에러 없이 실행될 것.

#### 제안 B: [Anti-Overfitting] Feature Lag & Constraints
*   **Why:** OOS Mean 3.32는 미래 데이터를 참조했을 가능성이 높음. 또한 4개 Fold의 실패는 특정 종목 몰빵 후 폭락 가능성을 시사.
*   **Risks:** 수익률(OOS Mean) 급락 예상 (정상화 과정).
*   **Experiments:**
    1.  `exp_lag_1d`: 모든 Feature(Open, High, Low, Close, Vol)에 `shift(1)` 적용.
    2.  `exp_max_weight_15`: 단일 종목 비중 상한 `0.15` 설정 (최소 7개 종목 분산 강제).
    3.  `exp_min_exposure_30`: 포트폴리오 전체 노출도 최소 `0.3` 강제 (현금 도피 방지).
*   **PASS 조건:**
    *   `degenerate_folds` 개수 감소 (4개 -> 1개 이하).
    *   OOS Mean이 1.0~2.0 수준으로 현실화되더라도 Sharpe > 1.5 유지.

#### 제안 C: [Universe] Tech/Bio Focus & Liquidity
*   **Why:** 미국 주식 Tech/Healthcare 8~14개로 제한하려면, 유동성이 부족한 소형주가 포함되어 슬리피지를 유발할 수 있음.
*   **Risks:** 유니버스 축소로 인한 분산 효과 감소.
*   **Experiments:**
    1.  `exp_univ_top20_vol`: Tech/Healthcare 섹터 내 거래대금 상위 20개로 유니버스 제한 후 상위 10개 선별.
    2.  `exp_remove_penny`: $10 미만 종목 거래 금지.
*   **PASS 조건:**
    *   백테스트 상 `Cost` 차감 후에도 우상향 그래프 확인.
    *   선택된 종목들이 주류 Tech/Bio 종목(NVDA, LLY 등)을 포함하되 쏠리지 않을 것.

### 3. 성능 정체 원인 분해 아이디어

성능이 개선되지 않거나 지표가 움직이지 않을 경우 다음을 점검:

1.  **트리거(Trigger) 불발:**
    *   *현상:* 매매 신호 자체가 생성되지 않음 (0 거래).
    *   *원인:* 진입 임계값(Threshold)이 너무 높거나(예: 예측 스코어 > 0.99), 데이터 결측치로 인해 신호가 NaN 처리됨.
    *   *해결:* 진입 임계값 완화 (`score > 0.6`) 또는 결측치 `ffill` 적용 확인.

2.  **비용(Cost) 과다 반영:**
    *   *현상:* 승률은 좋으나 PnL이 음수.
    *   *원인:* 잦은 리밸런싱으로 슬리피지/수수료 누적.
    *   *해결:* 회전율(Turnover) 패널티 추가 또는 리밸런싱 주기(Weekly) 고정.

3.  **레짐(Regime) 불일치:**
    *   *현상:* `degenerate_folds`가 특정 연도(예: 2022년 하락장)에 집중.
    *   *원인:* Long-Only 전략이 하락장에서 손실을 방어하지 못함.
    *   *해결:* 하락장(MA200 하회 시)에서는 현금 비중 50% 이상 강제하는 로직 추가 (ETF 매매 제외 조건이므로 인버스 불가 -> 현금 보유가 유일한 헷지).

4.  **관측 불가(Blind Spot):**
    *   *현상:* 로그 파일 누락.
    *   *원인:* 파일 경로 설정 오류 또는 권한 문제.
    *   *해결:* 절대 경로(`/home/ubuntu/...`) 사용 및 `try-except` 블록으로 파일 쓰기 보장.
