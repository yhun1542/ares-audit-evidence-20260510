## 1. 우선순위 TOP-5 패치

### PATCH-1: MDD 계측 파이프라인 복구 (BLOCKER)

**(a) 왜 필요한가**
- `worst_mdd: None` → 백테스트 결과에 drawdown 계산 누락
- 리스크 게이트 없이 champion 승격은 blind deployment

**(b) 위험/부작용**
- MDD 계산 로직 버그 시 false reject 가능
- 기존 run 재계산 필요 → 시간 소요

**(c) 최소 실험**

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 1-1 | `calc_max_drawdown()` 함수에 synthetic equity curve (직선→50% drop→회복) 투입 | 출력 == 0.50 ±0.01 | PASS: 정확도 확인 |
| 1-2 | 현재 champion run에 MDD 재계산 적용 | `worst_mdd` 값 출력 | PASS: None → 숫자 |
| 1-3 | MDD > 25% fold 존재 시 champion 강등 로직 dry-run | 강등 여부 로그 | PASS: 로직 작동 확인 |

**(d) PASS 조건**
```
worst_mdd ∈ (0, 0.30] AND 모든 fold MDD < 0.35
```

### PATCH-2: OOS Min Fold 취약 구간 분해

**(a) 왜 필요한가**
- OOS Min 0.43 vs Mean 1.88 → 특정 fold Sharpe 77% 하락
- 레짐 의존성 또는 종목 집중 리스크 의심

**(b) 위험/부작용**
- Fold 제거 시 survivorship bias 발생 가능
- 과최적화로 이어질 수 있음

**(c) 최소 실험**

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 2-1 | 최저 fold 기간 식별 → VIX/금리 레짐 태깅 | 레짐 라벨 출력 | 고변동 구간 여부 |
| 2-2 | 해당 fold 내 종목별 P&L 분해 | 단일 종목 손실 > 50% 기여? | 집중 리스크 확인 |
| 2-3 | 해당 fold exposure를 0.5로 cap한 시뮬 | Sharpe 변화 | PASS: Min > 0.6 |

**(d) PASS 조건**
```
원인 식별 완료 AND (레짐 필터 추가 OR exposure cap 적용 후 OOS Min > 0.55)
```

### PATCH-3: 거래비용 현실화 검증

**(a) 왜 필요한가**
- 비용 미반영 시 OOS Sharpe 20~40% 과대 추정 일반적
- 현재 비용 가정 불명확

**(b) 위험/부작용**
- 비용 과대 적용 시 전략 자체가 음수 Sharpe로 전환 가능
- 슬리피지 모델 선택에 따른 결과 민감도

**(c) 최소 실험**

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 3-1 | 현재 비용 가정 명시 (bp 단위) | 문서화 | 기준선 확보 |
| 3-2 | 비용 10bp/trade 적용 후 OOS 재계산 | Sharpe 변화율 | PASS: 하락 < 15% |
| 3-3 | 비용 20bp/trade (보수적) 적용 | Sharpe > 1.0 유지? | 전략 생존성 확인 |

**(d) PASS 조건**
```
cost=10bp 기준 OOS Mean > 1.5 AND OOS Min > 0.3
```

### PATCH-4: Exposure 상한 스트레스 테스트

**(a) 왜 필요한가**
- Max exposure 84% → 레버리지 없이도 집중 리스크
- 급락장에서 MDD 급증 가능성

**(b) 위험/부작용**
- Exposure cap 강화 시 수익 기회 손실
- 최적 cap 탐색 → 과최적화 위험

**(c) 최소 실험**

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 4-1 | Exposure max 70% cap 적용 | OOS Mean/Min 변화 | 기준선 확보 |
| 4-2 | Exposure max 60% cap 적용 | MDD 변화 | PASS: MDD < 20% |
| 4-3 | 변동성 기반 동적 cap (VIX>25 → 50%) | OOS 안정성 | 레짐 적응 확인 |

**(d) PASS 조건**
```
MDD < 0.22 AND OOS Mean > 1.5 (둘 중 하나 cap 선택)
```

- Look-ahead bias (미래 S&P500 편입 종목으로 백테스트) 가능성

**(b) 위험/부작용**

- Point-in-time 데이터 구축 비용

**(c) 최소 실험**

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 5-1 | 현재 유니버스 종목 리스트 + 선정일 명시 | 문서화 | 기준선 확보 |

**(d) PASS 조건**

유니버스 선정 기준 문서화 AND 생존자 필터 후 OOS Mean > 1.6
