### 2) 48시간 자동 루프 실행 계획 (Actionable Experiments)

**공통 전제**: US Tech/Healthcare (XLK, XLV 구성 종목 중 선별), ETF 매매 금지.

#### 실험 A: `FIX_DEGENERATE_REG` (모델 안정성 확보)
*   **정의**: 기존 모델 파라미터에서 Regularization penalty를 0.01 -> 0.1로 상향 조정하고, Outlier Clipping(z-score > 3.0 제거) 적용.
*   **게이트 (조건)**:
    1.  `degenerate_folds` 리스트가 비어있거나 1개 이하일 것.
    2.  OOS Mean > 1.5 (기존 3.32보다 낮아도 용인).
*   **기대 관측치**: Fold별 성과 편차(Std Dev across folds) 감소. 1, 2, 3, 8번 Fold의 정상화.

#### 실험 B: `COST_REALITY_CHECK` (비용 현실화)
*   **정의**: 매수/매도 시그널 발생 시, *Entry Price*를 `Close * 1.001`, *Exit Price*를 `Close * 0.999` (합계 20bps 패널티)로 백테스트 재구동.
*   **게이트 (조건)**:
    1.  `worst_mdd`가 `None`이 아니고 -0.3 (-30%) 이내일 것.
    2.  Sharpe Ratio > 1.2 유지.
*   **기대 관측치**: 거래 횟수(Turnover)가 높은 전략일수록 성과 급락 확인. 실제 운용 가능한 수익 곡선 도출.

#### 실험 C: `VIX_FILTER_GATE` (레짐 필터링)
*   **정의**: VIX ETF(VIXY 등) 또는 지수 데이터를 관측지표로만 사용. VIX > 30 구간에서는 신규 진입 금지(Cash 100%).
*   **게이트 (조건)**:
    1.  MDD 개선(절대값 감소).
    2.  `exposure_max`는 변동 없으나 `exposure_avg` 감소.
*   **기대 관측치**: 하락장(Fold 1, 2, 3 추정)에서의 방어력 상승 여부 확인.

### 3) 성능이 안 움직일 때(Stagnation) 원인 분해 아이디어

성능 지표(OOS Mean)가 특정 구간에 갇혀 변하지 않을 경우, 다음 순서로 디버깅:

1.  **트리거(Trigger) 불감증**:
    *   시그널 임계값(Threshold)이 너무 높아(예: 0.9) 매매가 거의 없는지 확인.
    *   *Check*: `Trade Count`가 0이거나 매우 낮은지 로그 확인.

2.  **노출(Exposure) 왜곡**:
    *   포트폴리오 비중이 특정 1~2개 종목(예: AAPL, NVDA)에만 쏠려 전체 성과를 지배하는지 확인.
    *   *Check*: HHI(허핀달 지수) 또는 종목별 기여도 분해.

3.  **데이터 누수(Look-ahead Bias)로 인한 고정**:
    *   미래 데이터를 참조하여 항상 '정답'에 가까운 포지션을 잡고 있어, 파라미터를 바꿔도 결과가 비슷하게(비정상적으로 좋게) 나오는지 의심.
    *   *Check*: 피처 생성 시점의 `shift` 여부 재검토.

4.  **비용(Cost) 잠식**:
    *   알파는 생성되나, 잦은 리밸런싱 비용이 이를 정확히 상쇄하고 있는지 확인.
    *   *Check*: `Gross Return` vs `Net Return` 스프레드 확인.

5.  **레짐(Regime) 불일치**:
    *   현재 전략이 'Trend Following'인데, 테스트 구간이 'Mean Reversion' 시장인지.
    *   *Check*: 벤치마크(QQQ/XLV) 대비 상관계수(Correlation) 변화 추이 확인.
