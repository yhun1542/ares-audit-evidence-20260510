## 2. 성능이 안 움직일 때 — 원인 분해 트리

```
Delta ≈ 0 ?
│
├─[1] 트리거 문제
│   └─ 신호가 발생 안 함 → signal_count == 0?
│   └─ 조건이 너무 tight → trigger_rate < 5%?
│
├─[2] 적용 문제  
│   └─ 신호 있으나 포지션 미반영 → position_change == 0?
│   └─ 리밸런스 로직 버그 → rebalance.csv 비어있음
│
├─[3] 노출 문제
│   └─ exposure 변화 없음 → exp_min ≈ exp_max?
│   └─ 헷지가 상쇄 → net_exposure ≈ 0?
│
├─[4] 비용 문제
│   └─ 턴오버 높아서 비용이 alpha 상쇄
│   └─ turnover * cost > gross_alpha
│
└─[5] 레짐 문제
    └─ 테스트 기간이 flat market → beta ≈ 0
    └─ 특정 regime에서만 작동 → regime_split 필요
```
