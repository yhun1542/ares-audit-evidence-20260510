### 2. 성능 정체(No-Delta) 원인 분해 및 대응

성능이 움직이지 않거나(Flat), 진단기가 "No Delta"를 뱉는 경우 다음 트리를 점검하십시오.

1.  **트리거 불발 (Trigger Failure)**
    *   *원인:* 진입 조건(Threshold)이 너무 높아 아무 종목도 매수되지 않음.
    *   *확인:* `rebalance` 로그(복구 후)에서 `orders_count`가 0인지 확인.
    *   *대응:* 진입 임계값(Threshold)을 0.5배로 낮춰 민감도 테스트.

2.  **포지션 고착 (Position Stagnation)**
    *   *원인:* 매도(Exit) 로직이 작동하지 않아, 한 번 산 주식을 끝까지 들고 감 (Buy & Hold와 동일).
    *   *확인:* 평균 보유 기간(Avg Holding Period) > 60일 이상인지 확인.
    *   *대응:* `Time_Stop`(n일 후 강제 청산) 로직 추가 (예: 20일).

3.  **데이터 무결성 (Data Integrity)**
    *   *원인:* 특정 기간(2025-2026) 데이터가 결측되어 신호가 생성되지 않음.
    *   *확인:* 입력 OHLCV 데이터의 `NaN` 비율 점검.
    *   *대응:* 결측치 구간을 `ffill` 처리하거나 해당 구간 거래 정지 로직 확인.

4.  **비용 잠식 (Cost Erosion)**
    *   *원인:* 잦은 매매로 인한 비용이 수익을 정확히 0으로 수렴시킴.
    *   *확인:* Gross Profit vs Net Profit 괴리율 확인.
    *   *대응:* 최소 기대 수익률(Min Profit Target) 미달 시 진입 금지 필터 적용.
