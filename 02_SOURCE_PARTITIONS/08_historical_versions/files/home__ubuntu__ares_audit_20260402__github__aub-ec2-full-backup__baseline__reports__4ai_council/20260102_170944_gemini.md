[우선순위 TOP 5 제안: 48시간 루프]

### 1. Degenerate Folds(1,2,3,8) 원인 규명 및 데이터 무결성 Patch
*   **이유:** `degenerate_folds`가 4개나 존재한다는 것은 전체 기간의 약 40%에서 전략이 작동하지 않았거나(Flat), 데이터가 없거나, 즉시 파산했음을 의미. 현재의 OOS Mean 3.32는 왜곡되었을 가능성이 매우 높음(생존 편향). `MDD: None` 역시 계산 로직 붕괴를 시사.
*   **위험:** 버그 수정 시 OOS Mean이 급격히 하락할 수 있음(현실화).
*   **실험:**
    1.  **[EXP-01] Fill-Method Fix:** 결측치 처리 방식을 `ffill` 혹은 `drop`으로 명시적 변경 후 Fold 재실행.
    2.  **[EXP-02] Min-Obs Constraint:** 각 Fold 별 최소 거래 가능 종목 수(예: 8개)가 확보되지 않으면 Cash 100%로 강제하는 로직 추가.
    3.  **[EXP-03] MDD Calculator Debug:** 수익률 시계열의 `NaN/Inf`를 0.0으로 치환 후 MDD 계산 로직 재적용.
*   **PASS 조건:** `degenerate_folds` 개수 = 0, `MDD` 값이 유효한 숫자로 도출.

### 2. Rebalance Logger 복구 및 비용 민감도 테스트
*   **이유:** `Error loading ... rebalance.csv` 오류 발생. 실제 회전율(Turnover)과 비용이 반영되지 않은 상태에서 Tech/Bio 종목의 높은 변동성만 취했을 가능성. 2026년 시점의 슬리피지는 과거보다 높게 설정해야 함.
*   **위험:** 로그 복구 후 과도한 비용으로 인해 샤프지수가 음수로 전환될 수 있음.
*   **실험:**
    1.  **[EXP-04] Jsonl Logger Fix:** `rebalance.jsonl` 기록 포맷을 표준 JSON으로 강제하고 Flushing 주기 단축.
    2.  **[EXP-05] High Cost Stress:** 편도 비용을 10bps -> 20bps로 2배 상향 설정 후 백테스트.
*   **PASS 조건:** 로그 파일 정상 생성 AND 비용 2배 적용 시 OOS Mean > 1.5 유지.

### 3. Tech/Healthcare 섹터 밸런싱 강제 (Correlation Break)
*   **이유:** 8~14개 종목이 모멘텀에 따라 Tech로만 쏠릴 경우(Over-concentration), 기술주 조정기에 MDD 방어 불가. ETF(XLV, XLK)를 관측 지표로 사용하여 비중 강제.
*   **위험:** 강력한 모멘텀(Tech Bull) 구간에서 수익률 캡이 씌워질 수 있음.
*   **실험:**
    1.  **[EXP-06] Sector Quota:** 포트폴리오 내 Healthcare(XLV 유니버스) 비중 최소 30% 강제 할당.
    2.  **[EXP-07] Volatility Targeting:** XLK(Tech)의 변동성이 XLV(Health)의 1.5배를 초과하면 Tech 비중 10% 축소.
*   **PASS 조건:** 전체 기간 MDD 5%p 개선(감소) AND OOS Mean 하락폭 10% 이내.

### 4. 동적 노출도(Exposure) 제어: Regime Filter 적용
*   **이유:** 현재 `exposure_max: 0.83`이나 `oos_min: -0.02`로 하방이 뚫려있음. 하락장(Bear Regime)에서 노출도를 0.0에 가깝게 줄이는 로직 필요.
*   **위험:** 휩소(Whipsaw) 장세에서 잦은 진입/청산으로 손실 누적.
*   **실험:**
    1.  **[EXP-08] SPY MA Filter:** SPY(관측용)가 200일선 하회 시 전체 Exposure Max를 0.4로 제한.
    2.  **[EXP-09] VIX Gate:** VIX(혹은 파생 지표)가 상위 80분위수 이상일 때 신규 진입 금지.
*   **PASS 조건:** `oos_min` > -0.015 (손실폭 축소) AND 거래 횟수 20% 이상 감소 방지.

### 5. 유니버스 생존 편향 제거 (Survivor Check)
*   **이유:** 2026년 기준 시가총액 상위 종목을 2020년 데이터에 적용했을 가능성(Look-ahead Bias). Tech/Bio는 상장폐지나 M&A가 빈번함.
*   **위험:** 유니버스 축소로 인해 분산 효과 감소.
*   **실험:**
    1.  **[EXP-10] Point-in-Time Universe:** 매 월초 기준 시가총액/거래량 상위 종목을 동적으로 재선정(고정 리스트 사용 금지).
*   **PASS 조건:** OOS Mean이 기존 대비 70% 이상 유지될 것 (급락 시 기존 성과는 거짓임).

### [성능 정체 시 원인 분해 (Diagnosis Logic)]

1.  **트리거(Trigger) 부재:**
    *   *현상:* 포지션 진입이 거의 없음.
    *   *체크:* 진입 임계값(Threshold)이 최근 낮아진 변동성 대비 너무 높은지 확인. (Tech/Bio 변동성 축소 구간인지?)
2.  **노출(Exposure) 제약:**
    *   *현상:* 신호는 강한데 수익이 작음.
    *   *체크:* `exposure_max` (현재 0.83) 또는 개별 종목 가중치 한도(Weight Cap)에 걸려 알파가 잘리는지 확인.
3.  **비용(Cost) 잠식:**
    *   *현상:* Gross Return은 좋으나 Net Return이 Flat/Down.
    *   *체크:* 평균 보유 기간(Holding Period)이 너무 짧아(예: < 3일) 슬리피지가 수익을 상쇄하는지 확인.
4.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 Fold에서만 성능이 급락.
    *   *체크:* 해당 기간 ETF(QQQ, XLV)와 전략 간의 상관계수(Beta)가 음수로 역전되었는지 확인. (추세 추종인데 횡보장인지)
