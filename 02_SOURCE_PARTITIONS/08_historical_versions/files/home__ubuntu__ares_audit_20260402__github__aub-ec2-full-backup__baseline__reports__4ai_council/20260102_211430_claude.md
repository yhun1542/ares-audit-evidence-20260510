## 성능 미변동 시 원인 분해 트리

```
Performance Δ = 0 일 때 체크 순서:

1. TRIGGER (신호 생성)
   └─ 신호 분포 변화 있나? → histogram diff
   └─ 새 feature가 기존과 상관 0.95+? → redundancy
   
2. APPLICATION (신호 → 포지션)
   └─ position sizing 로직이 신호 무시? → signal vs weight scatter
   └─ rebalance 주기 내 신호 소멸? → signal decay 분석

3. EXPOSURE (포지션 → 시장 노출)
   └─ max_exposure cap에 걸림? → cap hit frequency
   └─ sector 제한으로 실행 안됨? → blocked trades log

4. COST (실행 비용)
   └─ turnover 증가 = 비용 상쇄? → turnover vs return scatter
   └─ bid-ask spread 과소평가? → liquidity 필터 점검

5. REGIME (시장 환경)
   └─ 테스트 기간이 flat market? → SPY 수익률 체크
   └─ factor rotation 발생? → momentum/value/quality 성과 비교
```
