## 1. 우선순위 TOP-5 패치

### P1. Degenerate Fold 원인 분해
```
WHY: 4/10 fold 붕괴 = 과최적화 또는 레짐 미스매치 강력 신호
RISK: 원인 오진 시 잘못된 방향 수정 → 전체 붕괴
```

| 실험 ID | 정의 | Gate (PASS 조건) | 기대 관측치 |
|---------|------|------------------|-------------|
| `P1-A` | Degenerate fold 기간 추출 → 시장 레짐 태깅 (VIX>25, SPY DD>10%, 금리급등) | 4개 fold 중 3개 이상 동일 레짐 클러스터 | 레짐 상관 >0.7 → 레짐필터 도입 |
| `P1-B` | Fold별 feature importance diff 산출 | 정상 fold vs 붕괴 fold 상위3 feature 겹침 <50% | 특정 feature 과의존 식별 |
| `P1-C` | Degenerate fold 제외 후 OOS 재산출 (sanity check only) | OOS mean >4.0 이면 레짐 문제, <3.5면 구조 문제 | 원인 분기점 확정 |

### P2. Rebalance 파이프라인 복구
```
WHY: 비용 미반영 시 실제 수익률 과대추정 (치명적 누수)
RISK: 파싱 오류 원인이 코드 vs 데이터 미생성 불명확
```

| 실험 ID | 정의 | Gate | 기대 관측치 |
|---------|------|------|-------------|
| `P2-A` | `rebalance.csv` 파일 존재 및 포맷 검증 스크립트 | 파일 존재 + 헤더 정상 + row >100 | 존재 시 파싱 버그, 미존재 시 생성 버그 |
| `P2-B` | Backtest 로그에서 turnover/슬리피지 raw 추출 | 월평균 turnover 산출 가능 | 20% 이상이면 비용 impact 재계산 필수 |

|---------|------|------|-------------|

| `P3-B` | 기존 MDD 계산 함수 로그 추가 후 재실행 | 에러 메시지 또는 정상 값 | 버그 위치 특정 |

### P4. Zero-Exposure 구간 분석
```
WHY: Exposure 0% = 시그널 완전 사망, 시장 상승 시 기회비용 발생
RISK: 과도한 시그널 완화 시 노이즈 진입 증가
```

| 실험 ID | 정의 | Gate | 기대 관측치 |
|---------|------|------|-------------|
| `P4-A` | Exposure=0 기간 추출 → 해당 기간 SPY 수익률 | SPY >5% 구간 비중 | >30%면 Cash drag 문제 |
| `P4-B` | Entry threshold 10% 완화 실험 | OOS mean 유지 + degenerate fold 증가 없음 | Exposure min >5% |

## 2. 성능 미이동 원인 분해 프레임워크

```
성능 Δ = 0 일 때 원인 트리:

[1] 트리거 문제
    └─ 시그널 자체가 안 바뀜 (threshold 너무 높음)
    └─ 실험 파라미터 변화량 < 노이즈
    
[2] 적용 문제  
    └─ 코드 버그로 파라미터 미반영
    └─ Config override 실패
    
[3] 노출 문제
    └─ Position sizing이 변화 흡수
    └─ Max exposure cap에 걸림
    
[4] 비용 문제
    └─ Turnover 증가 → 수익 상쇄
    └─ 슬리피지 모델 미반영
    
[5] 레짐 문제
    └─ 실험 기간이 특정 레짐에 편중
    └─ OOS 기간 레짐 ≠ 학습 기간 레짐
```

**자동 진단 체크리스트:**
```
□ param_diff.json 확인 → 파라미터 실제 변경 여부
□ signal_diff 통계 → before/after 시그널 분포
□ trade_count 비교 → 거래 빈도 변화
□ exposure 히스토그램 → 분포 이동 여부
□ fold별 분해 → 특정 fold에서만 변화 여부
```

  --base-log baseline/reports/run_champion_v5_20251231/rebalance.csv \
  --cand-log baseline/reports/run_champion_v5_20251231/rebalance.csv

# [P3-A] Equity curve에서 MDD 추출
python3 -c "
import json
import numpy as np
with open('baseline/champion_v5_latest.json') as f:
    d = json.load(f)
eq = np.array(d.get('equity_curve', d.get('oos_equity', [])))
if len(eq) > 0:
    peak = np.maximum.accumulate(eq)
    dd = (peak - eq) / peak
    print(f'MDD: {dd.max()*100:.2f}%')
else:
    print('No equity curve found')
"
