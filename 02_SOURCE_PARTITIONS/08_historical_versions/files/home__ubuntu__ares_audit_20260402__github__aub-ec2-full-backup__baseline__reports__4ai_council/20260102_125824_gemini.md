[성능 정체 시 원인 분해 트리거]

성능(Sharpe/MDD)이 개선되지 않고 제자리걸음일 경우, 다음 5가지 차원에서 디버깅하십시오.

1.  **Trigger (진입 신호):**
    *   *현상:* 신호가 너무 적거나(과소), 노이즈에 다 반응함(과다).
    *   *액션:* 시그널 임계값(Threshold)을 고정값이 아닌 `Rolling z-score`로 변경.

2.  **Apply (실행/비중):**
    *   *현상:* 승률은 높은데 계좌가 안 불어남.
    *   *액션:* 켈리 베팅(Kelly Criterion) 비율을 0.3~0.5배로 적용하여 "이길 때 크게" 먹는지 확인.

3.  **Exposure (시장 노출):**
    *   *현상:* 시장 하락 시 같이 무너짐 (Alpha가 아닌 Beta 플레이 중).
    *   *액션:* `Market Neutral` 모드로 전환(ETF 숏 헤지 가상 적용) 시 잔여 Alpha가 양수인지 확인.

4.  **Cost (비용 민감도):**
    *   *현상:* Gross Return은 좋은데 Net Return이 나쁨.
    *   *액션:* 진입 횟수를 강제로 1/2로 줄이는 `Cooldown` 기간(예: 매도 후 3일 진입 금지) 적용.

5.  **Regime (시장 국면):**
    *   *현상:* 2022년(하락장)과 2023년(상승장) 성과 차이가 극심함.
