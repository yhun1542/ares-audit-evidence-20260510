## 1. 우선순위 TOP 5 액션

### ━━━ P1: Degenerate Fold 원인 분해 ━━━

**(a) 왜 필요한지**
- 4/10 폴드가 degenerate = 40%에서 전략이 무의미
- 이 상태로 OOS 평균 신뢰 불가

**(b) 위험/부작용**
- 분석만으로 시간 소모, 즉각 개선 없음
- 폴드별 분리 시 데이터 스누핑 위험

**(c) 실험 체크리스트**

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P1-A | `fold_anatomy.py`: 폴드별 레짐(VIX, 금리, 섹터모멘텀) 라벨링 | 완료 | 폴드1,2,3,8 공통 레짐 식별 |
| P1-B | 해당 폴드만 IS에서 제외하고 재학습 | OOS mean ≥ 2.0 & degen ≤ 2 | 일반화 개선 확인 |
| P1-C | 폴드별 exposure 분포 히스토그램 | 완료 | degen 폴드가 저노출인지 확인 |

**(d) PASS 조건**
```
degenerate_folds ≤ 2 AND oos_min > -0.01
```

### ━━━ P2: MDD 계산 파이프라인 복구 ━━━

**(a) 왜 필요한지**
- worst_mdd=None → 리스크 게이트 작동 불가
- 실제 운용 시 드로다운 제한 불가능

**(b) 위험/부작용**
- 버그 수정 시 기존 결과 무효화 가능
- MDD 계산 정의 불일치 (일간 vs 주간)

**(c) 실험 체크리스트**

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P2-A | `backtest_engine.py` MDD 계산 로직 trace | 버그 위치 식별 | None 반환 지점 |
| P2-B | 수동 MDD 계산 스크립트로 교차검증 | 오차 < 1bp | 일치 확인 |
| P2-C | 패치 후 champion 재실행 | worst_mdd 출력 | 수치 확보 (기대: -8% ~ -15%) |

**(d) PASS 조건**
```
worst_mdd IS NOT NULL AND worst_mdd > -0.20
```

**(c) 실험 체크리스트**
