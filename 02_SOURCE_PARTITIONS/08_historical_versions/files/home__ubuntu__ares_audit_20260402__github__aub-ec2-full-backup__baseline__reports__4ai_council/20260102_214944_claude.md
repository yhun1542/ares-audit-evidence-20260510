### 2️⃣ [LEAK] Degenerate Fold 원인 분리

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | 50% fold 퇴화 = 전략이 특정 레짐에서만 작동 or 룩어헤드 누수 |
| **(b) 위험** | 퇴화 원인이 "실제 레짐 의존"이면 전략 자체 재검토 필요 |
| **(c) 실험** | 아래 참조 |
| **(d) PASS** | 퇴화 fold ≤ 1개 OR 퇴화 원인 명확히 문서화 |

```yaml
EXP-2A: fold_regime_label
  - 정의: 각 fold 기간에 VIX/SPY 레짐 태깅 (bull/bear/chop)
  - 게이트: 퇴화 fold가 특정 레짐에 집중되는지 확인
  - 기대: fold 1,2,3,8 공통 패턴 발견

EXP-2B: purge_embargo_audit
  - 정의: fold 경계에서 purge=5d, embargo=2d 적용 여부 검증
  - 게이트: 코드 내 cv splitter 로직 확인
  - 기대: 누수 발견 시 즉시 패치

EXP-2C: degenerate_threshold_sensitivity
  - 정의: 현재 퇴화 판정 기준(exposure<0.05? return<0?) 명시
  - 게이트: 기준 완화 시 퇴화 fold 수 변화
  - 기대: 기준 문서화 완료
```

## 48H 자동 루프 YAML

```yaml
# aub_48h_loop.yaml
experiments:
  - id: EXP-1A
    cmd: "python3 tools/fix_rebalance_logger.py"
    gate: "ls -la reports/*/rebalance.jsonl | wc -l >= 8"
    timeout: 2h
    
  - id: EXP-2A  
    cmd: "python3 tools/fold_regime_tagger.py --folds 1,2,3,8"
    gate: "cat reports/regime_tags.json | jq '.common_pattern != null'"
    timeout: 1h
    
  - id: EXP-3A
    cmd: "python3 backtest.py --cost-bps 10 --commission 1"
    gate: "abs(new_oos - old_oos) / old_oos < 0.05"
    timeout: 4h
    
  - id: EXP-4A
    cmd: "python3 backtest.py --min-exposure 0.20"
    gate: "degenerate_folds <= 2 && worst_mdd < 0.25"
    timeout: 4h

  - id: EXP-5A
    cmd: "python3 tools/survivorship_audit.py --asof 2020-01-01"
    gate: "pool_diff_pct < 0.20"
    timeout: 1h

abort_conditions:
  - "any experiment worst_mdd > 0.35"
  - "oos_mean < 1.5 for 2 consecutive runs"
```
