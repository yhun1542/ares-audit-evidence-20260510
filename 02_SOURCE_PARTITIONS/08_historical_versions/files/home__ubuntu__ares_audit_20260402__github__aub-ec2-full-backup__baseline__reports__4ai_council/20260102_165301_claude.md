## 3. 성능 미변동 시 원인 분해 트리

```
OOS Mean 변화 없음
├─ 트리거 미발화
│   ├─ 시그널 threshold 너무 높음 → exposure 로그 확인
│   └─ 데이터 지연/누락 → raw data freshness 체크
├─ 포지션 적용 실패
│   ├─ 리밸런스 로직 버그 → rebalance diff
│   └─ 최대 종목 수 제한 hitting → position_count 히스토그램
├─ 노출(exposure) 희석
│   ├─ 헷지 비율 과다 (hedge_ratio > 0.3) → config 확인
│   └─ 현금 비중 고정 → cash_weight 로그
├─ 비용 상쇄
│   ├─ 턴오버 폭발 → turnover % 시계열
│   └─ 슬리피지 가정 비현실 → fill-rate 시뮬
└─ 레짐 불일치
    ├─ 훈련 기간 bull-only → fold별 regime label
    └─ OOS 기간 특이 이벤트 → VIX spike overlay
```
