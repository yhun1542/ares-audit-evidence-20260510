## 3. 성능 미변동 시 원인 분해 트리

```
OOS Mean 변화 없음
│
├─▶ [1] 트리거 실패
│   └─ 시그널이 threshold 미달 → signal coverage < 30%
│      → 진단: fold별 active_days / total_days 비율
│
├─▶ [2] 적용 실패  
│   └─ 시그널 발생했으나 포지션 미생성 → min_position 필터
│      → 진단: signal_fired vs position_opened 카운트
│
├─▶ [3] 노출 부족
│   └─ 포지션 있으나 exposure < 0.1 → 스케일링 과소
│      → 진단: exposure_mean per fold
│
├─▶ [4] 비용 상쇄
│   └─ 수익 발생했으나 거래비용이 흡수 → turnover 과다
│      → 진단: gross_return vs net_return 비교
│
└─▶ [5] 레짐 미스매치
    └─ 특정 시장 국면에서만 작동 → fold간 분산 과다
       → 진단: oos_std / oos_mean > 0.5 여부
```
