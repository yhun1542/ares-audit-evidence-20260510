## 1. 우선순위 TOP 5 실험 제안

### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### P1. Tuning-Lockbox Gap 누수 점검
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한가**
- Champion tuning→lockbox 드롭: 1.90 → 1.79 (6% 감소)
- 그러나 Candidate는 1.37 → 1.52 (11% **증가**) ← 역전 현상 = 데이터 경계 오염 가능성

**(b) 위험/부작용**
- False positive: 실제 정상인데 구조 변경 유발
- 점검 비용 1-2시간 소요

**(c) 최소 실험**

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P1-A | fold 경계 ±5일 수익률 분포 비교 | `abs(mean_diff) < 0.05` | 경계 누수 없으면 분포 동질 |
| P1-B | Champion 파라미터로 lockbox 단독 재실행 (seed 3개) | `std(returns) < 0.15` | 높으면 우연 의존 |
| P1-C | Feature 생성 시점 timestamp 로그 audit | 미래 참조 0건 | 1건이라도 있으면 FAIL |

**(d) PASS 조건**
```
P1-A 통과 AND P1-B 통과 AND P1-C = 0건
→ 누수 없음 확정, 다음 단계 진행
```

### P2. MDD 개선이 수익을 죽이는 구조 분해
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한가**
- Candidate: MDD -4.2% (우수) but 수익 1.37 (열등)
- 리스크 제어가 과도하게 진입 억제 → 기회비용 발생 의심

**(b) 위험/부작용**
- MDD 제약 완화 시 테일 리스크 재노출
- 2022-type 하락장에서 큰 손실 가능

**(c) 최소 실험**

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P2-A | Candidate의 "진입 스킵" 로그 추출 → 스킵된 날의 실제 수익 시뮬 | `skipped_return_mean > 0.002` | 기회비용 정량화 |
| P2-B | MDD 한도 -6% → -7% 로 1%p 완화 후 재실행 | `lockbox_mean > 1.45 AND mdd < -7.5%` | 수익 회복 폭 관측 |
| P2-C | 변동성 레짐별 MDD 한도 차등 적용 (VIX<20: -8%, VIX≥20: -5%) | `레짐별 수익 분산 감소` | 적응형 효과 검증 |

**(d) PASS 조건**
```
P2-B에서 lockbox_mean ≥ 1.55 AND worst_mdd ≤ -7.5%
→ MDD+수익 균형점 발견
```

### P3. Fold14 단독 분석 (Survivorship 체크)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한가**
- Champion fold14_mdd = -9.3% (worst_mdd와 동일)
- 최근 fold가 최악 = 전략 열화 or 시장 레짐 변화

**(b) 위험/부작용**
- Fold14만 튜닝하면 레짐 과적합
- 최근 데이터 과신

**(c) 최소 실험**

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P3-A | Fold14 기간 종목별 성과 분해 (섹터/개별) | 상위3 종목 기여도 < 60% | 집중 리스크 확인 |
| P3-B | Fold14 기간 vs 전체 기간 팩터 노출 비교 | `abs(factor_drift) < 0.3` | 팩터 로테이션 감지 |
| P3-C | Fold14에서 상장폐지/대규모 하락 종목 존재 여부 | 0건 | Survivorship bias 배제 |

**(d) PASS 조건**
```
P3-A 통과 AND P3-C = 0건
→ Fold14 문제는 레짐 문제, 구조 결함 아님
```

    ├─ VIX/금리/섹터로테이션 시계열과 수익 상관분석
    └─ 실험: 레짐 필터 ON/OFF 비교
