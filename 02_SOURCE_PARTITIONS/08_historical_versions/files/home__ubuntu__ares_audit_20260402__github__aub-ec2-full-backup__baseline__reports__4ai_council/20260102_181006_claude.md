## 3. 48시간 자동 루프 스펙

```yaml
LOOP_CYCLE:
  hour_0-8:
    - run: EXP-1A, EXP-1B, EXP-1C (fold 감사)
    - gate: 누수 없음 확인
    - fail_action: STOP, alert "Data Leak Detected"

  hour_8-16:
    - run: EXP-3A, EXP-3B (비용 분석)
    - gate: 20bp 기준 통과
    - fail_action: 비용 파라미터 조정 후 재실행

  hour_16-32:
    - run: EXP-2A, EXP-2B (MDD 개선)
    - gate: worst_mdd ≤ -0.08
    - fail_action: position cap 10% 단위 강화

  hour_32-48:
    - run: EXP-4A, EXP-5A (관측 실험)
    - gate: 데이터 수집 완료
    - fail_action: N/A (관측만)

OUTPUT:
  - next_handoff.json
  - experiment_results/YYYYMMDD_HHMMSS/
  - PASS/FAIL 요약 1-pager
```
