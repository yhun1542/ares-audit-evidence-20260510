## 2. 성능 정체 원인 분해 프레임워크

```
성능 = 트리거 × 적용률 × 노출 × (수익 - 비용) × 레짐적합도
```

| 구성요소 | 점검 질문 | 측정 방법 |
|----------|-----------|-----------|
| **트리거** | 시그널이 발생하는가? | 일평균 시그널 수 |
| **적용률** | 시그널이 실제 거래로 전환되는가? | 시그널 → 주문 전환율 |
| **노출** | 포지션 사이즈가 충분한가? | 평균 노출 % |
| **비용** | 숨겨진 비용이 수익을 상쇄하는가? | gross vs net 수익 gap |
| **레짐** | 현재 시장이 전략에 적합한가? | regime별 sharpe 분산 |

### 정체 시 자동 분기 로직
```
IF 트리거 부족 → 시그널 threshold 완화 실험
IF 적용률 낮음 → 필터 조건 점검
IF 노출 부족 → sizing 로직 점검  
IF 비용 과다 → 거래 빈도 축소 실험
IF 레짐 부적합 → 방어 모드 전환 검토
```
