## 🔬 성능 불변 시 원인 분해 트리

```
성능 Δ = 0 일 때 체크 순서:

1. 트리거 (Signal Fire)
   └─ 시그널이 실제로 발생했는가?
   └─ 체크: signal_count, entry_trigger_log
   └─ 의심: 필터 과잉, 임계값 과다

2. 적용 (Order Execution)  
   └─ 시그널 → 실제 포지션 전환 됐는가?
   └─ 체크: rebalance.jsonl 존재 여부
   └─ 의심: 최소 거래 금액, 리밸런스 쿨다운

3. 노출 (Exposure Realization)
   └─ 포지션 크기가 의도대로인가?
   └─ 체크: exposure_min/max, position_size_log
   └─ 의심: 리스크 스케일러 과잉 축소

4. 비용 (Cost Leakage)
   └─ 수익이 비용에 잠식되는가?
   └─ 체크: gross_return vs net_return 갭
   └─ 의심: 회전율 과다, 슬리피지 과소추정

5. 레짐 (Regime Mismatch)
   └─ 현재 시장이 전략 유효 레짐인가?
   └─ 체크: VIX > 25, SPY 200MA 하회 여부
   └─ 의심: 전략이 특정 레짐에만 작동
```
