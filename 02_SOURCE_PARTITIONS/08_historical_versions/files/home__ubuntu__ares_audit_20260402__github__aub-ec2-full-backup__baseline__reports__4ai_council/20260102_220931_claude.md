### P1. 측정 인프라 복구 — "눈부터 고쳐라"

**(a) 왜 필요한지**
- MDD=None → 리스크 게이트 작동 불가
- rebalance.csv 파싱 실패 → 원인 분해 불가
- OOS 값 불일치 (3.32 vs 2.63) → 어느 게 진짜?

**(b) 위험/부작용**
- 인프라 작업 중 실험 중단 (24h 손실)
- 과거 로그 포맷 호환성 깨질 수 있음

**(c) 최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **INF-1** | `backtest_engine.py`에 MDD 계산 로직 추가 + JSON 출력 | 모든 fold에 `worst_mdd` 필드 존재 | MDD ∈ [-0.5, 0] |
| **INF-2** | rebalance 로그를 `.jsonl` 단일 포맷으로 통일, 파서 수정 | `aub_rebalance_pinpoint.py` 정상 실행 | diff 리포트 생성 |
| **INF-3** | ONE_TRUTH 생성 시점에 OOS 값 소스 명시 (`raw_fold_values[]`) | 값 역추적 가능 | mean(raw) == oos_mean |

**(d) PASS 조건**
```
✅ worst_mdd != None
✅ rebalance_pinpoint.md 정상 생성
✅ OOS 불일치 원인 문서화
```

### P2. Degenerate Fold 원인 분해 — "4/10 퇴화는 전략 문제"

**(a) 왜 필요한지**
- Fold 1,2,3,8 퇴화 = 특정 시장 레짐에서 전략 무력화
- 이걸 고치지 않으면 OOS 개선해도 실전 붕괴

**(b) 위험/부작용**
- 레짐 필터 추가 시 → 노출 감소 → 수익 하락
- 과도한 조건 분기 → 과최적화 악화

**(c) 최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **DEG-1** | 퇴화 fold의 시장 특성 추출 (VIX 평균, 섹터 수익률, 금리 방향) | 리포트 생성 | 공통 패턴 1개 이상 식별 |
| **DEG-2** | 해당 레짐에서 signal 강도 분포 vs 정상 fold 비교 | t-test p<0.05 | signal 분포 차이 확인 |
| **DEG-3** | 레짐 필터 (e.g., VIX>25 시 position scale 50%) 적용 백테스트 | degenerate fold ≤ 2개 | OOS 하락 < 15% |

**(d) PASS 조건**
```
✅ degenerate_folds 수 4 → 2 이하
✅ OOS mean 하락폭 < 0.5
```

**(b) 위험/부작용**
- 비용 반영 시 전략 수익 급락 → 심리적 충격
- 과도한 비용 가정 → 유효 전략 폐기

**(c) 최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **COST-1** | 슬리피지 10bp 고정 적용 | OOS 재계산 | 하락폭 기록 |
| **COST-2** | 종목별 ADV 기반 동적 슬리피지 (ADV<1M → 30bp, else 5bp) | OOS 재계산 | 소형주 비중 감소 확인 |

**(d) PASS 조건**
```
✅ 비용 반영 OOS > 1.5 (최소 수익성)

```

### P4. 시그널 품질 점검 — "쓰레기 in = 쓰레기 out"

**(a) 왜 필요한지**
- 성능 불변 시 가장 흔한 원인 = 시그널 자체가 무의미
- Look-ahead bias 가능성 점검 필요

**(b) 위험/부작용**
- 시그널 교체 시 전체 파이프라인 재작업
- 과거 실험 비교 불가

**(c) 최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **SIG-1** | 시그널 생성 시점 vs 사용 시점 timestamp 검증 | gap ≥ 1 영업일 | look-ahead 없음 확인 |
| **SIG-2** | 시그널 → 익일 수익률 상관계수 (단순 IC) | IC > 0.02 | 예측력 존재 확인 |
| **SIG-3** | 랜덤 시그널 대조군 백테스트 | 챔피언 OOS > 랜덤 OOS × 1.5 | 시그널 유의미 |

**(d) PASS 조건**
```
✅ look-ahead bias 없음
✅ IC > 0.02 or 랜덤 대비 1.5배
```
