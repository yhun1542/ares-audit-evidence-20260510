## 2. 성능 정체 원인 분해 (5-Layer Decomposition)

```
성능 = f(트리거) × f(적용) × f(노출) × f(비용) × f(레짐)
```

| Layer | 점검 질문 | 진단 방법 |
|-------|----------|----------|
| **트리거** | 시그널이 충분히 발생하는가? | 월별 시그널 발생 횟수 히스토그램 |
| **적용** | 시그널 발생 후 실제 포지션 변화가 있는가? | 시그널 → 체결 매핑률 |
| **노출** | 포지션 사이즈가 의미 있는 수준인가? | 평균 포지션 크기 / 전체 자본 |
| **비용** | 거래당 손실이 수익을 잠식하는가? | gross return - net return gap |
| **레짐** | 특정 시장 환경에서만 작동하는가? | Bull/Bear/Sideways 별 샤프 분해 |
