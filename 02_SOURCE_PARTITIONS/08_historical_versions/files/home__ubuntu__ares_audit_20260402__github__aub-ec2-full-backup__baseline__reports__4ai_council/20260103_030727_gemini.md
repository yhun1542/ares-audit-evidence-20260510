### 1. 24~48시간 우선순위 TOP 3 제안 (Action Checklist)

#### **Proposal A: Champion Leakage/Cost Stress Test (거품 제거)**
*   **필요성:** Tuning(2.3) vs Lockbox(4.0)의 괴리는 일반적이지 않음. 체결 지연(Lag)이나 거래 비용이 과소평가되었을 가능성 99%.
*   **위험:** 성능 지표가 급락하여 Champion 폐기 수순으로 갈 수 있음(그러나 이는 운영 리스크 방지를 위해 필수).
*   **실험 정의:**
    1.  `EXP_A1`: 매매 신호 발생 후 **1일 지연(T+1 Open)** 체결 강제.
    2.  `EXP_A2`: 왕복 슬리피지를 현재 설정의 **3배(예: 5bps -> 15bps)**로 적용.
    3.  `EXP_A3`: 조정된 종가(Adj Close) 사용 시 배당락일 데이터 정합성 재검증.
*   **PASS 조건:**
    *   Lockbox Sharpe > 1.5 유지.
    *   Tuning Min > -0.1 (손실폭이 감내 가능한 수준일 것).
*   **기대 관측치:** Lockbox 성능이 2.5~3.0 수준으로 하락하며 현실화됨.

#### **Proposal B: Dynamic Volatility Shield (하방 방어)**
*   **필요성:** Champion의 `Tuning Min: -0.025`는 실전 투입 불가 사유. 변동성 폭발 구간에서 Tech/Healthcare 바이오 종목들의 MDD를 제어하지 못함.
*   **위험:** 상승장에서 잦은 현금화로 인한 수익 기회비용 발생(Whipsaw).
*   **실험 정의:**
    1.  `EXP_B1`: **VIX > 25** 또는 **XLV(Healthcare ETF) 20일 이격도 < 95%** 시, 현금 비중 50% 강제 확보.
    2.  `EXP_B2`: 개별 종목 ATR(14)이 주가의 5% 초과 시 해당 종목 매수 금지(Blacklist).
*   **PASS 조건:**
    *   Tuning Min > 0.0 (손실 구간 제거).
    *   Worst MDD가 -5% 이내로 개선.
*   **기대 관측치:** 총 수익률(Mean)은 소폭 하락하나, 샤프 비율 및 Min Score 대폭 개선.

#### **Proposal C: Sector Balanced Ranking (편중 방지)**
*   **필요성:** Tech/Healthcare 8~14 종목 선정 시, 특정 시기에 Tech 몰빵 또는 바이오 몰빵이 되어 MDD -8%~-11%를 유발함.
*   **위험:** 주도 섹터(예: 엔비디아 랠리)의 비중이 줄어들어 Alpha 감소 가능성.
*   **실험 정의:**
    1.  `EXP_C1`: 포트폴리오를 Tech(XLK 유니버스) 50%, Healthcare(XLV 유니버스) 50%로 **하드코딩(Hard-cap)**.
    2.  `EXP_C2`: 각 섹터 내에서 Momentum 상위 4~7개 종목 선정 (Cross-sector ranking 금지).
*   **PASS 조건:**
    *   Candidate(shadow) 모델 대비 Lockbox Mean 상승.
    *   특정 섹터 폭락 시(예: 헬스케어 규제 이슈) 전체 MDD 방어 확인.
*   **기대 관측치:** Tuning/Lockbox 성과 차이(Gap)가 1.0 이내로 줄어들며 일관성 확보.

### 2. 성능 정체 시 원인 분해 아이디어 (Debug Logic)

성능이 개선되지 않거나(Tuning Mean 정체), 과최적화가 해결되지 않을 때 아래 트리를 따라 점검하십시오.

1.  **트리거(Trigger) 확인:**
    *   *증상:* 거래 횟수가 너무 적음 (< 월 2회).
    *   *조치:* 진입 임계값(Threshold) 완화. (예: RSI < 30 -> RSI < 40)
2.  **노출(Exposure) 확인:**
    *   *증상:* 시장(SPY/QQQ) 상승분만큼도 못 따라감.
    *   *조치:* 베타(Beta) 점검. Tech/Health 종목들이 시장과 역상관관계인 방어주(대형 제약사 등) 위주로만 뽑히는지 확인.
3.  **비용(Cost) 확인:**
    *   *증상:* 승률은 높은데 계좌 우상향이 안 됨.
    *   *조치:* 회전율(Turnover) 과다. 리밸런싱 주기를 주간 -> 월간으로 변경하거나, 교체 매매 시 최소 기대 수익(Thresh) 설정.
4.  **레짐(Regime) 불일치:**
    *   *증상:* Champion이 특정 연도(예: 2022년 하락장)에만 전멸함.
    *   *조치:* `Proposal B`의 마켓 타이밍 로직을 개별 종목이 아닌 '시장 지수(SPY, QQQ)' 기준으로 적용하여 전체 Beta 조절.
