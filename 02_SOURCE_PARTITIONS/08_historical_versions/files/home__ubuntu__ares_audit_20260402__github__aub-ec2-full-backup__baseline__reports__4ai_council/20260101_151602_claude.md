## 1. 우선순위 TOP-5 PATCH 제안

### PATCH-1: Position Sizing Ceiling 강화
```
┌─────────────────────────────────────────────────────────┐
│  tuning_min = -1.35 반복 → 극단 포지션 노출 의심        │
└─────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | 동일 worst-case 반복 = sizing cap 부재 또는 느슨함 |
| **(b) 위험** | cap↓ → 수익률 ceiling도 ↓, Sharpe 미개선 가능 |
| **(c) 실험** | |

```yaml
EXP-1A:
  name: "pos_cap_10pct"
  변경: max_position_pct = 0.10 (현행 추정 0.15~0.20)
  gate: tuning_min > -1.0 AND lockbox_mean ≥ 1.32

EXP-1B:
  name: "vol_scaled_cap"
  변경: max_position_pct = min(0.12, 0.02 / realized_vol_20d)
  gate: worst_mdd > -0.075 AND lockbox_mean ≥ 1.32

EXP-1C:
  name: "sector_cap_25pct"
  변경: Healthcare/Tech 각 sector_max = 0.25
  gate: tuning_min > -1.1
```

| **(d) PASS 조건** | `tuning_min > -1.0` **AND** `lockbox_mean ≥ 1.32` **AND** `worst_mdd > -0.08` |

### PATCH-2: Momentum Decay 가속 (Regime Filter)
```
┌─────────────────────────────────────────────────────────┐
│  VIX>25 / SPY<MA50 레짐에서 손실 집중 가능성            │
└─────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | tuning_min 극단치가 특정 기간 집중 → 레짐 미분리 |
| **(b) 위험** | 필터 과다 → 거래빈도↓, 수익기회 축소 |
| **(c) 실험** | |

```yaml
EXP-2A:
  name: "vix_brake_25"
  변경: VIX > 25 → position_scale *= 0.5
  gate: lockbox_mean ≥ 1.30 AND worst_mdd > -0.07

EXP-2B:
  name: "spy_ma50_filter"
  변경: SPY < MA50 → new_entry = False (기존 보유만 유지)
  gate: lockbox_mean ≥ 1.28 AND tuning_min > -1.0
```

| **(d) PASS 조건** | `lockbox_mean ≥ 1.30` **AND** `tuning_min > -1.0` |

### PATCH-3: 비용 현실화 (Slippage + Commission Audit)
```
┌─────────────────────────────────────────────────────────┐
│  lockbox vs tuning 갭 = 비용 미반영 또는 불일치 의심     │
└─────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | lockbox_mean 1.33 vs tuning_mean 1.07 → 24% 갭 이상 |
| **(b) 위험** | 비용↑ 반영 시 lockbox_mean 급락 가능 |
| **(c) 실험** | |

```yaml
EXP-3A:
  name: "cost_audit_log"
  변경: slippage=5bp, commission=1bp 고정 + 로그 출력
  gate: (lockbox_mean - tuning_mean) < 0.20

EXP-3B:
  name: "cost_stress_10bp"
  변경: slippage=10bp (스트레스)
  gate: lockbox_mean ≥ 1.25 (degraded but stable)
```

| **(d) PASS 조건** | `|lockbox - tuning| < 0.20` **AND** 로그에 비용 라인 존재 |

### PATCH-4: Holding Period 연장 (Turnover 억제)
```
┌─────────────────────────────────────────────────────────┐
│  회전율 → 비용 → tuning_min 악화 경로 차단              │
└─────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | 높은 turnover가 비용+슬리피지 증폭 |
| **(b) 위험** | 신호 지연 → 추세 후반 진입 |
| **(c) 실험** | |

```yaml
EXP-4A:
  name: "min_hold_5d"
  변경: min_holding_days = 5
  gate: turnover_annual < 12 AND lockbox_mean ≥ 1.30

EXP-4B:
  name: "rebal_weekly"
  변경: rebalance_freq = 'W' (현행 D 추정)
  gate: turnover_annual < 10 AND worst_mdd > -0.085
```

| **(d) PASS 조건** | `turnover_annual < 12` **AND** `lockbox_mean ≥ 1.30` |

### PATCH-5: OOS Fold 확장 (fold15+ 추가)
```
┌─────────────────────────────────────────────────────────┐
│  fold14_mdd 동일 = 동일 fold 반복 학습 의심             │
└─────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | lockbox_min 동일값 반복 → fold contamination |
| **(b) 위험** | 데이터 부족 시 fold15+ 노이즈 |
| **(c) 실험** | |

```yaml

  name: "fold15_16_add"
  변경: lockbox_folds = [14, 15, 16]
  gate: lockbox_min (new) != lockbox_min (old)

EXP-5B:
  name: "walk_forward_monthly"
  변경: WF window 30d, step 30d
  gate: fold_count ≥ 18
```

| **(d) PASS 조건** | `new_lockbox_min ≠ old_lockbox_min` **AND** `lockbox_mean ≥ 1.28` |

## 3. 성능 미움직임 원인 분해 트리

```
성능 불변
│
├─ [트리거] 신호 자체가 안 바뀜
│   └─ 점검: 일별 signal_diff 로그 → 0이면 trigger 미작동
│
├─ [적용] 신호 → 포지션 전환 안 됨
│   └─ 점검: position_change 로그 → min_hold/sector_cap 블로킹
│
├─ [노출] 포지션 바뀌어도 exposure 유사
│   └─ 점검: beta_to_SPY 일별 → 0.9 이상 고정이면 분산 무효
│
├─ [비용] 노출 바뀌어도 비용이 상쇄
│   └─ 점검: gross_return vs net_return 갭 → 갭 > 2% p.a.이면 비용 지배
│
└─ [레짐] 테스트 기간이 단일 레짐
    └─ 점검: VIX 구간별 return 분해 → 특정 구간만 기여이면 레짐 편향
```
