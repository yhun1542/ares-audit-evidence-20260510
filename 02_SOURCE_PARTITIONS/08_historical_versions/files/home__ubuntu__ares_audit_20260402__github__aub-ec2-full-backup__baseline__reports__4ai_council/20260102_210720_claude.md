#### (b) 위험/부작용
- 원인이 데이터(구간 특성)인지 로직(버그)인지 구분 필요
- 잘못 수정 시 overfitting 악화

#### (c) 실험 정의
| ID | 실험 | Gate | 기대 관측치 |
|----|------|------|-------------|
| P1-A | `--log-fold-exposure` 추가하여 fold별 daily exposure 로깅 | fold별 exposure CSV 생성 | Degen fold에서 exposure=0인 날 비율 확인 |

| P1-C | Fold 1,2,3,8 제외 후 OOS 재계산 → 편향 정량화 | - | "진짜 OOS mean" baseline 확보 |

#### (d) PASS 조건

```
✅ 제외 전/후 OOS mean 차이 < 15%
```
