| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | tuning_min(-1.50) vs lockbox_min(+0.33) 괴리 → 레짐 분포 불일치. 특정 레짐에서만 작동하는 신호 과적합 가능성 |
| **(b) 위험/부작용** | 레짐 판별 지연(1-2일) → 진입 타이밍 손실; 레짐 오분류 시 헷지 과다 |
| **(c) 최소 실험** | |

## 2. 48시간 자동 루프 스펙

```yaml
# experiment_queue.yaml
experiments:
  - id: EXP-1A
    script: patches/regime_gate.py --mode vix_3level
    gate: lockbox_min > 0.25 AND tuning_min > -1.0
    observe: [lockbox_mean, lockbox_min, tuning_min, worst_mdd]
    timeout: 4h

  - id: EXP-2A
    script: patches/cost_model.py --slip 10 --fee 0.1
    gate: lockbox_mean > 1.2 AND worst_mdd < -0.07
    observe: [lockbox_mean, turnover_annual, net_return]
    timeout: 2h

  - id: EXP-3A
    script: patches/signal_filter.py --zscore_top 0.5
    gate: lockbox_sharpe > 1.1 AND avg_holdings >= 6
    observe: [lockbox_sharpe, avg_holdings, hit_rate]
    timeout: 2h

  - id: EXP-4A
    script: patches/mdd_cap.py --l1 0.06 --l2 0.08
    gate: worst_mdd < -0.08
    observe: [worst_mdd, lockbox_mean, cash_ratio]
    timeout: 2h

  - id: EXP-5A
    script: patches/survivorship_check.py --start 2020
    gate: lockbox_mean_adj > 1.1
    observe: [lockbox_mean_raw, lockbox_mean_adj, dropped_tickers]
    timeout: 6h
```

## 3. 성능 미동 시 원인 분해 트리 (Cause Tree)

```
성능 불변
├── [트리거 문제] 신호 자체가 발생 안 함
│   ├── threshold 과도 → 진입 빈도 0.1회/일 미만 확인
│   └── 데이터 지연 → timestamp 정렬 오류
│
├── [적용 문제] 신호는 발생하나 포지션 미반영
│   ├── position sizer 버그 → 로그에서 target vs actual 괴리 확인
│   └── 기존 포지션 우선 로직 → 신규 신호 무시
│
├── [노출 문제] 포지션은 잡히나 수익 기여 無
│   ├── 보유 기간 너무 짧음 → 평균 holding period < 2일
│   └── 진입 타이밍 늦음 → 모멘텀 이미 소진
│
├── [비용 문제] gross 수익은 있으나 net 제로
│   ├── turnover 과다 → 연 500% 이상
│   └── 슬리피지 과소 추정 → 실거래 대비 +5bp 이상 괴리
│
└── [레짐 문제] 특정 구간만 작동
    ├── bull only 전략 → bear 구간 손실로 상쇄
    └── 저변동 only → VIX 25+ 구간 MDD 급등
```
