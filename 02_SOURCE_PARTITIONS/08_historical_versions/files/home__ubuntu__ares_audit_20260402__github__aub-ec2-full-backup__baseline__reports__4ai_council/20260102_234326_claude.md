### **#1. 측정 인프라 수리** (BLOCKING)
> 현재 실험 결과 신뢰 불가 → 다른 실험 무의미

**(a) 필요성**
- OOS mean 2개 값 공존 (3.32 vs 2.63) → 어느 것이 진실?
- rebalance.csv 파싱 실패 → 거래비용 0원으로 계산 중
- MDD=None → 리스크 게이트 작동 안 함

**(b) 위험/부작용**
- 수리 후 실제 OOS가 급락할 수 있음 (현실 직면)
- 기존 champion이 invalid 판정날 수 있음

**(c) 최소 실험**

```
EXP-1.1: metric_consistency_check
──────────────────────────────────
정의: 동일 config로 3회 백테스트, OOS mean 편차 측정
게이트: std(OOS_mean) < 0.05
기대치: 재현성 확인 또는 RNG seed 문제 발견

EXP-1.2: rebalance_logger_fix  
──────────────────────────────────
정의: rebalance 이벤트 → JSONL 포맷 강제 출력
게이트: 파일 row수 == 예상 리밸런싱 횟수
기대치: 거래비용 계산 활성화

EXP-1.3: mdd_calculator_patch
──────────────────────────────────
정의: equity curve에서 rolling MDD 계산 추가
게이트: worst_mdd 값 출력 (숫자)
기대치: MDD > -25% 확인 또는 전략 기각
```

**(d) PASS 조건**
- [ ] 3회 실행 OOS std < 0.05
- [ ] rebalance.jsonl 파싱 성공
- [ ] worst_mdd 숫자 반환

### **#2. Degenerate Fold 원인 분해** (HIGH)
> 4/10 fold 실패 = 전략이 특정 구간에서만 작동

**(a) 필요성**
- Fold 1,2,3 = 초기 구간 → 2020-2021 bull run 과적합?
- Fold 8 = 2023 후반? → 레짐 전환 실패?
- Survivorship bias 의심: 해당 기간 종목 상폐 확인 필요

**(b) 위험/부작용**
- 원인 발견 시 전략 재설계 필요 (시간 소요)
- "고칠 수 없는 구조적 문제"일 수 있음

**(c) 최소 실험**

```
EXP-2.1: fold_regime_overlay
──────────────────────────────────
정의: 각 fold 기간에 VIX/SPY 레짐 라벨 매핑
게이트: degenerate fold와 특정 레짐 상관계수 > 0.7
기대치: "고변동성 구간 실패" 등 패턴 발견

EXP-2.2: fold_stock_survival_audit
──────────────────────────────────
정의: degenerate fold 기간 내 상폐/M&A 종목 리스트
게이트: 해당 종목이 전략 보유 내역에 포함 여부
기대치: survivorship bias 유무 확정

EXP-2.3: fold_signal_density
──────────────────────────────────
정의: fold별 트레이드 발생 횟수 비교
게이트: degenerate fold 트레이드 수 < 정상 fold의 50%
기대치: "신호 부족" vs "신호는 있으나 실패" 구분
```

**(d) PASS 조건**
- [ ] Degenerate 원인 1개 이상 특정
- [ ] 해당 원인 제거 시 fold 정상화 확인

**(b) 위험/부작용**

- 과거 실험 결과 전체 무효화

**(c) 최소 실험**

```

──────────────────────────────────

──────────────────────────────────
```

### **#4. Exposure 상한 검증** (MEDIUM)

- 0% 노출 기간 = 신호 없음? 강제 청산? 버그?

**(b) 위험/부작용**
- 0% 노출 기간이 길면 기회비용 발생
- "안전하게 현금 보유" vs "신호 누락" 구분 필요

**(c) 최소 실험**

```

──────────────────────────────────

게이트: 0% 노출 기간 < 전체의 20%
기대치: 의도된 행동인지 확인

EXP-4.2: exposure_vs_regime
──────────────────────────────────
정의: exposure와 VIX 상관관계
게이트: 고VIX 시 exposure 감소 패턴 확인
기대치: 방어적 행동 vs 무작위 확인
```

**(d) PASS 조건**
