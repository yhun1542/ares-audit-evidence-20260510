    *   **이유:** `Worst MDD: None` 및 JSON 파싱 에러는 리스크 관측 시스템이 꺼져있음을 의미. 맹인 비행 중.

    *   **액션:** QQQ/XLV의 MA(Moving Average) 하회 시 개별 종목 매수 금지(Veto) 로직 추가.

4.  **[RISK] 비용 모델(Cost Model) 현실화 및 Stress Test**

    *   **액션:** 왕복 비용(bps)을 2배로 설정한 상태에서도 살아남는지 검증.

5.  **[UNIVERSE] Universe Availability Check (Survivorship Bias)**

#### P1. Degenerate Folds 복구 (안전장치 마련)
*   **(a) 필요성:** Fold 1, 2, 3, 8의 실패 원인(거래 없음 vs 로직 에러)을 모르면 OOS 수치는 허상임.
*   **(b) 위험:** 강제 거래 유도로 인한 MDD 급증 가능성.
*   **(c) 실험 (Experiments):**
    *   `EXP_FIX_01`: 진입 임계값(Threshold)을 기존 대비 50% 수준으로 완화하여 거래 발생 강제.

    *   `EXP_FIX_03`: `NaN` 데이터 발생 시 0 또는 직전 값 채우기(Forward Fill) 강제 적용.
*   **(d) PASS 조건:** Degenerate Folds 목록이 빈 배열 `[]`이 되거나 1개 이하로 줄어들 것.

#### P2. Reporting Pipeline 수리
*   **(a) 필요성:** `Worst MDD: None` 상태에서는 그 어떤 전략 수정도 승인 불가.
*   **(b) 위험:** 코드 수정 과정에서 기존 로그 데이터 오염 가능성 (백업 필수).
*   **(c) 실험 (Experiments):**
    *   `SYS_REP_01`: `rebalance.csv` 로딩 시 JSONL 포맷 에러 예외처리 구문(`try-except`) 추가 및 로깅 강화.
    *   `SYS_REP_02`: 거래 내역이 0건일 때 MDD를 0.0으로 명시적 리턴하도록 계산 함수 패치.
*   **(d) PASS 조건:** 리포트 생성 시 에러 로그 없이 완료되고, MDD 필드에 숫자(Float)가 찍힐 것.

### 3. 48시간 자동 루프 정의 (Experiment Loop)

**[실험 1: Fold Integrity Check]**
1.  **실험 정의:** 파손된 Fold(1,2,3,8) 기간에 대해 유니버스 내 가용 종목(Data Count > Lookback)이 5개 미만이면 해당 Fold를 Skip하지 않고 'Cash Only'로 처리하여 에러 방지.
2.  **게이트(Gate):**
    *   IF `Degenerate_Folds` count > 0 THEN Reject immediately.
    *   IF `Trade_Count` on Fold 1 < 5 THEN Warn.
3.  **기대 관측치:** 모든 Fold 정상 종료, OOS Mean은 하락하더라도 신뢰할 수 있는 수치 확보.

**[실험 2: Force Cost Impact]**
1.  **실험 정의:** 거래 비용(Slippage + Commission)을 현재 설정의 200%로 적용하여 백테스트 수행.
2.  **게이트(Gate):**
    *   IF `OOS_Mean` remains > 2.0 THEN Strategy is robust.
    *   IF `OOS_Mean` drops < 0.5 THEN Strategy is relying on micro-structure noise (Overfitting).
3.  **기대 관측치:** 수익률 곡선의 평탄화. 진짜 알파인지 노이즈 트레이딩인지 판별.

**[실험 3: Tech/Bio Regime Filter]**
1.  **실험 정의:** 유니버스를 (AAPL, MSFT, NVDA, JNJ, PFE, LLY, UNH, AMZN 등 10개)로 고정하고, QQQ 50일 이평선 아래에서는 Long 포지션 진입 금지.
2.  **게이트(Gate):**
    *   IF `Worst_MDD` improves by > 15% (vs Champion) THEN Promote.
3.  **기대 관측치:** 하락장에서 현금 보유 비중 증가, MDD 대폭 감소.

### 4. 성능 정체(Stagnation) 원인 분해 및 디버깅 가이드

성능이 움직이지 않거나(No Delta), 리포트가 비어있을 때 다음 순서로 점검하십시오.

1.  **트리거(Trigger) 확인:** 신호 자체가 발생하는가?
    *   *Check:* `Buy_Signal_Count`가 0인지 확인. 0이라면 진입 조건(Threshold)이 너무 높거나 데이터가 `NaN`임.
2.  **노출(Exposure) 확인:** 신호는 있는데 포지션을 잡지 않는가?
    *   *Check:* `Cash_Balance`가 줄어들지 않음. 1주 가격이 자본금보다 비싸거나, 리스크 관리 모듈(Position Sizing)이 0을 리턴하고 있음.
3.  **비용(Cost) 확인:** 수익이 비용에 잠식되는가?
    *   *Check:* `Gross_Profit`은 양수인데 `Net_Profit`이 음수이거나 0 근처. 잦은 매매(Churn rate)를 줄여야 함.
4.  **레짐(Regime) 불일치:** 역추세 전략을 추세장에서 쓰고 있는가?
    *   *Check:* Tech/Bio 섹터 지수(QQQ, XLV)와 내 전략의 수익 곡선 상관관계(Correlation) 확인. 지수가 오를 때 잃고 있다면 로직 반대 적용 고려.
5.  **시스템(System) 오류:**
    *   *Check:* `Degenerate Folds`. 데이터 파이프라인이 끊겨 특정 기간을 건너뛰고 계산하여 결과가 왜곡됨. **(현재 가장 유력한 원인)**
