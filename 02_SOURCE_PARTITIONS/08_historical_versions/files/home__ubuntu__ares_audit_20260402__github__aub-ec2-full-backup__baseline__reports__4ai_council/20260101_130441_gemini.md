### 1. 우선순위 TOP 3 제안 (긴급 패치)

**Priority A: Macro Regime Filter (ETF 기반 매매 차단)**
*   **(a) 필요성:** `tuning_min`이 -1.35로 극단적임. 챔피언과 후보 모델의 값이 동일한 것으로 보아, 특정 하락장에서 로직이 작동했거나 방어하지 못함. 섹터 ETF(XLK, XLV)의 추세가 꺾였을 때 개별 종목 매수를 강제 차단해야 함.
*   **(b) 리스크:** 'Dead Cat Bounce'나 V자 반등 구간에서 진입이 늦어 수익 기회(Lockbox Mean)가 감소할 수 있음.
*   **(c) 실험 (Experiments):**
    1.  **EXP_REGIME_MA:** XLK 또는 XLV가 200일 이동평균선(MA200) 하회 시 Cash 100% 전환.
    2.  **EXP_REGIME_VIX:** VIX 지수가 30 이상일 때 포지션 사이즈 50% 축소.
*   **(d) PASS 조건:** `tuning_min` > -0.5 (대폭 개선 필요), `lockbox_mean` > 1.2 유지.

**Priority B: Volatility Targeting (변동성 역가중)**
*   **(a) 필요성:** Tech/Bio(Healthcare)는 변동성이 큼. 현재 동일 비중(Equal Weight) 또는 단순 스코어 비중일 가능성이 높음. 개별 종목 변동성이 클수록 비중을 줄여 MDD를 방어해야 함.
*   **(b) 리스크:** 급등주(Tech Momentum)의 비중이 줄어들어 총 수익률(CAGR) 저하 가능성.
*   **(c) 실험 (Experiments):**
    1.  **EXP_VOL_TGT:** 포트폴리오 목표 변동성을 연 20%로 설정하고 비중 동적 조절.
    2.  **EXP_INVERSE_VOL:** 개별 종목의 ATR(14) 역수로 비중 할당.
*   **(d) PASS 조건:** `worst_mdd` > -0.06 (현재 -0.09), `fold14_mdd` 개선.

**Priority C: Dynamic Trailing Stop (개별 종목 손절 강화)**
*   **(a) 필요성:** `candidate`가 챔피언 대비 worst MDD를 약간 개선(-0.09 -> -0.08)했으나 여전히 부족함. 진입 후 고점 대비 하락 시 강제 청산 로직이 느슨함.
*   **(b) 리스크:** 잦은 손절(Whipsaw)로 인한 거래 비용 증가 및 누적 손실.
*   **(c) 실험 (Experiments):**
    1.  **EXP_TS_TIGHT:** 개별 종목 수익률이 고점 대비 -7% 하락 시 전량 매도.
    2.  **EXP_TIME_CUT:** 진입 후 5일 내 수익이 0% 이하일 경우 강제 청산 (Time-based Stop).
*   **(d) PASS 조건:** 거래 횟수 증가 대비 `sharpe` 비율 유지, `tuning_min`의 꼬리 절단 확인.
