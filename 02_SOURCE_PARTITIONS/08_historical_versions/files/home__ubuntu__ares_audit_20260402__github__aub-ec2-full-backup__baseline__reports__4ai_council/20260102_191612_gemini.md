## 1) 24~48시간 우선순위 TOP 5 제안 (Imperative Checklist)

현재 `Champion(v5)`의 Lockbox 성능(4.01)이 Tuning 성능(2.32)보다 월등히 높은 현상은 **"데이터 유출(Leakage)"** 또는 **"운 좋게 정렬된 특정 구간 과최적화"**의 강력한 신호다. 즉시 리스크 검증 모드로 전환하라.

### [P1] 실행 지연(Lag) 스트레스 테스트
*   **이유:** `lockbox_mean`이 비정상적으로 높음. 종가(Close)를 예측에 사용하고 당일 종가에 거래하는 Look-ahead bias 가능성 차단.
*   **위험:** 실제 알파가 단기적일 경우 성능이 급락할 수 있음.
*   **실험 정의:**
    1.  `EXP_LAG_01`: 시그널 생성 후 **T+1 시가(Open)** 진입으로 변경.
    2.  `EXP_LAG_02`: 시그널 생성에 사용하는 모든 Feature 데이터를 `shift(1)` 강제 적용.
    3.  `EXP_SLIPPAGE_X2`: 슬리피지(Slippage) 비용을 현재 설정의 2배(예: 5bps -> 10bps)로 적용.
*   **PASS 조건:** `lockbox_mean` > 1.5 유지 AND `worst_mdd` > -15% 이내 (성능 급락 시 기존 모델 폐기).

### [P2] 유니버스 서바이버십 바이어스(Survivorship Bias) 제거
*   **이유:** Tech/Bio 상위 8~14개 종목이 현재 시점 기준으로 우량한 종목들로만 구성되었을 가능성. (예: 2020년에 이미 상장폐지 위기였던 종목이 제외됨).
*   **위험:** 유동성이 낮은 과거 데이터가 포함되어 백테스트 속도 저하 및 노이즈 증가.
*   **실험 정의:**
    1.  `EXP_UNIV_POINT_IN_TIME`: 매 월 1일 기준 시총 상위 50위 내 Tech/Health 중에서만 동적으로 8~14개 선택(정적 리스트 금지).
    2.  `EXP_INCLUDE_DELISTED`: 과거 5년 내 상장 폐지되거나 티커 변경된 종목 2개 이상 강제 포함하여 로직 검증.
*   **PASS 조건:** 유니버스 변경 후에도 `tuning_mean`과 `lockbox_mean`의 괴리가 20% 이내일 것.

### [P3] 단일 종목 집중도(Concentration) 제한
*   **이유:** MDD가 -8%로 매우 낮음. 특정 초강세 종목(NVDA, LLY 등)에 몰빵(100% 비중)했을 가능성. 이는 운영 리스크.
*   **위험:** 수익률(Mean)의 대폭 하락 가능성.
*   **실험 정의:**
    1.  `EXP_CAP_WEIGHT_15`: 개별 종목 최대 비중 15% 하드 캡 적용.
    2.  `EXP_MIN_ASSETS_5`: 포트폴리오 내 최소 보유 종목 수 5개 강제 (현금 비중 제외).
    3.  `EXP_SECTOR_BALANCE`: Tech와 Healthcare 간 비중 차이 30%p 이내 제한.
*   **PASS 조건:** `worst_mdd` 변화폭 < 5%p (MDD 방어 기제 확인) AND `Sharpe` > 1.2.

### [P4] 2022년 하락장(Bear Market) 전용 검증
*   **이유:** `fold14_mdd`(-0.039)가 너무 낮음. 금리 인상기(2022)에 Tech/Bio 섹터가 타격을 입었을 때 모델이 현금화(Cash)했는지 숏(Inverse ETF 불가하므로 현금 비중 확대)했는지 확인 필요.
*   **위험:** 방어적 로직 강화로 인한 상승장(2023-2024) 수익률 저하.
*   **실험 정의:**
    1.  `EXP_REGIME_2022_ONLY`: 학습 데이터를 2021년까지로 제한하고, 2022년 1년만 Lockbox로 설정하여 생존 여부 확인.
    2.  `EXP_VOLATILITY_FILTER`: VIX(혹은 시장 변동성)가 특정 임계치 이상일 때 매매 중단(Cash 100%) 로직 추가.
*   **PASS 조건:** 2022년 구간 `MDD` > -20% 이내 방어.

### [P5] 피처(Feature) 노이즈 주입 테스트
*   **이유:** 과최적화 확인. 약간의 데이터 노이즈에도 모델 예측이 붕괴된다면, 패턴이 아닌 노이즈를 학습한 것.
*   **위험:** 모델의 신뢰도 자체를 부정하게 될 수 있음(Champion 폐기).
*   **실험 정의:**
    1.  `EXP_NOISE_OPEN_HIGH`: 시가/고가 데이터에 랜덤 노이즈(0.5%) 주입 후 추론.
    2.  `EXP_DROP_MOMENTUM`: 모멘텀 지표(RSI, MACD 등) 전량 제거 후 펀더멘털/거래량 지표만으로 재학습.
*   **PASS 조건:** `tuning_mean` 하락폭 30% 이내 (견고성 확인).

## 2) 제안별 48시간 자동 루프 정의

### Experiment 1: Lag & Slippage Stress (최우선)
1.  **실험 정의:** `Champion_v5` 로직 복제 -> 매수/매도 로직을 `Next Open` 실행으로 변경. 슬리피지 10bps 설정.
2.  **게이트(Gate):** `Tuning Mean` > 1.5 (이보다 낮으면 시그널이 즉시 소멸되는 단기 노이즈임).
3.  **기대 관측치:** `Lockbox Mean`이 4.0 -> 2.0 수준으로 하락하되, 양수(+)를 유지해야 함. 마이너스 전환 시 전량 폐기.

### Experiment 2: Dynamic Universe Check
1.  **실험 정의:** 정적 리스트(Static Tickers) 해제 -> 매월 Rebalancing 시점에 `Market Cap Top N` 필터링 적용.
2.  **게이트:** `Data Loading` 성공 및 `Look-ahead` 없는 티커 선택 로직 확인.
3.  **기대 관측치:** `Survivorship Bias`가 제거된 상태에서 `CAGR` 15% 이상 유지.

### Experiment 3: Max Weight Constraint
1.  **실험 정의:** Optimizer 제약 조건에 `w_i <= 0.20` 추가.
2.  **게이트:** 솔버(Solver)가 해를 찾지 못하는(Infeasible) 경우 예외 처리(Cash 비중 확대) 로직 작동 여부.
3.  **기대 관측치:** `MDD`가 소폭 상승하더라도, 특정 종목 의존도가 낮아진 상태의 `Sharpe Ratio` 1.5 이상.

## 3) 성능 정체(Stagnation) 시 원인 분해 아이디어

성능 지표가 개선되지 않고 제자리걸음일 때, 다음 5가지 차원으로 문제를 쪼개서 디버깅하라.

1.  **트리거(Trigger) 민감도:**
    *   *현상:* 매매 횟수가 너무 적거나, 거의 모든 날 매매함.
    *   *액션:* 진입 임계값(Threshold)을 동적으로 변경 (예: 고정값 0.5 -> 볼린저 밴드 기반 상대값).
2.  **적용(Application) 시차:**
    *   *현상:* 예측은 맞는데 체결 가격이 불리함.
    *   *액션:* 장중(Intraday) 부분 체결 시뮬레이션 or VWAP(거래량 가중 평균가) 기준 체결로 변경.
3.  **노출(Exposure) 부족:**
    *   *현상:* 현금 비중이 지나치게 높음 (쫄보 알고리즘).
    *   *액션:* 하락 추세가 아님(MA200 위)이 확인되면 최소 주식 비중 50% 강제.
4.  **비용(Cost) 장벽:**
    *   *현상:* Gross Return은 좋은데 Net Return이 나쁨.
    *   *액션:* 회전율(Turnover) 제약 추가 (예: 일일 포트폴리오 교체율 10% 미만).
5.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 연도(2022 등)에만 성능이 박살남.
    *   *액션:* Macro 지표(금리, 달러지수)를 Feature가 아닌 'Switch'로 사용하여 전략 자체를 이원화 (Bull 전략 / Bear 전략).
