[우선순위 TOP 5 제안]
1. **Regime Filter 도입 (지수 MA 필터링)**: `tuning_min` (-1.34) 수치는 특정 하락장(Fold)에서 전략이 붕괴됨을 의미. Tech/Health 섹터는 시장 베타가 높으므로, SPY/QQQ가 200일 이동평균선 아래일 때 Long 포지션 진입을 차단하거나 비중을 축소하는 'Regime Switch'가 필수적임.
2. **Falling Knife 방지 (변동성 기반 진입 제한)**: `exp_mrd_fsa`(Mean Reversion)는 급락 시 매수하는 로직일 가능성이 높음. 개별 종목의 단기 변동성(ATR 등)이 극단적으로 확대된 구간을 회피(Skip)하여 '떨어지는 칼날'을 잡는 리스크 제거.
3. **상관관계 기반 포트폴리오 캡(Cap)**: Tech와 Healthcare는 동조화 현상이 발생할 수 있음. 특정 섹터나 상관계수가 높은 종목군에 할당되는 자금을 전체 Equity의 60% 이하로 강제하는 리스크 관리 레이어 추가.
4. **Leakage(누수) 검증 및 Lockbox 신뢰도 재확인**: `lockbox_mean`(1.33)이 `tuning_mean`(1.06)보다 높은 현상은 비정상적(보통 역전됨). Lockbox 데이터가 튜닝에 암묵적으로 포함되었거나, 특정 Bull Market 구간만 잘려있을 가능성(Lucky)을 의심해야 함. 전수조사 필요.
5. **Cost/Slippage 현실화**: Tech 바이오 종목은 호가 공백이 큼. 슬리피지 모델을 보수적으로(예: 10bps -> 20bps) 상향했을 때도 `worst_mdd`가 -9% 대를 유지하는지 확인.

[실행 가능한 Patch/실험 (3~5개)]

### 실험 1: `Exp_Regime_MA_Filter` (거시 지표를 활용한 진입 차단)
*   **정의**:
    *   참조 지표: SPY 또는 QQQ (ETF 매매는 안 하되 지표로만 사용).
    *   로직: `Close(SPY) < MA(SPY, 200)` 상태에서는 신규 진입 금지 혹은 전체 포지션 사이즈 50% 축소.
*   **게이트 (Pass Condition)**:
    *   `tuning_min` > -1.0 (치명적 손실 방어 확인).
    *   `worst_mdd` > -0.07 (MDD 7% 이내 진입).
    *   `tuning_mean` 감소폭이 10% 미만일 것.
*   **기대 관측치**:
    *   하락장 Fold에서의 손실폭 급감.
    *   총 거래 횟수 감소로 인한 비용 절감 효과.

### 실험 2: `Exp_InvVol_Sizing` (역변동성 가중치 적용)
*   **정의**:
    *   기존 균등(Equal) 비중 또는 단순 비중 방식을 변경.
    *   로직: `Weight_i = (1 / Volatility_i) / Sum(1 / Volatility_all)`. 변동성이 큰 바이오/테크 종목의 비중을 자동으로 낮춤.
*   **게이트 (Pass Condition)**:
    *   `fold14_mdd` 및 `worst_mdd` 수치 개선 (현재 -4.9% / -9.0% 보다 우위).
    *   Sharpe Ratio > 1.4 (리스크 조정 수익률 개선).
*   **기대 관측치**:
    *   변동성이 큰 개별 종목(특히 바이오)에 의한 포트폴리오 전체 충격 완화.

### 실험 3: `Exp_TimeBased_Stop` (체류 시간 제한)
*   **정의**:
    *   Mean Reversion 전략 특성상 반등이 즉시 나오지 않으면 추세 하락일 가능성 높음.
    *   로직: 진입 후 N일(예: 5일) 내 수익권 미진입 시 강제 청산(Time-Stop).
*   **게이트 (Pass Condition)**:
    *   `tuning_min` 점수 개선.
    *   Avg Holding Period 감소 확인.
*   **기대 관측치**:
    *   손실 포지션을 길게 끌고 가며 발생하는 `worst_mdd` 누적 방지. 자금 회전율 증가.

[성능 정체 원인 분해 (Diagnosis Checklist)]

성능 지표가 개선되지 않고 횡보할 경우, 다음 순서로 원인을 제거하라.

1.  **Trigger (진입 타이밍) 문제인가?**
    *   *Check*: 진입 신호 발생 후 `Forward 1-day Return`의 평균이 양수인가?
    *   *Action*: 음수라면 역추세 매매가 아니라 '추세 추종'으로 로직 반전 고려.

2.  **Exposure (노출) 문제인가?**
    *   *Check*: `tuning_min`이 발생한 날짜의 시장(SPY) 수익률과 포트폴리오 베타 확인.
    *   *Action*: 시장이 -2% 빠질 때 포트폴리오가 -4% 빠진다면, 레버리지나 베타가 과도함. 현금 비중(Cash Buffer) 강제 설정.

3.  **Cost (비용) 문제인가?**
    *   *Check*: `Gross Profit`과 `Net Profit`의 괴리가 30% 이상인가?
    *   *Action*: 회전율이 과도함. 진입 임계값(Threshold)을 높여 거래 횟수를 줄이고 퀄리티 높은 거래만 수행.

4.  **Survivorship/Data (데이터) 문제인가?**
    *   *Check*: 현재 유니버스(8~14개)가 2026년 기준 우량주로만 구성되어 과거(2020년 등)를 시뮬레이션하고 있는가?
    *   *Action*: 상장 폐지되었거나 과거에는 우량했으나 현재 탈락한 종목이 유니버스 히스토리에 포함되었는지 점검 (Point-in-Time Data 검증).

5.  **Regime (국면) 불일치인가?**
    *   *Check*: `Lockbox`(1.33)와 `Tuning`(1.06)의 괴리.
    *   *Action*: Lockbox 기간이 상승장에 편중되었을 확률 90%. 튜닝 데이터의 'Worst Fold'를 Lockbox 검증 셋으로 이동시켜 과최적화 여부 테스트.
