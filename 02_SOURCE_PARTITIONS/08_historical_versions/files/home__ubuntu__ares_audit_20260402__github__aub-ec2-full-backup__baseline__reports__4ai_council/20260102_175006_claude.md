### PATCH-1: Degenerate Fold 원인 격리
```
WHY: 4/10 fold 실패는 과적합 or 데이터 누수 신호
RISK: 원인 오진 시 잘못된 방향 수정
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `P1-A` | Fold 1,2,3,8 공통 기간 추출 → 레짐 라벨링 (VIX>25 / SPY<MA200) | 자동 | 공통 레짐 존재 여부 (Y/N) |

| `P1-C` | Fold별 train/test 시간 갭 확인 (최소 21거래일?) | gap ≥ 21d | 누수 여부 확인 |

**✅ PASS 조건**: P1-C gap ≥ 21d 확인 AND (P1-A 레짐 일치율 > 70% OR P1-B KL > 0.3)
