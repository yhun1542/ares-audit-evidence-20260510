## 3. 성능 정체 원인 분해 트리

```
lockbox 안 움직임
├─ [트리거] signal 자체가 발생 안 함
│   └─ 점검: signal_count / day 추출 → 최근 30일 평균 vs 과거
│
├─ [적용] signal 발생했으나 진입 조건 미충족
│   └─ 점검: triggered vs executed ratio
│
├─ [노출] 진입했으나 position size 너무 작음
│   └─ 점검: avg_position_size 시계열
│
├─ [비용] gross return은 있으나 cost가 상쇄
│   └─ 점검: gross_return vs net_return gap
│
└─ [레짐] 현재 시장이 전략 불리 구간
    └─ 점검: 최근 60일 SPY regime vs 전략 성능 scatter
```

**진단 명령 (1회성):**
```bash
python3 analysis/plateau_diagnosis.py \
  --checks trigger,execution,exposure,cost,regime \
  --window 60 \
  --output reports/plateau_root_cause.md
```
