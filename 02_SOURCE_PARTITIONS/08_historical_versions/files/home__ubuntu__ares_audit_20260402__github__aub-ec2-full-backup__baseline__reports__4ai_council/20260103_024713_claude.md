## 성능 불변 시 원인 분해 프레임워크

```
성능이 안 움직이는 5가지 원인:

┌─────────────┬────────────────────────────────────────┬─────────────────────┐
│ 레이어      │ 체크 방법                              │ 해결책              │
├─────────────┼────────────────────────────────────────┼─────────────────────┤
│ 1. TRIGGER  │ 시그널 발생 횟수 카운트                │ threshold 완화      │
│             │ → 0이면 조건이 너무 까다로움           │                     │
├─────────────┼────────────────────────────────────────┼─────────────────────┤
│ 2. APPLY    │ 시그널 → 실제 포지션 변환율            │ 실행 로직 버그 체크 │
│             │ → 시그널 100, 거래 0 = 적용 실패       │                     │
├─────────────┼────────────────────────────────────────┼─────────────────────┤
│ 3. EXPOSURE │ 포지션 사이즈가 너무 작음              │ sizing 로직 조정    │
│             │ → 평균 exposure < 10% = 영향 미미      │                     │
├─────────────┼────────────────────────────────────────┼─────────────────────┤
│ 4. COST     │ 거래 비용이 수익 상쇄                  │ 거래 빈도 축소      │
│             │ → gross return > 0, net return ≈ 0     │                     │
├─────────────┼────────────────────────────────────────┼─────────────────────┤
│ 5. REGIME   │ 테스트 기간이 전략과 안 맞음           │ 기간 확장/분할      │
│             │ → 특정 레짐에서만 작동                 │                     │
└─────────────┴────────────────────────────────────────┴─────────────────────┘
```
