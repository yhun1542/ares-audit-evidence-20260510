### P2. Fold-0 저성과 원인 격리 (누수/과최적화 점검)
```
WHY: OOS Min 0.43 → 특정 fold가 전체 평균을 끌어내림
RISK: fold 제거 시 survivorship bias
```

**체크리스트**
- [ ] Fold-0 기간 식별 (어떤 시장 레짐?)
- [ ] 해당 기간 exposure, 종목 집중도 확인
- [ ] IS vs OOS 괴리율 계산

**실험**
| ID | 정의 | Gate | 기대 관측치 |
|----|------|------|-------------|
| FOLD-01 | Fold별 IS/OOS 괴리율 리포트 생성 | 괴리 > 50% fold 식별 | 과적합 fold 리스트 |
| FOLD-02 | Fold-0 제외 후 OOS Mean 재계산 | Mean > 2.2 이면 fold 문제 | 격리 확인 |
| FOLD-03 | Fold-0 기간 VIX/SPY drawdown 오버레이 | 레짐 매핑 | 시장 요인 vs 전략 요인 분리 |

### P3. FSA Scale/Hedge 파라미터 민감도 (과최적화 점검)
```
WHY: exp_fsa_only_scale_090_hedge_025가 champion 대비 열화 → 파라미터 cliff 가능성
RISK: grid 확장 시 케이스 폭발
```

**체크리스트**
- [ ] scale 0.85~1.0 / hedge 0.20~0.30 범위 내 성능 곡면 확인
- [ ] cliff (>20% 변동) 존재 여부
- [ ] champion 파라미터 vs 현재 파라미터 delta

**실험**
| ID | 정의 | Gate | 기대 관측치 |
|----|------|------|-------------|
| SENS-01 | scale ±0.05 × hedge ±0.05 = 9-point grid | 3×3 only | 곡면 플롯 |
| SENS-02 | OOS Mean std across grid < 0.3 | std < 0.3 | 안정성 확인 |
| SENS-03 | cliff 발견 시 해당 영역 제외한 robust 평균 | 제외 후 Mean > 2.0 | 운영 파라미터 밴드 확정 |

**PASS 조건**: 9-point 중 7개 이상 OOS Mean > 1.5
