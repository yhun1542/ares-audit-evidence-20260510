## 1. 우선순위 TOP 5 실험 제안

### PATCH-1: Fold Stability Regularization
**왜 필요한가**
- Candidate tuning_min=0.05 → 특정 fold에서 거의 0% 수익
- 이런 fold 편차는 live에서 "운 나쁜 시기" 진입 시 치명적

**위험/부작용**
- 평균 성능 하락 가능 (안정성↔수익 트레이드오프)
- 과도한 regularization → 신호 약화

**최소 실험**
| ID | 설명 | 변경점 |
|----|------|--------|
| 1a | Min-fold constraint | Objective += `λ * max(0, 0.3 - fold_min)` |
| 1b | Fold-std penalty | Objective -= `0.1 * std(fold_returns)` |
| 1c | Worst-2-fold avg | 최악 2개 fold 평균으로 평가 |

**PASS Gate**
```yaml
gate:
  tuning_min: ">= 0.25"
  tuning_std: "<= 0.35"
  lockbox_mean: ">= 1.75"  # 기존 대비 -3% 허용
```

---

### PATCH-2: MDD Ceiling Enforcement
**왜 필요한가**
- MDD가 -9.3% → -11.2%로 악화 추세
- 현재 시스템에 MDD hard cap 없음 → 실제 운용 시 심리적 한계 초과

**위험/부작용**
- Position cut이 빈번해지면 whipsaw 손실
- 변동성 구간에서 "손절 → 반등 miss" 반복

**최소 실험**
| ID | 설명 | 변경점 |
|----|------|--------|
| 2a | Hard MDD cap -10% | Drawdown > 10% → 전 포지션 50% 축소 |
| 2b | Trailing MDD | 20일 rolling peak 대비 -8% → 신규진입 금지 |
| 2c | Vol-adjusted MDD | VIX>25 구간에서 MDD cap -7%로 긴축 |

**PASS Gate**
```yaml
gate:
  worst_mdd: ">= -0.10"
  lockbox_mean: ">= 1.70"
  win_rate_decay: "<= 5%"  # MDD rule로 인한 승률 하락 제한
```

---

### PATCH-3: Concentration Risk Dampener
**왜 필요한가**
- 8~14 종목에서 상위 3개가 60%+ 비중이면 단일 악재에 취약
- Fold14(최근)가 worst → 특정 종목 집중 의심

**위험/부작용**
- 분산 강제 → 확신 높은 베팅 희석
- 거래 비용 증가 (더 많은 종목 리밸런싱)

**최소 실험**
| ID | 설명 | 변경점 |
|----|------|--------|
| 3a | Max single weight 15% | 개별 종목 cap |
| 3b | Top-3 cap 45% | 상위 3종목 합계 제한 |
| 3c | Sector cap 35% | Tech 내 sub-sector (AI/Cloud/Semi) 분산 |

**PASS Gate**
```yaml
gate:
  herfindahl_index: "<= 0.15"
  fold14_return: ">= 0.8 * fold_mean"
  lockbox_min: ">= 1.20"
```

### PATCH-4: Signal Decay Detection
**왜 필요한가**
- Fold14(최신)가 계속 worst → 알파 신호가 decay 중일 가능성
- 과거 최적화가 현재 regime에서 작동 안 할 수 있음

**위험/부작용**
- 잦은 모델 교체 → 새로운 과최적화 위험
- "Decay"와 "일시적 underperformance" 구분 어려움

**최소 실험**
| ID | 설명 | 변경점 |
|----|------|--------|
| 4a | Rolling alpha t-stat | 60일 rolling으로 t-stat < 1.5면 신호 가중치 ↓ |
| 4b | Regime-aware weighting | VIX/금리 레짐별로 다른 factor weight |
| 4c | Recency bias | 최근 3개 fold에 1.2x 가중치 |

**PASS Gate**
```yaml
gate:
  recent_3fold_avg: ">= 0.9 * all_fold_avg"
  alpha_tstat_current: ">= 1.5"
  lockbox_mean: ">= 1.75"
```

---

### PATCH-5: Cost Model Realism
**왜 필요한가**
- 현재 비용 모델 검증 필요 (슬리피지, 세금, 환전)
- Backtest에서 10bps 가정 → 실제 20~30bps일 수 있음

**위험/부작용**
- 비용 과대 추정 → 실제보다 보수적 운용
- 종목별 유동성 차이 미반영

**최소 실험**
| ID | 설명 | 변경점 |
|----|------|--------|
| 5a | Cost sensitivity | 10/20/30bps로 3가지 시뮬레이션 |
| 5b | Turnover penalty | 월간 회전율 > 30% → 추가 페널티 |
| 5c | Size-adjusted slippage | 소형주(SMID) 슬리피지 2x |

**PASS Gate**
```yaml
gate:
  cost_30bps_lockbox: ">= 1.50"
  monthly_turnover: "<= 0.35"
  performance_delta_10vs30bps: "<= 0.15"  # 비용 민감도 낮아야
```
