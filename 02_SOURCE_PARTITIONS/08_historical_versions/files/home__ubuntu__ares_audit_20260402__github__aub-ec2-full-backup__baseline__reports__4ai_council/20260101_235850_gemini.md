### 1. Candidate 검증: 노이즈 주입 및 민감도 테스트 (Robustness Check)
*   **이유:** `candidate` (Mean: 1.55)가 `champion` (Mean: 1.33) 대비 급격한 성능 향상을 보임. 이는 특정 파라미터가 노이즈에 과적합되었을 가능성이 높음. 라이브 투입 전 신호의 강건함을 증명해야 함.
*   **위험:** 과적합된 전략이 폐기될 경우, 단기적으로 성능 정체 발생 가능.
*   **실험 정의:**
    *   `exp_noise_price`: OHLC 데이터에 무작위 노이즈(±0.1~0.5%) 주입 후 백테스트.
    *   `exp_noise_param`: 핵심 파라미터(Lookback window 등)를 ±10% 변동시켜 결과 관측.
    *   `exp_lag_execution`: 체결을 1-bar 지연(Open 체결 가정)시켜 슬리피지 내성 확인.
*   **게이트 (PASS 조건):**
    *   노이즈 주입 시 Lockbox Mean 하락폭이 15% 이내일 것.
    *   MDD가 -10%를 초과하여 악화되지 않을 것.
*   **기대 관측치:**
    *   과적합이면 성능이 50% 이상 급락함(Fail). 강건하면 완만한 하락세 유지.

### 2. 섹터 상관관계 강제 분산 (Tech vs Healthcare Allocation)
*   **이유:** Tech와 Healthcare는 금리/규제 민감도가 다름. 현재 8~14 종목이 특정 섹터(예: Tech Momentum)에 쏠려 수익을 냈을 가능성 배제 필요. 낮은 MDD(-0.04)가 분산 효과인지, 단순히 현금 비중이 높아서인지 확인해야 함.
*   **위험:** 강제 분산으로 인해 주도주(Tech)의 업사이드가 제한되어 수익률(Mean) 감소 가능성.
*   **실험 정의:**
    *   `exp_sector_balance`: 포트폴리오 내 Tech(XLK/QQQ proxy)와 Healthcare(XLV proxy) 비중의 합이 각각 최소 20%가 되도록 페널티 부여.
    *   `exp_corr_filter`: 유니버스 내 종목 간 상관계수가 0.7 이상인 종목 동시 보유 금지.
*   **게이트 (PASS 조건):**
    *   Lockbox Min(최악의 경우) > -0.1 (방어력 유지).
    *   Fold14_MDD 변화폭 < 0.02 (MDD 안정성 확인).
*   **기대 관측치:**
    *   수익률은 소폭 하락하더라도, 샤프 지수(Sharpe)와 손익비가 개선되어야 함.

### 3. 변동성 돌파 임계값 동적 조정 (Regime Adaptive Threshold)
*   **이유:** `worst_mdd`가 -4.8%로 매우 낮음. 이는 진입 장벽이 너무 높거나(기회 손실), 손절이 너무 타이트함(잦은 손절비용). 변동성 장세(VIX 상승 등)에서 진입/청산 로직을 유연하게 하여 수익 기회 포착 필요.
*   **위험:** 진입 허들을 낮출 경우 MDD가 급격히 증가할 수 있음(특히 Tech 급락 시).
*   **실험 정의:**
    *   `exp_dynamic_vol`: 시장 변동성(관측지표 ETF: SPY/QQQ의 ATR)에 비례하여 진입 임계값(Threshold)을 0.8x~1.2x로 자동 스케일링.
    *   `exp_stop_widen`: 손절폭(Stop Loss)을 현재 설정의 1.2배로 확장하여 휩소(Whipsaw) 회피 테스트.
*   **게이트 (PASS 조건):**
    *   Tuning Mean > 1.45 (기존 Candidate 수준 유지/상승).
    *   Worst MDD < -0.08 (8% 이내로 리스크 통제).
*   **기대 관측치:**
    *   거래 횟수(Trade Count) 증가 및 승률(Win Rate)의 미세한 하락, 그러나 총 손익(Net Profit) 증가.

### 성능 정체 시 원인 분해 (Debugging Checklist)

성능 지표(Mean/Sharpe)가 개선되지 않을 경우 다음 순서로 점검:

1.  **트리거(Trigger) 빈도:**
    *   *현상:* 거래 횟수가 극히 적음 (월 1~2회 미만).
    *   *조치:* 진입 로직의 `AND` 조건을 `OR`로 완화하거나, 필터(RSI, MA 이격도 등)의 임계값을 10% 넓힘.

2.  **노출(Exposure) 부족:**
    *   *현상:* 승률은 높으나 수익금(Total Return)이 낮음.
    *   *조치:* 포지션 사이징(Position Sizing) 로직 점검. Kelly Criterion 비율을 상향하거나, 변동성 역가중(Volatility Inverse Weighting) 강도를 낮춤.

3.  **비용(Cost) 과다:**
    *   *현상:* Gross Return은 좋으나 Net Return이 나쁨.
    *   *조치:* 잦은 리밸런싱 제한 (Holding Period 최소 3~5일 강제). 슬리피지 모델이 Tech 주식의 호가 갭을 과하게 반영하는지 확인.

4.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 연도(예: 2022년 하락장)에만 성과가 좋고 상승장에서 소외됨.
    *   *조치:* 숏(Short) 비중 축소 또는 롱 온리(Long-only) 로직의 모멘텀 필터 기간(Lookback) 단축 (Fast Signal 적용).
