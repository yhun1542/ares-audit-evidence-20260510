## 2. 성능 정체 시 원인 분해 (Decomposition)

성능 지표(OOS Mean 1.88)가 움직이지 않을 때, 다음 순서로 원인을 제거하라.

1.  **트리거(Trigger) 확인:**
    *   **증상:** 매매 횟수(Trade Count)가 0이거나 매우 낮음.
    *   **액션:** 진입 조건(Threshold)을 완화하여 신호가 발생하는지 확인 (예: RSI < 30 -> RSI < 40).
    *   **비용:** 신호가 없으면 비용도 0이므로, 로그 파일 크기로 1차 판별 가능.

2.  **적용(Allocation) 확인:**
    *   **증상:** 신호는 있는데 잔고가 안 바뀜.
    *   **액션:** 포지션 사이징 로직(Kelly, Equal weight)에서 `target_weight`가 `min_weight`보다 작은지 체크. 레버리지 한도 체크.

3.  **노출(Exposure) 확인:**
    *   **증상:** 시장 상승분 대비 수익률이 현저히 낮음 (Beta < 0.3).
    *   **액션:** `exposure_min`이 너무 낮게 설정되어(0.47) 현금 보유 비중이 과다한지 점검. ETF(SPY/QQQ) 대비 상관계수 측정.

4.  **레짐(Regime) 불일치:**
    *   **증상:** 특정 기간(예: 금리 인상기)에만 손실 집중.
    *   **액션:** 2024-2025년 구간의 섹터 로테이션(Tech -> Bio)을 모델이 따라가고 있는지 확인. `rebalance_pinpoint` 실패 원인이므로 수동으로 섹터 비중 시계열 플롯 확인.
