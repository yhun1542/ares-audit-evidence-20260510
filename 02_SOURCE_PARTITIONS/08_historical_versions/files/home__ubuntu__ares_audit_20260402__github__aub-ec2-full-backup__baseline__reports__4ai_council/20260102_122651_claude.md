## 1. TOP 5 우선순위 제안

### PATCH-1: Risk-Off 트리거 과민도 점검

**(a) 필요성**
- Candidate의 lockbox_min 0.33 (Champion 1.13 대비 -70%) → 특정 fold에서 과도한 현금화 발생
- FSA 모듈 추가 후 시그널 충돌로 "이중 헷지" 가능성

**(b) 위험/부작용**
- 트리거 완화 시 MDD 악화 (현재 -4.2% → -6%+ 복귀)
- 레짐 의존도 상승

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|----------|--------|-------------|
| P1-A | FSA threshold 0.3→0.4 상향 | lockbox_min > 0.8 AND worst_mdd < -6% | 현금비중 30%→20% 감소 |
| P1-B | MRD+FSA 동시발동 금지 (mutex) | lockbox_mean > 1.65 | 시그널 중복률 50%↓ |
| P1-C | Risk-off 진입 후 3일 쿨다운 | turnover < 25% | 휩소 감소 |

**(d) PASS 조건**
```
lockbox_min >= 0.9 AND lockbox_mean >= 1.65 AND worst_mdd <= -6.5%
```

## 2. 성능 미움직임 원인 분해 트리

```
성능 불변
├─ 트리거 미발동
│   ├─ 조건 과다 (AND 체인)
│   └─ 임계값 극단치
├─ 발동 but 미적용
│   ├─ 포지션 이미 동일
│   └─ 충돌 규칙 override
├─ 적용 but 노출 미변화
│   ├─ 종목 상관관계 1.0
│   └─ 섹터 편중 유지
├─ 노출 변화 but 비용 상쇄
│   ├─ 거래비용 > 기대수익
│   └─ 슬리피지 과소추정
└─ 비용 반영 후도 불변
    └─ 레짐 불일치 (백테스트 ≠ 실제)
```
