**위험/부작용:**

- fold 재분할 시 과거 실험 비교 불가

**실험 정의:**

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P2-A | 5-fold별 OOS 분포 시각화 | 모든 fold > 1.0 | fold별 Sharpe 리스트 |
| P2-B | Walk-forward 1년 lag 검증 | OOS degradation < 30% | 연도별 decay 곡선 |
| P2-C | Lookhead bias 스캔 (feature timestamp audit) | 0 violations | 위반 feature 목록 |

```
✅ min_fold / mean_fold > 0.5

✅ lookahead violation = 0
```
