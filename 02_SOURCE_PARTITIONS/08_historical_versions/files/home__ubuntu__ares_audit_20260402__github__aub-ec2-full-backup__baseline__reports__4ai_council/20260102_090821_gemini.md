[TOP 5 우선순위: 체크리스트 및 실험 제안]

### 1. [CRITICAL] MDD 메트릭 산출 로직 디버깅 및 서킷브레이커 검증
`worst_mdd: None` 상태는 리스크 관리 모듈이 작동하지 않음을 의미. 최우선 수정 필요.

*   **(a) 이유:** MDD가 계산되지 않으면 파산 위험(Ruin Risk)을 감지할 수 없음. 현재 OOS Mean(1.88)은 하락장을 무시한 수치일 가능성 높음.
*   **(b) 위험:** MDD 계산 후 실제 성과가 급락하여 전략 폐기 수순을 밟을 수 있음(그러나 필수적인 과정).
*   **(c) 실험 (48h Loop):**
    1.  **[EXP-01]** 메트릭 계산기 디버그: Drawdown 계산 로직을 수정하여 `None` 제거.
    2.  **[EXP-02]** Hard Stop 로직 주입: 개별 종목 -15% 또는 포트폴리오 -10% 도달 시 강제 청산(Stop-loss) 로직 적용 후 OOS 변화 관찰.
*   **(d) PASS 조건:** `worst_mdd` 수치 도출 완료 및 MDD < -25% 유지.

### 2. 동적 노출도(Exposure) 하한선 해제 (Cash Buffer 확장)
현재 `exposure_min: 0.47`은 하락장에서도 자산의 절반을 강제로 태운다는 의미. Tech/Healthcare는 변동성이 크므로 0%까지 열어야 함.

*   **(a) 이유:** OOS Min(0.43)이 낮은 이유는 하락장에서 강제 매수 포지션을 유지하기 때문일 수 있음.
*   **(b) 위험:** 강세장에서 현금 비중 과다로 인한 수익률(Upside) 저조.
*   **(c) 실험 (48h Loop):**
    1.  **[EXP-03]** Regime Filter: 관측용 ETF(QQQ, XLV)가 200일 이동평균선 하회 시 `target_exposure`를 0.0으로 강제 설정.
    2.  **[EXP-04]** Volatility Scaling: VIX > 25 구간에서 `max_exposure`를 0.5로 제한.
*   **(d) PASS 조건:** OOS Min > 0.8로 상승, 전체 CAGR 감소폭 10% 이내.

### 3. 거래 비용 및 슬리피지(Slippage) 스트레스 테스트
Tech/Healthcare 8~14개 종목의 잦은 리밸런싱은 비용에 민감함.

*   **(a) 이유:** 백테스트 상의 1.88이 실제 체결 오차와 수수료를 반영하지 않은 '종이 수익'일 가능성 배제.
*   **(b) 위험:** 샤프 비율이 1.0 이하로 붕괴될 가능성.
*   **(c) 실험 (48h Loop):**
    1.  **[EXP-05]** Cost Penalty: 매매 회전율(Turnover)에 비례하여 왕복 비용을 10bps(0.1%)에서 20bps(0.2%)로 상향 적용.
    2.  **[EXP-06]** Liquidity Filter: 하위 20% 유동성 종목(일평균거래대금 기준) 제외 후 8~14개 유니버스 재구성.
*   **(d) PASS 조건:** 비용 2배 적용 시에도 OOS Mean > 1.3 유지.

### 4. 상관관계 기반 유니버스 압축 (Decorrelation)
Tech와 Healthcare가 동시에 무너지는 거시경제 이벤트(금리 급등 등) 방어.

*   **(a) 이유:** 8~14개 종목이 모두 고성장주(High Beta)에 쏠려있으면 분산 효과 없음.
*   **(b) 위험:** 헷지(Hedge) 종목이 전체 수익률을 갉아먹을 수 있음(Performance Drag).
*   **(c) 실험 (48h Loop):**
    1.  **[EXP-07]** Cluster Pruning: 최근 6개월 상관계수 행렬(Correlation Matrix) 기반, 상관계수 > 0.8인 종목 쌍 중 모멘텀 낮은 종목 제거.
    2.  **[EXP-08]** Defensive Sector Mix: 유니버스 내에 대형 제약주(Low Beta Healthcare) 최소 30% 할당 강제.
*   **(d) PASS 조건:** `worst_mdd` 개선(수치 감소) 및 Sharpe Ratio 상승.

### 5. 생존 편향(Survivorship Bias) 제거 검증
2026년 시점에서 과거 데이터를 볼 때, 상장 폐지된 바이오/테크 기업이 데이터셋에 포함되어 있는지 확인.

*   **(a) 이유:** 망한 기업을 제외하고 테스트했다면 성과는 100% 허구. 특히 Bio/Tech는 상폐 빈번.
*   **(b) 위험:** 데이터셋 재구축에 시간 소요, 성능 대폭 하락.
*   **(c) 실험 (48h Loop):**
    1.  **[EXP-09]** Delisted Injection: 과거 S&P500/Nasdaq100 구성 종목 히스토리를 로드하여, 당시 시점 기준 유니버스 구성(현재 존재 여부 무관).
*   **(d) PASS 조건:** 데이터셋 수정 후에도 OOS Mean > 1.0 유지 (만약 급락 시 전략 폐기 고려).

### [성능 정체 시 원인 분해 아이디어]

성능 지표(Sharpe/Return)가 유의미하게 변하지 않을 때 다음 트리를 따라 점검:

1.  **트리거(Trigger) 민감도 부족:**
    *   *현상:* 시장이 급변해도 포트폴리오 종목 교체가 거의 없음.
    *   *액션:* 진입/청산의 임계값(Threshold)을 좁히거나, 룩백 윈도우(Lookback Window)를 단축(예: 60일 -> 20일)하여 반응 속도 테스트.

2.  **노출(Exposure) 로직의 경직성:**
    *   *현상:* `exposure_min/max` (0.47 / 0.84) 범위 내에서만 움직이며 레버리지나 현금화 효과를 못 봄.
    *   *액션:* 노출도 결정 함수를 'Binary(On/Off)'가 아닌 'Sigmoid(확률적 비중 조절)' 형태로 변경.

3.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 연도(예: 2022년)에만 손실이 집중되고 나머지 해에는 평타.
    *   *액션:* Tech/Healthcare 외에 '방어적 현금(SHV/BIL)'을 하나의 종목으로 간주하여 경쟁시킬 것.

4.  **비용(Cost) 장벽:**
    *   *현상:* 총 수익(Gross Return)은 좋으나 순수익(Net)이 낮음.
    *   *액션:* 매매 빈도를 강제로 절반으로 줄이는(Hold 기간 2배 연장) 제약 조건 추가 후 순수익 변화 관찰.
