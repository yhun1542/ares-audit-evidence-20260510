## 1. 우선순위 TOP-5 Patch

### PATCH-1: 파이프라인 정합성 복구 (CRITICAL)

**(a) 왜 필요한가**
- MDD=None → 리스크 게이트가 작동 안 함
- rebalance.csv 로드 실패 → 회전율/비용 계산 불가
- OOS Mean 불일치(1.88 vs 2.63) → 어느 숫자가 진실인지 불명

**(b) 위험/부작용**
- 수정 중 기존 로그 포맷 변경 시 하위호환 깨짐
- 잘못 수정하면 전체 autopilot 중단

**(c) 최소 실험**

| ID | 실험 | 게이트 |
|----|------|--------|
| P1-A | `aub_validator.py --check-mdd` 추가, champion JSON에 mdd 필드 강제 | mdd ≠ None |
| P1-B | rebalance 출력을 JSON→CSV 듀얼로 변경, 경로 하드코딩 제거 | 파일 존재 & row > 0 |
| P1-C | OOS 계산 로직 단위테스트: 같은 입력 → 동일 출력 확인 | assert diff < 1e-6 |

**(d) PASS 조건**
```
□ worst_mdd 필드 존재 & 숫자
□ rebalance_pinpoint.py 정상 로드
□ OOS Mean 단일 소스에서 일관된 값
```

### PATCH-2: OOS Min Fold 원인 분해

**(a) 왜 필요한가**
- OOS Min 0.43 → 특정 폴드에서 SR < 0.5
- 해당 폴드가 특정 레짐(예: 2022 금리인상)인지, 전략 버그인지 구분 필요

**(b) 위험/부작용**
- 최악 폴드만 타겟 수정 시 과최적화 위험
- 폴드 수 줄이면 통계적 신뢰도 하락

**(c) 최소 실험**

| ID | 실험 | 게이트 |
|----|------|--------|
| P2-A | 최악 폴드 기간 추출 → 해당 기간 SPY/QQQ 벤치마크 SR 비교 | 벤치도 < 0.5면 레짐 문제 |

| P2-C | 해당 폴드만 exposure cap 70%로 제한 후 재실행 | OOS Min > 0.6 |

**(d) PASS 조건**
```
□ 원인 식별: 레짐 / 섹터집중 / 전략버그 중 1개 확정
```

## 2. 성능 불변 원인 분해 트리

```
OOS 안 움직임
├─ [트리거] 신호가 안 바뀜
│   ├─ 피처 포화 (같은 피처 재탕)
│   └─ 임계값이 너무 넓음 (항상 발동 or 항상 미발동)
│
├─ [적용] 신호 → 포지션 전환 안 됨
│   ├─ exposure cap에 막힘
│   └─ 리밸런스 주기가 너무 김
│
├─ [노출] 포지션 잡았으나 수익 없음
│   ├─ 종목 선택 무관 (SPY 추종)
│   └─ 레짐 전환 (모멘텀 → 밸류)
│
├─ [비용] 수익 있으나 비용에 흡수
│   ├─ 회전율 과다
│   └─ 슬리피지 과소 추정
│
└─ [레짐] 백테스트 기간 특이성
    ├─ 2020-2021 Tech 버블
    └─ 2022 금리 쇼크
```

**점검 순서**:
1. 트리거 발동률 로그 → 너무 높거나 낮으면 임계값 문제
2. 실제 체결 로그 → exposure 변화 없으면 적용 문제
3. 종목별 기여도 → SPY 상관 > 0.95면 알파 없음
4. 회전율 계산 → 400%/yr 초과면 비용 문제
5. 폴드별 레짐 태깅 → 특정 레짐만 실패면 전략 한계
