## 1. 우선순위 TOP 5 실행 체크리스트

### P1. Fold 퇴화 원인 격리 (블로커)

**(a) 왜 필요한가**
- 4/10 fold가 degenerate → OOS 평균이 6개 fold에만 의존
- 생존자 편향으로 3.32라는 숫자 자체가 무의미

**(b) 위험/부작용**
- 원인이 데이터(특정 기간 레짐)면 구조적 한계
- 원인이 코드면 전체 백테스트 재실행 필요

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P1-A | `--degenerate-debug` 플래그로 fold 1,2,3,8만 단독 실행 → 어느 단계에서 0 리턴 확인 | 로그에 `signal_count=0` 또는 `position_size=0` 출력 | 퇴화 지점 특정 |
| P1-B | 퇴화 fold 기간의 VIX/SPY drawdown 상관 분석 | 4개 fold 모두 VIX>30 기간과 80%+ 겹침 | 레짐 필터 필요 확인 |
| P1-C | `min_signal_threshold=0.01→0.001` 로 완화 후 재실행 | degenerate fold ≤1 | 임계값 과민 여부 |

**(d) PASS 조건**
```
degenerate_folds ≤ 1 AND oos_min > 0.5
```

### P2. 재현성/추적 인프라 복구

**(a) 왜 필요한가**
- `lane_hash=None, run_hash=None` → 어떤 코드/파라미터로 생성됐는지 불명
- 48h 루프가 돌아도 어떤 실험이 어떤 결과인지 매핑 불가

**(b) 위험/부작용**
- 해시 생성 오버헤드 (무시 가능, <1s)
- 기존 아티팩트와 호환성 체크 필요

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P2-A | `git rev-parse HEAD` + config hash를 HANDOFF에 자동 삽입 | 다음 HANDOFF에 `lane_hash != None` | 재현 가능 |
| P2-B | rebalance.csv 경로 검증 스크립트 추가 (`--dry-run`) | `FileNotFoundError` 0건 | 파이프라인 안정 |

**(d) PASS 조건**
```
lane_hash != None AND run_hash != None AND file_errors = 0
```

### P3. OOS 과최적화 검증

**(a) 왜 필요한가**
- 2.63 → 3.32 (+26%) 단일 iteration 점프는 레드플래그
- IS/OOS gap 미보고 → 과적합 여부 판단 불가

**(b) 위험/부작용**
- 실제 개선일 수도 있으나, fold 퇴화와 동시 발생은 우연 아님

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P3-A | 동일 config로 `--seed` 3개 변경 재실행 | OOS 분산 < 0.3 | 안정적이면 실제 개선 |
| P3-B | IS Sharpe 대비 OOS Sharpe 비율 리포트 추가 | `oos/is_ratio > 0.6` | 과적합 아님 |
| P3-C | 최근 6개월 holdout (2025H2) 별도 테스트 | holdout Sharpe > 1.5 | 시간외 일반화 |

**(d) PASS 조건**
```
seed_variance < 0.3 AND oos_is_ratio > 0.6 AND holdout_sharpe > 1.5
```

## 2. 48h 자동 루프 실행 순서

```
HOUR 0-8:   P2-A,B (인프라) → P1-A,B,C (fold 진단)
HOUR 8-16:  P3-A,B (과적합 검증)
HOUR 16-32: P4-A,B (비용) → P5-A,B (집중도)
HOUR 32-48: P3-C (holdout) → 종합 리포트
```

**자동 중단 조건 (Circuit Breaker)**
```python
if degenerate_folds >= 5 or oos_mean < 1.0:
    STOP("구조적 결함 - 수동 개입 필요")
```

└─ 5. 레짐 불일치
    └─ 훈련 기간 bull, 테스트 기간 bear → 레짐 라벨 추가
