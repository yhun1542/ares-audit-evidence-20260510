━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 실전 배포 시 해당 레짐 진입 → 손실 집중

**(b) 위험/부작용**
- 폴드 정의 변경 → 기존 baseline과 비교 불가
- 과도한 정규화 → 전체 수익 하락

**(c) 실험 체크리스트**

```

  - 게이트: degenerate_folds ≤ 2개
  - 기대치: OOS variance 감소, mean 소폭 하락 허용

□ EXP-P2.3: 레짐 분기 시그널 추가
  - 정의: VIX>30 시 별도 파라미터셋 적용
  - 게이트: 고VIX 폴드 수익률 > -0.5%
  - 기대치: degenerate → marginal로 전환
```

```
수익 변화 없음

│   ├── 진단: 일간 시그널 발생 빈도 체크
│   └── 패치: threshold 완화 또는 feature 추가
│
├── [적용 실패] 시그널 → 포지션 변환 안 됨
│   ├── 진단: rebalance 로그에서 시그널 vs 실행 비교
│   └── 패치: position sizing 로직 검토
│
├── [노출 실패] 포지션은 있으나 exposure 미미
│   ├── 진단: 평균 exposure 체크 (현재 min=0 이슈)
│   └── 패치: 최소 exposure 강제 또는 확신도 캘리브레이션
│
├── [비용 상쇄] 수익 발생했으나 비용이 잡아먹음
│   ├── 진단: gross vs net 수익 비교
│   └── 패치: 턴오버 감소, 거래 임계값 상향
│
└── [레짐 불일치] 현재 시장이 학습 구간과 다름
    ├── 진단: 현재 VIX/섹터모멘텀 vs 학습구간 분포 비교
    └── 패치: 온라인 적응 로직 또는 레짐 스위칭
```
