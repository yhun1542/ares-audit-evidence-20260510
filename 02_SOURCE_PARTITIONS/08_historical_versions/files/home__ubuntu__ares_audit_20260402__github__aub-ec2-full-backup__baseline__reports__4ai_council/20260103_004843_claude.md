### P1. Degenerate Fold 원인 격리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한지**
- 4개 폴드가 퇴화 → 40% 샘플이 유효 학습 안됨
- 남은 6개 폴드만으로 OOS Mean 계산 시 서바이버십 바이어스

**(b) 위험/부작용**
- 퇴화 원인이 데이터 품질이면 전체 파이프라인 재검토 필요
- 폴드 정의 변경 시 기존 결과와 비교 불가

**(c) 실험 체크리스트**

```
┌─────────────────────────────────────────────────────────────┐
│ EXP-1A: Fold별 데이터 분포 덤프                              │
├─────────────────────────────────────────────────────────────┤
│ □ python3 tools/fold_inspector.py --folds 1,2,3,8           │
│   --output reports/degenerate_fold_stats.json               │
│                                                             │
│ GATE: 각 폴드의 sample_count, date_range, ticker_coverage   │
│ PASS: 모든 폴드 sample ≥ 500, ticker ≥ 6                    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ EXP-1B: 퇴화 폴드 제외 후 OOS 재계산                         │
├─────────────────────────────────────────────────────────────┤
│ □ python3 backtest_engine.py --exclude-folds 1,2,3,8        │
│   --tag "healthy_folds_only"                                │
│                                                             │
│ GATE: oos_mean, oos_std, worst_mdd                          │
│ PASS: oos_mean > 2.0 AND worst_mdd > -15%                   │
│ WARN: 결과는 참고용, Champion 교체 불가                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ EXP-1C: 폴드 시드 변경 후 퇴화율 측정                        │
├─────────────────────────────────────────────────────────────┤
│ □ for seed in 42 137 256; do                                │
│     python3 backtest_engine.py --cv-seed $seed              │
│       --tag "seed_${seed}_degen_test"                       │
│   done                                                      │
│                                                             │
│ GATE: degenerate_fold_count per seed                        │
│ PASS: median(degen_count) ≤ 1                               │
└─────────────────────────────────────────────────────────────┘
```

**(d) 종합 PASS 조건**
- `degenerate_folds ≤ 1` 달성하는 seed 또는 fold 정의 발견
