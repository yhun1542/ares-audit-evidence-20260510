## 1. 우선순위 TOP 5 Patch

```

[RISK] 과최적화: 특정 기간 피하도록 fitting 시 미래 레짐 miss
[EXPERIMENT]

  EXP-1C: 위 둘 AND 조건으로 결합

[EXPECTED] worst_mdd → -9.5% 이하, tuning_mean 유지 ±3%
```

### PATCH-2: Signal Decay 점검 (Staleness Audit)
```
[WHY] 동일 lockbox 수치 = 신호가 이미 반영됐거나 지연 과다
[RISK] latency 축소 시 거래비용 급증
[EXPERIMENT]
  EXP-2A: entry signal → T+0 close 적용 (현재 T+1 가정 시)
  EXP-2B: holding period 5d → 3d 축소 후 turnover/cost 측정
  EXP-2C: signal 유효기간 tagging (>3d old → weight 0.5)
[GATE] Sharpe 개선 ≥0.05 AND turnover 증가 ≤20%
[EXPECTED] tuning_mean 1.80+, cost-adjusted 유지
```

### PATCH-3: Sector Concentration Clamp
```
[WHY] Tech+Healthcare 집중 → 동일 drawdown 구간 overlap
[RISK] 분산 과다 시 alpha 희석
[EXPERIMENT]
  EXP-3A: 단일 섹터 max 60% (현재 무제한 가정)
  EXP-3B: 상관계수 >0.7 종목 pair 중 1개만 보유
  EXP-3C: Healthcare 비중 floor 20% 강제
[GATE] fold별 mdd 분산 감소 (σ_mdd ↓ 15%+) AND mean 유지
[EXPECTED] worst_mdd → -10% 이하, 수익 ±2%
```

### PATCH-4: Cost Model Audit (Hidden Drag)
```
[WHY] lockbox 정체 = 실현 수익 예측 오차 → 비용 과소 추정 가능
[RISK] 비용 과대 반영 시 거래 억제 → alpha 누락
[EXPERIMENT]
  EXP-4A: slippage 가정 3bp → 5bp로 상향 후 재계산
  EXP-4B: 소형주(시총 하위 30%) 별도 10bp 적용
  EXP-4C: 비용 민감도 sweep (1bp~10bp) → break-even 찾기
[GATE] 비용 조정 후 lockbox/tuning gap ≤ 5%
[EXPECTED] 실제 운영 시 수익 괴리 축소
```

### PATCH-5: Inactive Ticker Pruning
```
[WHY] 8~14 종목 중 signal 미발생 종목 → 기회비용
[RISK] 과거 비활성 종목이 미래 급등 시 miss
[EXPERIMENT]
  EXP-5A: 최근 60d signal 0회 종목 제외 후 backtest
  EXP-5B: 교체 후보 3개 (Healthcare 1, Tech 2) 추가 테스트
  EXP-5C: 동적 universe (quarterly rebalance) vs 고정
[GATE] tuning_mean ≥ 1.75 유지 AND 종목 수 10~12
[EXPECTED] 자본 효율 +5%, turnover ±10%
```
