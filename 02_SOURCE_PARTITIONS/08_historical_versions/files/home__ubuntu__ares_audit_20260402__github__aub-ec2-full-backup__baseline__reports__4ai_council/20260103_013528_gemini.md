### 2. 실행 가능한 Patch/실험 제안

#### A. Cost & Slippage Reality Patch
*   **이유**: 챔피언의 높은 수익률이 낮은 비용 설정 덕분일 가능성 차단. Tech 고변동성 종목은 슬리피지가 큼.
*   **위험**: 모든 전략이 폐기될 수 있음(Start over risk).
*   **실험 정의**:
    1.  `Exp_Cost_Base`: 수수료 0.1%, 슬리피지 0.05% (기존 대비 상향).
    2.  `Exp_Cost_High`: 수수료 0.15%, 슬리피지 0.10%.
    3.  `Exp_Cost_Variable`: Volatility 기반 동적 슬리피지 적용.
*   **Gate (통과 조건)**:
    *   `Exp_Cost_Base`에서 Tuning Sharpe > 1.5 유지.
    *   `Exp_Cost_High`에서 MDD < -15% 방어.
*   **기대 관측치**: 수익률 20~30% 하락하더라도, 우상향 곡선 유지 시 'Real Alpha'로 판정.

#### B. Macro Regime Filter (ETF 관측)
*   **이유**: Tech/Bio는 금리(TLT)와 시장 심리(SPY/VIX)에 민감. 하락장에서 현금 비중을 늘려야 함.
*   **위험**: 신호 지연으로 인한 휩소(Whipsaw) 손실.
*   **실험 정의**:
    1.  `Exp_Macro_TLT`: TLT 20일 이평선 하회 시, 전체 포지션 사이즈 50% 축소.
    2.  `Exp_Macro_VIX`: VIX > 25 구간에서 신규 진입 금지.
    3.  `Exp_Market_Timing`: SPY 200일 이평선 하회 시 Tech 비중 0, Health(방어) 비중 유지.
*   **Gate (통과 조건)**:
    *   Worst MDD가 기존 대비 10% 이상 개선 (예: -8% -> -7.2% 이내).
    *   Total Return 감소폭이 10% 미만일 것.
*   **기대 관측치**: 상승장 수익 일부 반납하더라도, 하락 구간(2022년 등)에서 Flat한 곡선 형성.

#### C. Parameter Stability Check (Noise Injection)
*   **이유**: `Champion_v5`가 특정 파라미터 값에 과적합되었는지 확인. Lockbox 괴리 해소 목적.
*   **위험**: 챔피언 모델 탈락 가능성 매우 높음.
*   **실험 정의**:
    1.  `Exp_Noise_Pos`: 주요 Lookback Period +10% 변경.
    2.  `Exp_Noise_Neg`: 주요 Lookback Period -10% 변경.
    3.  `Exp_Noise_Entry`: 진입 Threshold ±5% 변경.
*   **Gate (통과 조건)**:
    *   3가지 실험의 Performance Mean이 원본 대비 80% 이상 유지.
    *   Sharpe Ratio 표준편차가 0.2 이하일 것.
*   **기대 관측치**: 파라미터 변화에도 성능이 평탄(Plateau)하면 강건한 모델. 급락하면 폐기.

### 3. 성능 정체 시 원인 분해 (Decomposition)

성능 지표가 개선되지 않을 경우, 아래 순서로 원인을 격리하여 디버깅하시오.

1.  **트리거(Trigger) 확인**: 매매 신호 자체가 발생하는가?
    *   *Check*: 거래 횟수(Number of Trades)가 0 또는 극단적으로 적은지 확인 (조건이 너무 엄격함).
2.  **노출(Exposure) 확인**: 신호는 뜨는데 포지션을 잡지 못하는가?
    *   *Check*: 현금 부족, 리스크 한도(Risk Budget) 초과, 종목당 최대 비중 제한에 걸리는지 로그 확인.
3.  **비용(Cost) 확인**: 벌어들이는데 비용으로 다 나가는가?
    *   *Check*: Gross Profit vs Net Profit 비율 확인. (비율 < 0.6이면 매매 빈도 과다).
4.  **레짐(Regime) 불일치**: 전략이 현재 시장과 안 맞는가?
    *   *Check*: 최근 1개월 Tech/Health 섹터 지수(XLK, XLV)와 전략 수익률 간의 상관계수 확인. 역행한다면 알파 소멸.
