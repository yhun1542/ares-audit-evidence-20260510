## 🎯 TOP 5 우선순위 액션

### **#1. Regime Detector 오작동 점검 (누수/서바이버십 리스크)**

**(a) 왜 필요한가**
- Tuning min이 -1.50까지 빠짐 → 특정 fold에서 regime 분류 실패 가능성
- VIX/금리 기반 regime이 실제 out-of-sample에서 look-ahead 없는지 확인 필요

**(b) 위험/부작용**
- Regime 로직 변경 시 전체 position sizing 영향
- 과거 폴드 재계산 필요 (연산 비용 +2h)

**(c) 최소 실험**

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `exp_regime_lag1` | VIX/금리 시그널에 T+1 lag 강제 적용 | lockbox_min ≥ 0 | tuning_min 개선 0.3+ |
| `exp_regime_disable` | Regime 모듈 off, 동일 가중 비교 | worst_mdd 비교 | 기존 대비 MDD 악화 ≤ 2% |
| `exp_regime_vix_only` | 금리 제거, VIX 단독 | fold14_mdd | 현행 대비 ±0.5% 이내 |

**(d) PASS 조건**
```
(lockbox_min ≥ 0.2) AND (tuning_min ≥ -1.0) AND (worst_mdd ≤ -0.06)
```

(sector_max_weight ≤ 0.50) AND (lockbox_mean ≥ 1.25) AND (turnover_increase ≤ 15%)

**(b) 위험/부작용**

### **#5. Position Sizing 민감도 (아키텍처)**

**(a) 왜 필요한가**
- 현재 sizing 로직이 변동성 역비례인지, 동일가중인지 미명시
- Sizing이 alpha 대비 과도하면 MDD 급등

**(b) 위험/부작용**
- Sizing 변경은 전체 리턴 분포 변경
- 레버리지 암묵 가정 확인 필요

**(c) 최소 실험**

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `exp_size_equal` | 동일 가중 (1/N) 강제 | lockbox_mean 비교 | 현행 대비 ±15% |
| `exp_size_vol_inv` | 변동성 역비례 명시 적용 | worst_mdd 개선 | MDD -1%+ |
| `exp_size_kelly_half` | Half-Kelly 적용 | lockbox_min ≥ 0.5 | 안정성 확인 |

**(d) PASS 조건**
```
(worst_mdd ≤ -0.05) AND (lockbox_mean ≥ 1.2) AND (leverage_implicit ≤ 1.0)
```
