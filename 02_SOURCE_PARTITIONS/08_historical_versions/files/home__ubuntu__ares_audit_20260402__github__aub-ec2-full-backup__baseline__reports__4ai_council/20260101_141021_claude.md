  정의: fold14 구간 sector exposure 히트맵 생성

## 2. 48h 자동 루프 명령 체크리스트

```bash
# STEP 1: Fold14 & tuning_min 진단 (blocking)
python3 experiment_system/tools/fold_diagnosis.py \
  --target-folds 14,worst_min \
  --output baseline/reports/fold_diagnosis.json

# STEP 2: PATCH-1~2 실험 병렬 실행
python3 experiment_system/tools/aub_autopilot.py \
  --experiments EXP-1.1,EXP-1.2,EXP-1.3,EXP-2.1,EXP-2.2 \
  --parallel 4 \
  --output baseline/results/patch_1_2.json

# STEP 3: gate 검사 후 PATCH-3~4 조건부 실행
python3 experiment_system/tools/gate_check.py \
  --input baseline/results/patch_1_2.json \
  --pass-then "EXP-3.1,EXP-3.2,EXP-4.1,EXP-4.2"

# STEP 4: PATCH-5는 관측용으로만 (commit 금지)
python3 experiment_system/tools/aub_autopilot.py \
  --experiments EXP-5.1,EXP-5.2 \
  --observe-only \
  --output baseline/reports/regime_signal_obs.json

# STEP 5: 최종 champion 업데이트 판정
python3 experiment_system/tools/aub_next_fix.py \
  --registry experiment_system/config/module_registry.yaml \
  --promote-if "lockbox_mean > 1.34 AND worst_mdd > -0.08"
```
