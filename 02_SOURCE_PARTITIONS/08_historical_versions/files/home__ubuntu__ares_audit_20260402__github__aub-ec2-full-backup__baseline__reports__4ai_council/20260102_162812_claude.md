## 🔴 우선순위 #2: Degenerate Folds 근본 원인 (40% 실패)

### 왜 필요한가
- 10개 폴드 중 4개 degenerate → **과최적화 또는 데이터 누수 징후**
- 특정 시장 레짐에서만 작동하는 전략일 가능성

### 위험/부작용
- Fold 제거 시 OOS 수치 인위적 상승 (서바이버십)
- 레짐 필터 추가 시 거래 기회 급감

### 실험 체크리스트

```

│   python3 experiment_system/tools/fold_regime_mapper.py \       │
│     --folds 1,2,3,8 \                                           │
│     --regime-indicator VIX,SPY_SMA200                           │
│                                                                 │
│ □ 게이트: degenerate fold들의 공통 레짐 특성 식별               │
│ □ 기대치: "VIX>25" 또는 "SPY<SMA200" 같은 패턴 발견             │
```
