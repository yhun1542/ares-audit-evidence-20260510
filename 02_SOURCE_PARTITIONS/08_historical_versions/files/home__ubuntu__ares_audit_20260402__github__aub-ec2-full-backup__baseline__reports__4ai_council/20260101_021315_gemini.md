[분석 결과]
현재 `champion`과 `candidate`의 성능이 소수점 단위까지 거의 동일함. 이는 **현재 탐색 공간(Hyperparameter Space)이 포화 상태**이거나, **새로운 실험 로직이 실제 거래 결정에 영향을 미치지 못하고 있음(Inactive Code)**을 시사. 또한 `tuning_min`(0.05)과 `lockbox_min`(1.34)의 괴리는 특정 과거 구간(Folds)에서의 치명적 손실(Drawdown)을 의미하며, 이는 과최적화의 강력한 신호임.

### 우선순위 TOP 5 제안 (48시간 루프)

#### 1. [Risk/Regime] '지옥의 Fold' 식별 및 매크로 컷오프 적용
*   **이유:** `tuning_min` 0.05는 특정 시기(예: 2022년 금리 인상기)에 자산이 녹아내렸음을 의미. 개별 종목 로직으로는 방어가 불가능한 시스템 리스크일 확률 높음.
*   **위험:** 방어적 로직 추가 시 상승장 수익(Upside) 일부 포기.
*   **실험 (Patch):**
    *   **(1) 실험 정의:** `Regime_Filter_SPY_MA`: SPY(관측용)가 200일 이동평균선 아래일 때 포지션 진입 금지 또는 현금 비중 50% 강제.
    *   **(2) 게이트:** `tuning_min` > 0.5 (기존 0.05에서 10배 개선 목표), `tuning_mean` 하락폭 < 5%.
    *   **(3) 기대 관측치:** MDD 대폭 축소, 특정 Fold의 수익률 급락 방어.

#### 2. [Universe/Sector] Healthcare 섹터의 '방어적 성격' 강제 검증
*   **이유:** Tech와 Healthcare가 동시에 무너지는 구간이 존재한다면, 현재 포함된 Healthcare 종목이 'High Beta Biotech'일 가능성 높음. 전통적 제약(Pharma) 위주로 유니버스 재정렬 필요.
*   **위험:** 바이오테크의 폭발적 성장성(Alpha) 제거.
*   **실험 (Patch):**
    *   **(1) 실험 정의:** `Filter_Low_Beta_Health`: Healthcare 종목 선정 시 Beta < 0.8 인 종목(대형 제약주 등)만 허용하는 화이트리스트 적용.
    *   **(2) 게이트:** `correlation_tech_health` < 0.3 (섹터 간 상관계수 하락 확인).
    *   **(3) 기대 관측치:** Tech 하락 구간에서 Healthcare 포트폴리오의 손실 상쇄 효과 발생.

#### 3. [Cost/Reality] 슬리피지/수수료 가중 스트레스 테스트
*   **이유:** 48시간 루프의 빈번한 리밸런싱 가정 시, `tuning_mean` 1.76이 실제 비용 반영 후 마이너스로 전환될 수 있음. 현재 챔피언이 '잦은 매매'로 수익을 낸다면 가짜 수익임.
*   **위험:** 거래 횟수가 급감하여 통계적 유의성 확보 실패.
*   **실험 (Patch):**
    *   **(1) 실험 정의:** `Cost_Multiplier_Test`: 거래 비용(수수료+슬리피지)을 현재 설정의 2배, 4배로 설정하여 백테스트.
    *   **(2) 게이트:** 4배 비용 적용 시에도 `Sharpe` > 1.0 유지.
    *   **(3) 기대 관측치:** 회전율(Turnover)이 높은 전략의 점수 급락 확인 및 저회전 전략 선별.

#### 4. [Mechanism] 동적 포지션 사이징 (Volatility Targeting)
*   **이유:** Tech(변동성 큼)와 Healthcare(변동성 작음)에 동일 비중을 투자하면 리스크는 Tech가 지배함. 변동성 역가중 방식이 필요.
*   **위험:** 저변동성 종목(Healthcare) 비중 과다로 전체 수익률 저하.
*   **실험 (Patch):**
    *   **(1) 실험 정의:** `Vol_Target_Positioning`: 개별 종목 비중 = `Target_Vol / Recent_ATR`. (변동성이 크면 비중 축소).
    *   **(2) 게이트:** `worst_mdd` > -0.09 (9% 이내로 방어).
    *   **(3) 기대 관측치:** Tech 급락 시 손실폭 감소, 포트폴리오 변동성 안정화.

#### 5. [Data/Bias] 서바이버십 바이어스 전수 조사 (수동 개입 필요)
*   **이유:** `lockbox` 성과가 `tuning`보다 비정상적으로 좋음(1.79 vs 1.76). 이는 2026년 시점(현재 시뮬레이션 시점)에 살아남은 '승자'들만 과거 데이터에 존재하기 때문일 수 있음.
*   **위험:** 데이터셋 전체 교체 필요성 대두 (시간 소요).
*   **실험 (Patch):**
    *   **(1) 실험 정의:** `Delisted_Include_Check`: 상장 폐지된 종목이 유니버스 풀에 포함되어 있는지 확인하는 더미 테스트 수행.
    *   **(2) 게이트:** 과거 5년 내 상폐 종목 3개 이상 포트폴리오 진입 이력 확인.
    *   **(3) 기대 관측치:** 상폐 종목 포함 시 `tuning_mean` 하락(현실화).

### 성능 정체(Plateau) 원인 분해 아이디어

현재 챔피언과 후보가 동일한 점수(`1.7618...`)를 기록 중. 다음 체크리스트로 원인을 파악하라.

1.  **트리거(Trigger) 부재:**
    *   새로 추가한 로직(예: `lockbox_v1`의 조건)이 너무 엄격하여, 전체 기간 동안 한 번도 `True`가 되지 않았는지 로그 확인. (If condition never met -> No change).
2.  **노출(Exposure) 미미:**
    *   변경된 로직이 전체 포트폴리오의 5% 미만 비중 종목에만 영향을 미쳐 전체 수익률에 희석되었는지 확인.
3.  **레짐(Regime) 불일치:**
    *   현재 전략이 '추세 추종'인데, 테스트 구간이 '박스권'이라 모든 시그널이 노이즈로 처리되고 있는지 확인. (ADX 지표 등으로 시장 추세 강도 필터링 필요).
