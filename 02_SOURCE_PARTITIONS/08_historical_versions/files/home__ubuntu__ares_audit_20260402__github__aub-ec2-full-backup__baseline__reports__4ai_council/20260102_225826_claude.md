## 3. 성능 불변 시 원인 분해 트리

```
Δ(oos) ≈ 0
├─ 1) 트리거 미발동: 시그널 hit 자체가 0 → 로그에서 signal firing count 확인
├─ 2) 적용 무효화: 포지션 열렸으나 holding period 내 price move ≈ 0
├─ 3) 노출 부족: exposure cap이 너무 낮아 수익 희석
├─ 4) 비용 상쇄: 수익 ≈ 거래비용 → turnover × cost 계산
└─ 5) 레짐 상쇄: 상승 fold 이익 = 하락 fold 손실 → fold별 PnL 분해
```

**다음 자동 루프에서 위 5가지 중 가장 variance 큰 항목을 자동 라벨링하도록 diagnoser 확장 권장.**
