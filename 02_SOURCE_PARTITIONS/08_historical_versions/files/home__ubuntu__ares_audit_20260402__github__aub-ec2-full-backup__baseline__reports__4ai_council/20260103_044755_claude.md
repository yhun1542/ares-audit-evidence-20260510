## 3. 성능이 안 움직일 때 원인 분해 트리

```
Delta ≈ 0 일 때 체크 순서:

1. 트리거 (Signal 발동 여부)
   └─ signal_fired_ratio < 10%? → threshold 너무 높음

2. 적용 (Position 실제 진입)
   └─ signal fired but position=0? → execution 로직 버그

3. 노출 (Exposure 크기)
   └─ avg_exposure < 20%? → 신호 있어도 sizing 너무 보수적

4. 비용 (Turnover × Slippage)
   └─ gross_return > 0 but net < 0? → 비용이 alpha 초과

5. 레짐 (시장 상태)
   └─ 특정 fold만 음수? → 해당 기간 VIX/SPY 확인

6. 측정 (계측 오류)
   └─ 위 모두 정상인데 delta=0? → 로깅/계산 버그
```
