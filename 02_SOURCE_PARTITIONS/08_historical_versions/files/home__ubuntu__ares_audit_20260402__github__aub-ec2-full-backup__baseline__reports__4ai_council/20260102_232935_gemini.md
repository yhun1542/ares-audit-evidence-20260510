[우선순위 분석 및 제안]

현재 상태는 **'신뢰할 수 없는 고성능(High OOS Mean)'과 '구조적 결함(Degenerate Folds 4개, MDD None, 로그 누락)'이 공존**하는 위험 단계입니다. Degenerate Folds가 4개(약 40%)라는 것은 특정 구간에서 모델이 거래를 포기했거나, 데이터가 깨졌음을 의미합니다.

다음 48시간의 목표는 **"수익률 개선"이 아니라 "모델 정상화(Sanity Check)"**입니다.

### 1. 우선순위 TOP 5 제안

1.  **[CRITICAL] Data Leakage & Alignment Test (Lag Enforcement)**
    *   (a) **이유:** OOS Mean 3.32는 현실적이지 않음. Degenerate fold가 있는데도 평균이 높다는 것은 나머지 구간에서 미래 참조(Look-ahead bias)가 의심됨.
    *   (b) **위험:** 챔피언 모델 폐기 가능성 높음(성능 급락).
    *   (c) **실험:** 모든 Feature 생성 시 `shift(1)` 강제 적용 후 재학습.
    *   (d) **PASS 조건:** OOS Mean > 1.2 유지 시 유효한 알파로 인정. 1.0 미만 시 현재 챔피언 폐기.

2.  **[CRITICAL] Degenerate Folds Recovery (Relaxed Constraints)**
    *   (a) **이유:** Folds [1, 2, 3, 8]에서의 실패는 과도한 정규화(L1/L2)나 리스크 제약으로 인해 솔버가 'No Trade(All Cash)'를 선택했거나 데이터가 비어있음을 시사.
    *   (b) **위험:** 거래 빈도 증가로 인한 슬리피지/수수료 증가.
    *   (c) **실험:** 최적화 목적함수에서 정규화 페널티 50% 축소 또는 Min Weight > 0.05 강제.
    *   (d) **PASS 조건:** `degenerate_folds` 개수 0~1개로 감소.

3.  **[INFRA] Execution Log Pipeline Fix**
    *   (a) **이유:** `rebalance.csv` 로드 실패(`Errno 2`, `Expecting value`). 백테스트와 실제 시그널 간 괴리를 추적할 수 없음.
    *   (b) **위험:** 없음(시스템 수정).
    *   (c) **실험:** 로깅 포맷을 JSONL로 단일화하고, 디렉토리 자동 생성 로직 추가.
    *   (d) **PASS 조건:** `aub_rebalance_pinpoint.py`가 에러 없이 리포트 생성.

4.  **[STRATEGY] Tech/Healthcare Sector Neutrality Constraint**
    *   (a) **이유:** Tech/Healthcare 8~14 종목 집중 시, 섹터 붕괴(예: 2022년) 구간에서 손실을 막기 위해 아예 거래를 안 하는(Degenerate) 쪽으로 학습되었을 가능성.
    *   (b) **위험:** 알파 기회비용 발생.
    *   (c) **실험:** 포트폴리오 내 Tech/Health 비중 상한(예: 각 60%) 설정 또는 현금 비중 상한(Max Cash 50%) 설정.
    *   (d) **PASS 조건:** MDD 수치가 `None`이 아닌 유효한 값으로 계산됨.

5.  **[RISK] Cost Model Reality Injection**
    *   (a) **이유:** 현재 초고수익률이 거래비용 0 가정에서 나왔을 확률 99%.
    *   (b) **위험:** OOS Mean 대폭 하락.
    *   (c) **실험:** 매매당 10bps(0.1%) + 슬리피지 모델 적용.
    *   (d) **PASS 조건:** 비용 반영 후에도 OOS Mean > 1.5 유지.

### 2. 실행 가능한 Patch/실험 (48시간 루프용)

**Experiment 1: Strict Lag & Data Integrity Check**
*   **(1) 실험 정의:** `feature_pipeline` 내 모든 기술적 지표 계산 후 `t-1` 데이터만 `t` 시점 트레이딩에 사용하도록 엄격한 Lag 적용. 동시에 NaN 데이터 포함된 종목 제외 로직 강화.
*   **(2) 게이트:** `degenerate_folds` 리스트 변화 확인.
*   **(3) 기대 관측치:**
    *   OOS Mean: 3.32 -> 1.5 내외로 하락 (정상화).
    *   MDD: `None` -> 구체적 수치(예: -0.15) 등장.

**Experiment 2: Force Active Trading (Anti-Degeneracy)**
*   **(1) 실험 정의:** 포트폴리오 최적화 제약 조건 중 `min_weights` 제약을 제거하고, `target_volatility`를 연 15% 이상으로 강제 설정하여 변동성이 낮은 구간(Degenerate 구간)에서도 포지션을 잡도록 유도.
*   **(2) 게이트:** `degenerate_folds` == Empty list [].
*   **(3) 기대 관측치:**
    *   Exposure Min: 0.0 -> 0.3 이상으로 상승.
    *   OOS Sharpe: 다소 하락하더라도 전 구간 거래 발생 확인.

**Experiment 3: Fix Logging & Cost Application**
*   **(1) 실험 정의:**
    *   코드 패치: `rebalance.csv` 저장 경로/포맷 수정.
    *   설정 패치: `transaction_cost_model` = `FixedBasisPoints(0.0010)`.
*   **(2) 게이트:** 로그 파일 파싱 성공 여부.
*   **(3) 기대 관측치:**
    *   Pinpoint Report 생성 성공.
    *   비용 반영된 Net Return 확인.

### 3. 성능 정체(Stagnation) 시 원인 분해 아이디어

만약 위 조치 후에도 성능이 제자리거나 학습이 안 된다면 다음 트리를 점검하십시오.

1.  **트리거(Trigger) 실패:**
    *   **현상:** 시그널 자체가 생성되지 않음.
    *   **체크:** 8~14개 종목의 데이터가 해당 기간(Degenerate Folds)에 실제로 존재하는가? (Survivorship Bias 역효과 - 상장 폐지나 합병 데이터 누락).
2.  **적용(Application) 실패:**
    *   **현상:** 시그널은 있는데 주문이 안 나감.
    *   **체크:** 최적화 솔버(Optimizer)가 `Infeasible` 상태를 반환하여 이전 포지션(현금 100%)을 유지하는지 확인.
3.  **노출(Exposure) 왜곡:**
    *   **현상:** 롱/숏 비율이 깨짐.
    *   **체크:** Tech/Health 섹터 특성상 Beta가 높음. 시장 하락기에 숏 헷지(ETF 제외 조건으로 인해 불가)가 없어 포지션을 전량 청산하는 형태로 과최적화 되었는지 확인.
4.  **레짐(Regime) 불일치:**
    *   **현상:** 특정 연도만 박살남.
    *   **체크:** 금리 인상기(2022) vs 유동성 장세(2020-2021) 간 팩터 중요도(Feature Importance)가 뒤집히는지 확인. 
    *   **액션:** 레짐별 별도 모델 앙상블 고려 (이번 48시간 범위 밖이나 염두).
