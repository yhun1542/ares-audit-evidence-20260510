[우선순위 분석 및 제안]

현재 Champion(`v5`)의 **Lockbox Mean(4.01)이 Tuning Mean(2.32)보다 월등히 높은 현상**은 심각한 **과적합(Specific Bull-run Bias) 또는 룩어헤드(Look-ahead)** 가능성을 시사함. 반면 Candidate는 안정적(`tuning_min > 0`)이나 수익성이 부족함. 따라서 다음 48시간은 '수익성 유지'가 아니라 **'수익의 실체 검증'과 '하방 경직성 확보'**에 집중해야 함.

---

### 1. [검증] 거래 비용 스트레스 테스트 (Slippage/Cost Injection)
*   **이유:** `lockbox` 성과가 비정상적으로 높음. 실제 체결 오차(Slippage)나 거래 비용이 과소평가되었을 경우, 고빈도 매매가 수익을 왜곡했을 가능성.
*   **위험:** 챔피언 모델 폐기 가능성 (그러나 이는 필요한 리스크임).
*   **실험:**
    1.  **EXP-C01-DoubleCost:** `commission` 및 `slippage` 설정을 현재의 2배로 증액 후 `v5` 재검증.
    2.  **EXP-C02-ExecutionDelay:** 매수/매도 시그널 발생 후 `Open`이 아닌 `Next Open` 혹은 `Close` 체결로 로직 변경(지연 반영).
*   **PASS 조건:** `lockbox_mean`이 2.5 이상 유지되며, `worst_mdd`가 -10% 미만으로 악화되지 않을 것.
*   **기대 관측치:** 수익률 하락은 필연적이나, 급격한 붕괴(>50% 하락) 시 현재 로직은 '노이즈 트레이딩'으로 판명.

### 2. [로직] 섹터 ETF 기반 레짐 필터 (Regime Filter)
*   **이유:** `tuning_min`이 음수(-0.02)라는 것은 하락장에서 손실을 방어하지 못함. Tech(XLK/QQQ)와 Healthcare(XLV) ETF를 관측지표로 사용하여 하락 추세 시 현금 비중 확대 필요.
*   **위험:** 휩소(Whipsaw)로 인한 기회비용 발생, 진입 시점 지연.
*   **실험:**
    1.  **EXP-L01-SectorMA:** `QQQ` 또는 `XLV`가 20일 이동평균선(MA20) 하회 시, 해당 섹터 종목 매수 금지(Exit Only).
    2.  **EXP-L02-VolFilter:** `QQQ`의 VIX(VXN)가 상위 80% 구간일 때 포트폴리오 베타 0.5로 제한.
*   **PASS 조건:** `tuning_min` > 0.0 달성 (손익분기점 방어), `fold14_mdd` 개선.
*   **기대 관측치:** 거래 횟수 감소, MDD 대폭 개선, 수익률 소폭 하락.

### 3. [최적화] Inverse Volatility 가중치 적용 (Weighting)
*   **이유:** Tech/Bio 종목은 변동성이 큼. 현재 챔피언이 고변동성 종목에 과다 노출되었을 가능성. 동일 비중이나 시그널 비중 대신 변동성 역가중 방식 적용.
*   **위험:** 대형주(Low Vol) 위주로 포트폴리오가 쏠려 알파가 희석될 수 있음.
*   **실험:**
    1.  **EXP-W01-InvVol:** 선정된 8~14개 종목 내에서 `weight = 1 / (std_dev_20d)`.
    2.  **EXP-W02-RiskParityLite:** 섹터별(Tech vs Health) 리스크 총량 균등 배분.
*   **PASS 조건:** `worst_mdd`가 -5% 이내로 진입. Sharpe Ratio 2.5 이상 유지.
*   **기대 관측치:** 수익 곡선의 스무딩(Smoothing), 급락 구간에서의 방어력 상승.

### 4. [통합] Alpha Shadow 앙상블 (Hybrid)
*   **이유:** `candidate`(`macro_alpha_shadow`)는 `min` 값이 양수임. 챔피언의 공격성과 후보의 안정성을 결합.
*   **위험:** 로직 복잡도 증가, 연산 비용 증가.
*   **실험:**
    1.  **EXP-H01-SignalBlend:** 최종 시그널 = (Champion * 0.7) + (Candidate * 0.3).
    2.  **EXP-H02-ConditionalSwitch:** 시장 변동성 지표가 낮으면 Champion, 높으면 Candidate 로직 사용.
*   **PASS 조건:** `tuning_mean` > 2.0 AND `tuning_min` > 0.02.
*   **기대 관측치:** 두 모델의 장점 절충. Lockbox와 Tuning 간의 괴리 축소.

### 5. [데이터] 유니버스 생존 편향 재점검 (Data Sanity)
*   **이유:** 2026년 시점에서의 백테스팅 시, 상장 폐지된 바이오/테크 종목이 유니버스에 포함되어 있었는지 확인 필수. 현재 성과가 "살아남은 승자"만 골랐기 때문일 수 있음.
*   **위험:** 데이터 전처리 파이프라인 수정 소요.
*   **실험:**
    1.  **EXP-D01-IncludeDelisted:** 과거 시점 기준 시가총액/거래량 필터로 유니버스 재구성(상폐 종목 포함 시뮬레이션).
*   **PASS 조건:** `lockbox_mean`이 기존 대비 20% 이상 하락하지 않을 것.
*   **기대 관측치:** 실제 운영 환경과 유사한 보수적 성과 도출.

### [성능 정체 시 원인 분해 프로토콜]

만약 위 실험 후에도 성능(특히 `tuning_min`)이 개선되지 않는다면, 아래 순서로 원인을 분해하여 리포트할 것.

1.  **트리거(Trigger) 실패:**
    *   *가설:* 매수 신호가 너무 늦게 뜸.
    *   *확인:* 시그널 발생 시점 대비 주가 상승폭(Forward Return 1d/3d)의 상관계수 측정. 상관계수가 낮으면 지표(Feature) 교체 필요.
2.  **필터(Filter) 과다:**
    *   *가설:* `tuning_min` 방어를 위해 너무 많은 기회를 필터링함.
    *   *확인:* 필터링된 거래들의 가상 수익률(Counterfactual)을 계산. 필터가 수익 거래까지 죽이고 있는지 확인.
3.  **노출(Exposure) 왜곡:**
    *   *가설:* 특정 섹터(예: Bio)에 몰빵되어 바이오 지수 하락 시 동반 추락.
    *   *확인:* 포트폴리오와 QQQ, XLV, SPY 간의 Rolling Correlation 추이 확인.
4.  **비용(Cost) 잠식:**
    *   *가설:* 잦은 매매로 수수료 누적.
    *   *확인:* (총 수익 - 순 수익) 비율 계산. 턴오버(Turnover)가 100%를 초과하는지 점검.
5.  **레짐(Regime) 불일치:**
    *   *가설:* 현재 로직이 '저변동성 상승장'에만 특화됨.
    *   *확인:* `worst_mdd` 발생 구간의 시장 상황(금리, VIX)을 태깅하여 해당 구간 전용 로직(Cash Out) 필요성 판단.
