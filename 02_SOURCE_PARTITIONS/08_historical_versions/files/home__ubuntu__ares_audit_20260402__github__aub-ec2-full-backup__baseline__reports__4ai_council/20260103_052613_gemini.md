### 제안 상세: 실행 가능한 Patch/실험 (3가지)

#### 1. Experiment: `Dynamic_Cost_Penalty_Injection`
*   **(a) 필요성:** `v5`의 높은 수익률이 얇은 호가창이나 급격한 변동성 상황에서의 체결 오차를 무시한 결과인지 확인.
*   **(b) 위험:** 수익률 급감으로 기존 챔피언 폐기 가능성 (그러나 이것이 '진짜' 성능임).
*   **(c) 실험 정의 (48h Loop):**
    1.  **실험 A:** 고정 수수료 10bps -> 25bps 상향.
    2.  **실험 B:** `ATR(14)`가 높을수록 슬리피지 페널티를 지수적으로 증가시키는 로직 적용.
    3.  **실험 C:** 거래량이 `AverageVolume(20)`의 150% 미만인 날 진입 금지 (유동성 필터).
*   **(d) PASS 조건:**
    *   `Experiment B` 적용 후에도 `Lockbox Mean > 1.5` 유지 & `Worst MDD > -12%`.

#### 2. Experiment: `Sector_Relative_Strength_Tilt`
*   **(a) 필요성:** 금리 인상기(Healthcare 방어)와 인하기(Tech 주도)를 구분하지 않고 섞으면 MDD가 깊어짐. ETF를 나침반으로 사용.
*   **(b) 위험:** 잦은 섹터 로테이션으로 인한 거래비용(Turnover) 증가.
*   **(c) 실험 정의 (48h Loop):**
    1.  **지표:** `Ratio = SMA(XLK, 20) / SMA(XLV, 20)`
    2.  **게이트:**
        *   `Ratio > 1.05` (Tech 강세): Tech 종목 상위 8개, Healthcare 2개.
        *   `Ratio < 0.95` (Healthcare 강세): Healthcare 종목 상위 8개, Tech 2개.
        *   `그 외`: 5:5 균등 배분.
    3.  **관측치:** `Win Rate`의 변화가 유의미한지 확인 (기존 대비 +3%p 이상).
*   **(d) PASS 조건:**
    *   `Turnover` 증가폭 < 20% 대비 `Sharpe Ratio` +0.2 이상 개선.

#### 3. Experiment: `Volatility_Targeted_Sizing`
*   **(a) 필요성:** `worst_mdd`가 -8%로 양호하나, 레버리지 효과(알파)를 극대화하기 위해 변동성이 낮은 구간에서 비중 확대 필요.
*   **(b) 위험:** 시장 급락(Black Swan) 시 레버리지로 인한 큰 손실(Over-exposure).
*   **(c) 실험 정의 (48h Loop):**
    1.  **로직:** 목표 변동성(Target Vol)을 연 20%로 설정.
    2.  **수식:** `Position_Weight = Target_Vol / Asset_Vol(20d)` (단, 개별 종목 Max Weight 20% 제한).
    3.  **비교군:** 동일 비중(Equal Weight) 포트폴리오.
*   **(d) PASS 조건:**
    *   `CAGR` 상승분이 `MDD` 증가분보다 클 것 (MAR Ratio 개선).

### 성능 정체(Stagnation) 시 원인 분해 아이디어

성능 지표가 움직이지 않거나(Flat), 개선되지 않을 때 다음 트리를 점검:

1.  **Trigger Failure (진입 불가):**
    *   *현상:* 매매 횟수(Trades)가 극도로 적음.
    *   *원인:* 진입 조건(Threshold)이 너무 높아 최근 시장 변동성(VIX) 하에서는 시그널이 발생하지 않음.
    *   *Action:* 진입 임계값을 ATR 기반 동적 수치로 변경. (예: `RSI < 30` -> `RSI < Dynamic_Lower_Band`)

2.  **Exposure Mismatch (레짐 불일치):**
    *   *현상:* 지수(S&P500)는 오르는데 포트폴리오는 횡보.
    *   *원인:* 현재 선택된 유니버스(Tech/Health 8~14개)가 현재 시장 주도주(예: 에너지, 금융 등)에서 소외됨.
    *   *Action:* `Relative Strength`가 낮은 종목을 유니버스에서 강제 탈락시키는 'Bad Monkey' 필터 적용.

3.  **Cost Drag (비용 잠식):**
    *   *현상:* Gross Return은 우상향이나 Net Return이 0에 수렴.
    *   *원인:* 평균 보유 기간(Holding Period)이 너무 짧아(1~2일), 슬리피지가 수익을 다 깎아먹음.
    *   *Action:* 최소 보유 기간(Minimum Holding Period) 3일 강제 또는 진입 시 기대 수익(Expected Return)이 수수료의 3배 이상일 때만 진입.
