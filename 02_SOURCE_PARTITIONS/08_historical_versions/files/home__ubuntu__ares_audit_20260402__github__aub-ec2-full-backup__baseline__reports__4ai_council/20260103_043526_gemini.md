### [성능 정체 시 원인 분해 (Diagnosis Logic)]

성능(OOS Metric)이 움직이지 않거나 `degenerate` 상태가 지속될 때 다음 순서로 체크:

1.  **트리거(Trigger) 확인**:
    *   *Check*: 매매 신호(Signal)가 생성되고 있는가? 아니면 모든 날짜에 `Wait` 상태인가?
    *   *Action*: Threshold(임계값)가 너무 높지 않은지 확인 (예: z-score > 3.0 등).

2.  **노출(Exposure) 확인**:
    *   *Check*: `exposure_max`가 0에 수렴하거나 매우 낮은가?
    *   *Action*: 리스크 모델(Covariance Matrix)이 폭발하여 현금 비중만 높이는지 확인.

3.  **적용(Execution) 확인**:
    *   *Check*: 목표 비중(Target Weight)과 실제 비중(Holdings) 간의 괴리.
    *   *Action*: 최소 주문 금액($) 제약 때문에 소액 리밸런싱이 무시되는지 확인.

4.  **비용(Cost) 확인**:
    *   *Check*: Gross Return은 좋은데 Net Return이 나쁜가?
    *   *Action*: 회전율(Turnover)이 과도하게 높은지 체크 (Tech 종목 변동성 기인).

5.  **레짐(Regime) 불일치**:
    *   *Check*: Tech/Health 섹터 ETF(XLK, XLV) 자체가 하락장인가?
    *   *Action*: 벤치마크 대비 상대 수익률(Alpha)로 평가 기준 변경 필요.
