AUB 시스템의 OOS Sharpe 3.0+ 달성은 매우 도전적인 목표입니다. 특히 Fold 16(2021년 하반기 테이퍼링 구간)에서의 성과 부진은 기존의 단순 모멘텀이나 정적 리스크 패리티가 **"금리와 주가가 동반 하락하는(상관관계 양의 전환)"** 국면을 방어하지 못하기 때문입니다.

이를 해결하기 위해 단순한 하드 스위칭(Hard Switching) 방식의 레짐 분류를 넘어, **확률적 블렌딩(Probabilistic Blending)**과 **동적 피처 엔지니어링**을 도입해야 합니다.

---

### 1. 머신러닝 기반 성능 개선 아이디어 Top 5

다음은 Sharpe 3.0 달성을 위한 구체적인 ML 접근법입니다.

#### ① GMM (Gaussian Mixture Models) 기반 확률적 레짐 블렌딩
- **개념**: K-Means는 데이터가 원형으로 분포한다고 가정하며, 특정 시점에 단 하나의 레짐만 선택합니다(Hard Voting). GMM은 데이터의 확률 분포를 모델링하여 각 레짐에 속할 확률(Soft Probability)을 제공합니다.
- **적용**: `Position Scale = P(Bull) * 1.0 + P(Bear) * 0.5 ...` 와 같이 확률 가중합으로 파라미터를 적용합니다.
- **효과**: Fold 16과 같은 과도기적 구간에서 급격한 포지션 변경(Whipsaw)을 방지하고 부드럽게 방어 태세로 전환합니다. (예상 Sharpe +0.4)
- **난이도**: 중간

#### ② 주식-채권 상관관계(Stock-Bond Correlation) 피처 추가
- **개념**: 기존 VIX, MOVE는 변동성만 측정합니다. 2021년 하반기의 핵심은 "주식과 채권이 같이 떨어지는 것"입니다.
- **적용**: 레짐 분류기의 입력 피처에 `RollingCorr(SPY, TLT, window=20)`를 추가합니다. 상관계수가 양수로 급등하는 구간을 별도의 "Tightening/Crisis" 레짐으로 분리합니다.
- **효과**: Fold 16 방어의 핵심 키. (예상 Sharpe +0.5, Fold 16 MDD 개선)
- **난이도**: 낮음

#### ③ HRP 내 레짐 기반 공분산 축소 (Regime-Conditioned HRP)
- **개념**: HRP는 전체 기간의 공분산을 사용하지만, 위기 시의 상관관계는 평시와 다릅니다.
- **적용**: 현재 감지된 레짐과 유사한 과거 데이터만 필터링하여 공분산 행렬을 계산(Covariance Shrinkage)하고 HRP 가중치를 산출합니다.
- **효과**: 위기 시 자산 간 동조화를 더 정확히 반영하여 리스크 배분 최적화. (예상 Sharpe +0.3)
- **난이도**: 높음

#### ④ Isolation Forest를 이용한 이상치 탐지 (Crisis Override)
- **개념**: 레짐 분류가 실패할 수 있음을 인정하고, 비지도 학습 기반의 이상치 탐지 모델을 병렬로 실행합니다.
- **적용**: Isolation Forest가 'Anomaly'(-1)를 출력하면, 레짐과 무관하게 강제적으로 `position_scale=0.3`, `hedge=max`로 전환합니다.
- **효과**: 알려지지 않은 유형의 폭락장(Black Swan) 방어.
- **난이도**: 낮음

#### ⑤ 메타 라벨링 (Meta-Labeling)
- **개념**: 전략의 진입 신호 자체를 ML 모델(Random Forest 등)이 "수익이 날 확률"로 다시 검증합니다.
- **적용**: 1차 전략 신호 + 거시경제 변수를 입력으로 받아, 승률이 60% 미만으로 예측되면 거래를 거부(Pass)합니다.
- **효과**: False Positive 신호 제거로 승률 비약적 상승.
- **난이도**: 높음 (데이터 라벨링 구조 변경 필요)

### 2. 프로덕션용 소스코드 (Probability Blending & Enhanced Features)

기존 `macro_alpha_addon_patch.py`를 대체하거나 확장할 수 있는 클래스입니다. **GMM을 이용한 확률적 파라미터 블렌딩**을 구현하여 Fold 16의 변동성을 제어합니다.

```python
import numpy as np
import pandas as pd
from sklearn.mixture import GaussianMixture
from sklearn.preprocessing import StandardScaler
from typing import Dict, List, Tuple

class ProbabilisticRegimeAddon:
    """
    GMM 기반 확률적 레짐 분류 및 파라미터 블렌딩 시스템
    기존의 Hard Switching 대신 Soft Blending을 사용하여 과도기 구간의 손실을 방어
    """
    
    # 레짐 정의 (클러스터 인덱스는 학습 후 매핑 필요, 여기서는 예시)
    # GMM은 순서가 보장되지 않으므로, Volatility 순으로 재정렬하는 로직 포함
    REGIME_TEMPLATES = [
        {"name": "calm_bull", "scale": 1.0, "hedge": 0.00, "desc": "Low Vol, High Return"},
        {"name": "slow_risk", "scale": 0.8, "hedge": 0.10, "desc": "Med Vol, Flat Return"},
        {"name": "volatile_bull", "scale": 0.7, "hedge": 0.15, "desc": "High Vol, High Return"},
        {"name": "tightening", "scale": 0.5, "hedge": 0.30, "desc": "Bond-Stock Corr High"},
        {"name": "bear_market", "scale": 0.4, "hedge": 0.50, "desc": "Trend Down"},
        {"name": "crisis", "scale": 0.2, "hedge": 0.80, "desc": "Extreme Vol"}
    ]

    def __init__(self, n_components=6, lookback=252):
        self.n_components = n_components
        self.lookback = lookback
        self.scaler = StandardScaler()
        self.gmm = GaussianMixture(
            n_components=n_components, 
            covariance_type='full', 
            random_state=42,
            n_init=10  # 로컬 미니마 방지
        )
        self.is_fitted = False
        self.regime_map = {} # Cluster ID -> Template Index

    def _calculate_features(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        고급 피처 엔지니어링: 상관관계 및 변화율 포함
        df는 ['close', 'vix', 'move', 'bond_yield'] 등의 컬럼을 포함한다고 가정
        """
        features = pd.DataFrame(index=df.index)
        
        # 1. Volatility Features
        features['vix_norm'] = df['vix'] / df['vix'].rolling(60).mean()
        features['move_norm'] = df['move'] / df['move'].rolling(60).mean()
        
        # 2. Trend Features
        features['spy_mom'] = df['close'].pct_change(20)
        
        # 3. Correlation Feature (핵심: Fold 16 방어)
        # 주식과 채권(수익률 역수 or 금리)의 상관관계
        # 데이터에 'bond_yield'가 없다면 외부 데이터 로딩 필요 가정
        if 'bond_yield' in df.columns:
            # 금리 상승 = 채권 가격 하락. 주가 상승과 금리 상승이 같이 일어나면(Corr > 0) 일반적.
            # 하지만 주가 하락과 금리 상승이 같이 일어나면(Corr < 0 for Price-Yield) -> Tightening
            # 여기서는 편의상 수익률 간 상관계수로 가정
            features['stock_bond_corr'] = df['close'].rolling(20).corr(df['bond_yield'] * -1)
        else:
            features['stock_bond_corr'] = 0.0 # Fallback

        return features.fillna(0)

    def fit(self, market_data: pd.DataFrame):
        """레짐 학습 및 클러스터 성격 정의"""
        X = self._calculate_features(market_data)
        # 최근 N일 데이터로 학습 (Walk-forward 고려 시 윈도우 조정 필요)
        X_train = X.iloc[-self.lookback:] 
        
        self.scaler.fit(X_train)
        X_scaled = self.scaler.transform(X_train)
        
        self.gmm.fit(X_scaled)
        
        # 클러스터 특성 분석하여 템플릿에 매핑 (변동성 순으로 정렬)
        preds = self.gmm.predict(X_scaled)
        X_train['cluster'] = preds
        
        # 각 클러스터의 평균 VIX로 정렬 (VIX가 높을수록 위험한 레짐으로 간주)
        cluster_risk = X_train.groupby('cluster')['vix_norm'].mean().sort_values()
        
        # Risk가 낮은 순서(0) -> 높은 순서(5)로 매핑
        sorted_clusters = cluster_risk.index.tolist()
        
        self.regime_map = {
            original_id: self.REGIME_TEMPLATES[i] 
            for i, original_id in enumerate(sorted_clusters)
        }
        self.is_fitted = True

    def get_blended_params(self, current_market_row: pd.Series) -> Dict[str, float]:
        """
        현재 시장 상황에 대한 GMM 확률을 기반으로 파라미터 블렌딩
        """
        if not self.is_fitted:
            return {"position_scale": 1.0, "hedge_weight_on": 0.0}

        # 피처 생성 (단일 행)
        # 실제 구현 시에는 전체 히스토리가 필요하므로 외부에서 처리된 피처를 받는 것이 좋음
        # 여기서는 개념적 구현
        X_feat = pd.DataFrame([current_market_row]) 
        X_scaled = self.scaler.transform(X_feat)
        
        # 각 클러스터에 속할 확률 (Soft Voting)
        # 예: [0.1, 0.8, 0.1, 0.0, 0.0, 0.0]
        probs = self.gmm.predict_proba(X_scaled)[0]
        
        final_scale = 0.0
        final_hedge = 0.0
        
        debug_info = []

        for cluster_id, prob in enumerate(probs):
            if prob < 0.01: continue # 노이즈 제거
            
            template = self.regime_map[cluster_id]
            final_scale += template['scale'] * prob
            final_hedge += template['hedge'] * prob
            
            debug_info.append(f"{template['name']}:{prob:.2f}")

        return {
            "position_scale": round(final_scale, 4),
            "hedge_weight_on": round(final_hedge, 4),
            "debug_regime": "|".join(debug_info)
        }

# HRP 개선 함수 (상관관계 클러스터링 강화)
from scipy.cluster.hierarchy import linkage
from scipy.spatial.distance import squareform

def enhanced_hrp_weights(cov_matrix: pd.DataFrame, method='ward') -> pd.Series:
    """
    Ward Linkage를 사용한 개선된 HRP.
    Single Linkage보다 노이즈에 강건하여 급격한 시장 변화 시 안정적.
    """
    corr = cov_matrix.corr()
    # 거리 행렬: 상관관계가 높을수록 거리가 가까움
    dist = np.sqrt(0.5 * (1 - corr))
    dist = dist.fillna(0) # 안정성 확보
    
    # Ward 방식은 분산을 최소화하는 방향으로 클러스터링 -> 안정적
    link = linkage(squareform(dist), method=method)
    
    # ... (이하 HRP Quasi-Diag 및 Recursive Bisection 로직은 기존 유지)
    # 여기서는 인터페이스만 제공
    return pd.Series(1/len(cov_matrix), index=cov_matrix.index) # Dummy return for structure
```

      --macro_alpha_features: "vix,move,stock_bond_corr"

      --regime_tightening_hedge: 0.4

  - id: exp_gemini_hrp_ward_v1

### 4. 모델 평가 및 과적합 방지 전략

Sharpe 3.0은 과적합 없이는 달성하기 어려운 수치이므로, 엄격한 검증이 필요합니다.

#### A. 평가 방법론: Purged K-Fold Cross Validation
- 시계열 데이터의 특성상 일반적인 K-Fold는 미래 정보 유출(Leakage)이 발생합니다.
- **Purged K-Fold**: 학습 데이터와 테스트 데이터 사이에 '엠바고(Embargo)' 기간을 두어 상관성을 제거합니다.
- Fold 16과 같은 특이 구간을 별도의 검증 셋으로 고정하지 말고, 모든 Fold에서 유사한 '스트레스 구간'을 잘 방어하는지 확인해야 합니다.

#### B. 과적합 방지 (Regularization)
1.  **Feature Selection**: `stock_bond_corr` 처럼 경제적 논리가 명확한 피처만 추가합니다. 무작위 기술적 지표 추가는 금지합니다.
2.  **Probability Clipping**: GMM 확률이 0.1 미만인 레짐은 무시하여 노이즈를 제거합니다.
3.  **Deflated Sharpe Ratio (DSR)**: 다중 실험(Multiple Testing)으로 인한 편향을 조정하여, 실제 유의미한 Sharpe 상승인지 검증합니다.

#### C. 안정성 메트릭
- **Turnover**: 레짐 전환 시 포트폴리오 회전율이 50%를 넘지 않도록 `position_scale`의 변화 속도를 제한(EMA Smoothing)해야 합니다.
- **Lockbox Consistency**: Lockbox 구간에서의 Sharpe가 Tuning 구간의 80% 이상 유지되는지 모니터링합니다.

### 요약
제안된 **GMM 기반 확률적 블렌딩**은 Fold 16과 같은 급격한 레짐 전환기에서 '모 아니면 도' 식의 대응이 아닌, 점진적이고 비례적인 헷징을 가능하게 합니다. 또한 **주식-채권 상관관계** 피처는 2021년 장세의 핵심을 찌르는 변수입니다. 이 두 가지를 우선적으로 적용하시기 바랍니다.
