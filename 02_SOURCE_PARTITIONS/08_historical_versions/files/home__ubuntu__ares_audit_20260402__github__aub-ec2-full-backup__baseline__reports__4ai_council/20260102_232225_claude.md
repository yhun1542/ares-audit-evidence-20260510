## 1. 우선순위 TOP-5 실험 (48h 루프)

### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### P1. MDD/Drawdown Gate 복구
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 필요성**
- `worst_mdd: None` → 위험 관리 게이트 작동 안함
- DD 25% 초과 전략이 챔피언으로 승격될 수 있음

**(b) 위험/부작용**
- DD 계산 로직 수정 시 과거 실험 결과와 비교 불가
- 너무 tight한 gate (예: 10%)는 유효 전략 사살

**(c) 최소 실험**

| ID | 실험 정의 | Gate | 기대 관측치 |
|----|-----------|------|-------------|
| P1-A | `backtest.py`에 rolling MDD 계산 추가 | 코드 실행 성공 | MDD 값 float 반환 |
| P1-B | Gate: MDD ≤ 20% | champion 승격 조건 | degenerate fold 중 MDD > 20% 탈락 |
| P1-C | Gate: MDD ≤ 25% (완화) | 비교 | 탈락 fold 수 비교 |

**(d) PASS 조건**
```
worst_mdd != None AND worst_mdd <= 0.20 AND oos_mean >= 2.0
```

### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### P2. Degenerate Fold 원인 분해
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 필요성**
- 4/10 fold 실패 = 특정 시장 레짐에서 시그널 무효
- 원인 모르면 실전 배포 시 동일 실패 반복

**(b) 위험/부작용**
- 레짐 필터 추가 시 표본 수 급감 → 통계적 유의성 상실
- 과거 fold에 과적합된 필터 위험

**(c) 최소 실험**

| ID | 실험 정의 | Gate | 기대 관측치 |
|----|-----------|------|-------------|
| P2-A | Fold 1,2,3,8 기간 추출 → VIX/금리/섹터 로테이션 매핑 | 분석 완료 | 공통 레짐 패턴 식별 |
| P2-B | 해당 기간 exposure=0 원인: 시그널 없음 vs 필터 차단 | 로그 파싱 | 차단 비율 계산 |
| P2-C | Fold별 개별 종목 hit rate 계산 | hit ≥ 45% | 특정 종목 drag 식별 |

**(d) PASS 조건**
```
degenerate_folds 원인 분류 완료 (레짐/시그널/종목 중 1개 이상 지목)
```

## 3. 성능 안 움직일 때 원인 분해 트리

```
성능 Δ ≈ 0
│
├─[1] 트리거 실패
│   └─ 시그널 발생 빈도 → 0이면 데이터/로직 오류
│
├─[2] 적용 실패  
│   └─ 시그널 → 주문 전환율 → 0이면 필터/조건 과다
│
├─[3] 노출 실패
│   └─ position size 너무 작음 → sizing 로직 점검
│
├─[4] 비용 상쇄
│   └─ gross return > 0 but net ≈ 0 → 슬리피지/수수료 과다
│
└─[5] 레짐 미스매치
    └─ 특정 기간만 작동 → fold별 성능 분산 확인
```

**체크리스트 (자동화용)**
```bash
# 트리거
grep -c "signal_generated" logs/*.log  # expect > 100/day

# 적용
grep -c "order_placed" logs/*.log      # expect > 50% of signals

# 노출
awk '{sum+=$exposure} END {print sum/NR}' positions.csv  # expect > 0.3

# 비용
diff <(grep gross results.json) <(grep net results.json)  # expect < 15%

# 레짐
python3 -c "import json; d=json.load(open('results.json')); print(max(d['fold_oos'])-min(d['fold_oos']))"  # expect < 2.0
```
