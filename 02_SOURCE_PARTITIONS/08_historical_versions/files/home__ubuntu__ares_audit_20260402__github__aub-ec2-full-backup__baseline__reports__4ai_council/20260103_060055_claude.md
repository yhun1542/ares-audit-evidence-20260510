```
├─[1] 트리거 문제

│   ├─ 시그널 → 실제 포지션 전환율 (execution_rate)
│   ├─ 기대: > 80% / 실제 < 50% → 충돌/우선순위 로직 점검
│   └─ 조치: 모듈 간 의존성 그래프 검토

├─[3] 노출 문제
│   ├─ 평균 순노출 (net_exposure_mean)
│   ├─ 기대: 60-90% / 실제 < 40% → 현금 과다 보유
│   └─ 조치: 레짐 필터 완화 또는 제거
│
├─[4] 비용 문제
│   ├─ 회전율 × 비용 = 연간 drag
│   ├─ 기대: < 1% / 실제 > 2% → 과잉 매매
│   └─ 조치: 리밸런싱 주기 확대 (주간 → 격주)
│
└─[5] 레짐 미스매치
    ├─ 현재 시장 레짐 vs 학습 레짐 분포
    ├─ 기대: 유사 / 실제: OOS 레짐 미경험
    └─ 조치: 레짐별 서브모델 또는 앙상블 가중치 조정
```
