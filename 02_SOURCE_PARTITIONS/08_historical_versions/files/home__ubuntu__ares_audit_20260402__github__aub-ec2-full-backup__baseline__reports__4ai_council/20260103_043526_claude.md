## 1. 우선순위 TOP 5 실행 체크리스트

### PATCH-1: Degenerate Fold 원인 분해 (최우선)

**(a) 필요성**
- 4개 폴드(1,2,3,8) 실패 = OOS 신뢰구간 붕괴
- 실제 운용 시 40% 확률로 전략 무력화 가능

**(b) 위험/부작용**
- 과적합 폴드만 살리면 전체 과최적화 증가
- 폴드별 튜닝 시 케이스 폭발

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| D1-A | 폴드별 시장 레짐 매핑 (VIX>25, SPY drawdown>10% 구간 태깅) | 자동 | degenerate 폴드 = 특정 레짐 클러스터링 여부 |
| D1-B | 폴드별 signal 발생 빈도 카운트 | 자동 | degenerate 폴드의 signal_count < 5이면 트리거 문제 |
| D1-C | 폴드별 평균 exposure 측정 | 자동 | degenerate 폴드 exposure_mean < 0.1이면 적용 문제 |

**(d) PASS 조건**
```
✅ PASS: 4개 폴드 중 3개 이상 원인 식별 (레짐/트리거/적용 중 하나로 분류)
❌ FAIL: 원인 불명 2개 이상 → 데이터 품질 점검으로 회귀
```

### PATCH-2: MDD 측정 파이프라인 복구

**(a) 필요성**
- `worst_mdd: None` = 리스크 관리 불가
- 규제/운용 관점에서 MDD 미측정 전략은 배포 불가

**(b) 위험/부작용**
- MDD 계산 로직 버그 시 과소/과대 추정
- 일별 vs 분봉 기준 차이로 수치 불일치

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| M2-A | `calc_mdd()` 함수 단위 테스트 (synthetic data) | 자동 | known MDD=-20% 데이터에서 오차 < 0.1% |
| M2-B | Champion 전 폴드 MDD 재계산 | 자동 | worst_mdd 수치 출력 (예: -15% ~ -25% 범위 예상) |

**(d) PASS 조건**
```
✅ PASS: worst_mdd 수치 정상 출력 + 10개 폴드 전체 MDD 리스트 확보
❌ FAIL: None 또는 계산 오류 → 백테스트 엔진 점검
```

### PATCH-3: Rebalance 로그 포맷 정규화

**(a) 필요성**
- `rebalance_pinpoint.py` 실패 = 매매 원인 분석 불가
- JSON/CSV 포맷 불일치로 진단 도구 전체 마비

**(b) 위험/부작용**
- 포맷 변경 시 기존 로그 호환성 깨짐
- 저장 용량 증가 가능

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| R3-A | 현재 로그 파일 존재/포맷 확인 스크립트 | 자동 | 파일 경로, 포맷(json/csv/jsonl), 레코드 수 출력 |
| R3-B | 표준 스키마 정의 + 변환기 작성 | 수동 검토 후 자동 | `aub_rebalance_pinpoint.py` 정상 실행 |

**(d) PASS 조건**
```
✅ PASS: pinpoint 리포트 정상 생성 (최소 10개 rebalance 이벤트 파싱)
❌ FAIL: 파싱 오류 지속 → 로그 생성 코드 수정
```

### PATCH-4: Exposure 0% 구간 원인 식별

**(a) 필요성**
- `exposure_min: 0.0` = 완전 현금 구간 존재
- 의도된 hedge인지, 버그인지 구분 필요

**(b) 위험/부작용**
- 강제 최소 노출 설정 시 손실 구간 증가 가능
- 과거 데이터 레짐에 과적합 위험

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| E4-A | Exposure=0 구간 날짜 추출 + 시장 상황 매핑 | 자동 | 해당 구간 SPY 수익률, VIX 수준 |
| E4-B | Exposure 하한 0.1 적용 실험 | 자동 | OOS mean 변화, MDD 변화 |

**(d) PASS 조건**
```
✅ PASS: Exposure=0 구간이 VIX>30 또는 SPY MDD>15% 구간과 80% 이상 일치 (의도적 hedge)
⚠️ WATCH: 일치율 50-80% → 추가 분석
❌ FAIL: 일치율 <50% → 시그널 버그 의심
```
