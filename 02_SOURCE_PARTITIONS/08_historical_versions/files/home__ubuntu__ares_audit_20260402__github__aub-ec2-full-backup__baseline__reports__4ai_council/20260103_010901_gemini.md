### [성능 정체 시 원인 분해 (Debug Logic)]

지표가 움직이지 않거나 0에 수렴할 경우, 아래 순서로 로그를 grep할 것.

1.  **TRIGGER (신호)**: 예측 모델의 Output(Score)이 임계값을 넘는가? (모든 Score가 0.5 부근이면 Feature 문제)
2.  **OPTIMIZER (실행)**: `SolverStatus`가 `OPTIMAL`인가? (`INFEASIBLE`이면 제약조건 충돌)
3.  **EXPOSURE (노출)**: 현금 비중이 100%로 고정되어 있는가? (리스크 매니저가 변동성을 과대평가하여 진입 차단 중)
4.  **COST (비용)**: Gross Return은 우상향인데 Net Return이 하락인가? (과도한 리밸런싱)
5.  **REGIME (시장)**: ETF(SPY/XLK) 지표가 하락 추세(MA 데드크로스)라 숏/현금 관망 중인가?
