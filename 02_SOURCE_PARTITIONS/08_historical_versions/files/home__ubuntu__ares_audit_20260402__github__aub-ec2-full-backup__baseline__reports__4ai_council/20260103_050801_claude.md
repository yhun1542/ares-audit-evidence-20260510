## ⚡ 48H Priority Patches (TOP 5)

### PATCH-1: Degenerate Fold 근본 원인 수정
```
WHY: 4/10 fold가 degenerate → OOS mean이 6개 fold에서만 계산됨
     → 실제 성능 과대추정 가능성 높음
```

| 항목 | 내용 |
|------|------|
| **위험/부작용** | 수정 후 OOS mean 하락 예상 (honest estimate) |
| **실험** | |
| EXP-1a | `min_samples_per_fold >= 60` 강제, 미달 시 fold 병합 |
| EXP-1b | Purged K-Fold → Combinatorial Purged CV 전환 |
| EXP-1c | Degenerate fold에 penalty=-1.0 부여 후 재계산 |
| **PASS 조건** | `degenerate_folds == []` AND `oos_min > -0.01` |

```yaml
# 48h-loop format
experiment_id: patch1_degen_fix
gate: degenerate_folds == [] 
expected_oos_mean: [1.8, 2.5]  # 하락 허용
abort_if: oos_mean < 1.0 OR degenerate_folds > 2
```
