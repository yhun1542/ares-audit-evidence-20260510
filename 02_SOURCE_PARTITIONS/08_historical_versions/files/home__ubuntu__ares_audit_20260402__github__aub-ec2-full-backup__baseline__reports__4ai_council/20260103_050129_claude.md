## 3. 성능 미변동 시 원인 분해 트리

```
OOS 변화 없음
├─ [1] 트리거 미발생
│   └─ 확인: 신호 발생 횟수 로그
│   └─ 원인: 임계값 과다, 데이터 커버리지 부족
│
├─ [2] 트리거 → 포지션 미적용
│   └─ 확인: 리밸런스 로그 vs 신호 로그 대조
│   └─ 원인: 필터 과다 (유동성/섹터), 버그
│
├─ [3] 포지션 적용 → 노출 미반영
│   └─ 확인: exposure 시계열
│   └─ 원인: 가중치 스케일링 버그, 현금 강제
│
├─ [4] 노출 → 수익 미반영
│   └─ 확인: 포지션 수익률 vs 벤치마크
│   └─ 원인: 비용 과다, 역선택 (신호 후 역행)
│
└─ [5] 수익 발생 → OOS 미반영
    └─ 확인: fold별 수익 분포
    └─ 원인: 특정 fold 집중, 레짐 편향
```
