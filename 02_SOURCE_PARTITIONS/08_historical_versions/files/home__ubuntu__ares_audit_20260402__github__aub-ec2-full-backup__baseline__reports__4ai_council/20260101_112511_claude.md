### PATCH-1: 비용 민감도 스트레스

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | lockbox 수익 1.33 vs worst_mdd -9% → 실거래 슬리피지 10bp 적용 시 sharpe 붕괴 가능 |

| **(c) 실험** | ① cost=5bp(현행) ② cost=10bp ③ cost=15bp |
| **(d) PASS** | lockbox_mean ≥ 1.20 & worst_mdd ≤ -0.12 @ cost=10bp |

```yaml

params:
  slip_bps: [5, 10, 15]

observe: [sharpe_delta, turnover_annual]
```
