[분석 요약]
현재 `Candidate(macro_alpha_shadow)`는 Tuning Min(0.05)과 Lockbox Min(1.34) 간의 괴리가 극심함. 이는 특정 Fold(시장 국면)에서 전략이 붕괴되거나, Lockbox 기간에 과도한 운이 작용했을 가능성을 시사함. 반면 `Champion(v5)`는 안정적임.
**향후 48시간의 핵심 목표는 Candidate의 하방 안정성을 확보하여 Champion을 교체하거나, Champion의 비용 민감도를 검증하는 것임.**

### 1. 우선순위 TOP 5 제안 (48시간 내 실행)

다음 체크리스트를 순차적으로 수행할 것.

#### 1) Candidate 'Shadow' 모듈의 하방 경직성 보강 (최우선)
*   **(a) 이유:** `Tuning Min: 0.05`는 실전 투입 불가 수치임. 특정 거시 변수(금리/VIX 등) 급변 시 포트폴리오가 붕괴되는지 확인 필요.
*   **(b) 위험:** 방어 로직 추가 시 Lockbox 수익률(1.34)이 희석될 수 있음.
*   **(c) 실험:**
    1.  **[Exp_Fix_01]**: `macro_alpha_shadow`에 VIX > 25 구간에서 현금 비중 50% 강제 할당 로직 주입.
    2.  **[Exp_Fix_02]**: 개별 종목 손실폭 -5% 도달 시 해당 주(Week) 매매 중단(Cut-off) 로직 추가.
*   **(d) PASS 조건:** Tuning Min > 0.6 AND Lockbox Mean 감소폭 < 10%.

#### 2) Tech vs Healthcare 섹터 로테이션 민감도 조정
*   **(a) 이유:** 8~14개 종목이 Tech/Healthcare에 집중됨. 두 섹터 동반 하락 시 MDD(-11%) 방어 불가. XLK/XLV ETF를 관측 지표로 활용하여 비중 조절 필요.
*   **(b) 위험:** 휩소(Whipsaw)로 인한 거래 비용 증가.
*   **(c) 실험:**
    1.  **[Exp_Sec_01]**: XLK가 MA(20) 하회 시 Tech 비중 0.5배 축소.
    2.  **[Exp_Sec_02]**: XLV/XLK 모멘텀 격차가 상위 20%일 때, 열위 섹터 매매 제외.
*   **(d) PASS 조건:** Worst MDD > -0.09 (Champion 수준 회복).

#### 3) 비용 구조 가혹화 테스트 (Slippage Stress)
*   **(a) 이유:** `Champion v5`의 성과가 낮은 유동성 종목의 호가 갭을 무시한 결과인지 검증 필요.
*   **(b) 위험:** 모든 전략이 탈락할 수 있음(그러나 이는 "진짜" 위험을 발견하는 것임).
*   **(c) 실험:**
    1.  **[Exp_Cost_01]**: 기본 슬리피지 모델을 `Fixed 5bps`에서 `Volatility Adjusted (ATR 기반)`로 변경.
    2.  **[Exp_Cost_02]**: 매수 시 Ask+1 tick, 매도 시 Bid-1 tick 체결 가정 시뮬레이션.
*   **(d) PASS 조건:** Lockbox Min > 1.0 유지.

#### 4) 상관관계 페널티(Correlation Penalty) 도입
*   **(a) 이유:** Tech 종목 간 동조화 현상으로 인한 리스크 집중 완화.
*   **(b) 위험:** 강세장에서의 Alpha 축소.
*   **(c) 실험:**
    1.  **[Exp_Corr_01]**: 포트폴리오 내 종목 간 평균 상관계수가 0.7 초과 시 레버리지 비율(혹은 총 노출도) 0.8배로 축소.
*   **(d) PASS 조건:** Sharpe Ratio 상승 (수익률 하락을 감내하고 변동성을 더 크게 줄여야 함).

#### 5) 유니버스 생존 편향(Survivorship Bias) 재검증
*   **(a) 이유:** 현재 8~14개 종목이 2026년 시점에서 "살아남은" 승자들로만 구성되었는지 확인.
*   **(b) 위험:** 데이터셋 재구축 비용 발생.
*   **(c) 실험:**
    1.  **[Exp_Valid_01]**: 2020~2024년 사이 상장 폐지되거나 시총 하위로 밀려난 종목 3개를 더미로 추가하여 백테스트 수행.
*   **(d) PASS 조건:** 기존 Champion 로직이 더미 종목을 필터링(매매 제외)하거나, 손실폭이 전체 포트폴리오의 3% 미만이어야 함.

### 2. 실행 루프 설계 (48시간 자동화)

다음 포맷으로 시스템에 Job을 등록할 것.

**[Cycle A: Candidate Repair]**
*   **실험 정의:** `baseline/candidate...shadow.json` 로드 -> Stop-loss(-3% daily) 모듈 활성화 -> 재학습 없이 검증.
*   **게이트:** Tuning Min > 0.4 (기존 0.05에서 대폭 개선 요구).
*   **기대 관측치:** MDD가 -11%에서 -9%대로 진입하며, Lockbox 수익률은 소폭 하락(1.79 -> 1.6대) 예상.

**[Cycle B: Sector Hedge Check]**
*   **실험 정의:** ETF(XLK, XLV)의 60일 이격도(Disparity)를 Feature로 추가 -> Random Forest 가중치 재조정.
*   **게이트:** Fold 14 (최악의 구간) MDD가 -0.07 이상으로 개선.
*   **기대 관측치:** 하락장에서의 현금 비중 증가 패턴 확인.

**[Cycle C: Champion Stress Test]**
*   **실험 정의:** `Champion v5` + Transaction Cost 2x 적용.
*   **게이트:** Lockbox Min > 0.9 (원금 보존).
*   **기대 관측치:** 매매 빈도가 높은 전략일 경우 성과 급락 확인 -> 매매 횟수 제한 로직 필요성 도출.

### 3. 성능 정체 시 원인 분해 (Debugging Logic)

성능 지표(Sharpe, MDD)가 움직이지 않을 때 다음 트리거를 점검할 것.

1.  **신호 동결(Signal Freezing):**
    *   *현상:* 매매 회전율(Turnover)이 0에 수렴.
    *   *원인:* 14개 종목 모두 필터링 조건(예: RSI < 30)을 만족하지 못하는 극단적 강세/약세장 지속.
    *   *액션:* 진입 장벽(Threshold) 완화 실험 수행.

2.  **비용 잠식(Cost Erosion):**
    *   *현상:* Gross Return은 우상향이나 Net Return이 횡보.
    *   *원인:* 평균 이익(Avg Profit per Trade) < 왕복 비용(Roundtrip Cost).
    *   *액션:* 기대 수익률 상위 3개 종목에만 자본 집중 (Concentration).

3.  **레짐 불일치(Regime Mismatch):**
    *   *현상:* Tuning 성과는 좋으나 Lockbox 성과가 평이함 (현재 Champion 상태).
    *   *원인:* 과거의 "Tech 주도주 패턴"이 최근 "Healthcare 방어주 패턴"으로 전이됨을 반영 못함.
    *   *액션:* Lookback Period를 단기(3개월)와 장기(12개월)로 분리하여 앙상블.

4.  **노출 부족(Under-exposure):**
    *   *현상:* MDD는 매우 낮으나(-3% 미만), 수익도 없음.
    *   *원인:* 변동성 타겟팅 로직이 너무 보수적으로 작동하여 현금만 보유.
    *   *액션:* 최소 노출 비중(Min Weight) 30% 강제 설정 테스트.
