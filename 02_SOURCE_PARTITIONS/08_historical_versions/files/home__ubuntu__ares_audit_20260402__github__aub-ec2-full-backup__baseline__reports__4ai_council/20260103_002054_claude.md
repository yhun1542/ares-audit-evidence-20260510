### P1. 파이프라인 무결성 복구 (BLOCKING)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 필요 이유**
- rebalance.csv 파싱 실패 → 비용/슬리피지 반영 불가 → 모든 OOS 수치 신뢰 불가
- MDD=None → 리스크 게이트 작동 안함

**(b) 위험/부작용**
- 수정 중 기존 로그 덮어쓰기 위험
- 포맷 변경 시 downstream 툴 호환성 파손

**(c) 실험 체크리스트**

```
□ EXP-P1-A: rebalance 로그 포맷 검증
  - CMD: head -20 baseline/reports/run_champion_v5_20251231/rebalance.csv
  - CMD: file baseline/reports/run_champion_v5_20251231/rebalance.csv
  - GATE: CSV 헤더 확인 또는 JSON 구조 확인
  - EXPECT: 파일 존재 + 유효 포맷 → pinpoint 재실행 성공

□ EXP-P1-B: MDD 계산 모듈 독립 실행
  - CMD: python3 -c "from core.metrics import calc_mdd; print(calc_mdd('champion_v5'))"
  - GATE: 숫자 반환 (not None)
  - EXPECT: MDD ∈ [-0.30, -0.05] 정상 범위

□ EXP-P1-C: HANDOFF 파일 재생성
  - CMD: python3 experiment_system/aub_runner.py --recompute-handoff
  - GATE: worst_mdd != None, degenerate_folds 재계산
  - EXPECT: 필드 완전성 100%
```

**PASS 조건**: MDD 숫자 존재 + rebalance pinpoint 정상 출력

### P2. Degenerate Fold 원인 분해
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 필요 이유**
- 4/10 fold가 degenerate = 40% 구간에서 전략 무력화
- 과최적화 vs 레짐 미스매치 vs 데이터 품질 구분 필수

**(b) 위험/부작용**
- fold별 분석 시간 소모 (각 ~10분)
- 원인 오진 시 잘못된 방향 수정

**(c) 실험 체크리스트**

```
□ EXP-P2-A: Degenerate fold 시계열 구간 매핑
  - CMD: python3 tools/fold_inspector.py --folds 1,2,3,8 --output fold_periods.json
  - GATE: 각 fold의 [start_date, end_date] 추출
  - EXPECT: 특정 레짐(예: 2022 금리인상기) 집중 여부 확인

□ EXP-P2-B: Fold별 신호 발생 횟수 카운트
  - CMD: grep -c "SIGNAL" logs/fold_{1,2,3,8}.log
  - GATE: signal_count > 10 per fold
  - EXPECT: 0이면 신호 로직 자체 문제, >10이면 실행/비용 문제

□ EXP-P2-C: Non-degenerate fold와 feature importance 비교
  - CMD: python3 tools/feature_diff.py --good 4,5,6,7,9,10 --bad 1,2,3,8
  - GATE: 차이나는 top feature 식별
  - EXPECT: 특정 feature가 bad fold에서만 dominant → 오버핏 증거
```

**PASS 조건**: Degenerate 원인 1개 이상 명확히 식별 (레짐/신호부재/오버핏)

    data = json.load(open('champion_v5_latest.json'))
    folds = data['fold_results']

    print('Non-degen only:', sum(f['oos'] for f in folds if not f['degenerate'])/6)

□ EXP-P3-C: 거래 불가 종목 포함 여부
  - CMD: python3 tools/tradability_check.py --universe champion_v5 --date-range 2020-2025
  - GATE: untradable_ratio < 5%

    ├─ 변동성/상관관계 구조 변화
