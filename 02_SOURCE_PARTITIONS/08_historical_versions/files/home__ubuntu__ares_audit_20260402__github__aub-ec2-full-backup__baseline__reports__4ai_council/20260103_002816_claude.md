| 1-2 | Fold [1,2,3,8] 구간 데이터 덤프: 종목 수/이벤트 수/시그널 분산 | 타 폴드 대비 50%↓ 시 데이터 문제 확정 | raw_stats.json |
| 1-3 | 시그널 threshold 0.7 → 0.5 완화 후 CV | degenerate ≤ 1 | signal_hit_rate |

**(d) PASS 조건**
```
degenerate_folds ≤ 1 AND oos_mean ≥ 2.0
```

## 2. 성능 불변 시 원인 분해 트리

```
수익률 변화 없음
│
├─ [트리거] 시그널 발생 빈도 동일?
│   ├─ YES → 시그널 로직 변경 미반영 / 파라미터 오버라이드 실패
│   └─ NO  → 데이터 피드 문제 / 유니버스 필터 과잉
│
├─ [적용] 포지션 실제 변경됨?
│   ├─ YES → 노출/비용 단계로
│   └─ NO  → 리밸런스 로직 버그 / 현금 비중 과다
│
├─ [노출] Exposure 변화?
│   ├─ YES → 방향/사이즈 점검
│   └─ NO  → 롱숏 상쇄 / 섹터 중립화 과잉
│
├─ [비용] 슬리피지/수수료 흡수?
│   ├─ YES → 비용 모델 과대 or 턴오버 과다
│   └─ NO  → 다음 단계
│
└─ [레짐] 시장 국면 변화?
    ├─ 저변동 레짐 → 시그널 엣지 희석
    └─ 섹터 로테이션 → Tech/HC 언더퍼폼 구간
```
