## 1. 우선순위 TOP-5 액션

### P1. MDD·비용 측정 파이프라인 복구
```
WHY: worst_mdd=None → 리스크 블라인드, rebalance 파싱 실패 → 회전율·슬리피지 미반영
```

| 실험 ID | 정의 | 게이트 (PASS 조건) | 기대 관측치 |
|---------|------|-------------------|-------------|
| **P1-A** | `calc_mdd()` 함수에 unit test 추가, None 반환 시 raise | MDD ≠ None for all folds | MDD 10~25% 범위 확인 |
| **P1-B** | rebalance.csv → JSON Lines 포맷 통일, 파서 수정 | 파싱 성공 & row count > 0 | 연 회전율 200~400% 추정치 도출 |
| **P1-C** | 슬리피지 10bp + 수수료 1bp 적용 후 OOS 재계산 | OOS mean 재계산 완료 | **예상: OOS 2.6 → 1.8~2.2** |

**위험/부작용**: 비용 반영 시 기존 Champion 실격 가능 → 새 baseline 필요

---

### P2. Degenerate Fold 원인 분해
```
WHY: 4/10 fold 퇴화 = 과최적화 or 레짐 의존 신호
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **P2-A** | fold 1,2,3,8의 기간·섹터 분포 추출 | 리포트 생성 완료 | 특정 연도(2022?) 또는 섹터 집중 여부 |
| **P2-B** | 해당 fold만 feature importance 비교 | top-5 feature 일치율 < 50% | 레짐 의존 feature 식별 |
| **P2-C** | degenerate fold 제외 후 OOS 재계산 (sanity) | 6-fold OOS mean 산출 | **leak 없으면 비슷, 있으면 급등** |

**위험/부작용**: fold 제외는 서바이버십 bias → 최종 판단용 아님, 진단 전용

---

### P3. Exposure 상한 과최적화 점검
```
WHY: exposure_max=83.8% → 레버리지 없이 높은 편, 특정 종목 집중 의심
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **P3-A** | 종목별 max weight 히스토그램 생성 | 단일 종목 > 15% 횟수 카운트 | 집중도 지표 |
| **P3-B** | exposure cap 60%로 강제 후 OOS | OOS mean ≥ 2.0 | **robust하면 유지, 아니면 집중 의존** |

**위험/부작용**: cap 낮추면 alpha 손실 가능 → 둘 다 기록 비교

---

### P4. Look-ahead Leak 정밀 점검
```
WHY: OOS mean 3.32 vs 진단기 2.63 괴리, fold 퇴화 패턴
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **P4-A** | feature 생성 timestamp vs target timestamp audit | 모든 feature t < target t | leak 없음 확인 |
| **P4-B** | shuffle-label test (label random permute) | OOS mean ≈ 0 (±0.3) | **> 0.5면 leak 의심** |

**위험/부작용**: shuffle test 자체는 파괴적 → 별도 branch

---

### P5. 전략 레이어: FSA+Hedge 조합 축소 실험
```
WHY: 현재 exp_fsa_only_scale_090_hedge_025 실행 중 → 결과 대기 + 추가 축소
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **P5-A** | hedge 0%로 완전 제거, FSA scale 1.0 | OOS mean ≥ 2.5, MDD ≤ 30% | hedge 불필요 여부 |
| **P5-B** | FSA 제거, 순수 momentum only | OOS mean 기록 | **baseline alpha 분해** |

**위험/부작용**: 단순화로 alpha 손실 → 기록 목적
