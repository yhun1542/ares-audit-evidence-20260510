# 48시간 내 실행 체크리스트 (Imperative Checklist)

현재 Champion(`v5`)의 상태는 **"과적합 의심 구간"**에 진입해 있습니다. `Lockbox_mean(4.0)`이 `Tuning_mean(2.3)`보다 비정상적으로 높고, `Tuning_min`이 음수(-0.02)인 것은 특정 시장(Lockbox 기간)에 운 좋게 맞아떨어졌으나, 범용성(Tuning)은 결여되었음을 시사합니다.

다음 5가지 항목을 즉시 실행하여 거품을 제거하고 안정성을 확보하십시오.

### 1. [Patch] Macro Regime Filter 병합 (안정성 강화)
*   **Target:** `champion_v5`에 `candidate_exp_macro_alpha_shadow`의 마켓 타이밍 로직 이식.
*   **Why:** Champion의 `Tuning_min < 0`는 하락장에서 방어가 안 된다는 뜻. Candidate의 안정적 방어 기제(Macro Alpha)를 주입해야 함.
*   **Risk:** 거래 빈도 급감으로 인한 표본 부족(Under-trading).
*   **Experiments:**
    1.  **EXP_REGIME_HARD:** VIX > 20 or US10Y 급등 시 신규 진입 금지 (Exit Only).
    2.  **EXP_REGIME_SOFT:** 비우호적 Macro 지표 발생 시 Position Size 50% 축소.
    3.  **EXP_REGIME_HEDGE:** 하락 시그널 발생 시 현금 비중 30% 강제 확보.
*   **PASS Gate:**
    *   `Tuning_min` > 0.0
    *   `Lockbox_mean` > 2.5 (4.0에서 하락하더라도 수용)
*   **Expectation:** 수익률 곡선의 변동성 감소, MDD 개선.

### 2. [Patch] ATR 기반 변동성 타겟팅 (Position Sizing)
*   **Target:** 고정 비중(Equal Weight) 또는 단순 점수 비중 로직 변경.
*   **Why:** Tech/Bio(Healthcare) 섹터는 변동성이 큼. 단순 비중은 급락 종목에 과다 노출됨. 개별 종목의 ATR(Average True Range) 역수로 비중을 조절하여 리스크 평준화.
*   **Risk:** 폭등하는 주도주(Momenum)의 비중이 줄어들어 수익률 상단이 깎임.
*   **Experiments:**
    1.  **EXP_ATR_SIZING:** `Weight = (1/ATR_14) / Sum(1/ATR_all)`
    2.  **EXP_VOL_CAP:** 개별 종목 변동성이 포트폴리오 전체 변동성의 X%를 넘지 않도록 Cap 설정.
*   **PASS Gate:**
    *   `Fold14_MDD` > -0.05 (현재 -0.039 유지 확인)
    *   `Worst_MDD` > -0.06
*   **Expectation:** 급락 종목에 의한 `Worst_MDD` 방어.

### 3. [Patch] 비용/슬리피지 스트레스 테스트 (비용 현실화)
*   **Target:** 시뮬레이션 환경 설정 (`sim_config`).
*   **Why:** `Lockbox_mean` 4.0은 비현실적. 슬리피지나 수수료가 과소평가되었을 가능성 99%. Tech/Bio 소형주 포함 시 슬리피지 영향 큼.
*   **Risk:** 모든 전략이 탈락(Fail)하여 배포 가능한 모델이 사라질 수 있음.
*   **Experiments:**
    1.  **EXP_COST_2X:** Transaction Cost와 Slippage를 현재 설정의 2배로 적용 후 재검증.
    2.  **EXP_MIN_HOLD:** 최소 보유 기간(3일/5일) 강제 적용으로 회전율 억제.
*   **PASS Gate:**
    *   (2배 비용 적용 시) `Tuning_mean` > 1.0 유지.
*   **Expectation:** 거품 제거 후 진짜 Alpha 확인. Turnover가 높은 전략 자동 필터링.

### 4. [Patch] 섹터 밸런싱 강제 (Tech/Health 편중 방지)
*   **Target:** 포트폴리오 최적화 제약조건.
*   **Why:** 8~14개 종목이 특정 시점에 Tech 100% 또는 Bio 100%로 쏠리면 MDD 관리 불가능.
*   **Risk:** 상관관계가 높은 시기(시장 전체 하락)에는 효과가 제한적일 수 있음.
*   **Experiments:**
    1.  **EXP_SECTOR_LIMIT:** 단일 섹터(Tech or Health) 비중 Max 60% 제한.
    2.  **EXP_CORR_FILTER:** 포트폴리오 내 종목 간 평균 상관계수가 0.7 이상이면 상관계수 높은 종목 제거.
*   **PASS Gate:**
    *   `Worst_MDD` 개선 (절대값 감소).
*   **Expectation:** 섹터 로테이션 효과로 꾸준한 우상향 유도.

### 5. [System] 유니버스 동적 교체 점검 (Survivorship Bias)

*   **Why:** 현재 유니버스가 "현재 살아남은 우량주"로만 구성되었는지 확인 필요. 상장폐지 종목이 포함된 과거 데이터를 쓰고 있는지 점검.
*   **Experiments:**

*   **Expectation:** 생존 편향으로 인한 가짜 성과 식별.

### 성능 정체(Stagnation) 시 원인 분해 트리

성능이 개선되지 않고 제자리걸음일 경우, 다음 순서로 원인을 진단하고 조치하십시오.

1.  **트리거(Trigger) 확인:**
    *   *증상:* 매매 횟수가 극단적으로 적음 (월 1~2회).
    *   *진단:* 진입 조건(Entry Threshold)이 너무 높거나, 필터가 너무 빡빡함.
    *   *조치:* Entry Threshold를 낮추고 Exit 조건을 강화하여 회전율을 높여 실험.

2.  **레짐(Regime) 불일치:**
    *   *증상:* 특정 연도(예: 2022년)에만 손실이 집중됨.
    *   *진단:* 금리 인상기/하락기에 대한 대응 로직 부재.
    *   *조치:* `Macro Alpha` 비중 확대 또는 현금 비중 로직(Cash Rule) 추가.

3.  **비용(Cost) 잠식:**
    *   *증상:* 승률(Win Rate)은 높은데(>60%), 수익 곡선이 평평하거나 우하향.
    *   *진단:* 평균 이익(Avg Profit)이 비용(Comm+Slip)을 겨우 상회함. "짤짤이" 매매 중.
    *   *조치:* 최소 기대 수익률(Min Profit Target) 설정 전까지 청산 금지 또는 변동성 돌파(Volatility Breakout) 기준 상향.

4.  **노출(Exposure) 왜곡:**
    *   *증상:* 지수(QQQ/XLV) 대비 Alpha가 0에 수렴.
    *   *진단:* 사실상 ETF를 보유한 것과 다를 바 없는 포트폴리오 구성 (Beta=1).
    *   *조치:* 8~14개 종목 선별 기준을 시가총액 가중이 아닌, 모멘텀/Value factor 가중으로 변경하여 Alpha 추구.
