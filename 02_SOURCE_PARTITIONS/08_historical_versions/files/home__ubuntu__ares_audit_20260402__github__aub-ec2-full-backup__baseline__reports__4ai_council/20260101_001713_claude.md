## 2. 성능 정체 원인 분해 트리 (Δ ≈ 0 일 때)

```
lockbox Δ ≈ 0
│
├─ [1] 트리거 미발동
│   └─ 점검: 실험 기간 중 리밸런스 횟수 = 0? → 신호 변화 임계값 검토
│
├─ [2] 신호는 바뀌었으나 포지션 불변
│   └─ 점검: 종목 순위 변동 vs 실제 거래 diff → position sizing 로직 버그
│
├─ [3] 포지션 변경되었으나 수익 미발생
│   └─ 점검: hit rate & payoff ratio by period → alpha decay 확인
│
├─ [4] 수익 발생했으나 비용이 상쇄
│   └─ 점검: gross return - cost = net → turnover 과다 여부
│
└─ [5] 레짐 불일치
    └─ 점검: lockbox 기간 내 VIX regime (≥25 일수 비율) → 방어모드 필요성
```
