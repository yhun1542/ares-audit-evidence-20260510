## 1. 우선순위 TOP-5 실험 패치

### ① MDD 게이트 복원 및 리스크 캘리브레이션

**왜 필요?**  
`worst_mdd: None` → 현재 챔피언이 리스크 게이트 없이 승격됨. OOS mean 1.88은 MDD 무한대일 가능성 배제 불가.

**위험/부작용**  
- MDD 계산 로직 버그 시 정상 실험도 reject  
- 과거 런 재계산 필요 → 비용 증가

**최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **EXP-MDD-01** | Champion JSON에서 daily equity curve 추출 → MDD 재계산 | MDD ≤ -25% | MDD 수치 확정, -15% ~ -25% 범위 |
| **EXP-MDD-02** | MDD > -30% 실험 자동 reject 로직 autopilot에 삽입 | CI 통과 | reject 로그 1건 이상 발생 |

**PASS 조건**: `worst_mdd` 필드 non-null, 값 -30% 이내

### ② Exposure 밴드 이상 탐지 (0.47~0.84 → 왜?)

**왜 필요?**  
min 0.47 / max 0.84 → 변동폭 37%p. 레짐 전환 없이 이 정도면 **시그널 불안정 or 리밸런스 과잉**.

**위험/부작용**  
- 밴드 강제 제한 시 수익 기회 손실  
- 원인 미파악 상태에서 패치 시 숨은 버그 은폐

**최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **EXP-EXP-01** | exposure 변동이 큰 날짜 TOP-10 추출 → 해당일 시그널 로그 확인 | - | 특정 종목/섹터 집중 여부 |
| **EXP-EXP-02** | `exposure_cap=0.75` 하드리밋 적용 후 OOS 재실행 | OOS mean ≥ 1.80 | Sharpe 하락폭 < 5% |

**PASS 조건**: 원인 1개 이상 특정 + 리밋 적용 시 OOS 유지

---

### ③ OOS Mean 드리프트 점검 (2.63 → 1.88)

**왜 필요?**  
Diagnoser 리포트 Champion OOS 2.63 vs HANDOFF 1.88 → **28% 하락**. 데이터 레이크 불일치 or 코드 변경 의심.

**위험/부작용**  
- 실제 시장 레짐 변화일 경우 false alarm  
- 롤백 시 최신 데이터 미반영

**최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **EXP-DRIFT-01** | 동일 config로 2025-12-15 데이터 스냅샷 재실행 | OOS diff < 0.1 | 2.5+ 복원 시 데이터 문제 |
| **EXP-DRIFT-02** | git diff `champion_v5` vs 현재 HEAD → 로직 변경점 리스트업 | - | 변경 함수 0~3개 특정 |
| **EXP-DRIFT-03** | 최근 30일 신규 데이터만 OOS 테스트 | - | 신규 구간 Sharpe < 1.0 시 레짐 시프트 |

**PASS 조건**: 원인 분류 완료 (데이터/코드/레짐 중 1개)

### ④ 트랜잭션 비용 실반영 검증

**왜 필요?**  
`exposure` 변동 37%p + 8~14종목 → **연간 턴오버 추정 400%+**. 슬리피지/스프레드 미반영 시 OOS 과대.

**위험/부작용**  
- 비용 과다 책정 시 전략 폐기 오판  
- 실제 체결 데이터 없으면 추정치 신뢰도 낮음

**최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **EXP-COST-01** | rebalance 로그에서 일별 turnover 계산 → 연환산 | - | 턴오버 300~600% 확인 |
| **EXP-COST-02** | `cost_bps=10` (편도 10bp) 적용 후 OOS 재실행 | OOS mean ≥ 1.50 | 비용 후 Sharpe 1.5+ 유지 |

**PASS 조건**: 비용 반영 OOS ≥ 1.50 (30% 이상 감소 시 전략 재설계)

### ⑤ Fold Stability / 서바이버십 점검

**왜 필요?**  
`degenerate_folds: []` 이나 9개 실험 중 챔피언 1개만 통과 → **서바이버십 bias** 가능.

**위험/부작용**  
- 전체 폴드 재실행 비용 증가  
- 실제로 robust해도 보수적 판정

**최소 실험**

| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| **EXP-FOLD-01** | 5-fold 전체 OOS 분포 시각화 (mean, std, min) | std < 0.5 | 폴드 간 편차 확인 |
| **EXP-FOLD-02** | 최악 폴드 단독 분석 → 해당 기간 시장 레짐 매핑 | - | 2022 베어마켓 등 특정 |

**PASS 조건**: 모든 폴드 OOS > 1.0, std < 0.5

## 3. 즉시 실행 명령어 (복붙용)

```bash
# 1. 인프라 패치
cd /home/ubuntu/AUB
git diff HEAD~5 -- experiment_system/tools/*.py > /tmp/tool_changes.diff

# 2. MDD 재계산
python3 -c "
import json
j = json.load(open('baseline/champion_v5_latest.json'))
eq = j.get('equity_curve', [])
if eq:
    peak = eq[0]; mdd = 0
    for v in eq:
        peak = max(peak, v)
        mdd = min(mdd, (v - peak) / peak)
    print(f'Computed MDD: {mdd:.2%}')
else:
    print('ERROR: No equity_curve in JSON')
"

# 3. Turnover 계산
python3 experiment_system/tools/aub_turnover_calc.py \
```
