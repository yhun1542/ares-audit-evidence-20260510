2.  **노출(Exposure) 확인**: 0.47~0.84 노출도가 고정되어 있는가? (동적 자산 배분 실패) -> *해결: 현금 비중 로직 강제 오버라이드 테스트.*
3.  **비용(Cost) 민감도**: 수수료를 0으로 설정했을 때도 성능이 안 나오는가? -> *해결: 알파 소멸(Alpha Decay). 전략 로직 교체 필요.*
4.  **레짐(Regime) 불일치**: 현재 시장이 Tech/Health 주도 장세가 아닌가? (에너지/금융 강세 등) -> *해결: 유니버스 확장 고려 전, XLK/XLV 대비 상대강도(RS)가 높은 종목으로 유니버스 압축.*
