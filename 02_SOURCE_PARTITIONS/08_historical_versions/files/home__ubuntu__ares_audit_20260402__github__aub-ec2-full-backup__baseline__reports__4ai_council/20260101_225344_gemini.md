## [시스템 24~48시간 우선순위 명령 리스트]

현재 `candidate_exp_mrd_fsa`가 Champion 대비 Lockbox 성능이 우월하나(Mean 1.55 vs 1.33), **Tuning Min(-1.49)과 Lockbox Min(0.33) 간의 괴리**가 심각함. 이는 특정 구간 과최적화(Overfitting) 또는 룩어헤드 편향(Look-ahead Bias) 가능성을 시사함. 즉시 다음 3가지 패치를 검증할 것.

### 1. [검증] Tuning/Lockbox 괴리 원인 분석 및 Regime Stress Test
*   **이유:** Tuning 구간의 최저점(-1.49)이 실운용 시 발생하면 계좌 파산 위험. Lockbox가 단순히 "운 좋은 구간(Bull market)"이었는지 확인 필요.
*   **위험/부작용:** 엄격한 스트레스 테스트로 인해 현재의 고수익 Candidate가 탈락하여 단기적 정체 발생 가능.
*   **실험 정의:**
    1.  **Exp_Stress_Bear:** 2022년형 하락장, 2020년형 급락장 데이터를 강제 오버샘플링하여 Tuning 재수행.
    2.  **Exp_Leakage_Check:** Feature Calculation 시점과 Target 시점의 `shift` 로직 재검수 (특히 종가/시가 혼용 여부).
    3.  **Exp_Noise_Injection:** 가격 데이터에 가우시안 노이즈(0.1~0.5%) 추가 후 성능 유지력 테스트.
*   **PASS 조건:**
    *   Stress Test 구간 MDD < -15% 방어.
    *   Noise 추가 시 Sharpe Ratio 하락폭 < 20%.

### 2. [리스크] Tech/Healthcare 섹터 공분산 페널티 (Correlation Penalty)
*   **이유:** Tech와 Healthcare는 금리 등 매크로 변수에 동조화되는 경향이 있음. 8~14종목이 동시에 무너지는 리스크 제어 부재.
*   **위험/부작용:** 강세장에서의 Upside Potential(수익률) 제한.
*   **실험 정의:**
    1.  **Exp_Cov_Penalty:** 포트폴리오 최적화 목적함수에 `lambda * Portfolio_Variance` 항 강화.
    2.  **Exp_Sec_Cap:** 단일 섹터(Tech or Health) 비중 상한 60% 강제 설정.
    3.  **Exp_Beta_Neutral:** SPY(S&P500) 대비 Beta가 1.5 초과 시 현금 비중 확대 로직 추가.
*   **PASS 조건:**
    *   Tuning Min 값이 -1.0 이상으로 개선 (현재 -1.49).
    *   Fold14_MDD 변화폭 < +10%p (안정성 유지).

### 3. [비용] 슬리피지/턴오버 현실화 (Conservative Cost Modeling)
*   **이유:** `exp_mrd`(Mean Reversion) 계열은 잦은 매매를 유발할 수 있음. 시뮬레이션 상의 고수익이 실제 슬리피지로 증발할 가능성 차단.
*   **위험/부작용:** 거래 횟수 급감으로 인한 표본 부족, 통계적 유의성 저하.
*   **실험 정의:**
    1.  **Exp_Cost_3x:** 거래 비용(수수료+슬리피지)을 현재 설정의 3배(예: 10bps -> 30bps)로 적용 후 재평가.
    2.  **Exp_Min_Hold:** 최소 보유 기간(예: 3일) 강제 또는 조기 청산 시 페널티 부과.
    3.  **Exp_Liquidity_Filter:** 하위 20% 유동성 종목 유니버스에서 영구 제외.
*   **PASS 조건:**
    *   Cost 3배 적용 시에도 Lockbox Mean > 1.0 유지.
    *   월간 회전율(Turnover) < 300% (양방향 기준).

### [성능 정체 시 원인 분해 (Debugging Checklist)]

성능 지표가 개선되지 않을 경우, 다음 순서로 원인을 규명하고 로그에 남길 것.

1.  **트리거(Trigger) 실패:** 신호가 발생해야 할 명백한 추세/반전 구간에서 Signal이 `0`인가?
    *   *Action:* Threshold(임계값)를 낮추거나, 필터(ADX 등)를 완화하여 감도 테스트.
2.  **적용(Application) 실패:** 신호는 발생했으나 포트폴리오 비중 할당(Optimizer)에서 0% 처리되었는가?
    *   *Action:* Risk Parity 등 최적화 제약조건(Constraint)이 너무 타이트한지 점검.
3.  **노출(Exposure) 왜곡:** 비중은 실렸으나, 갭락(Gap-down) 등 장 시작 시점에 이미 손실 확정 상태인가? (Overnight Risk)
    *   *Action:* 시가(Open) 진입 vs 종가(Close) 진입 전략 분리 테스트.
4.  **비용(Cost) 과다:** Gross Return은 좋으나 Net Return이 무너지는가?
    *   *Action:* 진입 횟수를 줄이고 승률(Win-rate)보다 손익비(P/L Ratio) 중심으로 전략 수정.
5.  **레짐(Regime) 불일치:** 현재 모델이 역추세(Mean Reversion)인데 시장이 강한 추세(Momentum)장인가?
    *   *Action:* 최근 3개월 시장 Hurst Exponent 측정. H > 0.5면 Momentum 모듈 가중치 상향.
