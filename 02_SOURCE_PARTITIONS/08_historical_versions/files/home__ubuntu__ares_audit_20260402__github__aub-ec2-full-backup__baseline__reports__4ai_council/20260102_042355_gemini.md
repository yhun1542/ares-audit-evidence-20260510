[우선순위 제안 및 실행 계획]

### 1. [검증] 거래 비용 및 슬리피지(Slippage) 스트레스 테스트
**왜 필요한가:** Champion의 Tuning Sharpe(3.47)가 비현실적으로 높음. 실제 라이브 트레이딩 환경(유동성 부족, 호가 스프레드) 반영 시 성능이 급락할 가능성 농후.
**위험/부작용:** 모든 후보 모델이 탈락하여 배포 가능한 모델이 없게 될 수 있음.
**실험 제안:**
1.  **EXP_COST_2X:** 기존 거래 비용 설정(수수료+슬리피지)을 2배로 상향 적용.
2.  **EXP_LIQUIDITY_PENALTY:** 거래량 하위 20% 종목 진입 시 추가 페널티(bps) 부과.

**48시간 루프 정의:**
1.  **실험 정의:** `champion_v5` 로직 유지하되, `sim_cost_bps`를 5bps -> 10bps(또는 15bps)로 변경 후 백테스트.
2.  **게이트(PASS):** Lockbox Min Sharpe > 1.2 유지 & DD < -10%.
3.  **기대 관측치:** 수익률은 하락하겠지만, 시스템이 손익분기점 위에서 버티는지 확인.

---

### 2. [운영] 실행 시점 지연(Execution Lag) 테스트
**왜 필요한가:** 현재 로직이 종가(Close) 배팅인지 확인 필요. 실제로는 종가 확인 후 진입 시 익일 시가(Open) 체결되거나, 종가 예측 오차가 발생함. Tech/Bio 섹터는 장 마감 후 변동성이 큼.
**위험/부작용:** 수익률 곡선의 평탄화, MDD 급증(오버나잇 갭 리스크 노출).
**실험 제안:**
1.  **EXP_NEXT_OPEN:** 시그널 발생 당일 종가가 아닌, 익일 시가(T+1 Open)로 진입/청산 가격 변경.
2.  **EXP_VWAP_EXEC:** 종가 대신 고가/저가/종가의 평균(VWAP 근사)으로 체결 가정.

**48시간 루프 정의:**
1.  **실험 정의:** `execution_price_mode`를 'close'에서 'next_open'으로 변경.
2.  **게이트(PASS):** Tuning Mean Sharpe > 2.0 (기존 대비 40% 이상 하락 방어).
3.  **기대 관측치:** 오버나잇 갭으로 인한 MDD 증가폭(-0.07 -> -0.10 내외) 측정.

---

### 3. [전략] 변동성 기반 동적 유니버스 축소 (Vol-Regime Filtering)
**왜 필요한가:** `candidate_..._mrd_fsa`가 MDD 방어(-0.04)에 성공했으나 수익이 낮음. Champion에 '방어 기제'만 이식 필요. Tech/Healthcare는 금리/규제 이슈 시 동반 하락하므로 섹터 간 상관관계가 높아질 때 현금 비중 확대가 필수.
**위험/부작용:** 상승장 초입에서 진입이 늦어 수익 기회(Alpha) 상실.
**실험 제안:**
1.  **EXP_CORR_FILTER:** 포트폴리오 내 종목 간 평균 상관계수가 0.7 이상이면 현금 비중 50% 강제.
2.  **EXP_VIX_SCALING:** VIX(또는 XLK/XLV 내재변동성) 급등 시 포지션 사이징 축소.

**48시간 루프 정의:**
1.  **실험 정의:** `champion_v5`에 Pre-trade filter 모듈 추가 (Correlation > Threshold 시 size *= 0.5).
2.  **게이트(PASS):** Worst MDD > -0.06 (개선) & Tuning Mean Sharpe > 3.0 (유지).
3.  **기대 관측치:** Lockbox Min 성능이 `candidate` 수준(DD -0.04)으로 수렴하는지 확인.

---

### 4. [과최적화] Feature Noise Injection
**왜 필요한가:** Tuning(3.47)과 Lockbox Min(1.53)의 괴리가 큼. 특정 패턴(노이즈)을 시그널로 착각하고 있을 가능성.
**위험/부작용:** 모델 성능 전반적 하락.
**실험 제안:**
1.  **EXP_NOISY_OPEN:** 입력 데이터(OHLCV)에 랜덤 가우시안 노이즈(0.5%)를 섞어서 학습/추론.
2.  **EXP_DROP_FEAT:** 중요도 하위 30% 피처를 강제로 제거하고 재학습.

**48시간 루프 정의:**
1.  **실험 정의:** 데이터 로더 단계에서 `noise_injection=True` 활성화 또는 Feature set 축소.
2.  **게이트(PASS):** Lockbox Mean 성능 하락폭이 10% 이내일 것.
3.  **기대 관측치:** 노이즈에도 불구하고 주요 시그널(Trend/Mean-reversion)이 유지되는지 확인.

### [성능 정체 시 원인 분해 아이디어]

만약 위 실험들 후에도 성능이 개선되지 않거나(Stagnation), Champion을 이기는 모델이 나오지 않을 때 점검할 항목:

1.  **트리거(Trigger) 불감증:**
    *   *현상:* 매매 횟수가 극단적으로 적거나(Hold), 너무 많음(Churn).
    *   *점검:* 시그널 Threshold가 너무 높게 설정되어 유효한 진입 기회를 모두 놓치고 있는지 확인.

2.  **비용(Cost)의 지배:**
    *   *현상:* Gross Return은 우상향이나 Net Return이 횡보/하락.
    *   *점검:* 평균 보유 기간(Holding Period)이 너무 짧아(예: 1~2일) 수수료가 알파를 잠식하는지 확인. (Tech/Bio는 변동성이 커서 잦은 손절 유발 가능)

3.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 연도(예: 2022년 하락장)에만 MDD가 집중됨.
    *   *점검:* 숏(Short) 포지션이 없거나 제한적인 경우, Long-only 편향이 하락장에서 드로우다운을 심화시키는지 확인. (미국주식 Only 제약 상 ETF 인버스 헤지 로직 고려 필요성 대두)

4.  **유니버스(Universe) 편향:**
    *   *현상:* 8~14개 종목이 모두 'Mega Cap Tech'로만 구성됨.
    *   *점검:* Healthcare 종목이 제대로 섞이지 않아 분산 효과가 사라졌는지 확인. 섹터 쿼터제(최소 3개는 Healthcare 강제) 도입 고려.
