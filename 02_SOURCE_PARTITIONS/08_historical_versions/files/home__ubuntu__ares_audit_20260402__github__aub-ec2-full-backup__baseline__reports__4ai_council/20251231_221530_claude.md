## 1. TOP 5 우선순위 패치

### PATCH-1: Signal Utilization Audit (신호 활용률 점검)

#### (a) 왜 필요한지
- 모듈 변경 → 신호 변경 → **포지션 변경 없음** 가능성
- 신호가 바뀌어도 sizing/filter에서 잘려나가면 실험 무의미

#### (b) 위험/부작용
- 순수 진단용, 성능 변경 없음
- 로깅 오버헤드 minimal

#### (c) 최소 실험
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| 1-A | 각 종목별 `signal_raw → position_final` 변환율 로깅 | 자동 | 변환율 < 30%면 bottleneck 식별 |
| 1-B | Top3 필터(volatility/liquidity/sector) 제거 시 position diff | lockbox_mean ±5% 이내 | diff > 20% 종목일수 = 필터 과적합 |

#### (d) PASS 조건
```
signal_to_position_ratio >= 0.4 AND position_diff_ratio >= 0.15
```

### PATCH-2: Regime Exposure 분해

#### (a) 왜 필요한지
- lockbox_min = 1.35 (≈+35%) 고정 → **특정 레짐에서만 수익** 의심
- 전체 평균은 좋아도 2022-type drawdown 재현 시 취약

#### (b) 위험/부작용
- 레짐별 과최적화 유혹
- 레짐 정의 자체가 사후적(survivorship)

#### (c) 최소 실험
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| 2-A | VIX 20 기준 High/Low vol 구간 CAGR 분해 | 자동 | Low vol CAGR > High vol CAGR 1.5배 이상이면 경고 |
| 2-B | 2022-Q1~Q3 구간만 별도 리포트 | MDD < -15% | Healthcare 방어력 실측 |
| 2-C | Rate-hike 기간(2022.03~2023.07) 샤프 분리 | Sharpe > 0.3 | 금리 민감도 확인 |

#### (d) PASS 조건
```
high_vol_sharpe >= 0.5 * low_vol_sharpe AND 2022_mdd >= -15%
```

### PATCH-3: Position Concentration / Turnover 비용 검증

#### (a) 왜 필요한지
- 현재 비용 모델 미명시 → 실제 slippage/spread 미반영 가능
- 8-14종목인데 Top3 집중 시 실질 분산효과 ↓

#### (b) 위험/부작용
- 비용 과대 추정 시 시스템 과소 매매
- 비용 모델 파라미터 자체가 새 레버

#### (c) 최소 실험
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| 3-A | 10bp roundtrip 비용 추가 후 lockbox 재계산 | lockbox_mean > 1.65 | 비용 민감도 < 8% 하락 |
| 3-B | HHI(집중도) 일별 계산 → HHI > 0.25 일수 비율 | < 20% | 과집중 일수 제한 |
| 3-C | 월간 turnover > 200% 시 sizing 캡 적용 | worst_mdd 불변 | 과매매 방지 |

#### (d) PASS 조건
```
cost_adjusted_lockbox >= 0.92 * lockbox_mean AND hhi_alert_days <= 0.2
```

### PATCH-5: Leakage / Lookahead 체크리스트 자동화

#### (a) 왜 필요한지
- 성능 변화 없음 = 이미 최적 or **누수로 천장**
- Champion이 진짜인지 검증 필수

#### (b) 위험/부작용
- 순수 검증, 부작용 없음
- 누수 발견 시 Champion 무효화 → 대규모 롤백

#### (c) 최소 실험
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| 5-A | 전 모듈 `data_as_of` timestamp 검증 스크립트 | FAIL 0건 | t+1 이후 데이터 사용 없음 |
| 5-B | Price reference point 체크 (open/close/adj) | 일관성 100% | 혼용 없음 |
| 5-C | Universe 결정 시점 vs 신호 계산 시점 gap | gap = 0 | 미래 종목 포함 없음 |

#### (d) PASS 조건
```
leakage_flags == 0 AND timestamp_consistency == 1.0
```

## 3. 48h 자동 루프 명령

```bash

  --champion baseline/champion_v5_20251231.json \
  --output baseline/reports/leakage_20250101.json

python3 experiment_system/tools/signal_utilization.py \
  --champion baseline/champion_v5_20251231.json \
  --threshold 0.4 \
  --output baseline/reports/signal_util_20250101.json

  --champion baseline/champion_v5_20251231.json \
  --cost-bp 10 \
  --output baseline/reports/cost_sens_20250101.json

# Step 4: Regime decomposition
python3 experiment_system/tools/regime_split.py \
  --champion baseline/champion_v5_20251231.json \
  --vix-threshold 20 \
  --output baseline/reports/regime_20250101.json

# Step 5: Autopilot with new diagnostics
python3 experiment_system/tools/aub_autopilot.py \
  --registry experiment_system/config/module_registry.yaml \
  --diagnostics baseline/reports/ \
  --run --select-best
```
