## 1. 우선순위 TOP 5 제안

### P1. MDD 방어층 강화 (fold14: -3.95% → 목표 -2.5%)

**(a) 필요성**
- Champion의 fold14 MDD -3.95%, worst -8.15% → 실전 운용 시 심리적 손절 유발
- Candidate는 MDD -10% 넘어 FAIL급

**(b) 위험/부작용**
- 과도한 방어 → 상승장 추종 실패 (CAGR 20%+ 감소 가능)
- 거래 빈도 증가 → 비용 증가

**(c) 최소 실험**

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `exp_mdd_vol_scale_v1` | 20일 실현변동성 > 25% 시 position 50% 축소 | tuning_min ≥ 0 | fold14_mdd → -2.5% 이내 |
| `exp_mdd_atr_stop_v1` | 개별 종목 2×ATR(14) trailing stop | 승률 ≥ 45% 유지 | worst_mdd → -6% 이내 |
| `exp_mdd_vix_hedge_v1` | VIX > 25 시 현금비중 30% 강제 | tuning_mean ≥ 2.0 | MDD 개선 + CAGR 유지 |

**(d) PASS 조건**
```
fold14_mdd ≥ -0.03 AND worst_mdd ≥ -0.07 AND tuning_mean ≥ 2.0
```

## 3. 성능 미이동 시 원인 분해 트리

```
성능 불변
│
├─ [트리거 실패] 신호가 발생 안 함
│   └─ 진단: `signal_fire_rate < 5%` → 임계값 완화 실험
│
├─ [적용 실패] 신호 발생 but 진입 안 함
│   └─ 진단: `entry_skip_rate > 30%` → 필터 조건 점검
│
├─ [노출 부족] 진입 but 포지션 너무 작음
│   └─ 진단: `avg_position_size < 5%` → 사이징 로직 점검
│
├─ [비용 잠식] 수익 but 비용이 상쇄
│   └─ 진단: `gross_return - net_return > 1%` → 회전율 축소
│
└─ [레짐 역행] 전략 방향 vs 시장 방향 불일치
    └─ 진단: `strategy_return × market_return < 0` 빈도 → 레짐 필터 강화
```
