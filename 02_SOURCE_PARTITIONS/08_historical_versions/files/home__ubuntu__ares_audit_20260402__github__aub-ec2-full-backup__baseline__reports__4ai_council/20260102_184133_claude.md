## 2. 성능 미변동 원인 분해 트리

```
성능 Δ ≈ 0
├─ [트리거] 시그널 자체가 안 바뀜?
│   └─ 점검: 시그널 분포 entropy / 일별 flip rate
├─ [적용] 시그널 → 포지션 전환 안 됨?
│   └─ 점검: rebalance 빈도 / position delta histogram
├─ [노출] 포지션은 잡히나 sizing 미미?
│   └─ 점검: avg exposure / max position weight
├─ [비용] 수익 = 비용으로 상쇄?
│   └─ 점검: gross return vs net return gap
└─ [레짐] 해당 기간 시장 자체가 flat?
    └─ 점검: SPY return / VIX 평균 해당 구간
```
