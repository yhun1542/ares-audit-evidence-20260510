### 1. 우선순위 TOP 3 제안 (48시간 루프)

#### **Proposal 1: 미래 참조(Look-ahead Bias) 및 시점 정합성 강제 검증**
*   **(a) 필요성:** Lockbox Min 값이 0.33(양수)인 것은 하락장이 포함된 기간이라면 불가능에 가까운 수치임. Feature 생성 시점이나 Target Label링에서 미래 데이터 누수(Leakage) 의심.
*   **(b) 위험:** 누수 확인 시 후보 모델 전량 폐기 필요. 개발 멘탈 리스크.
*   **(c) 실험 (Experiments):**
    1.  **EXP-LEAK-01 (Shift Execution):** 매수/매도 시점을 Signal 발생 `t`가 아닌 `t+1` Open/Close로 강제 지연시켜 백테스트 수행.
    2.  **EXP-LEAK-02 (Feature Lag):** 모든 입력 Feature에 `shift(1)`을 강제로 추가 적용 후 재학습/평가.
    3.  **EXP-LEAK-03 (Random Noise):** 가격 데이터에 미세한 노이즈(0.1%) 추가 후 성과 급락 여부 확인 (강건성 체크).
*   **(d) PASS 조건:** `EXP-LEAK-01` 수행 시 Tuning/Lockbox Mean 성과 하락폭이 15% 이내이며, MDD가 -10%를 초과하지 않을 것.

#### **Proposal 2: 유니버스 집중도 및 섹터 편향 스트레스 테스트**
*   **(a) 필요성:** Tech+Healthcare 8~14 종목 제한 상황에서, 특정 대형주(예: NVDA, LLY)에만 몰빵하여 얻은 수익인지 확인 필요. ETF 매매는 제외하더라도, ETF(XLK, XLV)와의 상관계수 확인 필수.
*   **(b) 위험:** 알파가 아니라 단순 베타(Beta) 노출로 판명될 경우 전략 가치 하락.
*   **(c) 실험 (Experiments):**
    1.  **EXP-CONC-01 (Jackknife):** 포트폴리오 내 비중 상위 2개 종목을 제외하고 백테스트 수행.
    2.  **EXP-CONC-02 (Sector Neutrality):** Tech와 Healthcare 비중을 강제로 50:50으로 고정(Rebalancing)했을 때의 성과 측정.
*   **(d) PASS 조건:** 상위 종목 제외 시에도 Sharpe Ratio가 1.0 이상 유지, MDD 악화폭 20% 이내.

#### **Proposal 3: 비용 민감도 및 거래 회전율(Turnover) 제어**
*   **(a) 필요성:** `tuning_mean`과 `lockbox_mean`의 차이가 큼. 과도한 매매로 인한 슬리피지/수수료 반영 시 실제 수익률이 음수로 전환될 리스크 점검.
*   **(b) 위험:** 거래 횟수 제한 시, 빠른 시세 변화에 대응 못해 MDD가 커질 수 있음.
*   **(c) 실험 (Experiments):**
    1.  **EXP-COST-01 (High Friction):** 거래 비용(수수료+슬리피지)을 현재 설정의 2배(예: 10bps -> 20bps)로 설정.
    2.  **EXP-FREQ-01 (Min Holding):** 최소 보유 기간(3일/5일) 제약 조건 추가.
*   **(d) PASS 조건:** `EXP-COST-01`에서 순수익(Net Profit)이 양수 유지, `EXP-FREQ-01` 적용 시 기존 챔피언 모델 대비 우위 유지.

### 3. 성능 정체(Stagnation) 시 원인 분해 디버깅 가이드

성능 지표가 움직이지 않거나 챔피언을 넘지 못할 때, 다음 트리 구조로 원인을 파악하십시오.

*   **1단계: 트리거 (Trigger) 부재**
    *   *증상:* 매매 횟수가 극도로 적거나 0임.
    *   *확인:* 진입 조건(Entry Threshold)이 너무 높거나, Tech/Health 종목 간의 상관관계가 높아 헷지 시그널이 상쇄되는지 확인.
*   **2단계: 적용 (Application) 실패**
    *   *증상:* 시그널은 뜨는데 포지션 사이즈가 미미함.
    *   *확인:* Volatility Targeting 로직이 최근의 고변동성(VIX 등) 때문에 포지션 크기를 0에 가깝게 줄이고 있는지 확인.
*   **3단계: 노출 (Exposure) 왜곡**
    *   *증상:* 시장 상승기에 수익이 안 남.
    *   *확인:* Long/Short 비중이 의도치 않게 Net Neutral(0)에 가까워져 Alpha만 남고 Beta 수익을 포기했는지 점검.
*   **4단계: 레짐 (Regime) 불일치**
    *   *증상:* Tuning 때는 좋았는데 Lockbox에서만 박살남.
    *   *확인:* Tuning 기간(저금리/상승장) vs Lockbox 기간(고금리/횡보장) 데이터 분포 확인. `System_Autopilot`에서 Regime Filter를 켜고 재학습.
