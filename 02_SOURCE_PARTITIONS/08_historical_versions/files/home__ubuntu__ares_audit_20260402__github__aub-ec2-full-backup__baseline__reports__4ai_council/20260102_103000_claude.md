## 2. 성능 미변동 시 원인 분해 트리

```
OOS 안 움직임
├─ [트리거] 시그널 자체가 안 바뀜
│   └─ 체크: 일간 signal diff count → 0이면 데이터 파이프라인 문제
├─ [적용] 시그널 → 포지션 전환 안 됨
│   └─ 체크: rebalance 로그 trades 수 → 0이면 execution 로직 문제
├─ [노출] 포지션은 바뀌는데 exposure 범위 좁음
│   └─ 체크: exposure_min/max 차이 < 0.1 → 사실상 고정 비중
├─ [비용] 수익은 있으나 비용으로 상쇄
│   └─ 체크: gross vs net return 차이 > 0.3 → 회전율 과다
└─ [레짐] 테스트 기간이 특수 레짐
    └─ 체크: VIX 평균 > 25 or SPY MDD > 15% → 레짐 라벨링
```
