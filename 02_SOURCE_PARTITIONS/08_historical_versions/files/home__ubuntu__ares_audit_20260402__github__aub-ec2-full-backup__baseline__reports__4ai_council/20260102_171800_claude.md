**(b) 위험/부작용**
- fold별 튜닝 시 과최적화 심화
- 너무 많은 조건 분기 → 복잡도 폭발

| P2-C | purged k-fold gap을 2→4주로 확대 | 누수 차단 | degenerate fold ≤ 2개 |

**(d) PASS 조건**
```
✅ degenerate_folds ≤ 2
✅ OOS mean 분산 (across folds) < 1.5
```
