## 1. 우선순위 TOP-5 액션 (48h)

### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### P1. 파이프라인 정합성 복구 (Rebalance Log + MDD)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한가**
- `rebalance.csv` 로드 실패 → 어떤 종목이 언제 진입/청산됐는지 추적 불가
- `worst_mdd: None` → 리스크 게이트 작동 안함, 실전 배포 불가
- 이 상태로 실험해도 원인 분해 불가능

**(b) 위험/부작용**
- 로그 포맷 변경 시 하위 호환성 깨질 수 있음
- MDD 계산 추가 시 백테스트 속도 5-10% 저하

**(c) 최소 실험**

| # | 실험 정의 | 게이트 | 기대 관측치 |
|---|-----------|--------|-------------|
| 1-1 | `rebalance.jsonl` 포맷 검증 및 CSV fallback 추가 | 파일 로드 성공 | pinpoint 리포트 정상 출력 |
| 1-2 | MDD 계산 로직 `backtest_engine.py`에 추가 | worst_mdd ≠ None | MDD 값 10개 fold 전부 출력 |
| 1-3 | Handoff vs Diagnoser OOS Mean 불일치 원인 추적 | 차이 < 0.1 | 동일 기준 측정 확인 |

**(d) PASS 조건**
```
✅ rebalance_pinpoint.md 정상 생성
✅ worst_mdd 숫자값 출력 (예: -0.15)
✅ OOS Mean 단일 기준 확정
```

### P2. Degenerate Fold 원인 분해 & 레짐 태깅
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한가**
- Fold 1,2,3,8이 degenerate → 특정 시장 레짐에서 전략 무력화
- 레짐 식별 없이 파라미터 튜닝하면 서바이버십 바이어스

**(b) 위험/부작용**
- 레짐 정의 자체가 과적합 소지 (레짐 snooping)
- 복잡도 증가 → 유지보수 부담

**(c) 최소 실험**

| # | 실험 정의 | 게이트 | 기대 관측치 |
|---|-----------|--------|-------------|
| 2-1 | Degenerate fold 기간 추출 → VIX/SPY 수익률 오버레이 | 시각화 완료 | 공통 패턴 식별 (예: VIX>25) |
| 2-2 | 레짐 태그 (bull/bear/chop) 추가 후 fold별 분류 | 태그 적용 | 레짐별 OOS Mean 분리 리포트 |
| 2-3 | Degenerate fold에서 exposure=0 비율 측정 | 측정 완료 | 노출 부족 vs 손실 구분 |

**(d) PASS 조건**
```
✅ Degenerate 4개 fold 중 3개 이상 동일 레짐
✅ 레짐별 OOS Mean 차이 > 1.0 확인
✅ 원인 1개 이상 확정 (노출↓ or 손실↑)
```

### P3. 비용 모델 현실화 (슬리피지 + 세금)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한가**
- 현재 비용 미반영 또는 과소 추정 가능성
- 리밸런스 빈도 높으면 실제 수익 50%+ 감소 가능

**(b) 위험/부작용**
- 비용 과다 추정 시 false negative (좋은 전략 버림)
- 종목별 스프레드 차이 미반영 시 편향

**(c) 최소 실험**

| # | 실험 정의 | 게이트 | 기대 관측치 |
|---|-----------|--------|-------------|
| 3-1 | 현재 비용 설정값 로깅 (슬리피지 bps, 수수료) | 로그 출력 | 설정값 확인 |
| 3-2 | 슬리피지 10bps / 20bps / 30bps 시나리오 비교 | 3개 결과 | OOS Mean 민감도 (예: -0.5/10bps) |
| 3-3 | 리밸런스 횟수 집계 → 연간 회전율 계산 | 계산 완료 | 회전율 300%↑이면 경고 |

**(d) PASS 조건**
```
✅ 비용 설정 명시적 문서화
✅ 20bps 기준 OOS Mean > 2.0 유지
✅ 연간 회전율 < 400%
```

- 로깅 과다 시 백테스트 속도 저하

## 2. 48h 자동 루프 체크리스트

```

□ P2-1 degenerate fold 기간 시각화
□ P2-3 exposure=0 비율 측정
□ P3-1 비용 설정 로깅
□ P4-3 현금 비중 일수 계산

[Phase 3: 24-36h] 실험 실행
□ P3-2 슬리피지 시나리오 3개
□ P5-1 -10% stop
□ P5-2 VIX hedge

[Phase 4: 36-48h] 종합 판정
□ 실험 결과 비교 테이블 생성
□ 신규 Champion 후보 선정 (또는 기존 유지)
```

## 3. 성능 안 움직일 때 원인 분해 트리

```
OOS Mean 변화 없음
│
├─ [1] 트리거 문제
│   └─ 신호 자체가 발생 안함 → 팩터/지표 점검
│
├─ [2] 적용 문제  
│   └─ 신호 있으나 거래 안됨 → 필터/유니버스 제한 점검
│
├─ [3] 노출 문제
│   └─ 거래했으나 사이즈 작음 → 사이징 로직/현금 비중 점검
│
├─ [4] 비용 문제
│   └─ 수익 있으나 비용에 잠식 → 회전율/슬리피지 점검
│
└─ [5] 레짐 문제
    └─ 특정 기간만 작동 → fold별 분해, 레짐 태깅
```

**진단 순서**: 5→1→3→2→4 (레짐 먼저, 비용 마지막)
