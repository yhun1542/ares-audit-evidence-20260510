## Priority 1: MDD 압축 (현재 worst -11.2%)

### (a) 왜 필요한가
- 현재 worst_mdd = -11.18% → 실전 운용 시 심리적/제도적 한계
- lockbox와 tuning MDD 동일 → 특정 레짐에서 일관된 손실 패턴 존재

### (b) 위험/부작용
- 방어 강화 시 상승장 수익률 희석
- 추가 필터 = 거래 빈도 감소 → 표본 부족

### (c) 최소 실험

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|---|---|---|---|
| MDD-1 | `vol_regime` 모듈: 20D realized vol > 25% 시 position size × 0.5 | worst_mdd > -9% AND tuning_mean > 1.65 | MDD 2%p 개선, CAGR -0.05 이내 |
| MDD-2 | `trailing_stop` 추가: 고점 대비 -5% 시 강제 청산 | worst_mdd > -8% | 회전율 +20% 이내 |
| MDD-3 | `sector_cap` 강화: Tech 단일 섹터 60% → 45% 상한 | sector_concentration 감소 | 분산효과로 MDD -1~2%p |

### (d) PASS 조건
```
worst_mdd > -0.09 AND lockbox_mean >= 1.75
```

## Priority 2: Lockbox Robustness 강화

### (a) 왜 필요한가
- lockbox_min = 1.35 → fold 간 편차 존재
- fold14 외 다른 fold에서도 일관성 필요

### (b) 위험/부작용
- 일관성 추구 시 alpha 약화 가능
- 레짐별 특화 전략 포기

### (c) 최소 실험

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|---|---|---|---|
| ROB-1 | `min_fold_return` 제약: 최저 fold > 1.40 되도록 앙상블 가중치 재조정 | lockbox_min > 1.40 | min/mean 비율 0.80 이상 |
| ROB-2 | `regime_blend`: 모멘텀/퀄리티 50:50 고정 → 30:70 퀄리티 비중 확대 | lockbox 변동계수 < 0.15 | 안정성 증가 |

### (d) PASS 조건
```
lockbox_min >= 1.40 AND lockbox_mean >= 1.78
```

- 거래 빈도 높은 전략 폐기 가능

### (c) 최소 실험

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|---|---|---|---|
| COST-1 | 시가총액별 슬리피지: >100B=5bp, 10-100B=15bp, <10B=30bp | tuning_mean > 1.60 | 비용 반영 후에도 수익 유지 |
| COST-2 | `turnover_penalty`: 연간 회전율 × 0.002 차감 | 회전율 300% 이하 유도 | 순수익 현실화 |

### (d) PASS 조건

## Priority 5: 시그널 지연/신선도 점검

### (a) 왜 필요한가
- 모멘텀 시그널 decay: 12개월 모멘텀이 최근 레짐에서 약화 가능
- 지표 vintage가 성과에 미치는 영향 미측정

### (b) 위험/부작용
- 짧은 lookback = 노이즈 증가
- 과적합 유발

### (c) 최소 실험

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|---|---|---|---|
| SIG-1 | 모멘텀 lookback 12M → 6M으로 단축 | tuning 개선 여부 | 반응속도 증가 |
| SIG-2 | `signal_freshness`: 마지막 리밸런싱 후 5일 이상 시 시그널 강도 × 0.9 | 과잉보유 방지 | 회전율 +10% |

### (d) PASS 조건
```
tuning_mean >= 1.76 OR 명확한 레짐 구분 효과 확인
```
