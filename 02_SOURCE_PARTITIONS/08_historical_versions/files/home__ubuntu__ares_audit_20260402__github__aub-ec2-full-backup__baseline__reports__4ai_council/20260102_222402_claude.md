## TOP 5 Priority Patches (48H Autopilot용)

### PATCH-1: Degenerate Fold 원인 분리
```
WHY: 4/10 fold 실패는 전략 문제가 아닌 데이터/파이프라인 버그 가능성 높음
```

| 실험 ID | 정의 | GATE | 기대 관측치 |
|---------|------|------|-------------|
| `P1-A` | Fold 1,2,3,8 단독 IS 리턴 분포 출력 | IS_mean 존재 | μ, σ, sample_n |
| `P1-B` | 해당 Fold 기간 SPY drawdown 매핑 | 상관계수 산출 | corr(fold_fail, spy_dd) |
| `P1-C` | Universe coverage 체크 (종목수/일) | min_stocks ≥ 5 | gap_days 리스트 |

**PASS 조건**: Degenerate 원인이 (a) 레짐 vs (b) 데이터갭 vs (c) 코드버그 중 1개로 분류됨

**위험/부작용**: 없음 (진단 전용, 파라미터 변경 없음)

### PATCH-2: OOS Mean 버전 정합성 복구
```
WHY: 3.32 vs 2.63 차이 → 같은 champion 다른 숫자 = 신뢰 0
```

| 실험 ID | 정의 | GATE | 기대 관측치 |
|---------|------|------|-------------|
| `P2-A` | champion_v5_latest.json 재로드 후 OOS 재계산 | 스크립트 성공 | oos_mean 단일값 |
| `P2-B` | Handoff vs Diagnoser 입력파일 diff | 파일경로 출력 | 동일 여부 bool |

**PASS 조건**: 두 시스템 OOS mean 차이 < 0.01 또는 원인 명시

**위험/부작용**: 없음 (읽기 전용)

### PATCH-3: Rebalance 파이프라인 복구
```
WHY: 리밸런스 로그 없으면 turnover/cost/slippage 추정 불가 → 과최적화 점검 불가
```

| 실험 ID | 정의 | GATE | 기대 관측치 |
|---------|------|------|-------------|
| `P3-A` | rebalance.csv 생성 코드 경로 추적 | 파일 존재 | path, row_count |
| `P3-B` | JSON→JSONL 변환기 수동 실행 | 파싱 성공 | 최근 리밸런스 3건 출력 |
| `P3-C` | fallback: 포지션 delta로 turnover 역산 | turnover > 0 | daily_turnover % |

**PASS 조건**: Turnover 수치 1개 이상 추출 성공

**위험/부작용**: 역산 시 정확도 ±5% 오차 허용 필요
