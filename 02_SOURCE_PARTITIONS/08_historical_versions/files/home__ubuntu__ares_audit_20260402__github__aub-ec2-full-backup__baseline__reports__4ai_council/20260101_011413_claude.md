## 3. 성능 정체 원인 분해 (Diagnostic Tree)

```
lockbox 정체 원인 분해
│
├─[1] 트리거 문제 (Signal)
│   ├─ 신호 자체가 edge 없음 → IC<0.02 확인
│   └─ 신호 decay 빠름 → IC by holding period 분석
│
├─[2] 적용 문제 (Execution)
│   ├─ sizing이 신호 강도 미반영 → conviction vs return 상관
│   └─ 진입 지연 (다음날 시가) → overnight gap 손실
│
├─[3] 노출 문제 (Exposure)
│   ├─ 평균 투자비중 너무 낮음 → avg_exposure 확인
│   └─ 현금 비중 과다 (regime filter 과민)
│
├─[4] 비용 문제 (Cost)
│   ├─ turnover 대비 edge 부족 → edge/turnover ratio
│   └─ 소형주 slippage 과소 추정
│
└─[5] 레짐 문제 (Regime)
    ├─ 특정 fold(기간)에서만 작동 → fold별 Sharpe 분포
    └─ 2022-type drawdown 반복 시 구조적 약점
```
