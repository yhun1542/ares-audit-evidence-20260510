| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | Fold 1,2,3,8 퇴화 = 특정 시장 레짐(2020 COVID, 2022 금리)에서 전략 붕괴 의심 |
| **(b) 위험** | 레짐 과적합 확정 시 전략 재설계 필요 |
| **(c) 실험** | 아래 참조 |
| **(d) PASS** | 퇴화 fold ≤ 1개, 해당 fold OOS ≥ 0.5 |

```
┌─────────────────────────────────────────────────────────────┐
│ EXP-1A: fold별 시작/종료일, 레짐 태그 매핑                    │
│   → python3 tools/fold_regime_mapper.py --champion latest   │
│   GATE: 퇴화 fold가 특정 레짐(VIX>30, 금리역전)에 집중?       │
│   EXPECT: fold 1,2,3 = COVID / fold 8 = 2022Q4              │
├─────────────────────────────────────────────────────────────┤
│ EXP-1B: 퇴화 fold만 signal OFF 시 baseline 대비 변화         │
│   → --exclude-folds 1,2,3,8 --measure oos_mean              │
│   GATE: 나머지 fold OOS mean 유지 ≥ 2.5                      │
│   EXPECT: 6-fold OOS ~ 3.8 이면 레짐 문제 확정               │
├─────────────────────────────────────────────────────────────┤
│ EXP-1C: 퇴화 fold에 hedge multiplier 1.5x 적용              │
│   → --hedge-mult 1.5 --target-folds 1,2,3,8                 │
│   GATE: 해당 fold OOS ≥ 0.3                                 │
│   EXPECT: MDD 개선 10%+, OOS 소폭 하락 허용                  │
└─────────────────────────────────────────────────────────────┘
```
