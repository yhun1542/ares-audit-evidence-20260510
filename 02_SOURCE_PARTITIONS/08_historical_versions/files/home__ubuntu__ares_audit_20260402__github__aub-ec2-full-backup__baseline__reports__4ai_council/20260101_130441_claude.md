### P1. MDD Guard 강화 (worst_mdd -9% → -7% 목표)

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | worst_mdd -9%는 실전에서 -15% 이상 가능. lockbox fold14는 -5%인데 worst는 -9% → 특정 레짐 취약 |
| **(b) 위험** | 과도한 손절 → 회복 기회 상실, 거래비용 증가 |
| **(c) 실험** | |

```yaml
exp_p1_mdd:
  - id: mdd_trailing_5pct
    변경: "종목별 trailing stop -5% → 포트폴리오 레벨 -3% 추가"
    게이트: worst_mdd > -0.07 AND lockbox_mean 하락 < 3%
    
  - id: mdd_vol_regime
    변경: "VIX > 25 시 현금비중 +20%"
    게이트: worst_mdd 개선 AND 튜닝 수익률 유지
    
  - id: mdd_sector_cap
    변경: "단일 섹터(Tech) 최대 50% → 40%"
    게이트: worst_mdd > -0.075
```

| **(d) PASS** | `worst_mdd > -0.07` AND `lockbox_mean > 1.30` |

## 3. 성능 미개선 시 원인 분해 트리

```
성능 안 움직임
│
├─[1] 트리거 문제: 신호가 안 바뀜
│   └─ 확인: signal_changes_per_day < 0.1? → 임계값 조정

├─[2] 적용 문제: 신호 → 포지션 전환 실패

├─[3] 노출 문제: 포지션은 있으나 시장 움직임 없음
│   └─ 확인: 보유종목 vol vs 벤치마크 vol → 저변동 종목 과다?
│
├─[4] 비용 문제: 수익 < 거래비용
│   └─ 확인: gross_return vs net_return 차이 > 50%? → 회전율 감소
│
└─[5] 레짐 문제: 현재 시장이 전략과 안 맞음
    └─ 확인: 최근 30일 레짐 분류 → 히스토리 최악 레짐과 일치?
```
