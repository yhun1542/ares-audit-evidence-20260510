## 3. 성능 미개선 시 원인 분해 체크리스트

```
┌─────────────────────────────────────────────────────────────┐
│  성능이 안 움직일 때 5단계 진단 트리                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  [1] TRIGGER: 신호가 발생하는가?                             │
│      □ signal_count / day 확인                              │
│      □ 신호 임계값이 너무 보수적? → threshold 완화 실험       │
│      □ 데이터 누락/지연? → data freshness 점검               │
│                                                             │
│  [2] APPLICATION: 신호가 포지션으로 전환되는가?               │
│      □ entry_rate = 실제진입 / 신호발생 비율                 │
│      □ 필터(레짐/섹터/유동성)가 과도? → 필터 완화 실험        │
│      □ 자금 부족으로 진입 불가? → capital utilization 점검   │
│                                                             │
│  [3] EXPOSURE: 포지션 크기가 충분한가?                       │
│      □ avg_position_size / max_allowed 비율                 │
│      □ 변동성 조정이 과도? → vol_target 상향 실험            │
│      □ concentration limit이 alpha 희석? → cap 완화 실험    │
│                                                             │
│  [4] COST: 비용이 수익을 잠식하는가?                         │
│      □ gross_return vs net_return 비교                      │
│      □ turnover × cost_per_trade 계산                       │
│      □ holding period 연장으로 turnover 감소 실험            │
│                                                             │
│  [5] REGIME: 현재 시장이 전략 비우호적인가?                   │
│      □ regime_label별 성과 분해                             │
│      □ 최근 N일 성과 vs 전체 기간 성과 비교                  │
│      □ 비우호적 레짐 → exposure 축소 로직 작동 확인          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**진단 우선순위:**
1. **COST 먼저** → 가장 빠른 확인, 비용 미반영 시 전체 판단 오류
2. **TRIGGER 다음** → 신호 자체가 없으면 이후 단계 무의미
3. **REGIME 마지막** → 가장 해석 어려움, 다른 요인 배제 후 검토
