### [성능 정체 시 원인 분해 (Decomposition)]

성능 지표가 움직이지 않을 경우 아래 5가지 요인 순서로 디버깅할 것.

1.  **트리거 (Trigger)**: 시그널이 너무 드물게 발생하는가? (Tech/Healthcare 특성상 모멘텀이 강할 때만 진입하는지 확인). -> *Action: 진입 Threshold 완화.*
2.  **노출 (Exposure)**: 시그널은 발생했으나, 포트폴리오 내 비중(Weight)이 너무 작아 P&L에 영향이 없는가? -> *Action: 개별 종목 최소 비중(Min Weight) 5% 이상 설정.*
3.  **적용 (Application)**: 주문 집행 로직에서 유동성 부족이나 상한가/하한가 제한으로 체결이 거부되고 있는가? (시뮬레이터 로그 확인).
4.  **비용 (Cost)**: 수익이 나지만 수수료/슬리피지가 이를 상쇄하여 0으로 수렴하는가? -> *Action: 승률(Win Rate)보다 손익비(P/L Ratio) 중심으로 로직 변경.*
5.  **레짐 (Regime)**: 현재 Tuning/Lockbox 기간이 전략이 작동하지 않는 '비추세 횡보장'인가? -> *Action: Mean Reversion 로직 비중 확대.*
