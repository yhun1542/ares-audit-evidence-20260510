## 1. 우선순위 TOP 5 실행 패치

### PATCH-1: Degenerate Fold 원인 분해 및 수정
```
우선순위: ★★★★★ (가장 긴급)
```

**(a) 왜 필요한지**
- 4/10 폴드가 degenerate = 해당 기간에 시그널이 죽거나 포지션 0
- 이 상태로 OOS Mean 신뢰 불가 (생존 폴드만으로 평균 부풀림)

**(b) 위험/부작용**
- 수정 시 OOS Mean 급락 가능 (진짜 성능 노출)
- 과최적화 파라미터 드러남

**(c) 최소 실험**

| ID | 실험 | 게이트 |
|----|------|--------|
| D1-A | 각 degenerate fold의 exposure 로그 덤프 | exposure==0 구간 식별 |
| D1-B | 시그널 threshold 0.5→0.3 완화 후 재실행 | degenerate fold ≤1개 |
| D1-C | 폴드별 거래횟수 히스토그램 | 최소 거래 ≥20회/폴드 |

**(d) PASS 조건**
```
✅ degenerate_folds ≤ 1
✅ 모든 폴드 exposure_mean > 0.1
✅ OOS 재계산 후 mean > 1.5 유지
```

## 3. 성능 미변동 시 원인 분해 트리

```
OOS 성능 정체
│
├─[1] 트리거 문제 (시그널 자체)
│   ├─ 시그널 생성 빈도 → 일평균 몇 개?
│   ├─ 시그널 강도 분포 → threshold 근처 몰림?
│   └─ 점검: signal_histogram.py --check-bimodal
│
├─[2] 적용 문제 (시그널→포지션)
│   ├─ 시그널 있어도 포지션 안 잡힘? → exposure 로그
│   ├─ 리밸런싱 지연? → rebalance timestamp 확인
│   └─ 점검: position_lag_analyzer.py
│
├─[3] 노출 문제 (포지션 크기)
│   ├─ 너무 작은 포지션 → 수익 희석
│   ├─ 너무 큰 포지션 → 변동성에 먹힘
│   └─ 점검: exposure_vs_return_scatter.py
│
├─[4] 비용 문제 (숨겨진 손실)
│   ├─ 슬리피지 미반영
│   ├─ 고빈도 회전 → 비용 누적
│   └─ 점검: turnover_cost_simulator.py --cost-range 5,10,15bp
│
└─[5] 레짐 문제 (시장 구조 변화)
    ├─ 특정 연도에만 작동? → 폴드별 OOS 분산
    ├─ 변동성 레짐별 성과 차이? → VIX 구간 분할
    └─ 점검: regime_breakdown.py --by-vix-quartile
```

import json
with open('baseline/champion_v5_latest.json') as f:
    d = json.load(f)
eq = d.get('equity_curve', [])
if eq:
    peak = eq[0]
    mdd = 0
    for v in eq:
        peak = max(peak, v)
        mdd = min(mdd, (v - peak) / peak)
    print(f'Worst MDD: {mdd:.2%}')
else:
    print('No equity curve found')
"
