## 2. 성능 불변 시 원인 분해 트리

```
lockbox 동일 (Δ=0)
│
├─[1] 트리거 미발동
│   └─ 신호 생성 로직이 동일 input → 동일 output
│      → 점검: config diff가 signal 모듈에 도달했는가?
│
├─[2] 적용 차단
│   └─ position sizing 또는 filter에서 truncate
│      → 점검: raw signal ≠ 0 but weight = 0?
│
├─[3] 노출 희석
│   └─ 변경된 신호가 전체 포트의 < 5% 비중
│      → 점검: 변경 모듈의 영향 종목 비중 합계
│
├─[4] 비용 상쇄
│   └─ alpha 발생했으나 turnover 비용으로 소멸
│      → 점검: gross return vs net return diff
│
└─[5] 레짐 불일치
    └─ 변경 효과가 특정 레짐에서만 발현, lockbox 기간 미포함
       → 점검: 모듈 효과의 regime-conditional 분해
```
