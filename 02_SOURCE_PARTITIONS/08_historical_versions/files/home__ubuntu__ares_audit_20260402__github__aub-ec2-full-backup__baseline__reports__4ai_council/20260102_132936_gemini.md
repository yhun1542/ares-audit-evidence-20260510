### [실행 가능한 Patch/실험 제안 (3건)]

#### 1. 실험: **"Cost Stress Test" (비용 민감도 강화)**
*   **(a) 필요성:** Champion의 MDD(-9.3%)가 비현실적으로 낮음. 실제 슬리피지와 수수료 반영 시 수익 우상향이 유지되는지 확인 필수.
*   **(b) 위험:** 거래 빈도가 높은 전략일 경우 수익 곡선이 급격히 훼손될 수 있음(Sharpe 급락).
*   **(c) 실험 정의:**
    *   `config.sim.cost_bps`를 기존 10bps에서 25bps로 상향.
    *   `config.sim.slippage`를 'Fixed'에서 'Vol-adjusted' 모델로 변경.
*   **(d) PASS 조건 (Gate):**
    *   `lockbox_mean` > 1.5 (기존 1.79 대비 방어)
    *   `worst_mdd` > -15% (기존 -9% 대비 허용치 확장)
*   **(e) 기대 관측치:** 거래 횟수가 감소하고, 평균 보유 기간이 늘어나는지 확인.

#### 2. 실험: **"Sector Balance Clamp" (섹터 균형 강제)**
*   **(a) 필요성:** Tech와 Healthcare는 상관관계가 낮을 수 있으나, 특정 시기(금리 인상기 등)에 동반 하락함. 8~14개 종목이 한쪽으로 쏠리면 위험.
*   **(b) 위험:** 강세장(Tech Bull)에서 수익률(Alpha) 제한 가능성.
*   **(c) 실험 정의:**
    *   포트폴리오 최적화 제약조건(Constraints) 추가: `sum(weight_tech) <= 0.65`, `sum(weight_health) >= 0.25`.
    *   유니버스 선정 시 Tech 7개 / Health 7개 강제 할당 후 모멘텀 스코어링.
*   **(d) PASS 조건 (Gate):**
    *   `tuning_min` > 0.3 (Candidate의 0.05 붕괴 방지)
    *   `fold14_mdd` 개선 (또는 현행 유지)
*   **(e) 기대 관측치:** 특정 섹터 급락 구간에서 MDD 방어력 상승.

#### 3. 실험: **"Shadow Feature Lagging" (거시 지표 시차 적용)**
*   **(a) 필요성:** Candidate가 사용한 `macro_alpha_shadow`가 Tuning Min 0.05를 기록한 주범일 가능성(Look-ahead). 과적합 해소 필요.
*   **(b) 위험:** 예측력(Signal Strength) 약화로 인한 진입 시점 지연.
*   **(c) 실험 정의:**
    *   모든 Macro ETF 지표(관측용)의 Feature 생성 시 `shift(1)` 추가 (T-1일 종가 기준 확정).
    *   Shadow Feature의 가중치를 0.5로 축소하고 개별 종목 Volatility Factor 가중치 상향.
*   **(d) PASS 조건 (Gate):**
    *   `tuning_mean`과 `lockbox_mean`의 괴리율(Gap) < 10%.
    *   `tuning_min` > 0.4 (Champion 수준 회복).
*   **(e) 기대 관측치:** Lockbox 수익률은 소폭 하락하더라도, 전 구간(Fold)에서 성과 편차 감소.

### [성능 정체 시 원인 분해 아이디어]

만약 위 실험 후에도 성능 지표가 움직이지 않거나(Stagnant), Tuning Min이 개선되지 않는다면 아래 순서로 디버깅 수행.

1.  **트리거(Trigger) 부재:**
    *   *현상:* 매매 횟수(Trade Count)가 극단적으로 적음.
    *   *확인:* 진입 Threshold가 너무 높거나, Tech/Health 두 섹터가 동시에 '매수 금지' 필터(예: MA200 하회)에 걸려 있는지 확인.

2.  **적용(Allocation) 실패:**
    *   *현상:* 시그널은 발생했으나 포지션 사이즈가 0에 수렴.
    *   *확인:* 변동성 타겟팅(Vol Target) 로직이 최근 고변동성 장세를 반영해 포지션을 강제로 축소시켰는지 점검.

3.  **비용(Cost) 잠식:**
    *   *현상:* Gross Return은 우상향이나 Net Return이 횡보.
    *   *확인:* 회전율(Turnover) 확인. 이익이 나지 않는 '노이즈성 매매' 반복 여부. (Buy -> Sell -> Buy를 3일 내 반복 등)

4.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 연도(Fold)에서만 `tuning_min`이 박살남.
    *   *확인:* 해당 시기(예: 2022년 금리 인상기)에 Long-Only 로직만 작동하고 있는지. Cash 비중을 100%까지 늘릴 수 있는 `Cash_Buffer` 로직이 작동하는지 확인.
