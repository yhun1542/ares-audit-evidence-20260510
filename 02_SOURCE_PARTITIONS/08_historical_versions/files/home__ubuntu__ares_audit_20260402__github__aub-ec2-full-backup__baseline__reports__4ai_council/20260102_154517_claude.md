### P1. 파이프라인 무결성 복구 (BLOCKING)

**(a) 왜 필요한지**
- `rebalance.csv` 로드 실패 → 거래 비용/슬리피지 검증 불가
- OOS Mean 불일치 (1.88 vs 2.63) → 어느 숫자가 진짜인지 모름
- `worst_mdd: None` → 리스크 게이트 작동 안 함

**(b) 위험/부작용**
- 수리 중 false positive 챔피언 승격 가능
- 시간 소모 (4~6h)

**(c) 최소 실험**

| # | 실험 정의 | 게이트 | 기대 관측치 |
|---|-----------|--------|-------------|
| 1-1 | `aub_rebalance_pinpoint.py` 입력 경로 수정 → `baseline/reports/*/rebalance.jsonl` 탐색 로직 추가 | 파일 로드 성공 | row_count ≥ 1 |
| 1-2 | `champion_v5_latest.json`에 `worst_mdd` 필드 강제 계산 로직 삽입 | MDD 값 출력 | -0.25 < MDD < 0 |
| 1-3 | OOS Mean 계산 경로 2개 (Handoff vs Diagnoser) 비교 스크립트 | 차이 < 0.05 | delta 로깅 |

**(d) PASS 조건**
```
✅ rebalance_pinpoint 정상 출력
✅ worst_mdd ∈ [-0.30, -0.05]
✅ OOS Mean 불일치 해소 or 원인 문서화
```

## 4. 즉시 실행 커맨드 (복사-붙여넣기용)

```bash
# P1-1: 리밸런스 파일 경로 탐색
find /home/ubuntu/AUB -name "rebalance.*" -type f 2>/dev/null | head -20

# P1-2: MDD 계산 강제 주입
python3 -c "
import json
import numpy as np

with open('baseline/champion_v5_latest.json') as f:
    data = json.load(f)

# equity curve에서 MDD 계산 (있다면)
if 'equity_curve' in data:
    eq = np.array(data['equity_curve'])
    peak = np.maximum.accumulate(eq)
    dd = (eq - peak) / peak
    data['worst_mdd'] = float(dd.min())
    print(f'Computed MDD: {data[\"worst_mdd\"]:.4f}')
else:
    print('No equity_curve found')
"

# P1-3: OOS Mean 불일치 확인
grep -r "oos_mean" /home/ubuntu/AUB/baseline/reports/ | sort -u

# P2-1: 비용 반영 백테스트 (예시)
python3 experiment_system/run_backtest.py \
  --config baseline/champion_v5_latest.json \
  --slippage-bp 10 \
  --commission-bp 5 \
  --output artifacts/cost_adjusted_$(date +%Y%m%d).json
```
