## 3. 성능 정체 시 원인 분해 트리

```
수익 안 움직임
│
├─ [트리거 실패] 신호 발생 안 함
│   ├─ 피처 분포 drift (→ 피처 통계 모니터링)
│   └─ threshold 과보수 (→ 트리거 빈도 로깅)
│
├─ [적용 실패] 신호 → 포지션 전환 안 됨
│   ├─ 유동성 필터 과잉 (→ 필터 통과율 체크)
│   └─ 리밸런싱 주기 미스매치 (→ 실행 타임스탬프 로깅)
│
├─ [노출 부족] 포지션 있으나 수익 연결 안 됨
│   ├─ 비중 너무 작음 (→ avg_weight 로깅)
│   └─ 홀딩 기간 너무 짧음 (→ 평균 보유일 체크)
│
├─ [비용 잠식] 수익 발생하나 비용에 상쇄
│   ├─ turnover 과다 (→ 일일 turnover 로깅)
│   └─ 스프레드 과소 추정 (→ 실제 체결가 대비)
│
└─ [레짐 불일치] 전략과 시장 국면 미스매치
    ├─ 모멘텀 전략 in 횡보장 (→ 레짐 태그 추가)
    └─ 금리 민감 전략 in 금리 전환기 (→ 매크로 오버레이)
```
