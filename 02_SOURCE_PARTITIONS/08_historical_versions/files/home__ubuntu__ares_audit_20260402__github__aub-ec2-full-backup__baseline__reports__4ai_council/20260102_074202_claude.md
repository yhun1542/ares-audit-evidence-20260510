## 실행 우선순위 TOP 5

### ① Candidate의 tuning_min 붕괴 원인 분해
**왜 필요**: tuning_min = -1.417은 최소 1개 fold에서 손실. PASS했지만 lockbox 전이 시 리스크 잠재.

**위험/부작용**: 해당 fold만 수정하면 overfitting 가능

**최소 실험**:
```
EXP-1a: Candidate 전 fold별 성과 분해 → 어느 fold가 -1.4 유발하는지 특정
EXP-1b: 해당 fold의 regime(VIX>25? 금리급등?) 식별 후 Champion 대비 포지션 diff
EXP-1c: 해당 fold 제외 시 tuning_mean 변화 측정 (단, 실거래 반영 X)
```

**게이트 조건**:
| 통과 조건 | 값 |
|-----------|-----|
| 붕괴 fold 특정 완료 | Y/N |
| regime 라벨링 일치 | ≥2명 수동 확인 |

**기대 관측치**: 1개 fold가 80%+ 손실 기여 시 regime-specific 버그

### ② Champion v5 MDD -9.3% 구간 분석
**왜 필요**: lockbox에서 -9.3% MDD 발생 시점 = 실거래 최대 위험 구간. 방어 로직 부재 여부 확인.

**위험/부작용**: MDD 방어 과도하면 수익률 희생

**최소 실험**:
```
EXP-2a: MDD -9.3% 발생 일자 + 해당일 보유종목/비중 추출
EXP-2b: 해당 기간 VIX/SPY 대비 상대 drawdown 계산 (시장 충격 vs 포트 고유)
EXP-2c: 동일 구간 현금비중 50% 강제 시뮬 → MDD 개선폭 vs 수익 손실 trade-off
```

**게이트 조건**:
| 통과 조건 | 값 |
|-----------|-----|
| 시장 MDD 대비 초과 DD | <1.5x |
| 현금 hedge 수익 손실 | <15% |

**기대 관측치**: 초과 DD > 2x면 종목 집중 리스크, ≤1x면 시장 연동 정상

### ③ 거래비용/슬리피지 현실화 점검
**왜 필요**: tuning 성과가 lockbox에서 하락 (1.90→1.79) = 비용 미반영 가능성

**위험/부작용**: 비용 과다 추정 시 전략 폐기 오류

**최소 실험**:
```
EXP-3a: 현재 시뮬 거래비용 파라미터 추출 (spread, commission, slippage bps)
EXP-3b: 동일 전략에 비용 +5bps / +10bps 적용 후 lockbox 재계산
EXP-3c: 연간 turnover 계산 → 비용 민감도 = turnover × Δbps
```

**게이트 조건**:
| 통과 조건 | 값 |
|-----------|-----|
| 비용 +10bps 시 lockbox_mean | >1.5 |
| turnover | <12x/년 |

**기대 관측치**: turnover>15x면 비용이 20%+ 수익 잠식

### ⑤ Survivorship Bias 점검
**왜 필요**: 상장폐지/인수 종목 누락 시 백테스트 과대평가

**위험/부작용**: 데이터 수정 시 전체 재계산 필요

**최소 실험**:
```
EXP-5a: 사용 유니버스에서 2020-2024 상폐/인수 종목 리스트 추출
EXP-5b: 해당 종목 중 전략이 보유했던 기간 식별
EXP-5c: 상폐 종목 마지막 60일 return = -80% 가정 시 성과 재계산
```

**게이트 조건**:
| 통과 조건 | 값 |
|-----------|-----|
| 상폐 종목 보유 건수 | <3건/년 |
| 조정 후 tuning_mean 하락 | <15% |

**기대 관측치**: 보유 상폐 종목 > 5건/년이면 bias 심각

## 3. 성능 미동작 시 원인 분해 트리

```
성능 안 움직임
├── 트리거 미발동
│   ├── 시그널 threshold 과도 → 트리거 횟수/월 로그
│   └── 데이터 지연/누락 → 마지막 fetch 시점 확인
│
├── 적용 실패
│   ├── 주문 로직 버그 → dry-run 주문 검증
│   └── position sizing 0 수렴 → 최소 size floor 확인
│
├── 노출 부족
│   ├── 현금 비중 과다 (>30%) → 일평균 투자비중 로그
│   └── 종목 수 과소 (<5) → 일평균 보유 종목 수
│
├── 비용 잠식
│   ├── 고빈도 리밸런싱 → turnover/월
│   └── spread 과소 추정 → 실제 체결가 vs 시뮬 비교
│
└── 레짐 불일치
    ├── 훈련 기간 bull-only → 훈련 구간 SPY CAGR
    └── 현재 regime ≠ 훈련 → VIX/금리 regime 라벨 비교
```
