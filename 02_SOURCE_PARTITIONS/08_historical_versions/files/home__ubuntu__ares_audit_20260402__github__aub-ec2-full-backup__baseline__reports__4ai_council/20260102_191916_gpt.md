## 48시간 자동 루프에 넣을 “실행 가능한 Patch/실험” 5개만 확정 (1)실험 정의 (2)게이트 (3)기대 관측치

### [X1] Rebalance 로그/스키마 & 재현성 해시 강제
1) **실험 정의**
   - 리밸런스 이벤트를 단일 포맷(jsonl)로 기록, base/cand 비교 도구가 항상 읽게 수정
   - `run_hash/lane_hash` 필수, 없으면 런 FAIL
2) **게이트**
   - `aub_rebalance_pinpoint.py`가 base/cand 모두 로딩 성공
   - 필수 필드 누락 시 즉시 FAIL
3) **기대 관측치**
   - “적용(신호)→주문(목표비중)→체결(실현비중)→비용→성과” 체인이 한 번에 추적됨
   - 성능 무변화 원인이 **로직인지/체결인지/비용인지** 즉시 분리

### [X2] CV/누수/서바이버십 감사 스위트 + degenerate fold 제거
1) **실험 정의**
   - walk-forward + purge/embargo 고정
   - feature/label timestamp 테스트, 동적 유니버스 미래참조 테스트
2) **게이트**
   - degenerate fold = 0
   - 누수/정합성 테스트 FAIL = 0
3) **기대 관측치**
   - OOS mean이 덜 “운빨”로 변하고, 폴드별 편차 감소
   - oos_min(최저 성과) 안정화

### [X3] 거래비용+지연체결+턴오버 제어(운영 적합성)
1) **실험 정의**
   - 비용 모델 + t+1 체결 + min-hold/turnover cap
2) **게이트**
   - 평균 turnover 상한 준수
   - 비용 리포트(총비용/슬리피지/차입)가 rebalance 로그로부터 재구성 가능
3) **기대 관측치**
   - 비용 차감 후에도 살아남는 알파만 남음
   - “성능이 안 움직임”이 비용 때문인지 즉시 드러남(총비용 기여율로)

### [X4] 8~14 Tech+Healthcare 전용 포트폴리오 규칙(안정성)
1) **실험 정의**
   - 보유 종목 수, 단일 종목 상한, 섹터 비중 범위, 노출 스무딩 고정
2) **게이트**
   - 포트폴리오 제약 위반=0
   - exposure 점프(예: 일간 변화) 임계치 초과 빈도 제한
3) **기대 관측치**
   - tail 리스크 감소, 리밸런스 빈도 감소
   - 동일 신호에서도 “구현 방식”이 성능을 얼마나 바꾸는지 분리 가능

### [X5] ETF 관측지표 기반 레짐 게이트(노출 상한만 조절)
1) **실험 정의**
   - QQQ/XLK/XLV/IBB(및 가능하면 VIX)로 risk-on/off 판별 → max exposure만 조절
2) **게이트**
   - 레짐 스위칭 빈도 상한(히스테리시스)
   - 레짐별 성과 리포트 자동 생성
3) **기대 관측치**
   - 특정 레짐에서만 망가지는 패턴(예: risk-off에서 급락)이 줄어듦
   - oos_min 개선이 우선 관측 목표

## 성능이 안 움직일 때 “원인 분해” 아이디어(트리거/적용/노출/비용/레짐) — 질문 없이 바로 실행

### A) 트리거(신호 생성) 레벨
- **체크**
  - 신호 분포가 0 근처로 붕괴했는지(스케일/정규화/결측 처리 변화)
  - 피처가 동일 값으로 고정(스케일러 fit 범위 오류, 윈도우 길이 오류)
- **산출물**
  - (날짜별) 신호 평균/표준편차/상위-하위 스프레드, 피처 NaN 비율
- **결론 패턴**
  - 신호 분산↓인데 성능도 무반응 → “신호가 죽음(트리거 문제)”

### B) 적용(포지션 변환) 레벨
- **체크**
  - 목표비중 생성 후 제약/클리핑으로 대부분이 잘려나갔는지
  - min-hold/turnover cap이 너무 강해 “거의 거래 안 함”
- **산출물**
  - raw_weight vs final_weight 차이, 제약 위반으로 잘린 비중 총합
- **결론 패턴**
  - raw는 큰데 final이 작음 → “구현(적용)에서 알파 소거”

### C) 노출(실제 익스포저) 레벨
- **체크**
  - gross/net exposure가 레짐과 무관하게 랜덤하게 튀는지(현재 min 0, max 0.84의 원인)
  - 종목 수 8~14 유지 여부, 단일 종목 쏠림
- **산출물**
  - exposure 시계열, 종목 수 시계열, 상위 1~3종목 집중도
- **결론 패턴**
  - 노출이 자주 0으로 떨어짐 → “게이트/데이터 결측/리밸런스 실패” 가능

### D) 비용(슬리피지/스프레드/턴오버/차입) 레벨
- **체크**
  - 비용 차감 전엔 좋아 보이는데 차감 후 평평해지는지
  - turnover가 특정 구간에서 폭증하는지(레짐 전환/신호 급변)
- **산출물**
  - 총비용 기여율(성과 대비 비용), turnover 히트맵(레짐별)
- **결론 패턴**
  - 비용 기여율이 과대 → “알파가 아니라 마찰비용 게임”

### E) 레짐(환경 적합) 레벨
- **체크**
  - QQQ/XLK/XLV/IBB(관측지표) 상태별 성과가 극단적으로 갈리는지
  - 성과가 특정 레짐에서만 발생(서바이버십/우연 가능)하는지
- **산출물**
  - 레짐별 OOS mean/min, MDD, turnover, 비용
- **결론 패턴**
  - risk-off에서만 큰 손실 → [X5] 노출 상한 게이트가 직접 처방
