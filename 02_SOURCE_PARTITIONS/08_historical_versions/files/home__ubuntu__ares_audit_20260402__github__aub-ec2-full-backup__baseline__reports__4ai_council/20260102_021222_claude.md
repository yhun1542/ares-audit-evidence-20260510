## 2. 성능 미개선 시 원인 분해 트리

```
[성능 불변] 
    │
    ├─(1) 트리거 미발동 ─→ 시그널 생성 빈도/강도 로그 확인
    │        └─ "signal_count < 10/월" → 민감도 상향
    │
    ├─(2) 적용 실패 ─→ 리밸런싱 실행 로그 확인
    │        └─ "rebal_skip_count" 높으면 유동성/제약 충돌
    │
    ├─(3) 노출 부족 ─→ 평균 net_exposure 확인
    │        └─ "avg_exposure < 0.5" → 현금 과다, 기회비용
    │
    ├─(4) 비용 상쇄 ─→ gross_return vs net_return 차이
    │        └─ "diff > 0.5%/월" → 회전율/슬리피지 과다
    │
    └─(5) 레짐 미스매치 ─→ 기간별 성과 분해
             └─ "2022-H1 손실 집중" → 금리 레짐 필터 부재
```
