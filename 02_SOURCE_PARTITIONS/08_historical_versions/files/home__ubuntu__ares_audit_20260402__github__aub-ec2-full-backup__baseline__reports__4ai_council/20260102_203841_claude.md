### **P1. Degenerate Fold 근본 원인 분석**

#### (a) 왜 필요한지
- 4/10 fold 퇴화 = **특정 시장 레짐에서 시그널 완전 무효**
- 서바이버십/과최적화 1차 의심 구간

#### (b) 위험/부작용
- 분석만 하고 수정 안 하면 시간 낭비
- Fold 제거 시 OOS 과대평가 위험

#### (c) 최소 실험

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 1-1 | `fold_regime_mapper.py` — 각 fold의 시장 레짐(VIX레벨, SPY드로다운) 태깅 | 완료 | fold 1,2,3,8 공통 특성 식별 |
| 1-2 | Degenerate fold에서 **어떤 종목이 트리거 0회**인지 집계 | 완료 | 특정 섹터/종목 편중 확인 |
| 1-3 | `min_signal_threshold` 0.5 → 0.3 낮춰 재실행 | OOS Mean ≥ 2.5 유지 | Degenerate fold ≤ 2개 |

#### (d) PASS 조건
```
✅ Degenerate Folds ≤ 2/10 AND OOS Mean ≥ 2.5
```

#### (b) 위험/부작용
- 계산 로직 버그 시 false confidence
- Daily vs Intraday MDD 정의 혼선

#### (c) 최소 실험

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 2-1 | `backtest_core.py`에서 `equity_curve` 출력 확인 | 빈 배열 아님 | 데이터 존재 확인 |
| 2-2 | `mdd_calculator.py` 독립 실행 with mock equity | 정확한 MDD 값 | 계산 로직 정상 |
| 2-3 | Champion JSON에 `"mdd"` 필드 강제 inject 후 재측정 | MDD 수치 출력 | 파이프라인 E2E 복구 |

#### (d) PASS 조건
```
✅ worst_mdd 수치 출력 (예: -15% ~ -25% 범위 예상)
```
