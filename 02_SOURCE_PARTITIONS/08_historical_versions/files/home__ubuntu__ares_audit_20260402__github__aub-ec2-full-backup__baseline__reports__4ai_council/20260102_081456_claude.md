## 1. 우선순위 TOP 5 제안

### #1. Fold-Variance Regularization (과최적화 누수 차단)

**(a) 왜 필요**
- tuning_min -1.42 = 단일 fold에서 catastrophic failure
- fold간 분산이 크면 실제 운영시 특정 레짐에서 붕괴

**(b) 위험/부작용**
- 평균 수익 하락 가능 (trade-off)
- 너무 강한 regularization → 신호 소멸

**(c) 최소 실험**

| ID | 실험 정의 | Gate |
|----|-----------|------|
| FVR-1 | `fold_std_penalty=0.3` 추가, ranking score = mean - 0.3*std | tuning_min > 0.0 |
| FVR-2 | worst-fold dropout: 최악 fold 제외 후 평균으로 선택 | lockbox_mean 유지 ±5% |
| FVR-3 | fold-wise Sharpe floor: 모든 fold Sharpe > 0.8 필터 | 통과 fold 수 ≥ 12/14 |

**(d) PASS 조건**
```
tuning_min > 0.0 AND tuning_std < 0.8 AND lockbox_mean > 1.5
```

---

### #2. 거래비용 Full-Stress 테스트 (비용 미반영 점검)

**(a) 왜 필요**
- 현재 cost model 확인 불가 → 실제 운영시 slippage/spread 누락 가능
- Tech 종목 유동성 좋지만 Healthcare 일부 mid-cap 스프레드 클 수 있음

**(b) 위험/부작용**
- 과도한 cost 가정 시 전략 무력화
- 종목별 차등 적용 복잡도 증가

**(c) 최소 실험**

| ID | 실험 정의 | Gate |
|----|-----------|------|
| COST-1 | slippage 10bp → 20bp 전체 적용 | lockbox_mean > 1.3 |
| COST-2 | Healthcare 섹터만 30bp 적용 | 섹터별 PnL 분해 |
| COST-3 | turnover penalty: 연 회전율 > 12x 시 추가 -5bp/trade | 연 회전율 리포트 |

**(d) PASS 조건**
```
cost_stress_lockbox_mean > 1.2 AND turnover < 15x/year
```

### #3. Regime Filter 추가 (레짐 리스크)

**(a) 왜 필요**
- fold14_mdd -9.3%가 특정 레짐(2022 Q2? 2023 금리 피크?)에 집중 가능
- 레짐 무관하게 동일 로직 → tail risk 노출

**(b) 위험/부작용**
- 필터 추가 = 노출 감소 = 수익 기회 손실
- 레짐 정의 과적합 위험

**(c) 최소 실험**

| ID | 실험 정의 | Gate |
|----|-----------|------|
| REG-1 | VIX > 30 시 position size 50% 축소 | MDD 개선 > 2%p |
| REG-2 | 200일 MA 하회 종목 진입 금지 | win-rate 변화 < -5%p |
| REG-3 | Fed 금리 인상기 플래그 → Healthcare only | 섹터 쏠림 모니터 |

**(d) PASS 조건**
```
worst_mdd > -7% AND lockbox_mean > 1.4
```

### #4. Position Sizing 재검토 (운영 리스크)

**(a) 왜 필요**
- 8~14 종목 균등배분 가정시 단일 종목 리스크 7~12%
- 종목별 변동성 무시 → vol 높은 종목이 MDD 지배

**(b) 위험/부작용**
- 복잡도 증가
- vol targeting 과적합

**(c) 최소 실험**

| ID | 실험 정의 | Gate |
|----|-----------|------|
| POS-1 | inverse-vol weighting (20일 기준) | 포트 vol < 15% |
| POS-2 | max single position 8% cap | 집중도 HHI 리포트 |
| POS-3 | equal risk contribution (ERC) | 종목별 risk 기여도 편차 < 2x |

**(d) PASS 조건**
```
portfolio_vol < 18% AND lockbox_mean > 1.5 AND max_position_loss < -15%
```

### #5. Signal Decay 분석 (트리거 유효성)

**(a) 왜 필요**
- 신호 발생 후 1일/5일/10일 후 성과 분해 필요
- 신호가 즉시 반영 안 되면 alpha decay 문제

**(b) 위험/부작용**
- 분석 전용 → 직접 성능 개선 아님
- 잘못된 해석시 holding period 과최적화

**(c) 최소 실험**

| ID | 실험 정의 | Gate |
|----|-----------|------|
| SIG-1 | entry 후 1/5/10일 forward return 분해 | day1 > day5 > day10 순이면 decay 확인 |
| SIG-2 | holding period 5일 → 3일 축소 테스트 | Sharpe 변화율 |
| SIG-3 | signal strength 상위 50%만 진입 | hit-rate > 55% |

**(d) PASS 조건**
```
day1_fwd_return > 0.3% AND signal_top50_sharpe > full_sharpe
```

## 3. 성능 불변시 원인 분해 트리

```
성능 안 움직임
│
├─ [트리거] 신호 자체가 발생 안 함
│   ├─ 필터 과다 → 진입 기회 0
│   └─ 데이터 피드 오류 → 최근 데이터 누락
│
├─ [적용] 신호 발생했으나 포지션 변화 없음  
│   ├─ 이미 보유 중 → 중복 신호
│   └─ 리밸런싱 주기 미도래
│
├─ [노출] 포지션 잡혔으나 PnL 0
│   ├─ position size 너무 작음
│   └─ 롱/숏 상쇄 (섹터 내)
│
├─ [비용] gross는 움직이나 net은 0
│   ├─ 회전율 과다 → 비용이 alpha 잠식
│   └─ 슬리피지 모델 과대
│
└─ [레짐] 전략 로직은 정상이나 시장이 비협조
    ├─ 횡보장 → 모멘텀 무력
    └─ correlation breakdown → 분산 효과 소멸
```
