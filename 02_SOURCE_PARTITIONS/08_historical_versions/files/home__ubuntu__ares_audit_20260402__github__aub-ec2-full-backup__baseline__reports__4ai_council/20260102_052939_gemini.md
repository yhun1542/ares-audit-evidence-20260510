### 1. 우선순위 TOP 5 제안 (48시간 내 실행)

#### P1. [서바이버십/유니버스] 동적 유니버스(Dynamic Universe) 포인트-인-타임 검증
*   **이유:** 'Tech+Healthcare 8~14개'가 고정된 리스트라면 2026년 기준의 승자 편향(Survivorship Bias)일 확률 높음. 과거 시점 기준 시총/거래량 상위 종목으로 매월 리밸런싱해야 함.
*   **위험:** 수익률 대폭 하락 가능성(죽은 종목 포함 시). 데이터 처리 연산량 증가.
*   **실험 정의:**
    1.  **EXP_UNIV_STATIC:** 현재 고정된 14개 종목 백테스트 (Baseline).
    2.  **EXP_UNIV_ROLLING:** 매월 초 XLK/XLV 구성 종목 중 시총 상위 7개씩(총 14개) 선정하여 교체.
    3.  **EXP_UNIV_LIQUID:** 매월 초 거래대금 상위 14개 선정 (섹터 50:50 강제).
*   **게이트(Gate):** Rolling 방식의 Sharpe가 Static 대비 80% 이상 유지될 것.
*   **기대 관측치:** 수익률은 하락하더라도, Lockbox에서의 신뢰도(Train/Test 격차 감소) 상승.

#### P2. [비용/슬리피지] 보수적 비용 구조 스트레스 테스트 (Cost Deflator)
*   **이유:** Champion의 Sharpe 1.90은 슬리피지가 0이거나 낮게 설정되었을 가능성. Tech/Bio의 변동성 고려 시 체결 오차(Slippage)가 치명적임.
*   **위험:** 전략 폐기 수준으로 성능 저하 가능성.
*   **실험 정의:**
    1.  **EXP_COST_BASE:** 현재 설정(예: 5bps) 유지.
    2.  **EXP_COST_HIGH:** 슬리피지/수수료를 15bps(0.15%)로 상향.
    3.  **EXP_TURNOVER_CAP:** 일일 회전율(Turnover)을 10% 이하로 강제 제한.
*   **게이트(Gate):** High Cost에서도 Sharpe > 1.2, MDD > -12% 유지.
*   **기대 관측치:** 고빈도 매매 신호가 자연스럽게 필터링되고, 추세 추종 성향이 강화됨.

#### P3. [리스크/MDD] Candidate의 변동성 타겟팅(Vol Targeting) 이식
*   **이유:** Candidate의 낮은 MDD(-4%)는 유효한 자산 배분 로직(FSA 등) 덕분일 것임. 이를 Champion의 신호 위에 덮어씌워야 함.
*   **위험:** 튜닝 시 Min Sharpe가 깨지는 현상(Candidate의 문제) 재발 가능성.
*   **실험 정의:**
    1.  **EXP_VOL_TARGET:** 포트폴리오 전체 변동성이 연 15%를 초과할 것으로 예상되면 현금 비중 확대.
    2.  **EXP_CORR_CUT:** Tech와 Healthcare의 상관계수가 0.8 이상으로 동조화될 때 포지션 50% 축소.
    3.  **EXP_FSA_OVERLAY:** Candidate의 FSA 모듈을 Champion의 최종 웨이트 산출 직전에 적용.
*   **게이트(Gate):** Champion 대비 MDD 30% 개선, 수익률 감소 10% 이내.
*   **기대 관측치:** 급락장에서 현금 보유량 증가로 MDD 방어 확인.

#### P4. [과최적화/Leakage] ETF 관측 지표의 Look-ahead 차단
*   **이유:** "ETF는 관측지표로만 사용" 시, 당일 종가(Close)를 당일 매매 시그널에 쓰면 미래 참조(Look-ahead) 발생. 반드시 `Shift(1)` 처리 확인 필요.
*   **위험:** 예측력 급감(Lag 발생).
*   **실험 정의:**
    1.  **EXP_LAG_0:** ETF 지표 당일 종가 사용 (현재 상태 추정).
    2.  **EXP_LAG_1:** ETF 지표 전일 종가 사용.
    3.  **EXP_LAG_OPEN:** ETF 지표 당일 시가(Open) 사용 (실시간 대응 가정).
*   **게이트(Gate):** LAG_1 적용 시에도 Sharpe > 1.5 유지. (무너지면 현재 Champion은 Leakage임).
*   **기대 관측치:** 성과가 소폭 하락하나 현실적인 우상향 곡선 유지.

#### P5. [운영 리스크] 섹터 쏠림 방지 (Hard Constraints)
*   **이유:** Tech 또는 Healthcare 중 하나가 잘 나갈 때 몰빵하면 'Candidate'처럼 튜닝 안정성이 깨짐(특정 구간 폭망).
*   **위험:** 강한 추세장에서 수익 기회 상실.
*   **실험 정의:**
    1.  **EXP_SECTOR_CAP:** 단일 섹터 비중 최대 60% 제한.
    2.  **EXP_SINGLE_CAP:** 단일 종목 비중 최대 20% 제한.
    3.  **EXP_MIN_HOLD:** 최소 보유 종목 수 4개 강제.
*   **게이트(Gate):** Worst MDD가 -10% 이내로 제어됨.
*   **기대 관측치:** Lockbox Min Sharpe 지표의 획기적 개선 (안정성 확보).

### 2. 성능 정체 시 원인 분해 아이디어

성능이 움직이지 않거나(개선 없음), Lockbox와 Tuning 괴리가 줄지 않을 때 다음 항목을 순차 점검하십시오.

1.  **트리거(Trigger) 불감증:**
    *   *현상:* 시장이 급변해도 매매 신호가 0 또는 Hold로 유지됨.
    *   *원인:* 임계값(Threshold)이 너무 높거나, 변동성 정규화(Z-score) 기간이 너무 길어 최근 변동을 반영 못 함.
    *   *조치:* Lookback 기간을 단축(예: 60일 -> 20일)하거나 임계값 하향 조정 실험.

2.  **적용(Execution) 실패 - 비용 장벽:**
    *   *현상:* 신호는 발생하나 실제 포지션 변경이 미미함.
    *   *원인:* 예상 수익(Alpha) < 거래 비용(Cost)으로 인해 최적화 엔진이 매매를 포기함.
    *   *조치:* 예측된 Alpha의 스케일(Magnitude)을 강제로 1.2~1.5배 증폭시켜 매매를 유발한 뒤, 실제 손익이 개선되는지 확인 (알파 시그널이 맞다면 비용을 넘어서야 함).

3.  **노출(Exposure) 왜곡 - 베타 지배:**
    *   *현상:* 전략 수익률이 벤치마크(QQQ/XLV)와 똑같이 움직임.
    *   *원인:* 알파 팩터의 영향력이 사라지고, 단순히 시장 베타만 추종 중.
    *   *조치:* 벤치마크와의 공분산을 벌칙(Penalty)으로 넣는 목적함수 추가.

4.  **레짐(Regime) 불일치:**
    *   *현상:* 특정 연도(예: 2022년 하락장)에만 성능이 박살 나고 나머지는 좋음.
    *   *원인:* Long-Only 편향이거나 금리 민감도(Tech/Bio 공통 약점)가 높음.
    *   *조치:* 금리(TNX) 또는 달러(UUP) ETF가 상승 추세일 때 전체 현금 비중을 높이는 'Regime Switch' 모듈 활성화.
