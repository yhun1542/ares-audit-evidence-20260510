[성능 정체 원인 분해 (Diagnostics)]

성능이 개선되지 않고 횡보할 경우, 다음 순서로 원인을 제거하라.

1.  **트리거(Trigger) 불감증:**
    *   진입 신호가 너무 엄격(Rare Event)하여, 시장 반등기에 현금만 보유하고 있지 않은가?
    *   *Check:* 최근 3개월 매매 횟수(Number of Trades)가 5회 미만인지 확인.

2.  **노출(Exposure) 왜곡:**
    *   상위 1-2개 종목(예: NVDA, LLY)이 전체 PnL의 80%를 설명하는가?
    *   *Check:* 종목별 기여도(Attribution) 분석. 특정 종목 제외 시 마이너스라면 '운'임.

3.  **레짐(Regime) 불일치:**
    *   현재 전략이 'Trend Following'인데 시장은 'Mean Reversion' 구간인가?
    *   *Check:* 횡보장(ADX < 20)에서의 성과와 추세장(ADX > 25) 성과 분리 측정.

4.  **비용(Cost) 과소평가:**
    *   리밸런싱이 너무 잦아(High Turnover), 기대 수익이 수수료로 녹고 있는가?
    *   *Check:* 총 이익 대비 비용 비율(Cost/Gross Profit)이 20%를 초과하는지 확인.
