│   ├─ 확인: avg_position_size / max_allowed
│   └─ 처방: 사이징 로직 점검, 리스크 예산 확대
│
├─[4] 비용 문제: 수익 but 비용에 잠식
│   ├─ 확인: gross_return vs net_return 갭
