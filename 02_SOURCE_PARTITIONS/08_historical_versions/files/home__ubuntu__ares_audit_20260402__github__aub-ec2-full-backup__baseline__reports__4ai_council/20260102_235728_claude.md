### P2. 🔴 Degenerate Fold 원인 분해

**(a) 왜 필요?**
- 4/10 fold 퇴화 = **IS/OOS 시계열 커버리지 40% 손실**
- 특정 레짐(예: 2022 금리인상기)에서 시그널 전멸 가능성

**(b) 위험/부작용**
- Fold 정의 변경 시 과거 실험과 비교 불가
- 레짐 필터 추가 시 샘플 부족으로 과적합

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P2-A | 퇴화 fold [1,2,3,8] 날짜 범위 추출 → 시장 레짐 매핑 | 출력 성공 | `fold_id: date_range, SPY_return, VIX_avg` |
| P2-B | 퇴화 fold에서 `exposure == 0` 비율 계산 | 비율 < 80% | `zero_exposure_ratio per fold` |
| P2-C | Signal generator의 해당 기간 raw score 분포 출력 | 분포 출력 성공 | `mean, std, %above_threshold` |

**(d) PASS 조건**
```
✅ 퇴화 원인 특정 (exposure=0 OR signal=0 OR threshold 과다) AND 수정 방향 도출
```
