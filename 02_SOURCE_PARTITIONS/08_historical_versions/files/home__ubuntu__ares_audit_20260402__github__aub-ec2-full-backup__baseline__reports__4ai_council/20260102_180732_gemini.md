### 3. 성능 정체 시 원인 분해 (Debugging Tree)

성능 지표가 움직이지 않거나 `Degenerate`가 해결되지 않을 경우 다음 순서로 점검:

1.  **Trigger (신호 발생)**:
    *   *Check*: Raw Signal 값이 `Threshold`에 도달하지 못하는가? (지표 정규화 로직 오류)
    *   *Action*: Threshold를 0으로 설정하여 무조건 매수 후 랜덤 워크 대비 우위 확인.

2.  **Application (주문 집행)**:
    *   *Check*: 신호는 떴는데 `Optimizer`가 해를 찾지 못해(Infeasible) 0을 반환하는가?
    *   *Action*: 최적화 Solver 제약조건(Turnover, Leverage)을 모두 끄고 Equal Weight로 백테스트.

3.  **Exposure (노출)**:
    *   *Check*: `exposure_max` 0.83에서 보듯, 현금 비중이 의도치 않게 높은가?
    *   *Action*: ETF(SPY/QQQ)를 대용치로 사용하여 현금 대신 보유하게 로직 변경(Benchmarking).

4.  **Cost (비용)**:
    *   *Check*: 잦은 리밸런싱으로 슬리피지가 수익을 갉아먹어 Optimizer가 거래를 포기하는가?
    *   *Action*: Transaction Cost 파라미터를 0으로 설정 후 `Degenerate` 해소 여부 확인.

5.  **Regime (시장 국면)**:
    *   *Check*: Fold 1,2,3,8 기간이 2022년 하락장이나 횡보장인가?
    *   *Action*: 해당 구간에서는 `Long-Only` 전략을 `Long-Short` 또는 `Cash 100%` 전략으로 스위칭 가능한지 확인.
