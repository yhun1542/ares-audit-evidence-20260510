## 1. 우선순위 TOP-5 패치 (48H 루프)

### PATCH-1: Degenerate Fold 원인 분해
```
WHY: 40% 폴드가 붕괴 → 전체 OOS 신뢰도 0
RISK: 원인 오진 시 잘못된 방향 튜닝
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| P1-A | 폴드별 `n_trades`, `avg_holding_days` 덤프 | 코드 1파일 | 폴드1,2,3,8 → 거래수 < 5 여부 |
| P1-B | 해당 폴드 기간 시장 레짐 태깅 (SPY drawdown >10%) | SPY 데이터 조인 | 붕괴폴드 ∩ 위기기간 확인 |
| P1-C | 폴드별 신호 firing rate 로깅 | signal 모듈 수정 | firing < 1% → 신호 자체 문제 |

**PASS 조건**: 4개 폴드 중 ≥3개 원인 분류 완료 (거래부족 / 레짐 / 신호사망)

---

### PATCH-2: MDD 측정 파이프라인 복구
```
WHY: worst_mdd=None → 전략 승인 불가
RISK: 잘못된 NAV 계산 시 MDD 과소평가
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| P2-A | `equity_curve` 배열 존재 확인 + peak-to-trough 계산 추가 | backtest 출력 점검 | worst_mdd 숫자 출력 |
| P2-B | 일별 NAV 로그 → rolling MDD 시각화 | matplotlib 1장 | 그래프에서 -20% 이상 구간 식별 |

**PASS 조건**: `worst_mdd` ≠ None AND 값 ∈ [-0.50, 0.00]

---

### PATCH-3: 거래비용/슬리피지 실측 반영
```
WHY: rebalance.csv 파싱 실패 → 비용 미반영 OOS 의심
RISK: 과대 수익 환상 → 실거래 손실
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| P3-A | rebalance 로그 포맷 표준화 (JSON→CSV 재생성) | 파일 I/O 수정 | 파싱 성공 |
| P3-B | 비용 시나리오 3종 주입 (5bp/10bp/20bp) | config 파라미터화 | OOS mean 변화 Δ 기록 |
| P3-C | 턴오버 측정: 월간 평균 거래금액 / AUM | 계산 추가 | turnover > 100%/월 → 비용 치명적 |

**PASS 조건**: 10bp 비용 반영 후 OOS mean ≥ 2.0 유지

---

### PATCH-4: Fold-Stratified 신호 품질 점검
```
WHY: 신호 자체가 노이즈면 파라미터 튜닝 무의미
RISK: 잘못된 신호 폐기 → 유효 알파 손실
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| P4-A | 신호 발생 → 5일 후 방향 hit-rate 측정 | label 조인 | hit-rate > 52% (거래비용 커버) |
| P4-B | 신호 강도 상위 20% vs 전체 hit-rate 비교 | quantile split | 상위군 hit-rate - 전체 ≥ 3%p |

**PASS 조건**: 상위 신호군 hit-rate ≥ 55%

---

### PATCH-5: 레짐 필터 추가 (보수적 진입)
```
WHY: 위기 폴드 붕괴 → 레짐 무시 진입 의심
RISK: 필터 과다 → 거래 기회 소멸
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| P5-A | VIX > 25 시 신규 진입 차단 | 조건 1줄 추가 | degenerate fold 수 감소 |
| P5-B | SPY 20MA 하회 시 exposure 50% 캡 | position sizing 수정 | worst_mdd 개선 |

**PASS 조건**: degenerate fold ≤ 2개 AND worst_mdd > -25%

## 3. 성능 미변동 시 원인 분해 트리

```
OOS 변화 없음
    │
    ├─► 트리거 문제: 신호가 안 바뀜
    │       └─ 확인: signal_diff_count == 0?
    │
    ├─► 적용 문제: 신호→포지션 전환 실패
    │       └─ 확인: position_change_count == 0?
    │
    ├─► 노출 문제: 포지션 있으나 exposure 미미
    │       └─ 확인: avg_exposure < 0.1?
    │
    ├─► 비용 상쇄: 수익 ≈ 거래비용
    │       └─ 확인: gross_return - cost ≈ 0?
    │
    └─► 레짐 상쇄: 롱/숏 손익 대칭 소멸
            └─ 확인: long_pnl + short_pnl ≈ 0?
```
