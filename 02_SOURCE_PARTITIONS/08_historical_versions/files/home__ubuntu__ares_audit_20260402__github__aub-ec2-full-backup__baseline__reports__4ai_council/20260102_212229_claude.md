### P1. Degenerate Fold 원인 분해

**(a) 왜 필요한지**  
4/10 폴드 실패 = 전략이 특정 시장 레짐에서 완전 무력화. OOS mean이 살아남은 6개 폴드에서만 계산됨 → **Survivorship Bias**.

**(b) 위험/부작용**  
- 폴드 제외 기준 완화 시 노이즈 유입  
- 과도한 필터링 시 샘플 부족

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|----------|--------|-------------|
| P1-A | Fold 1,2,3,8 기간 시장 레짐 태깅 (VIX>25, SPY drawdown>10%) | 레짐 태깅 완료 | 4개 폴드 중 3개 이상 고변동 레짐 |
| P1-B | Degenerate 기준을 `trades>=20`으로 완화 후 재측정 | OOS 재계산 | Degenerate 2개 이하로 감소 |
| P1-C | 폴드별 exposure 히스토그램 출력 | 시각화 완료 | 실패 폴드 exposure < 0.1 확인 |

**(d) PASS 조건**  
- Degenerate fold ≤ 2개  
- 또는 레짐 기반 정당화 문서화 완료

### P2. OOS 점프 검증 (누수 탐지)

**(a) 왜 필요한지**  
2.63 → 3.32 (+26%) 점프가 코드 변경 없이 발생 = **데이터 누수 or 계산 버그**

**(b) 위험/부작용**  
- False negative: 실제 개선을 누수로 오판  
- 시간 소모

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|----------|--------|-------------|
| P2-A | 동일 config로 3회 반복 실행 | std(OOS) < 0.05 | 3.32 ± 0.05 재현 |
| P2-B | Train/Test 날짜 경계 1일 shift | OOS 변화 < 5% | 안정적 = 정상 |
| P2-C | Look-ahead 체크: 시그널 생성 시점 vs 가격 사용 시점 | 시그널 T → 가격 T+1 이후만 | 위반 0건 |

**(d) PASS 조건**  
- 3회 재현 std < 0.1 AND look-ahead 위반 0건

### P3. Exposure 과소 문제

**(a) 왜 필요한지**  
`exposure_min: 0.0` = 전략이 0% 투자 구간 존재. 현금 보유 기간이 OOS에서 수익률 희석.

**(b) 위험/부작용**  
- Exposure 강제 상향 시 변동성 폭발  
- 비용 증가

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|----------|--------|-------------|
| P3-A | `min_exposure=0.3` 강제 적용 | MDD < 15% 유지 | OOS mean ≥ 3.0 유지 |
| P3-B | 0 exposure 구간 시장 상태 분석 | 레포트 생성 | 하락장 회피 vs 단순 시그널 부재 구분 |

**(d) PASS 조건**  
- 0 exposure 구간이 SPY drawdown > 5% 기간과 70% 이상 일치 → 정당화  
- 또는 min_exposure 적용 후 OOS 유지

### P4. 비용 미반영 점검

**(a) 왜 필요한지**  
Rebalance 로그 파싱 실패 = 거래 비용 계산 불가능. 실제 비용 반영 시 OOS 급락 가능.

**(b) 위험/부작용**  
- 과도한 비용 가정 시 과소평가

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|----------|--------|-------------|
| P4-A | Rebalance 파서 수정 후 turnover 계산 | 연간 turnover 출력 | < 400% 기대 |
| P4-B | 슬리피지 10bps + 수수료 5bps 적용 | OOS 재계산 | OOS ≥ 2.5 유지 |

**(d) PASS 조건**  
- 비용 적용 후 OOS ≥ 2.5

**(b) 위험/부작용**

- 복잡도 증가

**(c) 최소 실험**

|----|----------|--------|-------------|

**(d) PASS 조건**

## 📊 성능 미작동 원인 분해 트리

```
OOS 변화 없음
├── 트리거 실패
│   ├── 시그널 생성 안 됨 (threshold 과다)
│   └── 유니버스 필터링 과다 (종목 0개)
├── 적용 실패  
│   ├── Position sizing이 0으로 수렴
│   └── Rebalance 주기 미도래
├── 노출 실패
│   ├── Exposure cap에 의해 절삭
│   └── Hedge가 상쇄
├── 비용 상쇄
│   ├── Turnover 과다로 수익 = 비용
│   └── 슬리피지 미반영 시 과대평가
└── 레짐 불일치
    ├── Train 기간과 OOS 레짐 상이
    └── 특정 섹터 집중 → OOS에서 해당 섹터 부진
```
