## 2. 성능 미변동 시 원인 분해 트리

```
OOS 변화 없음
├─ (1) 트리거 미발화
│   └─ 점검: signal > threshold 일수 비율 → <5%면 임계값 과다
├─ (2) 적용 오류
│   └─ 점검: target_weight vs actual_weight 불일치 → 코드 버그
├─ (3) 노출 부족
│   └─ 점검: 평균 exposure < 30% → 자본 유휴
├─ (4) 비용 상쇄
│   └─ 점검: gross return - cost ≈ 0 → 턴오버 과다
└─ (5) 레짐 미스매치
    └─ 점검: 실험 기간 vs 챔피언 훈련 기간 시장 상태 비교
```
