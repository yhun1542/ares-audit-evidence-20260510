### P2. Degenerate Fold 원인 격리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한지**
- 4/10 fold 퇴화 = 특정 시장 레짐(예: 2022 bear)에서 시그널 무효화
- 과적합 or 레짐 의존성 판별 필요

**(b) 위험/부작용**
- fold별 분석에 시간 과투입 → 48H 내 완료 어려움
- 퇴화 fold 제거 시 survivorship bias 발생

**(c) 최소 실험**

| # | 실험 | 게이트 | 기대 관측치 |
|---|------|--------|-------------|
| 2-1 | fold별 시작/종료 날짜 & 레짐 태그(bull/bear/sideways) 매핑 | 매핑 완료 | fold_regime_map.json 생성 |
| 2-2 | 퇴화 fold [1,2,3,8] 공통점 추출 (VIX>25? 금리상승기?) | 패턴 1개 이상 발견 | correlation > 0.6 |
| 2-3 | 퇴화 fold 제외 OOS vs 포함 OOS 비교 | 차이 < 0.5 | bias 경고 플래그 |

**(d) PASS 조건**
```
✅ 퇴화 원인 1개 이상 명문화
✅ 제외 시 OOS 변동폭 리포트 생성
```

## 3. 성능 미이동 시 원인 분해 트리 (Root Cause Decomposition)

```
OOS 개선 없음
│
├─[1] 트리거 문제 (시그널 미발생)
│   ├─ 시그널 threshold 너무 보수적?
│   ├─ 데이터 피드 지연/누락?
│   └─ 점검: signal_fire_rate 계산
│
├─[2] 적용 문제 (시그널→포지션 변환 실패)
│   ├─ 리밸런스 로직 버그?
│   ├─ 최소거래단위 미충족?
│   └─ 점검: intended_position vs actual_position diff
│
├─[3] 노출 문제 (포지션 크기 부족)
│   ├─ exposure cap 너무 낮음?
│   ├─ 분산 제약 과도?
│   └─ 점검: avg_exposure vs max_allowed
│
├─[4] 비용 문제 (수익 < 비용)
│   ├─ 회전율 과다?
│   ├─ 슬리피지 과소추정?
│   └─ 점검: gross_return vs net_return gap
│
└─[5] 레짐 문제 (전략-시장 미스매치)
    ├─ 현재 레짐에서 전략 엣지 없음?
    ├─ 레짐 감지 지연?
    └─ 점검: OOS by regime bucket
```
