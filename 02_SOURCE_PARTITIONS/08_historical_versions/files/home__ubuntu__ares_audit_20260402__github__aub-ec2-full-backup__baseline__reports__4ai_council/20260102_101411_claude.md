**(a) 왜 필요**

- 잘못된 수정 시 전체 백테스트 무효화

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P1-a | `backtest_engine.py`의 `compute_mdd()` 함수에 NaN/빈 배열 핸들링 추가 | 단위테스트 통과 | MDD 값 float 반환 |
| P1-b | champion 재실행 후 `worst_mdd` 필드 확인 | `worst_mdd < -0.15` | MDD ∈ [-0.40, -0.05] |

