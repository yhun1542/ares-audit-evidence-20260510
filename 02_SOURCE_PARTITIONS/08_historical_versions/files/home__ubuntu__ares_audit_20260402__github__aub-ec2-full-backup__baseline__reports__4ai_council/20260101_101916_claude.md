## 1. 우선순위 TOP 5 패치

### PATCH-1: 트리거 민감도 조정 (Signal Threshold Sweep)

| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | Champion/Candidate의 lockbox 결과가 **동일** → 트리거가 발동 안 했거나 임계치가 동일했을 가능성 |
| **(b) 위험** | 임계치↓ → 과매매 → 비용 폭증 / 임계치↑ → 기회 놓침 |
| **(c) 실험** | ① `threshold *= 0.8` ② `threshold *= 1.2` ③ adaptive threshold (ATR-band) |
| **(d) PASS** | lockbox에서 **trade_count 변화 ≥ 20%** AND **cost_ratio < 0.35** |

```yaml
# experiment_system/config/module_registry.yaml 추가
- id: exp_threshold_sweep
  params: [0.8, 1.0, 1.2]
  gate: trade_count_delta >= 0.2 AND cost_ratio < 0.35
```

## 2. 48h 자동 루프 스펙

```yaml
# experiment_system/config/next_48h.yaml

loop:
  interval: 6h
  max_iterations: 8

experiments:
  - id: exp_threshold_sweep
    priority: 1
    gate: trade_count_delta >= 0.2 AND cost_ratio < 0.35
    expected:
      trade_count: [+20%, +50%]
      lockbox_mean: [1.75, 1.85]

  - id: exp_sizing_cap
    priority: 2
    gate: tuning_min >= 0.30 AND worst_mdd >= -0.12
    expected:
      tuning_min: [0.30, 0.50]

  - id: exp_regime_filter
    priority: 3
    gate: tuning_mean >= 1.70 AND fold14_mdd >= -0.11
    expected:
      tuning_mean: [1.70, 1.80]

  - id: cost_audit
    priority: 4
    gate: lockbox_mean_cost >= 1.50
    expected:
      lockbox_mean: [1.50, 1.70]

  - id: survivorship_check
    priority: 5
    gate: ratio >= 0.90
    expected:
      ratio: [0.90, 1.00]

halt_conditions:
  - worst_mdd < -0.15
  - lockbox_mean < 1.20
  - cost_ratio > 0.50
```

```bash

# ── STEP 2: 패치 실행 (자동) ──

  --config experiment_system/config/next_48h.yaml \
  --run --select-best

# ── STEP 3: 게이트 통과 확인 ──
cat baseline/reports/gate_results.md

# ── STEP 4: PASS 시 Champion 교체 ──

# ── STEP 5: FAIL 시 원인 루프 ──
python3 tools/aub_next_fix.py --mode why_fail --output reports/fail_analysis.md
```
