## 1. 우선순위 TOP-5 패치

### PATCH-1: Degenerate Fold 원인 격리 (최우선)

| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | 4개 fold가 degenerate → OOS mean 3.32가 실제론 6개 fold에서만 계산됨. 서바이버십 바이어스 확정 |
| **(b) 위험** | 복구 후 실제 OOS mean 급락 가능 (50% 이상) |
| **(c) 실험** | |

```yaml
EXP-1.1: fold별 데이터 범위 덤프
  - cmd: python3 tools/fold_inspector.py --config champion_v5
  - gate: 각 fold의 start_date, end_date, n_samples 출력
  - expect: fold 1,2,3,8에서 n_samples < 50 또는 date_range < 60일 발견

EXP-1.2: degenerate 조건 완화 테스트
  - cmd: python3 run_backtest.py --min-samples-per-fold 20 --allow-partial
  - gate: 10/10 fold 정상 완료
  - expect: oos_mean 1.5~2.5 범위로 하락 (정상화)

EXP-1.3: fold별 개별 OOS 리포트
  - cmd: python3 tools/fold_oos_breakdown.py --output fold_detail.json
  - gate: 각 fold별 return, sharpe, mdd 개별 확인
  - expect: healthy fold와 degenerate fold 간 2x 이상 성능 차이 확인
```

| **(d) PASS 조건** | `degenerate_folds == []` AND `all_folds_n_samples > 100` |

## 2. 성능 불변 시 원인 분해 트리

```
OOS Mean 변화 없음
│
├─ [트리거] 신호 자체가 안 바뀜
│   ├─ feature 입력 데이터 동일? → data_hash 비교
│   └─ threshold/param이 실험에서 실제 적용됐나? → config diff
│
├─ [적용] 신호는 바뀌었으나 포지션 불변
│   ├─ rebalance 로직에서 min_change_threshold 너무 높음?
│   └─ 기존 포지션 유지 bias 있음?
│
├─ [노출] 포지션은 바뀌었으나 P&L 불변
│   ├─ 변경된 종목이 시장과 무상관 (beta ≈ 0)?
│   └─ long/short 상쇄로 net exposure ≈ 0?
│
├─ [비용] P&L은 바뀌었으나 net return 불변
│   ├─ 턴오버 증가 → 비용 상쇄
│   └─ 슬리피지 모델이 변경 효과 흡수
│
└─ [레짐] 특정 기간만 개선, 전체 평균은 불변
    ├─ fold별 성과 분산 체크
    └─ 시장 레짐(bull/bear/sideways)별 분해
```

## 3. 48h 자동 루프 실행 순서

```bash
# Phase 1: 인프라 복구 (0~8h)
./run_exp.sh EXP-1.1 && ./run_exp.sh EXP-2.1 && ./run_exp.sh EXP-3.1

# Gate-1: 진단 완료 체크
if [ $(cat fold_detail.json | jq '.degenerate | length') -gt 2 ]; then
  ./run_exp.sh EXP-1.2  # fold 복구 시도
fi

# Phase 2: 데이터 정합성 (8~24h)  
./run_exp.sh EXP-2.2 && ./run_exp.sh EXP-3.2

# Gate-2: MDD/Rebalance 정상화 체크
if [ "$(cat result.json | jq '.worst_mdd')" == "null" ]; then
  ./run_exp.sh EXP-2.3  # fallback 적용
fi

# Phase 3: 전략 검증 (24~48h)
./run_exp.sh EXP-4.1 && ./run_exp.sh EXP-5.1
./run_exp.sh EXP-5.2  # 비용 현실화

# Final Gate
python3 tools/champion_validator.py --require-all-folds --require-mdd --require-cost
```
