*   **위험/부작용**: 조건을 완화하면 전반적인 MDD가 악화될 수 있음 (Overfitting 해제 과정).

    3.  **[EXP-STOP-WIDEN] Stop Loss 1.5x**: 손절폭을 1.5배 넓혀 노이즈에 의한 조기 청산 방지 확인.

### [성능 정체 시 원인 분해 아이디어]

만약 위 실험 후에도 성능(Score)이 움직이지 않는다면 다음 트리 구조로 디버깅하시오.

1.  **트리거(Trigger) 불발**:
    *   *현상*: 매매 횟수 극도로 적음.
    *   *원인*: 진입 조건(Alpha Threshold)이 너무 높아 시장 노이즈에 묻힘.
    *   *액션*: Threshold를 표준편차(Z-score) 0.5 단위로 낮추며 매매 횟수 변화 관측.

2.  **노출(Exposure) 제한**:
    *   *현상*: 현금 비중이 계속 높음 (Exposure Max < 0.3).
    *   *원인*: 포트폴리오 최적화기(Optimizer)가 변동성을 회피하기 위해 현금을 선택.
    *   *액션*: `min_exposure` 제약조건을 0.6 이상으로 강제 설정.

3.  **레짐(Regime) 불일치**:
    *   *현상*: 상승장에서는 못 벌고, 횡보장에서 손실 누적.
    *   *원인*: 추세 추종(Trend) 로직을 평균 회귀(Mean Reversion) 시장에 적용 중(또는 그 반대).
    *   *액션*: ADX(추세 강도) 지표를 통해 추세/비추세 구간을 나누어 로직 스위칭.

4.  **운영 리스크(Op Risk) - 데이터**:
    *   *현상*: 특정 종목(Ticker)에서만 수익 발생.
    *   *원인*: 데이터 오류(액면분할 미반영 등)로 인한 가짜 수익.
    *   *액션*: 수익 기여도 상위 1위 종목을 제외하고도 우상향하는지 확인(Leave-One-Out Test).
