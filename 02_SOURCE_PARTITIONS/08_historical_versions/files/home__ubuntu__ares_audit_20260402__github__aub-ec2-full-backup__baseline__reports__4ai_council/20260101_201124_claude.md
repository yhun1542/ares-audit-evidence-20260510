## 1. 우선순위 TOP 5 액션

### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### PRIORITY #1: Candidate 승격 전 Stress Test
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

#### (a) 왜 필요한가
- tuning_min -1.50은 **단일 fold에서 -150% 수익** 의미
- lockbox에서 안 나타났을 뿐, 특정 레짐에서 폭발 가능
- 승격 후 실전 배포 시 해당 레짐 재현되면 치명적

#### (b) 위험/부작용
- 과도한 스트레스 조건 → 유효한 전략도 기각 (False Negative)
- 검증 시간 소요 → 다른 실험 지연

#### (c) 최소 실험

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 1A | `--stress covid_crash` (2020.02-03 집중) | tuning 해당 fold 재현 | MDD < -30% 이면 FAIL |
| 1B | `--stress rate_hike` (2022.01-10 집중) | 동일 | MDD < -25% 이면 FAIL |
| 1C | `--shuffle-folds 3` (fold 순서 무작위 3회) | tuning_min 분산 | std(tuning_min) < 0.3 이면 PASS |

#### (d) PASS 조건
```
ALL(1A, 1B) NOT FAIL  AND  1C PASS
→ Candidate를 Champion_v6로 승격
```

**실행 명령:**
```bash
python3 experiment_system/tools/stress_test.py \
  --candidate baseline/candidate_20260101_194908_exp_mrd_fsa.json \
  --scenarios covid_crash,rate_hike \
  --shuffle-folds 3 \
  --output baseline/reports/stress_candidate.md
```

### PRIORITY #2: 비용 모델 현실화 점검

- 현재 슬리피지/스프레드 파라미터 확인 필요

#### (b) 위험/부작용
- 비용 과다 추정 → 유효 신호도 필터링 (수익 기회 손실)

#### (c) 최소 실험

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|

#### (d) PASS 조건
```
2A 일치 → 2B, 2C 중 하나 PASS → 비용 모델 유지

### PRIORITY #3: 종목 풀 누수 점검 (Survivorship)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- Tech+Healthcare 8~14종목 → 상장폐지/합병 종목 제외됐을 가능성
- 2020~2024 Healthcare 섹터 M&A 빈번 (CELG→BMY, ALXN→AZN 등)
- 현재 유니버스가 "생존자만" 포함 시 +20~30% 과대추정 일반적

#### (b) 위험/부작용
- Point-in-time 데이터 구축 비용 (시간 2~4시간)
- 과거 데이터 품질 이슈로 노이즈 증가 가능

#### (c) 최소 실험

|----|-----------|--------|-------------|

| 3C | `--delist-aware` 플래그 적용 (상폐 시점 매도 강제) | worst_mdd | 악화폭 < 2% 이면 PASS |

#### (d) PASS 조건
```
3A < 3 누락 → SKIP (현재 풀 유지)

### PRIORITY #4: MDD 방어 모듈 강화 (운영 리스크)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

#### (a) 왜 필요한가
- Candidate worst_mdd -4.8%는 양호하나, **단일 종목 집중 시 급락 가능**
- 현재 포지션 사이즈 cap 확인 필요
- 실운영에서 개별 종목 -20% gap down 시 전체 MDD 영향 추정 필요

#### (b) 위험/부작용
- 너무 공격적 제한 → 수익률 희석
- Gap risk는 백테스트로 완전 포착 불가 (장외 이벤트)

#### (c) 최소 실험

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 4A | 현재 max_position_pct 확인 | <= 15% | 초과 시 즉시 수정 |
| 4B | `--inject-gap -20%` (무작위 종목 1개 -20% 주입) | 전체 MDD | < -8% 이면 PASS |
| 4C | `--correlation-limit 0.7` (상관 0.7 초과 종목 동시 보유 제한) | lockbox_mean | 하락 < 5% 이면 PASS |

#### (d) PASS 조건
```
4A 준수 AND 4B PASS → 현재 방어 유지
4A 미준수 OR 4B FAIL → max_position 12%로 하향 후 재실행
4C는 optional enhancement
```

**실행 명령:**
```bash
python3 experiment_system/tools/risk_inject.py \
  --candidate baseline/candidate_*.json \
  --gap-shock -0.20 \
  --correlation-check 0.7 \
  --output baseline/reports/mdd_stress.md
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

#### (d) PASS 조건
```
5A >= 2 후보 → 5B 실행
5B PASS → 5C로 가중치 결정

```
