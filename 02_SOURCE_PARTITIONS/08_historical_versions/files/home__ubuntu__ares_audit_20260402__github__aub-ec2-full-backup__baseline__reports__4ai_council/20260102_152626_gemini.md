### 2. 제안: 실행 가능한 Patch/실험 (TOP 3)

#### 제안 A: "Exposure Ceiling Test" (변동성 제어 실험)
*   **Why (필요성):** 현재 Exposure Max가 0.84임. 강세장에서 1.0(Full Invest)을 못 채워 수익 기회를 놓치고 있는지, 아니면 리스크 관리 덕분인지 확인 필요. Tech 섹터의 높은 Beta를 고려할 때 0.84가 적정 상한인지 검증해야 함.
*   **Risk (부작용):** 상한을 높일 경우 MDD 급증 및 Volatility Drag 발생 가능성.
*   **실험 설계 (48h Loop):**
    1.  **실험 정의:** Exposure Max를 `0.85` vs `0.98` vs `0.70`(방어형)으로 설정하여 백테스트.
    2.  **게이트 (Pass 조건):** `Calmar Ratio`가 기존 1.88 대비 유지되거나 상승할 것. 단, MDD가 15%를 초과하면 즉시 탈락.
    3.  **기대 관측치:** 강세장 구간(Tech Rally)에서 Max 0.98 모델의 `oos_mean` 상승 여부 확인.

#### 제안 B: "Sector Inverse-Covariance Weighting" (포트폴리오 배분)
*   **Why (필요성):** Tech와 Healthcare는 상관관계가 낮을 수 있음. 단순 시총 가중이나 동일 가중 대신, 상관관계가 높아질 때(시장 붕괴 조짐) 현금 비중을 늘리거나, 상관관계가 낮은 종목(Healthcare) 비중을 높이는 로직 필요.
*   **Risk (부작용):** 공분산 행렬 계산에 따른 연산 비용 증가 및 과최적화(Lookback period 민감도).
*   **실험 설계 (48h Loop):**
    1.  **실험 정의:** 유니버스 12개(Tech 8, Health 4)에 대해 `Risk Parity` 기반 비중 산출 vs `Equal Weight`. (ETF 사용 금지, 개별 주식 간 상관계수만 활용).
    2.  **게이트 (Pass 조건):** `Turnover`(회전율)가 주당 20% 이하일 것. (과도한 리밸런싱 방지).
    3.  **기대 관측치:** 하락장에서 `oos_min` 방어력이 개선되는지 확인.

#### 제안 C: "Execution Delay Lagging" (비용/슬리피지 반영)
*   **Why (필요성):** 현재 `oos_mean` 1.88이 실제 체결 오차(Slippage)를 반영하지 않은 수치일 가능성. 시뮬레이션 상의 '종가 매매'와 실제 '익일 시가 매매' 간 괴리 확인.
*   **Risk (부작용):** 성능 수치가 대폭 하락할 수 있음(현실 자각 타임).
*   **실험 설계 (48h Loop):**
    1.  **실험 정의:** 시그널 발생 후 `Execution Delay = 1 day` 적용 백테스트.
    2.  **게이트 (Pass 조건):** `oos_mean` 하락폭이 15% 이내일 것. 그 이상 하락 시 시그널의 예측력이 단기 노이즈에 의존함(알파 소멸)을 의미.
    3.  **기대 관측치:** 승률(Win Rate)의 유의미한 변화 관측.

### 3. 성능 정체 시 원인 분해 아이디어 (Debug Tree)

성능이 `oos_mean: 1.8~1.9` 구간에서 횡보할 경우, 다음 순서로 점검하십시오.

1.  **Cost Blindness (비용 누락):**
    *   **트리거:** 리밸런싱 빈도가 높은데 수익률이 일정하다?
    *   **확인:** 건당 TC 15bps(0.15%) 적용 시 수익률이 음전하는가? -> *Action: Turnover 제한 (Hard constraint).*
2.  **Universe Staleness (유니버스 고착화):**
    *   **트리거:** 특정 종목(예: NVIDIA, LLY 등)이 6개월 이상 포트의 30% 이상 점유.
    *   **확인:** Tech/Health 내 하위 섹터(예: Software vs Semi, Pharma vs Biotech) 로테이션이 없는지. -> *Action: 종목 교체 주기(Re-selection period) 단축.*
3.  **Regime Mismatch (레짐 불일치):**
    *   **트리거:** VIX 지수가 낮은데 Exposure가 0.5 수준에 머묾.
    *   **확인:** 변동성 감지 로직(GARCH 등)이 시장 노이즈에 과민반응 중인지. -> *Action: 변동성 지표의 Smoothing Window(MA) 확장.*
