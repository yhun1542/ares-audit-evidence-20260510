## 1. 우선순위 TOP 5 실험 (48H 루프)

### P1. Degenerate-Fold Root-Cause (가장 급함)

| 항목 | 내용 |
|------|------|
| **왜 필요** | 4개 fold가 degenerate → OOS mean 신뢰 불가, 서바이버십 편향 가능 |
| **위험/부작용** | 원인 미파악 시 모든 실험 결과 오염 |
| **게이트** | degenerate fold ≤ 1 |

| 실험 ID | 정의 | 기대 관측치 |
|---------|------|-------------|
| `DG-01` | fold별 signal coverage 로그 추가 → 0-exposure 구간 식별 | coverage < 20% fold 리스트 |
| `DG-02` | min_holding 완화 (3d→1d) 재실행 | degenerate fold 수 감소 여부 |
| `DG-03` | universe 필터 완화 (mcap > 5B → 2B) | 종목 수 +30% 시 fold 정상화 여부 |

**PASS 조건:** `degenerate_folds ≤ 1 AND oos_min > -0.01`

---

### P2. Exposure Floor Enforcement

| 항목 | 내용 |
|------|------|
| **왜 필요** | `exposure_min=0.0` → 현금 100% 구간 존재 = 전략이 아닌 타이밍 베팅 |
| **위험/부작용** | 강제 노출 시 drawdown 증가 가능 |
| **게이트** | `exposure_min ≥ 0.25` 유지하며 `worst_mdd < 15%` |

| 실험 ID | 정의 | 기대 관측치 |
|---------|------|-------------|
| `EF-01` | `min_exposure=0.25` 하드코딩 | exposure_min ≥ 0.25 |
| `EF-02` | `min_exposure=0.40` + hedge=0.20 | MDD 변화량, Sharpe 변화량 |

**PASS 조건:** `exposure_min ≥ 0.25 AND oos_mean ≥ 2.5 AND mdd < 15%`

---

### P3. Cost Model Realism

| 항목 | 내용 |
|------|------|
| **왜 필요** | 현재 비용 미반영 의심 (슬리피지/스프레드/세금) |
| **위험/부작용** | 비용 반영 시 수익률 급락 → 전략 무효화 가능 |
| **게이트** | `cost_adjusted_oos_mean ≥ 1.8` (현실적 목표) |

| 실험 ID | 정의 | 기대 관측치 |
|---------|------|-------------|
| `CM-01` | 편도 10bp 슬리피지 적용 | oos_mean 변화량 |
| `CM-02` | 편도 20bp + 연 0.5% 보관비용 | 손익분기 turnover 계산 |

**PASS 조건:** `cost_adjusted_oos_mean ≥ 1.8 AND turnover < 50%/month`

---

### P4. Regime Filter Validation

| 항목 | 내용 |
|------|------|
| **왜 필요** | `oos_min=-0.026` 소폭 음수 → 특정 레짐에서 손실 집중 가능 |
| **위험/부작용** | 레짐 필터 과적합 위험 |
| **게이트** | 레짐별 성과 분산 < 30% |

| 실험 ID | 정의 | 기대 관측치 |
|---------|------|-------------|
| `RF-01` | VIX > 25 구간 분리 성과 측정 | 해당 구간 oos_mean |
| `RF-02` | SPY 20D momentum < 0 구간 분리 | drawdown 집중도 |

**PASS 조건:** `min_regime_oos > 0.5 AND regime_std < 1.5`

---

### P5. Signal Decay / Lookahead Audit

| 항목 | 내용 |
|------|------|
| **왜 필요** | `oos_mean=3.32` 비정상적 고수익 → lookahead 누수 의심 |
| **위험/부작용** | 누수 발견 시 전체 파이프라인 재구축 필요 |
| **게이트** | T+1 shift 후에도 `oos_mean ≥ 2.0` |

| 실험 ID | 정의 | 기대 관측치 |
|---------|------|-------------|
| `LA-01` | 모든 signal을 T+1 shift 후 재실행 | oos_mean 변화량 |
| `LA-02` | price 데이터 T+1 shift | 급락 시 lookahead 확정 |
| `LA-03` | random entry (signal 무시) baseline | 무작위 대비 alpha 존재 확인 |

**PASS 조건:** `shifted_oos_mean ≥ 2.0 AND random_baseline < 0.5`

## 2. 48H 자동 루프 스펙

```yaml
loop_interval: 6h
experiments:
  - id: DG-01
    cmd: python3 run_backtest.py --config fold_coverage_debug.yaml
    gate: degenerate_folds <= 1
    
  - id: EF-01
    cmd: python3 run_backtest.py --min-exposure 0.25
    gate: exposure_min >= 0.25 AND mdd < 0.15
    
  - id: CM-01
    cmd: python3 run_backtest.py --slip-bp 10
    gate: cost_adj_oos >= 1.8
    
  - id: LA-01
    cmd: python3 run_backtest.py --signal-shift 1
    gate: shifted_oos >= 2.0
    depends_on: [DG-01]  # degenerate 해결 후 의미 있음

promotion_rule:
  all_gates_pass: promote to champion
  any_gate_fail: log + alert + continue
```

│
├─ [3] 노출 상쇄
│   └─ 체크: long/short 동시 증가로 net exposure 불변?
│
├─ [4] 비용 상쇄
│   └─ 체크: gross return ↑ but net return 불변? → turnover 확인
│
└─ [5] 레짐 혼합
    └─ 체크: bull 구간 ↑, bear 구간 ↓ 상쇄? → 레짐별 분리 분석
