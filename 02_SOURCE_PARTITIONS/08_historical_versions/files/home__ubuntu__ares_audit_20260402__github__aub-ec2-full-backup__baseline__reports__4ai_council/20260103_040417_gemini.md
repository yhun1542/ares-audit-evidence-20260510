### 4) 성능 정체(Stagnation) 시 원인 분해 아이디어

만약 위 조치 후에도 성능이 개선되지 않거나 OOS 3.32에서 변화가 없다면 다음을 점검.

1.  **Trigger Failure (신호 불발):**
    *   지표(Indicator)가 특정 값에 고착(Clamping)되어 매매 신호 자체가 생성되지 않는지 확인 (특히 Degenerate Folds 구간).
2.  **Exposure Gap (노출 누수):**
    *   Cash 비중이 비정상적으로 높게 유지되는지(`exposure_max`가 0.83인데 평균이 0.1 이하인지) 확인.
3.  **Look-ahead Bias Check (참조 오류):**
    *   Fold 경계에서 미래 데이터를 참조하여(Look-ahead) 수익률이 뻥튀기되었으나 실제 시뮬레이션에서는 체결 거부되는지 확인.
4.  **Regime Mismatch (국면 부조화):**
    *   학습된 모델이 'Low Volatility Bull Market'에만 과적합되어, 최근 데이터(고금리/고변동성)에서 작동을 멈췄는지 확인.
