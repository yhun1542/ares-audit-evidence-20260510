## 📋 TOP 5 우선순위 (48시간 실행)

### P1. Degenerate Fold 원인 격리
```
왜: 4개 폴드(40%) 퇴화 = 모델이 특정 레짐에서 완전 실패
    → IS/OOS 갭 과대 → 실전 성능 신뢰 불가
```

| 위험/부작용 | 실험 | PASS 조건 |
|-------------|------|-----------|
| 레짐 필터 과적합 가능 | **EXP-1A**: 폴드 1,2,3,8 날짜 추출 → 레짐 태깅 (VIX>25? 금리급등?) | 레짐 공통점 1개 이상 식별 |
| 표본 축소 리스크 | **EXP-1B**: 퇴화폴드 제외 후 OOS 재계산 vs 전체 비교 | 갭 < 0.5 |
| - | **EXP-1C**: 퇴화폴드만 단독 백테스트 → exposure 패턴 확인 | exposure_max < 0.1이면 "현금회피" 확정 |

```bash
# 실험 1A
python3 -c "
import json
with open('baseline/champion_v5_latest.json') as f:
    d = json.load(f)
    for fold_id in [1,2,3,8]:
        print(f'Fold {fold_id}:', d.get('fold_details',{}).get(str(fold_id),{}).get('date_range','N/A'))
"
```

### P3. Exposure 밴드 정규화
```
왜: exposure 0.0~0.84 = 현금 100%~84% 주식
    → 0% 구간 존재 = 시그널 완전 OFF 구간
    → 레버리지 효율 불균형
```

| 위험/부작용 | 실험 | PASS 조건 |
|-------------|------|-----------|
| 강제 노출 → MDD 악화 | **EXP-3A**: min_exposure=0.2 강제 (현금 최대 80%) | OOS Mean 하락 < 10% AND MDD 증가 < 5% |
| 과최적화 | **EXP-3B**: exposure smoothing (5일 EMA) | 일별 turnover 30% 이상 감소 |

```yaml
# config patch
exposure:
  min: 0.20
  max: 0.85
  smoothing: ema_5
```

### P4. 시그널 트리거 진단 (성능 정체 원인)
```
왜: "성능이 안 움직일 때" 원인 분해 필요
```

**원인 트리 (자동 체크)**
```
성능 정체
├─ [트리거] 시그널 자체가 안 바뀜?
│   └─ CHECK: 일별 signal_delta 분포 → std < 0.01이면 "죽은 시그널"
├─ [적용] 시그널 바뀌어도 포지션 불변?
│   └─ CHECK: rebalance 빈도 → 월 < 2회면 "실행 지연"
├─ [노출] 포지션 바뀌어도 exposure 미미?
│   └─ CHECK: position_delta * price_delta 상관 → < 0.1이면 "무의미 변경"
├─ [비용] 수익 발생해도 비용이 상쇄?
│   └─ CHECK: gross_return vs net_return 갭 → > 30%면 "과잉 회전"
└─ [레짐] 전략이 현재 레짐에 비활성?
    └─ CHECK: 최근 60일 exposure_mean < 0.3이면 "레짐 미스매치"
```

| 실험 | PASS 조건 |
|------|-----------|
| **EXP-4A**: 위 5개 CHECK 자동화 스크립트 | 5개 중 병목 1개 이상 식별 |
| **EXP-4B**: 병목 지점 단독 개선 실험 | 해당 지표 50% 이상 개선 |
