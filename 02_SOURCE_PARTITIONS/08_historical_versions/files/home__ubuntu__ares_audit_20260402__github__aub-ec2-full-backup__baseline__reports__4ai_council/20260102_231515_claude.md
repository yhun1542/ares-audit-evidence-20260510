## 1. 우선순위 TOP 5 액션

### P1. OOS 불일치 원인 분리 (Data Leak Hunt)

**왜 필요한지**
- Handoff(3.32) vs Diagnoser(2.63) = 26% 괴리 → 같은 champion인데 수치 다름
- 누수/Look-ahead 있으면 모든 후속 실험 무효

**위험/부작용**
- 누수 확정 시 champion 폐기, 실험 재시작 필요
- 진짜 원인이 버전 차이일 수도 (false alarm)

**최소 실험**

| ID | 실험 정의 | Gate | 기대 관측치 |
|----|-----------|------|-------------|
| P1-A | `champion_v5_latest.json` 동일 파일로 두 스크립트 재실행, hash 비교 | file_hash 일치 & OOS 차이 < 0.05 | 일치 → 버전 문제, 불일치 → 누수 |
| P1-B | Train/Test split timestamp 출력, future date 포함 여부 검증 | test_start > train_end 전 fold | 위반 fold 수 = 0 |
| P1-C | Feature generation에서 `.shift(-1)` 또는 future price 참조 grep | 0 hits | grep 결과 0 line |

**PASS 조건**: P1-A~C 모두 통과 시 누수 없음 확정 → P2 진행

---

### P2. Degenerate Fold 원인 분해

**왜 필요한지**
- 4/10 fold가 degenerate → 특정 레짐에서 전략 붕괴
- Survivorship bias 또는 레짐 과적합 가능성

**위험/부작용**
- Fold 제거하면 OOS 과대평가
- 레짐 필터 추가 시 exposure 급감 가능

**최소 실험**

| ID | 실험 정의 | Gate | 기대 관측치 |
|----|-----------|------|-------------|
| P2-A | Degenerate fold [1,2,3,8]의 date range 추출, VIX/SPY regime 매핑 | 특정 regime 집중도 < 80% | regime 분포 출력 |
| P2-B | 해당 fold에서 signal 분포(mean, std) 정상 fold와 비교 | KS-test p > 0.05 | signal drift 여부 |
| P2-C | Degenerate fold 제외 후 OOS 재계산 vs 포함 | 차이 < 0.3 | 차이 > 0.5면 과최적화 확정 |

**PASS 조건**: P2-A에서 regime 편중 확인 → regime-aware weighting 적용 검토

---

### P3. MDD/Drawdown 계산 복구

**왜 필요한지**
- `worst_mdd: None` → 리스크 메트릭 블라인드
- 실제 운용 시 -20% DD에서 패닉 가능

**위험/부작용**
- MDD 계산 추가하면 champion 탈락 가능성
- 계산 로직 오류 시 false reject

**최소 실험**

| ID | 실험 정의 | Gate | 기대 관측치 |
|----|-----------|------|-------------|
| P3-A | Equity curve에서 rolling MDD 계산 함수 추가 | 함수 출력 존재 | worst_mdd 값 출력 |
| P3-B | MDD < -15% fold 식별 | MDD > -25% 전체 | 위반 fold 리스트 |

**PASS 조건**: worst_mdd 계산 완료 & < -25%

**왜 필요한지**

**위험/부작용**

- 과도한 비용 가정은 전략 불필요 기각

**최소 실험**

| ID | 실험 정의 | Gate | 기대 관측치 |

| P4-A | Rebalance 로그 경로 수정, JSON/CSV 파싱 디버깅 | 파일 로드 성공 | row count > 0 |

| P4-C | Turnover 연간화 계산 (avg daily turnover * 252) | Turnover < 500% | turnover 값 |

**PASS 조건**: P4-B에서 비용 후 OOS > 1.5 유지

## 2. 성능 미변동 시 원인 분해 트리

```
OOS 안 움직임
├── [트리거] Signal이 안 바뀜
│   ├── Feature 입력 동일 (데이터 갱신 X)
│   └── 모델 weight frozen / 버전 잘못 로드
│
├── [적용] Signal → Position 전환 실패
│   ├── Threshold 너무 높아 no-trade
│   └── Risk filter가 전부 차단
│
├── [노출] Position 있으나 PnL 0
│   ├── 해당 기간 종목 수익률 ≈ 0
│   └── Long/Short 상쇄
│
├── [비용] Gross PnL은 있으나 Net ≈ 0
│   ├── Turnover 과다 → 비용 상쇄
│   └── Slippage 과대 추정
│
└── [레짐] 전략이 현재 regime에 무효
    ├── Vol regime 불일치 (low vol에서 mean-revert 실패)
    └── Sector rotation으로 Tech/HC 언더퍼폼
```
