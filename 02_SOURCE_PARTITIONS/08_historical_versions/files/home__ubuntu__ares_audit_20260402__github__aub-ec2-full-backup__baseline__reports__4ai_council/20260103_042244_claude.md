|---------|------|--------|-------------|
| **MDD-01** | Backtest 루프에 rolling MDD 계산 삽입 | 모든 런에 worst_mdd 출력 | 숫자 값 (예: -0.15) |
| **MDD-02** | MDD > -20% 시 자동 FAIL 플래그 | Gate 작동 여부 | 위반 시 HANDOFF 차단 |

```python
# 삽입 위치 예시
def calculate_mdd(equity_curve):
    peak = equity_curve.cummax()
    dd = (equity_curve - peak) / peak
    return dd.min()
```

**PASS 조건**: 다음 HANDOFF에 `worst_mdd: -0.XX` 숫자 출력

## 3. 48H 자동 루프 스크립트 템플릿

```yaml
# autopilot_48h.yaml
loop_interval: 6h
max_iterations: 8

stages:
  - name: infra_check
    commands:
      - python3 tools/validate_champion_json.py
      - python3 tools/check_rebalance_output.py
    gate: all_pass
    on_fail: STOP_LOOP
    
  - name: fold_diagnosis
    commands:
      - python3 tools/fold_regime_tagger.py --folds 1,2,3,8
    gate: report_generated
    
  - name: experiment_run
    commands:
      - python3 run_experiment.py --config configs/deg_03.yaml
    gate: oos_mean > 2.5 AND degenerate_folds <= 2
    
  - name: report
    commands:
      - python3 tools/aub_handoff.py --output artifacts/
```
