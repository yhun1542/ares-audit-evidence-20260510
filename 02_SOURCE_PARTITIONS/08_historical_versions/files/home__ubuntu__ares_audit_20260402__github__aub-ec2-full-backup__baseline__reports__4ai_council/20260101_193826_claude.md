  expected: 0 (누수 없음)

  action: |
    python3 experiment_system/tools/aub_autopilot.py \
      --registry experiment_system/config/module_registry.yaml \
      --shuffle-labels --run
  gate: shuffled_lockbox_mean < 0.3
  expected: ~0.0 (무작위 수준)

**(d) PASS 조건**
- EXP-1A: `max_corr < 0.5`

## 4. 자동 루프 설정 (cron/systemd)

```bash
# /etc/cron.d/aub_autopilot
0 */6 * * * root /path/to/run_patch_cycle.sh >> /var/log/aub.log 2>&1
```

```bash
#!/bin/bash
# run_patch_cycle.sh

set -e

cd /path/to/project

# 1. 현재 단계 확인
STAGE=$(cat .autopilot_stage 2>/dev/null || echo "1")

case $STAGE in
  1) # PATCH-1: 누수점검
    python3 experiment_system/tools/leakage_audit.py --run-all
    if [ $? -eq 0 ]; then echo "2" > .autopilot_stage; fi
    ;;
  2) # PATCH-2,3: Stress + Cost
    python3 experiment_system/tools/stress_test.py --all &
    python3 experiment_system/tools/cost_sensitivity.py --sweep &
    wait
    echo "3" > .autopilot_stage
    ;;
  3) # PATCH-4: 집중도
    python3 experiment_system/tools/concentration_check.py
    echo "4" > .autopilot_stage
    ;;
  4) # PATCH-5: Regime
    python3 experiment_system/tools/regime_robustness.py
    echo "5" > .autopilot_stage
    ;;
  5) # 종합 판정
    python3 experiment_system/tools/final_gate.py --promote-if-pass
    echo "1" > .autopilot_stage  # 다음 사이클
    ;;
esac
```
