## 1. 우선순위 TOP-5 제안

### P1. Degenerate Fold 원인 격리

| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | 4개 폴드 붕괴 = OOS 신뢰도 60% 이하. 이 상태로 실험 반복은 무의미 |
| **(b) 위험** | 폴드별 레짐 차이가 실제라면 전략 자체 폐기 가능 |
| **(c) 실험** | |

```
EXP-1A: fold별 regime label 추출 (VIX 평균, 금리 방향, 섹터 리더)
  → gate: fold 1,2,3,8 공통 특성 1개 이상 식별
  → 관측치: regime_overlap_score ≥ 0.7

EXP-1B: degenerate fold에서 exposure=0 구간 비율 측정
  → gate: zero_exposure_ratio < 0.5 이면 신호 문제, ≥0.5면 필터 문제
  → 관측치: zero_exposure_pct per fold

EXP-1C: 해당 폴드만 signal threshold 0.5→0.3 완화 후 OOS 재측정
  → gate: oos_mean 변화 없으면 신호 자체 부재
  → 관측치: oos_delta, trade_count_delta
```

### P2. 노출(Exposure) 불균형 수정

| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | min=0.0, max=0.84 → 대부분 구간 현금. 전략이 아니라 타이밍 베팅 |
| **(b) 위험** | 노출 강제 증가 시 MDD 악화 가능 |
| **(c) 실험** | |

```
EXP-2A: min_exposure=0.2 하한선 적용
  → gate: mdd_increase < 5%p AND oos_mean 유지
  → 관측치: exposure_mean, mdd, oos_mean

EXP-2B: position_size 스케일 0.9 → 1.0 복원
  → gate: 거래 비용 증가 < 수익 증가
  → 관측치: gross_return, net_return, turnover
```

| 항목 | 내용 |

| **(b) 위험** | 비용 반영 시 수익 50%+ 증발 흔함 |
| **(c) 실험** | |

```
EXP-3A: slippage=10bp, commission=5bp 적용 후 OOS 재계산
  → gate: oos_mean ≥ 1.5 (기존 3.32의 45% 이상 생존)
  → 관측치: oos_mean_net, cost_drag_pct

EXP-3B: 턴오버 기반 비용 민감도 분석
  → gate: breakeven_cost 확인
  → 관측치: breakeven_slippage_bp
```

### P4. 신호 품질 검증 (Lookahead/Leakage)

| 항목 | 내용 |
|------|------|

| **(b) 위험** | 누수 발견 시 전체 파이프라인 재설계 |
| **(c) 실험** | |

```
EXP-4A: 신호 생성 시점 +1일 lag 강제 적용
  → gate: oos_mean 50%+ 유지
  → 관측치: oos_mean_lagged, decay_ratio

EXP-4B: 랜덤 날짜 셔플 후 동일 파이프라인 실행
  → gate: oos_mean ≤ 0.5 (귀무가설 기각)
  → 관측치: oos_mean_shuffled
```

## 2. 48h 자동 루프 스펙

```yaml

  T+0h:  EXP-5A (인프라 수정)

  T+6h:  EXP-4A (lag 테스트) → FAIL 시 STOP
  T+12h: EXP-1A, 1B (폴드 진단)
```
