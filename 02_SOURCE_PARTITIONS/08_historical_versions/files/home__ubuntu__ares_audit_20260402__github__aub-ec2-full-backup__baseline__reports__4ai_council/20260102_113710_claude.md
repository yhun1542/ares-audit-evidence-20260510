## 1. 우선순위 TOP 5 액션

### P1. 🔴 진단 파이프라인 복구 (BLOCKING)

**(a) 필요성**
- `rebalance.csv` 로드 실패 → 리밸런스 비용/타이밍 분석 불가
- `worst_mdd: None` → 리스크 게이트 작동 안 함
- 원인 분해 자체가 불가능한 상태

**(b) 위험/부작용**
- 복구 작업 중 기존 로그 덮어쓰기 위험
- 경로 하드코딩 시 환경 의존성 증가

**(c) 최소 실험**

| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P1-1 | `rebalance.jsonl` → CSV 변환기 추가 | 파싱 성공 | row_count ≥ 50 |
| P1-2 | MDD 계산 로직에 null-safe 래퍼 | worst_mdd ≠ None | -0.05 ~ -0.25 범위 |
| P1-3 | 경로 resolver를 `$AUB_ROOT` 기반으로 통일 | FileNotFoundError 0건 | CI 그린 |

**(d) PASS 조건**
```

champion JSON 내 worst_mdd 필드 float 존재
```

## 3. 48시간 자동 루프 스펙

```yaml
loop_interval: 6h
max_iterations: 8

iteration:
  1. run_experiments: [P1-1, P1-2, P1-3]
  2. gate_check:
       P1 PASS → proceed to P2
       P1 FAIL → retry with debug flag
  3. run_experiments: [P2-1, P2-2, P2-3]
  4. branch:
       cause == "레짐" → skip P3, run P4
       cause == "비용" → run P3
       cause == "누수" → STOP, manual review
  5. run_experiments: [P3-1 or P4-1]
  6. final_gate:
       OOS Mean ≥ 1.7 AND worst_mdd ≥ -0.25 → PROMOTE
       else → log + continue

alert_conditions:
  - 3 consecutive FAIL → slack notify
  - OOS Mean < 1.0 → HALT pipeline
```
