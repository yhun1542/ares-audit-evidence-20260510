## 3. 성능 미동 시 원인 분해 트리

```
성능 Δ ≈ 0
│
├─[1] 트리거 미작동
│   └─ 신호가 threshold 못 넘음
│   └─ 체크: `signal_fire_rate < 0.1` → threshold 완화 실험
│
├─[2] 적용 누락
│   └─ 신호 발생했으나 position에 미반영
│   └─ 체크: `signal_to_trade_lag > 2d` → 코드 버그/로직 점검
│
├─[3] 노출 부족
│   └─ position 잡혔으나 sizing이 너무 작음
│   └─ 체크: `avg_position_size < 0.05` → sizing 로직 점검
│
├─[4] 비용 상쇄
│   └─ gross alpha > 0 but net alpha ≈ 0
│   └─ 체크: `gross_return - net_return > 0.02` → 회전율 감소 실험
│
└─[5] 레짐 불일치
    └─ 신호가 과거 레짐에만 유효
    └─ 체크: `IC_rolling_12m` 하락 추세 → 레짐 필터 추가
```
