### PATCH-1: 파이프라인 복구 (Rebalance 로그)

**(a) 왜 필요**
- rebalance.csv/jsonl 파싱 에러 → 종목별 기여도 분해 불가
- MDD=None → 리스크 게이트 자체가 무의미

**(b) 위험/부작용**
- 로그 포맷 변경 시 기존 분석 도구 호환성 깨질 수 있음
- 디스크 I/O 증가 (무시 가능 수준)

**(c) 실험 체크리스트**

```
□ EXP-1A: 로그 경로/포맷 검증

  - GATE: 파일 존재 + JSON/CSV valid parse
  
□ EXP-1B: 백필러 재실행
  - CMD: python3 experiment_system/run_backtest.py --config champion_v5 --export-rebalance
  - GATE: rebalance.jsonl 생성 + row_count > 100
  
□ EXP-1C: MDD 계산기 복구 확인
  - CMD: python3 tools/calc_mdd.py --input artifacts/latest/equity_curve.json
  - GATE: worst_mdd != None, 값 범위 [-0.5, 0]
```

**(d) PASS 조건**
- `rebalance_pinpoint.py` 에러 없이 diff 테이블 출력
- `worst_mdd` 숫자 값 반환

## 2. 48시간 자동 루프 스케줄

```yaml
# autopilot_next_48h.yaml

Phase_1_Pipeline_Fix:  # T+0 ~ T+4h
  - EXP-1A
  - EXP-1B
  - EXP-1C
  gate: "rebalance file valid AND mdd != None"
  on_fail: "STOP, alert maintainer"

Phase_2_Attribution:   # T+4 ~ T+12h
  - EXP-2A
  - EXP-2B (if Phase_1 pass)
  - EXP-2C
  gate: "top_loss_contributors identified"
  on_fail: "log gap, continue with partial data"

Phase_3_Experiments:   # T+12 ~ T+36h
  parallel:
    - EXP-3A, EXP-3B  # exposure
    - EXP-4A, EXP-4B  # cost
    - EXP-5A, EXP-5B  # regime
  gate_each: "OOS ≥ 1.5 AND MDD ≤ -0.20"

Phase_4_Selection:     # T+36 ~ T+48h
  - rank by: (OOS_mean * 0.4) + (1/abs(MDD) * 0.3) + (cost_robustness * 0.3)
  - promote if: score > champion_score * 1.05
  - output: new_champion.json OR "NO_PROMOTION"
```

## 3. 성능 불변 시 원인 분해 트리

```
성능이 안 움직인다
│
├─ [트리거] 신호 자체가 발생 안 함
│   ├─ 검증: signal_count per day 확인
│   └─ 패치: threshold 완화 실험
│
├─ [적용] 신호 발생했으나 포지션 미반영
│   ├─ 검증: signal vs actual_position 매칭률
│   └─ 패치: execution delay 로그 추가
│
├─ [노출] 포지션 있으나 사이즈 미미
│   ├─ 검증: avg_position_size / NAV
│   └─ 패치: sizing 로직 점검
│
├─ [비용] 수익 발생했으나 비용에 잠식
│   ├─ 검증: gross_return vs net_return gap
│   └─ 패치: turnover 감소 실험
│
└─ [레짐] 전략이 현재 시장과 불일치
    ├─ 검증: 레짐별 성과 분해 (bull/bear/sideways)
    └─ 패치: 레짐 스위칭 또는 노출 조절
```
