### 1. 향후 24~48시간 우선순위 TOP 3 제안

#### 제안 1: 솔버 제약조건 완화 (Solver Relaxation)
*   **(a) 필요성:** Degenerate Folds(1,2,3,8) 해결이 최우선. Tech/Healthcare 8~14종목 제약이 특정 시점(유동성 부족, 섹터 급락 등)에서 충족 불가능한 상태임.
*   **(b) 위험:** 종목 수가 너무 적어지거나(집중 투자 위험), 너무 많아져(인덱스 추종) 알파가 희석될 수 있음.
*   **(c) 실험 (Experiments):**
    1.  `cardinality_min`: 8 → 5로 하향 조정.
    2.  `weight_min`: 0.05 → 0.02로 하향 조정 (작은 비중 허용).
    3.  `solver_timeout`: 기존 대비 2배 연장.
*   **(d) PASS 조건:** `degenerate_folds` 개수가 0 또는 1 이하로 감소.

#### 제안 2: 비용 페널티 강제 주입 (Cost-Adjusted Objective)
*   **(a) 필요성:** OOS Mean 3.32는 비현실적. 로깅 에러(`Expecting value`)를 우회하여, 최적화 목적함수(Objective Function) 자체에 거래비용을 반영해야 함.
*   **(b) 위험:** 매매 빈도가 급격히 줄어들어(Turnover 감소) 시장 변화에 둔감해질 수 있음(Lagging).
*   **(c) 실험 (Experiments):**
    1.  Objective: `Return - (Turnover * 0.0020)` (20bps 비용 가정).
    2.  Objective: `Sharpe` 대신 `Calmar Ratio` 사용 (MDD 방어 중시).
    3.  Penalty: 리밸런싱 시 기존 포트폴리오와의 거리(L1 Norm)에 대한 페널티 계수 `lambda` 0.1 추가.
*   **(d) PASS 조건:** OOS Mean이 1.5 이상 유지되면서 Turnover가 기존 대비 30% 감소.

#### 제안 3: 섹터 변동성 기반 노출 제한 (Sector Vix Filter)
*   **(a) 필요성:** Tech/Health는 고변동성 섹터. `worst_mdd` 계산 복구와 함께, 시장 붕괴 시 현금 비중을 늘리는 로직 필수.
*   **(b) 위험:** 상승장에서 너무 빨리 현금화하여 수익 기회를 놓칠 수 있음(Whipsaw).
*   **(c) 실험 (Experiments):**
    1.  Condition: `XLK` 또는 `XLV`의 20일 변동성이 상위 80%위일 때, `exposure_max` 0.84 → 0.50 축소.
    2.  Condition: 최근 5일 연속 하락 시 `exposure_max` = 0.0 (Stop Loss 로직).
*   **(d) PASS 조건:** `worst_mdd` 계산값이 출력되고, 그 값이 -0.15(-15%) 이내로 방어됨.

### 3. 성능 정체 시 원인 분해 (Diagnosis Logic)

성능이 개선되지 않거나 지표가 움직이지 않을 때 다음 순서로 점검하라.

1.  **트리거 불발 (Signal Deadzone):**
    *   *현상:* 포트폴리오가 변경되지 않고 현금만 보유하거나 특정 종목에 고정됨.
    *   *액션:* 진입 임계값(Threshold)이 너무 높은지 확인 (상위 5% -> 상위 20%로 완화).
2.  **노출 제약 (Exposure Ceiling):**
    *   *현상:* `exposure_max`가 0.83으로 고정되어 레버리지 효과 부족.
    *   *액션:* 변동성이 낮은 구간(Regime)에서는 1.0까지 노출 허용.
3.  **과도한 비용 (Cost Drag):**
    *   *현상:* Gross Return은 좋으나 Net Return이 우하향.
    *   *액션:* 8~14개 종목을 매일 교체하는지 확인. 주간(Weekly) 리밸런싱으로 주기 변경 고려.
4.  **레짐 불일치 (Regime Mismatch):**
    *   *현상:* Tech/Health가 동시에 하락하는 구간(상관관계 1.0)에서 방어 불가.
    *   *액션:* 상관관계가 낮은 유니버스(예: 필수소비재 등)를 관측용으로 추가하여, 상관계수 급증 시 매매 중단.
