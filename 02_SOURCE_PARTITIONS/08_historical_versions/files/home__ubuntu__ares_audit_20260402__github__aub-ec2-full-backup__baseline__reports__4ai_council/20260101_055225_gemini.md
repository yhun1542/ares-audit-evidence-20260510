현재 Champion(v5)과 Candidate의 **Lockbox 성능(1.7927...) 및 MDD(-0.1118...)가 소수점 15자리까지 완벽하게 동일함.**
이는 다음 중 하나를 의미함:
1.  **Code/Config Freeze:** 후보 모델의 로직 변경이 실제 실행 경로에 반영되지 않음.
2.  **Inactive Features:** 추가된 기능(MRD, ARS 등)이 Lockbox 구간(Out-of-Sample)에서 전혀 트리거되지 않음.
3.  **Dominant Constraint:** 하드코딩된 제약조건(Stop-loss 등)이 전략의 알파를 완전히 덮어쓰고 있음.

따라서 다음 48시간은 "알파 개선"보다 **"변별력 확보 및 시스템 무결성 검증"**에 집중해야 함.

*   **(b) 위험/부작용:** 파이프라인 버그 발견 시 전체 백테스트 재수행 필요(시간 비용).
*   **(c) 실험 (Patch):**

*   **(d) PASS 조건:** Lockbox Mean/MDD 수치가 기존(1.7927 / -0.1118)과 **달라야 함**. (변화 없으면 시스템 디버깅 모드로 전환).

*   **(c) 실험 (Patch):**

    *   `Sector_Rotation`: XLK vs XLV 상대 강도에 따라 비중 조절 (50:50 -> 70:30 동적 할당).
*   **(d) PASS 조건:** Tuning Mean > 1.70 유지하면서 Worst MDD < -0.15 (Turnover 비용 반영 후).

#### [PRIORITY 3] Volatility Targeting (Risk Parity variation)
*   **(a) 필요성:** Tech 바이오 섹터는 변동성이 큼. 단순 동일 비중보다 변동성 역가중(Inverse Volatility)이 MDD 방어에 유리.
*   **(b) 위험/부작용:** 저변동성 구간에서 레버리지가 과도해질 수 있음(Regime Filter 필요).
*   **(c) 실험 (Patch):**
    *   `Weight_InvVol`: 최근 20일 변동성 역수 비중 할당.
    *   `Target_Vol_15`: 포트폴리오 변동성 15% 타겟팅 (현금 비중 조절).
*   **(d) PASS 조건:** Tuning/Lockbox 샤프 비율(Sharpe) 개선 (+0.1 이상).

#### [PRIORITY 4] Execution Stress Test (Reality Check)
*   **(a) 필요성:** 현재 MDD -11%는 매우 우수하나, 슬리피지 미반영일 가능성 높음. Tech/Bio의 갭락/갭상 리스크 반영 필요.

*   **(c) 실험 (Patch):**

    *   `Cost_Double`: 수수료/슬리피지 설정을 현재의 2배로 설정.
*   **(d) PASS 조건:** Worst MDD가 -20% 이내로 방어되면 합격 (생존성 검증).

*   **(a) 필요성:** 하락장(2022년 등)에서 Tech/Healthcare 동반 하락 방어.
*   **(b) 위험/부작용:** 필터 오작동 시 상승장 초입을 놓침(Whipsaw).
*   **(c) 실험 (Patch):**

*   **(d) PASS 조건:** MDD 개선폭 > 수익률 감소폭.

### 3. 성능 정체(Stagnation) 원인 분해

Candidate가 Champion과 동일한 결과(`1.7927...`)를 내는 현상을 타개하기 위한 디버깅 체크리스트.

1.  **Trigger (신호 발생):**
    *   새로운 로직(MRD, ARS 등)이 `False`만 반환하고 있는가?
    *   *Check:* 로그에 `Active Signal Count`를 출력하여 0인지 확인.

2.  **Application (적용):**
    *   신호는 발생했으나 `Min_Weight`나 `Max_Position` 제약에 의해 무시되었는가?
    *   *Check:* `Desired_Weight` vs `Actual_Weight` 델타 확인.

3.  **Exposure (노출):**
    *   유니버스가 너무 좁아(8-14개) 랭킹 로직이 항상 동일한 종목을 뽑는가?
    *   *Check:* 월별 보유 종목 리스트(Holdings List)의 Jaccard Similarity 측정. (Champion vs Candidate).

4.  **Cost/Risk (비용 및 위험 제약):**
    *   MDD 제약 로직이 너무 강력하여 포트폴리오를 현금 100%나 특정 방어주로 고정시켰는가?
    *   *Check:* 현금 보유 비중(Cash Ratio) 시계열 확인.

5.  **Regime (시장 국면):**
    *   테스트 구간(Lockbox)이 특정 매크로 장세(예: 초강세장)여서 엣지가 묻히는가?
    *   *Check:* Lockbox 구간을 쪼개서(Sub-period) 성능 확인.
