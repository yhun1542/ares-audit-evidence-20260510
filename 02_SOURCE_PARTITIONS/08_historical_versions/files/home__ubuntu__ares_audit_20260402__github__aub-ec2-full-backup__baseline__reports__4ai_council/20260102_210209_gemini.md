# ONE TRUTH 분석 및 긴급 진단
**Current Champion (`champion_v5_latest`)의 Lockbox Mean(4.01)이 Tuning Mean(2.32)보다 비정상적으로 높음.**
이는 전형적인 **"최근 장세 편승(Recency Bias)"** 또는 **"특정 종목(예: NVDA, LLY) 과적합"** 징후임. Lockbox 구간이 최근 Bull Market이라면, 전략은 알파가 아니라 단순 레버리지 베타일 가능성이 높음.

---

### [Part 1] 24~48시간 우선순위 TOP 5 (Action Checklist)

1.  **[검증] Cost/Slippage Stress Test**: 현재 4.01의 성과가 거래 비용 증가 시에도 유지되는지 확인 (과최적화/비용 미반영 점검).
2.  **[실험] Sector-Neutral Jackknife**: 유니버스 내 Top Performer 2개를 제외하고도 로직이 동작하는지 확인 (서바이버십/특정 종목 의존도 점검).
3.  **[실험] Volatility Targeting Logic**: MDD 방어를 위해 변동성 기반 포지션 사이징(Vol-Targeting) 모듈 주입 (운영 리스크 점검).
4.  **[패치] Look-ahead Bias Check**: 시가(Open) 진입 시 T-1 데이터만 참조하는지 강제 확인하는 지연(Lag) 실험 (누수 점검).
5.  **[실험] Regime Filter (Macro Overlay)**: ETF(SPY/XLV/XLK)의 모멘텀이 꺾였을 때 현금 비중을 높이는 로직 추가 (운영 리스크 점검).

### [Part 2] 제안별 상세 실행 계획 (Execution Loop)

#### 1. Cost/Slippage Stress Test (비용 충격 실험)
*   **(a) 필요성**: Lockbox 성과가 4.0에 달하는 것은 현실적이지 않음. 슬리피지 모델이 헐겁거나, 거래 빈도가 높아 실제로는 비용에 녹을 수 있음.
*   **(b) 위험**: 전략 폐기(Disqualify) 가능성 높음. 그러나 이는 Live 투입 전 필수적인 'Kill Switch'.
*   **(c) 실험 정의 (Experiments)**
    *   `EXP_COST_01`: 매매 수수료/슬리피지 설정을 현재의 2배(예: 10bps → 20bps)로 설정 후 재검증.
    *   `EXP_COST_02`: 진입/청산 가격을 `Next Open`이 아닌 `Next Open + 0.5% gap` (최악의 체결가)으로 가정.
*   **(d) PASS 조건 (Gate)**:
    *   `tuning_min` > 0 유지.
    *   `lockbox_mean`이 2.0 이하로 떨어져도 용인하되, MDD가 -15%를 넘지 말 것.

#### 2. Sector-Neutral Jackknife (종목 제외 검증)
*   **(a) 필요성**: Tech/Healthcare 8~14개 포트폴리오라면, NVDA나 LLY 같은 슈퍼 주도주 1~2개가 성과의 80%를 설명할 수 있음. 이를 제거해도 로직이 유효한지 봐야 함.
*   **(b) 위험**: 유니버스 축소로 인한 분산 효과 감소, 변동성 증가.
*   **(c) 실험 정의 (Experiments)**
    *   `EXP_JACK_01`: `baseline/champion_v5_latest.json`의 유니버스에서 수익 기여도 Top 2 종목 영구 제외 후 백테스트.
    *   `EXP_JACK_02`: Healthcare 섹터 전체 제외 후 Tech만으로 로직 구동 (로직의 섹터 중립성 확인).
*   **(d) PASS 조건 (Gate)**:
    *   `tuning_mean` 하락폭이 30% 이내일 것.
    *   MDD 변화폭이 5%p 이내일 것 (예: -8% → -13% 이내).

#### 3. Volatility Targeting Logic (변동성 역가중)
*   **(a) 필요성**: 현재 Worst MDD(-8.1%)는 훌륭하나, 시장 급락 시 포지션 청산이 늦을 수 있음. 변동성이 커지면 자동으로 노출(Exposure)을 줄여야 함.
*   **(b) 위험**: 강세장에서 수익률(Upside) 제한 (Underperformance).
*   **(c) 실험 정의 (Experiments)**
    *   `EXP_VOL_01`: 개별 종목의 20일 ATR이 3% 초과 시 포지션 사이즈 50% 축소.
    *   `EXP_VOL_02`: 포트폴리오 전체 변동성 타겟을 연 15%로 설정하고 레버리지 조절 (Cash 비중 조절).
*   **(d) PASS 조건 (Gate)**:
    *   `worst_mdd` 개선 (절댓값 감소).
    *   `tuning_mean` / `worst_mdd` (Calmar Ratio 유사 지표) 증가.

#### 4. Look-ahead Bias Check (지연 데이터 실험)
*   **(a) 필요성**: 시가(Open) 거래 시, 당일 시가나 전일 종가 데이터 처리에 미세한 참조 오류(미래 참조)가 있을 수 있음. 특히 Lockbox 점수 급등은 강력한 의심 사유.
*   **(b) 위험**: 코딩 오류가 아니라면 성능 급락은 없어야 함. 급락 시 코드 전체 리팩토링 필요.
*   **(c) 실험 정의 (Experiments)**
    *   `EXP_LAG_01`: 모든 입력 Feature에 `shift(1)`을 강제로 한 번 더 적용하여 신호 생성.
*   **(d) PASS 조건 (Gate)**:
    *   `tuning_mean`과 `lockbox_mean`의 상관계수가 0.8 이상 유지.
    *   성능이 완전히 무너지지 않아야 함 (Positive Mean 유지).

#### 5. Regime Filter (Macro Overlay)
*   **(a) 필요성**: 2022년과 같은 하락장에서 방어력이 검증되었는가? ETF(SPY, XLV)의 장기 추세를 필터로 사용.
*   **(b) 위험**: 휩소(Whipsaw) 구간에서 진입/청산 반복으로 손실 누적 가능.
*   **(c) 실험 정의 (Experiments)**
    *   `EXP_MACRO_01`: SPY 200일 이평선 하회 시, 신규 진입 금지 및 기존 포지션 50% 청산.
    *   `EXP_MACRO_02`: XLK(Tech)와 XLV(Health)의 60일 상관계수가 0.8 이상(동반 하락 위험)일 때 현금 비중 30% 확보.
*   **(d) PASS 조건 (Gate)**:
    *   `fold14_mdd` (검증 데이터셋의 MDD) 개선.
    *   수익률 곡선의 평탄화(Volatility 감소).

### [Part 3] 성능 정체 시 원인 분해 (Debugging Tree)

성능 지표(Mean/Sharpe)가 개선되지 않거나 0 근처에서 횡보할 때 체크:

1.  **트리거 빈도 (Trigger Frequency)**
    *   *현상*: 매매 횟수가 극도로 적음 (주 1회 미만).
    *   *원인*: 진입 조건(Threshold)이 너무 높음.
    *   *액션*: 진입 임계값을 낮추거나(Relax), 유니버스를 8개 → 14개로 확장.

2.  **노출 부족 (Under-exposure)**
    *   *현상*: 승률은 높은데 총 수익이 낮음.
    *   *원인*: 포지션당 할당 자산(Weight)이 너무 작거나, 현금 보유 비중이 과도함.
    *   *액션*: `max_position_size` 상향 또는 동시 보유 종목 수 제한 해제.

3.  **비용 잠식 (Cost Erosion)**
    *   *현상*: Gross Return은 우상향이나 Net Return이 횡보/하락.
    *   *원인*: 평균 보유 기간(Holding Period)이 너무 짧음 (잦은 매매).
    *   *액션*: 최소 보유 기간(Minimum Holding Period) 3일 강제 또는 진입 시그널 스무딩(Smoothing).

4.  **레짐 불일치 (Regime Mismatch)**
    *   *현상*: 특정 연도(예: 2022)에만 MDD가 깊고 회복 불능.
    *   *원인*: 전략이 'Low Volatility Bull Market'에만 최적화됨.
    *   *액션*: Short 전략을 섞거나(미국주식 Long Only 제약 시 불가능), 현금 비중을 동적으로 조절하는 'Smart Beta' 로직(Exp 5 참조) 필수.
