## 1. 우선순위 TOP-5 체크리스트

### P1. Degenerate Fold 원인 규명 및 패치
| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | 4/8 폴드 퇴화 = 50% 구간에서 전략 작동 안 함. 현재 OOS는 **cherry-picked 4개 폴드 평균**일 가능성 |
| **(b) 위험/부작용** | 패치 후 OOS 급락 예상 (실제 성능 노출), 과최적화 환상 붕괴 |
| **(c) 최소 실험** | 아래 참조 |
| **(d) PASS 조건** | `degenerate_folds ≤ 1` AND `oos_min > -0.01` |

```yaml
EXP-1.1: fold_debug_exposure
  정의: 퇴화 폴드(1,2,3,8)에서 exposure=0인 날짜/종목 덤프
  게이트: 덤프 성공 AND 원인 분류 완료
  기대관측: {no_signal | threshold_too_high | universe_empty} 중 하나

EXP-1.2: threshold_relax_sweep  
  정의: entry_threshold 0.7→0.5→0.3 sweep (퇴화 폴드만)
  게이트: 최소 1개 threshold에서 exposure > 0.1
  기대관측: 퇴화 해소 시 해당 폴드 OOS 측정 가능

EXP-1.3: min_position_force
  정의: 최소 2종목 강제 보유 (top-2 if signal < threshold)
  게이트: degenerate_folds ≤ 1
  기대관측: OOS mean 하락 but 분산 감소
```

### P5. Regime 필터 점검 (성능 미변동 시)
| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | 실험 10회 이상 돌려도 OOS 변동 없으면 **시그널 자체가 죽은 것** |
| **(b) 위험/부작용** | False positive로 유효한 alpha 버릴 수 있음 |
| **(d) PASS 조건** | 레짐별 OOS 분산 > 0.1 |

```yaml
EXP-5.1: regime_split_oos
  정의: VIX <20 / 20-30 / >30 구간별 OOS 분리 측정
  게이트: 3개 구간 모두 N > 50 거래일
  기대관측: 최소 1개 구간에서 OOS > 1.5

EXP-5.2: signal_decay_check
  정의: 시그널 생성 후 1d/3d/5d 지연 적용
  게이트: 지연별 OOS 측정 완료
  기대관측: 1d→5d 간 OOS 감소율 < 50% (alpha 잔존)
```

## 2. 성능 미변동 시 원인 분해 트리

```
OOS 안 움직임
│
├─ [트리거] 시그널이 발생 안 함?
│   └─ 체크: daily_signal_count == 0 → threshold/universe 문제
│
├─ [적용] 시그널 → 포지션 전환 안 됨?
│   └─ 체크: exposure == 0 in 퇴화 폴드 → min_position 강제
│
├─ [노출] 포지션은 있으나 수익 0?
│   └─ 체크: gross_return vs net_return 차이 → alpha 존재 but 비용에 먹힘
│
├─ [비용] 회전율 과다로 수익 상쇄?
│   └─ 체크: turnover > 50%/week → holding_period 연장
│
└─ [레짐] 특정 구간에서만 작동?
    └─ 체크: regime_split_oos → 전 구간 OOS < 0.5면 alpha 소멸
```
