### [제안 2] 진입 임계값(Threshold) 완화 (Degenerate Folds 해결)

*   **(a) 필요성**: Fold 1, 2, 3, 8의 퇴화는 모델이 신호를 전혀 생성하지 못함(Cash Trap)을 의미. 현재 진입 조건(Threshold)이 지나치게 보수적임.

*   **(c) 실행 실험 (Patch)**
    1.  `relax_entry_thr_05`: 진입 신호 강도(Alpha Score) 하한선을 기존 대비 50% 하향 조정.
    2.  `expand_universe_cap`: Tech/Healthcare 유니버스를 시총 상위 20개 -> 40개로 확장하여 선택지 증가.
    3.  `dynamic_vol_target`: 변동성 기반 포지션 사이징 로직에서 목표 변동성(Target Vol) 상향 (보수적 운용 완화).
*   **(d) PASS 조건**: Degenerate Folds 개수 0개 OR 모든 Fold에서 거래 횟수 > 30회.

### [성능 정체 시 원인 분해 아이디어]

1.  **트리거(Trigger) 불발**:
    *   *현상*: 시장은 움직이는데 포지션이 0.
    *   *체크*: 입력 데이터의 Z-Score 정규화가 이상치(Outlier)에 의해 왜곡되어 대부분의 신호가 0 근처에 머무는지 확인. Robust Scaler 도입 검토.
2.  **노출(Exposure) 왜곡**:
    *   *현상*: 특정 섹터(Tech)가 하락할 때 숏 포지션이 없어서 동반 하락.
    *   *체크*: Beta Neutral 제약 조건이 제대로 작동하는지, 혹은 Long-Only 편향이 강제되어 있는지 확인.
3.  **비용(Cost) 잠식**:
    *   *현상*: 총 수익은 플러스이나 순수익이 마이너스.
    *   *체크*: 평균 보유 기간(Holding Period)이 3일 미만인지 확인. 잦은 리밸런싱을 억제하는 버퍼(Buffer) 로직 필요.
4.  **레짐(Regime) 불일치**:
    *   *현상*: 2021년(상승장)엔 잘되나 2022년(하락장)에 Degenerate.
    *   *체크*: 훈련 기간에서 특정 연도(Year)를 제외하고 학습했을 때 성능이 급락하는지 확인(Data Leakage/Overfitting).
