## 🚨 Critical Issues 먼저

**현재 상태 진단:**
- `degenerate_folds: [1,2,3,8]` → 10개 중 4개 퇴화 = **40% fold 실패** (심각)

## 📋 TOP 5 우선순위 (48h 실행 체크리스트)

### PATCH-1: Degenerate Fold 원인 격리
| 항목 | 내용 |
|------|------|
| **(a) 필요성** | 4/10 fold 퇴화 = OOS 신뢰도 60% 미만. 과최적화/데이터누수 1차 용의선상 |
| **(b) 위험** | fold별 분석 시 implicit lookahead 발생 가능 → 분석코드도 OOS 격리 필수 |
| **(c) 실험** | |

```
EXP-1A: fold별 exposure 히트맵 생성 (퇴화 fold에서 exposure=0 구간 확인)
EXP-1B: fold 1,2,3,8의 시계열 구간 추출 → 해당 구간 시장 레짐 태깅 (bull/bear/chop)
EXP-1C: 퇴화 fold 제외 후 OOS 재계산 → 6-fold 기준 성능 delta 측정
```

| **(d) PASS** | 퇴화 원인 1개 이상 규명 + 6-fold OOS mean > 2.0 유지 |

**실행 명령:**
```bash
python3 tools/fold_degeneracy_analyzer.py \
  --champion baseline/champion_v5_latest.json \
  --output reports/fold_diagnosis_$(date +%Y%m%d).json
```
