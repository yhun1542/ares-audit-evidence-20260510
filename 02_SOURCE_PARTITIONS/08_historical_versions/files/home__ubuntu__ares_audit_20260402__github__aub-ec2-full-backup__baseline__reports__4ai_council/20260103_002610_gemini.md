### 2. 성능 정체(Stagnation) 시 원인 분해 아이디어

성능 지표가 움직이지 않거나(Flat), 개선되지 않을 때 다음 5가지 차원에서 디버깅을 수행하라.

1.  **트리거(Trigger) 감도:**
    *   *현상:* 거래 횟수가 너무 적거나, 진입 시점이 너무 늦음.
    *   *액션:* 진입 임계값(Threshold)을 10% 낮추고, 대신 손절(Stop-loss)을 타이트하게 설정하여 '일단 진입 후 검증' 구조로 변경.

2.  **적용(Application) - 종목 선정:**
    *   *현상:* 선정된 8~14개 종목이 시장 주도주(Alpha)가 아님.
    *   *액션:* 유니버스 필터 조건(예: 거래대금 상위, 시총 상위)을 변경하여 Pool 자체를 물갈이. ETF(XLK, XLV) 대비 상대강도(RS) 상위 종목만 필터링.

3.  **노출(Exposure) - 현금 비중:**
    *   *현상:* 하락장에서 현금 비중이 늘지 않고 계속 주식을 들고 있어 MDD 발생.
    *   *액션:* 거시 지표(VIX, 10년물 국채금리)가 특정 레벨 이상일 때 강제로 현금 비중 50% 확보 룰 추가.

4.  **비용(Cost) 구조:**
    *   *현상:* 백테스트는 좋은데 실전(Lockbox)이 나쁨.
    *   *액션:* 진입 시 '지정가(Limit)' 대신 '시장가(Market)+슬리피지 페널티'를 가정하여, 체결 가능성을 희생하더라도 비용을 보수적으로 산정했는지 확인.

5.  **레짐(Regime) 불일치:**
    *   *현상:* 전략이 횡보장에서는 죽고 추세장에서만 산다(또는 반대).
    *   *액션:* 현재 시장 상태(Trend vs Range)를 판별하는 메타 지표(예: ADX)를 도입하여, 전략 A(추세)와 전략 B(역추세)를 스위칭.
