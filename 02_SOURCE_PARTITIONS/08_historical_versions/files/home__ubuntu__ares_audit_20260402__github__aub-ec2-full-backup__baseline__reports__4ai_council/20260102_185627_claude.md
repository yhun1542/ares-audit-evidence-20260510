## Priority #1: Degenerate Fold 원인 분해

### (a) 왜 필요한지
- **4/10 folds가 degenerate** = 전략이 40% 시장 환경에서 작동 안 함
- OOS mean이 높아 보여도 실제 배포 시 해당 구간에서 **제로 포지션 or 손실**
- 이건 "과최적화" 또는 "regime mismatch"의 강력한 신호

### (b) 위험/부작용
- Fold 강제 제외 시 → survivorship bias 발생
- 과도한 정규화 시 → 전체 alpha 소멸

### (c) 실험 체크리스트

```
┌─────────────────────────────────────────────────────────────────┐
│ EXP-1A: Degenerate Fold Autopsy                                 │
├─────────────────────────────────────────────────────────────────┤
│ □ python3 tools/fold_autopsy.py --folds 1,2,3,8                 │
│   → 해당 fold의 시장 환경(VIX레벨, 섹터로테이션) 추출           │
│ □ 출력: fold별 평균 VIX, Tech/HC 상대강도, 거래일수             │
│ GATE: 4개 fold 공통 패턴 1개 이상 발견                          │
│ EXPECT: "고VIX+Tech언더퍼폼" 같은 regime tag                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ EXP-1B: Regime-Conditional Position Sizing                      │
├─────────────────────────────────────────────────────────────────┤
│ □ IF vix_20d_ma > 25 THEN max_exposure *= 0.5                   │
│ □ backtest with regime_guard=True                               │
│ GATE: degenerate_folds ≤ 2                                      │
│ EXPECT: oos_min > -1.5%, mdd 측정값 존재                        │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ EXP-1C: Minimum Holding Period (anti-whipsaw)                   │
├─────────────────────────────────────────────────────────────────┤
│ □ min_hold_days = 5 (현재 추정: 1 or None)                      │
│ □ 진입 후 5일간 exit signal 무시                                │
│ GATE: turnover -30% 이상, degenerate_folds 개선                 │
│ EXPECT: 비용 반영 후 oos_mean 유지                              │
└─────────────────────────────────────────────────────────────────┘
```
