## 1. 48h Priority Patches (1 → 5)

### P1. **Worst-MDD 미측정 해소**
| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | `worst_mdd: None` — 리스크 게이트가 작동 불가; 과최적화 탐지 불가 |
| **(b) 위험/부작용** | 계산 추가로 백테스트 시간 +5~10 % |
| **(c) 실험** | ① 기존 equity curve에서 MDD 계산 로직 추가 (rolling max drawdown) |
|  | ② fold별 MDD 분포 출력 → degenerate_folds 판정 기준 재정의 |
| **(d) PASS 조건** | `worst_mdd ≤ -0.12` 이면서 `oos_min > 0.8` 유지 |

```bash
# 실험 정의
EXP_ID=mdd_calc_v1
GATE="worst_mdd is not None AND worst_mdd >= -0.20"
EXPECT="worst_mdd in [-0.25, -0.08]"
```

### P3. **Transaction Cost 시뮬레이션 삽입**
| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | 현재 비용 미반영 → 실전 괴리 (특히 rebalance 빈도 높으면 심각) |
| **(b) 위험/부작용** | 비용 과다 추정 시 전략 폐기 오판 |
| **(c) 실험** | ① 슬리피지 5 bp / 10 bp / 20 bp 3단계 sweep |
|  | ② 연간 turnover 계산 → cost drag = turnover × slip |
| **(d) PASS 조건** | `cost_adjusted_oos_mean ≥ 1.60` (20 bp 기준) |

```bash
EXP_ID=txn_cost_sweep
GATE="cost_adjusted_oos >= 1.60 at slip=20bp"
EXPECT="turnover <= 8x/year"
```

### P5. **Fold Stability: min/mean 편차 축소**
| 항목 | 내용 |
|------|------|
| **(a) 왜 필요** | `oos_min=0.43` vs `oos_mean=1.88` → 4× 격차; 특정 fold 과적합 가능 |
| **(b) 위험/부작용** | regularization 과도 시 전체 수익률 하락 |
| **(c) 실험** | ① fold별 feature importance diff → 이상 fold 식별 |
|  | ② dropout/ensemble averaging 추가 → min 상승 여부 확인 |
| **(d) PASS 조건** | `oos_min ≥ 0.80` AND `oos_mean ≥ 1.70` |

```bash
EXP_ID=fold_stability_v1
GATE="oos_min >= 0.80"
EXPECT="oos_mean >= 1.70, degenerate_folds == []"
```

## 2. 48h 자동 루프 명령 체크리스트

```text
│ 5     run regime_filter_v1 (VIX>25)          regime_oos ≥ 1.0     │
│ 6     run fold_stability_v1                  oos_min ≥ 0.80       │
│ 7     compare & update ONE_TRUTH             new oos > old +0.05  │
└──────────────────────────────────────────────────────────────────┘
```

## 3. 성능 정체 시 원인 분해 트리

```
Performance Δ ≈ 0 ?
│
├─ Trigger 미발동
│   └─ 조건 미충족 (universe 축소, 신호 threshold 과다)
│
├─ 적용 오류
│   └─ rebalance 로직 버그, 파일 미갱신, hash 불일치
│
├─ Exposure 고정
│   └─ min/max 범위가 이미 포화 → 변경 여지 없음
│
├─ 비용/슬리피지 상쇄
│   └─ 수익 개선 ≈ 추가 turnover 비용
│
└─ 레짐 불일치
    └─ 최근 OOS 구간이 '평온기' → 전략 차별화 안 됨
```
