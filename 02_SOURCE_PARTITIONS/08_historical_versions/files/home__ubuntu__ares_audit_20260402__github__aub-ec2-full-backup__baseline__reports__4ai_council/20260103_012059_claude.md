## TOP 5 우선순위 패치 (실행 체크리스트)

### P1. Degenerate Fold 원인 분해 및 수정
```
WHY: 4개 fold에서 신호=0 또는 극단 편향 → OOS 40% 사실상 무효
     서바이버십: 살아남은 6개 fold만으로 성능 부풀려짐
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P1-A | `--min-signal-rate 0.05` 강제 | degenerate ≤ 1 | fold별 position_count > 20 |
| P1-B | Fold 1,2,3,8 단독 디버그 런 | 원인 식별 | regime/sector 편중 로그 |
| P1-C | Stratified time-split 적용 | 전 fold 생존 | oos_std < 1.5 |

**PASS 조건:** `degenerate_folds ≤ 1 AND oos_std/oos_mean < 0.5`

---

### P2. MDD 계산 파이프라인 복구
```
WHY: worst_mdd=None → 리스크 게이트 전체 무력화
     실운용 시 -30% DD 발생해도 탐지 불가
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P2-A | `calc_mdd()` null-check 삽입 | MDD 값 출력 | worst_mdd ∈ [-0.5, 0] |
| P2-B | 일별 equity curve 로깅 강제 | curve 파일 존재 | `equity_curve.csv` rows > 200 |

**PASS 조건:** `worst_mdd != None AND worst_mdd > -0.25`

---

### P3. OOS 메트릭 불일치 해소
```
WHY: 3.32 vs 2.63 (25% 괴리) → Champion 선정 기준 자체 의심
     누수 또는 계산 버전 충돌 가능
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P3-A | 동일 JSON 2개 스크립트로 재계산 | 오차 < 1% | `abs(A-B)/A < 0.01` |
| P3-B | IS/OOS 경계 timestamp 출력 | 중복 없음 | `overlap_days = 0` |
| P3-C | Feature 미래참조 스캔 | 누수 0 | `lookahead_cols = []` |

**PASS 조건:** `metric_delta < 2% AND lookahead_cols empty`

---

### P4. Rebalance 비용 로깅 복구
```
WHY: 로그 실종 → 거래비용 미반영 확정적
     실제 수익 = gross - (spread + commission + slippage)
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P4-A | `--output-rebalance rebalance.jsonl` 플래그 추가 | 파일 생성 | rows > 50 |
| P4-B | 10bps 비용 후처리 적용 | OOS 재계산 | `oos_net = oos_gross - cost` |

**PASS 조건:** `rebalance.jsonl exists AND turnover_annual < 400%`

---

### P5. Exposure 안정화 (과최적화 감지)
```
WHY: exposure 0→0.84 극단 스윙 → 올인/올아웃 패턴
     레버리지 없이 84% 단일 방향 = 집중 리스크
```

**실험 정의:**
| ID | 실험 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P5-A | `--max-position-size 0.15` | max_single ≤ 15% | herfindahl < 0.15 |
| P5-B | `--min-exposure 0.3` 바닥 설정 | exposure_min ≥ 0.3 | 현금비중 < 70% |

**PASS 조건:** `exposure ∈ [0.3, 0.7] for 90% of days`

## 48H 자동 루프 실행 스크립트

```bash
#!/bin/bash
# aub_48h_loop.sh

set -e
TIMESTAMP=$(date +%Y%m%d_%H%M)

# Phase 1: 인프라 수정 (P2, P4)
echo "[GATE-1] MDD/Rebalance 로깅 복구"
python3 aub_runner.py --fix-mdd --output-rebalance artifacts/rebalance_${TIMESTAMP}.jsonl

# Phase 2: 데이터 무결성 (P3)
echo "[GATE-2] 누수 스캔"
python3 tools/lookahead_scanner.py --config champion_v5
[ $(cat artifacts/lookahead_result.json | jq '.count') -eq 0 ] || exit 1

# Phase 3: Fold 디버그 (P1)
echo "[GATE-3] Degenerate Fold 진단"
python3 aub_runner.py --debug-folds 1,2,3,8 --output artifacts/fold_debug_${TIMESTAMP}.json

# Phase 4: Exposure 제약 실험 (P5)  
echo "[GATE-4] Exposure 안정화 A/B"
python3 aub_runner.py --max-position 0.15 --min-exposure 0.3 --output artifacts/exp_stable_${TIMESTAMP}.json

# Validation
python3 tools/aub_validator.py --check-all artifacts/exp_stable_${TIMESTAMP}.json
```
