## 1. 우선순위 TOP-5 액션

### ▸ P1. Degenerate Fold 근본 원인 격리

**(a) 왜 필요한가**
- 4/10 폴드가 퇴화 = 해당 기간 전략이 **아예 작동 안 함**
- OOS mean 3.3%는 남은 6폴드의 평균; 실제 robust가 아님
- 서바이버십 편향 가능성 (신호 발생 but 종목 누락)

**(b) 위험/부작용**
- 퇴화 원인이 "시장 레짐"이면 전략 자체 재설계 필요 (비용 큼)
- 원인이 "데이터 갭"이면 쉽게 픽스 가능

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P1-A | 퇴화 폴드(1,2,3,8)에서 `signal_count`, `eligible_universe_size` 일별 덤프 | 자동 | signal_count=0 구간 비율 |
| P1-B | 동일 폴드에 `min_signal_threshold=0` 강제 적용 후 exposure 측정 | exposure > 5% | 신호 자체는 있었는지 확인 |
| P1-C | 폴드 1,2,3,8의 날짜 범위 vs S&P500 regime(VIX>25 일수) 교차 분석 | 자동 | regime 일치율 |

**(d) PASS 조건**
```
✅ PASS: 퇴화 원인이 "VIX>30 regime에서 신호 필터 과잉" → hedge 파라미터 조정으로 해결 가능
❌ FAIL: 신호 자체가 0 → universe/data 파이프라인 버그
```

## 2. 성능 미동 시 원인 분해 트리

```
OOS Mean 변화 없음
│
├─► [1] 트리거 실패

│
├─► [2] 적용 실패
│   └─ signal 있으나 position_size=0 → sizing 로직 버그
│
├─► [3] 노출 부족
│   └─ position 있으나 exposure < 10% → max_position 제한
│
├─► [4] 비용 상쇄
│   └─ gross_return > 0 but net_return ≈ 0 → slippage/commission 과다
│
└─► [5] 레짐 상쇄
    └─ 일부 폴드 ↑, 일부 ↓ → 평균 불변
    └─ 확인: fold별 delta 분포
```
