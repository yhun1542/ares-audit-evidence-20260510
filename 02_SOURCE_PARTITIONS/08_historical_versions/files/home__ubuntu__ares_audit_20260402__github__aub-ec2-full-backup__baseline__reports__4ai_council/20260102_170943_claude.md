## 3. 성능 미변동 시 원인 분해 프레임워크

```
[성과 = 트리거 × 적용률 × 노출 × (수익률 - 비용) × 레짐적합도]

각 단계 점검:

┌─────────────────────────────────────────────────────────┐
│ 1. 트리거 빈도                                          │
│    → 신호 발생 횟수/월 측정                             │
│    → 너무 적으면: 임계값 완화 실험                      │
│    → 너무 많으면: 노이즈 가능성                         │
├─────────────────────────────────────────────────────────┤
│ 2. 적용률 (신호 → 실제 매매)                           │
│    → 필터/제약 조건이 신호 몇 % 차단하는지              │
│    → 90% 이상 차단 시 필터 과잉                         │
├─────────────────────────────────────────────────────────┤
│ 3. 노출 크기                                            │
│    → 평균 포지션 사이즈, 레버리지                       │
│    → 노출 작으면 맞아도 수익 미미                       │
├─────────────────────────────────────────────────────────┤
│ 4. 수익률 - 비용                                        │
│    → 그로스 수익 vs 비용 차감 후 비교                   │
│    → 비용이 수익의 50% 이상이면 구조 문제               │
├─────────────────────────────────────────────────────────┤
│ 5. 레짐 적합도                                          │
│    → VIX/금리/섹터 모멘텀 구간별 성과 분해              │
│    → 특정 레짐에서만 작동 시 범용성 부족                │
└─────────────────────────────────────────────────────────┘
```
