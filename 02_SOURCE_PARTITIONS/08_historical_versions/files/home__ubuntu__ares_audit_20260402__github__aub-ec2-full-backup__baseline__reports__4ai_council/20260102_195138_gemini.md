### 2. 제안별 상세 실험 설계 (48시간 루프용)

#### **Proposal A: Transaction Cost Stress Test (거품 제거)**
*   **(a) 필요성:** Lockbox Mean(4.01)이 비정상적으로 높음. 실제 라이브 환경의 슬리피지/수수료 반영 시 마이너스로 전락할 위험 1순위.
*   **(b) 위험:** 전략 폐기(Fail) 확률 매우 높음. 챔피언 모델 박탈 가능성.
*   **(c) 실험 정의 (Experiments):**
    *   **EXP-A1:** 현행 수수료/슬리피지 모델의 **2배** 적용 후 Backtest.
    *   **EXP-A2:** 현행 모델의 **3배** 적용 후 Backtest.
    *   **EXP-A3:** Limit Order(지정가) 가정 시 체결률 80%로 하향 조정 시뮬레이션.
*   **(d) PASS 조건:**
    *   EXP-A1에서 `Lockbox Mean > 2.0` 유지 & `MDD < -10%` 방어.
    *   EXP-A2에서 `Profit Factor > 1.2` 유지.

#### **Proposal B: Dynamic Sector Allocation (Tech vs Health)**
*   **(a) 필요성:** Tech(성장)와 Healthcare(방어)는 금리 민감도가 다름. 단순 1/N 배분은 매크로 충격에 취약.
*   **(b) 위험:** 로직 복잡도 증가로 인한 연산 시간 증대. Overfitting 가능성.
*   **(c) 실험 정의 (Experiments):**
    *   **EXP-B1:** XLK(Tech)와 XLV(Health) ETF의 20일 모멘텀 비교, 강한 섹터에 비중 70% 할당.
    *   **EXP-B2:** 두 섹터 간 60일 상관계수가 0.8 이상이면 전체 레버리지 0.5배로 축소.
    *   **EXP-B3:** 개별 종목 변동성 역가중(Inverse Volatility Weighting) 적용.
*   **(d) PASS 조건:**
    *   `Worst MDD`가 기존 대비 10% 이상 개선(-8% -> -7.2% 이내).
    *   `Sharpe Ratio` 0.2 이상 개선.

#### **Proposal C: Regime Filter using ETF Indicators**
*   **(a) 필요성:** 하락장 방어. Tech/Health 8-14개 종목만으로는 시장 붕괴 방어 불가능.
*   **(b) 위험:** "False Positive"로 인한 기회비용 발생(상승장 초입 진입 실패).
*   **(c) 실험 정의 (Experiments):**
    *   **EXP-C1:** SHY(단기채) 대비 SPY(시장) 모멘텀 음수 전환 시 **전량 매도(Cash 100%)**.
    *   **EXP-C2:** VIX 지수(또는 관련 ETF)가 30 이상 또는 20일 이동평균 20% 급등 시 신규 진입 금지.
    *   **EXP-C3:** TLT(장기채) 5일 급락(-3% 이상) 발생 시 Tech 비중 0%로 차단.
*   **(d) PASS 조건:**
    *   `Lockbox MDD` -5% 이내로 축소.
    *   `Tuning Mean` 손실이 10% 이내여야 함(방어 로직이 수익을 너무 갉아먹으면 안 됨).

### 3. 성능 정체 시 원인 분해 (Debugging Tree)

성능 지표가 움직이지 않거나(Flat), 개선되지 않을 때 다음 순서로 점검 및 조치.

1.  **트리거(Trigger) 점검:**
    *   *현상:* 매매 횟수가 극도로 적거나(월 1회 미만) 너무 많음.
    *   *조치:* Entry Threshold(진입 임계값)를 ±0.5 표준편차 단위로 조정하여 민감도 테스트.
2.  **노출(Exposure) 점검:**
    *   *현상:* Signal은 발생하나 포지션 사이즈가 미미함.
    *   *조치:* Volatility Targeting 로직이 너무 보수적인지 확인. Target Vol을 15% -> 20%로 상향 실험.
3.  **비용(Cost) 구조 점검:**
    *   *현상:* Gross Return은 좋으나 Net Return이 Flat.
    *   *조치:* 평균 보유 기간(Avg Holding Period) 확인. 3일 미만이면 수수료가 알파를 잠식 중. 최소 보유 기간 5일 강제.
4.  **레짐(Regime) 불일치:**
    *   *현상:* 롱/숏 신호가 시장 방향과 계속 엇박자.
    *   *조치:* 현재 전략이 '추세 추종'인지 '평균 회귀'인지 정의. 횡보장에서 추세 추종을 쓰고 있다면 오실레이터(RSI 등) 비중 상향.
