```

│   └─ 해결: 포지션 사이징 로직 점검
│
├─③ 노출 문제 (포지션 有 but 수익 無)
│   ├─ 진단: 롱/숏 방향 적중률 < 50%?
│   └─ 해결: 시그널 품질 재검토
│
├─④ 비용 문제 (gross > 0 but net ≤ 0)
│   ├─ 진단: gross vs net 괴리
│   └─ 해결: 턴오버 감소, 비용 모델 현실화
│
└─⑤ 레짐 문제 (특정 구간만 작동)
    ├─ 진단: 폴드별 성능 분산 큼
    └─ 해결: 레짐 필터 or 앙상블
```
