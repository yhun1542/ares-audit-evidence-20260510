## 1. 우선순위 TOP 5 제안

### P1. Fold Degeneracy 제거 (데이터 무결성)

**(a) 왜 필요한지**
- 4/10 fold가 degenerate → OOS mean이 6개 fold에서만 계산됨
- 생존편향: 신호 발생 fold만 살아남아 과대평가 가능성 90%+

**(b) 위험/부작용**
- 거래 빈도 강제 시 과매매 유도 가능
- fold 제외 시 OOS 샘플 축소 → 분산 증가

**(c) 최소 실험**

| 실험 ID | 설명 | 변경점 |
|---------|------|--------|
| `EXP-P1A` | Min-trade 필터 | `--min-signals-per-fold 3` |
| `EXP-P1B` | Fold 구간 재설계 | 12M→6M fold, 총 20 folds |
| `EXP-P1C` | Degenerate fold 0점 처리 | OOS에 0 대입 후 평균 재계산 |

**(d) PASS 조건**
```
✓ degenerate_folds ≤ 1
✓ OOS mean 재계산 후 >2.0 유지
✓ 전체 fold 대비 신호 발생률 >80%
```

**(b) 위험/부작용**

**(c) 최소 실험**

| 실험 ID | 설명 | 변경점 |
|---------|------|--------|
| `EXP-P2A` | Daily close 기준 MDD | `calc_mdd(equity_curve, freq='D')` |
