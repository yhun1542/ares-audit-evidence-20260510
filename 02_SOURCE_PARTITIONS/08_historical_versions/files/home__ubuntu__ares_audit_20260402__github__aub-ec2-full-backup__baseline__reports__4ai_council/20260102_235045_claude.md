## 1. 우선순위 TOP-5 실행 패치

### PATCH-1: OOS 불일치 원인 격리 (누수 점검)
```
WHY: 핸드오프(3.32) vs 진단기(2.63) = 26% 괴리 → Look-ahead 누수 의심
```

| 실험 ID | 정의 | 게이트 | PASS 조건 |
|---------|------|--------|-----------|
| P1-A | `--no-future-features` 플래그로 피처 시점 강제 T-1 | OOS 재계산 | 괴리 < 5% |
| P1-B | 폴드별 train/test 날짜 겹침 검사 스크립트 | overlap_days 출력 | overlap = 0 |
| P1-C | 단일 폴드(fold-5)만 격리 실행, 수동 검증 | fold5_oos | 핸드오프와 ±3% 내 |

**위험/부작용**: 누수 확정 시 전체 백테스트 무효화 → 48h 이상 소요 가능

### PATCH-2: Degenerate Fold 복구 (4/10 실패)
```
WHY: 폴드 1,2,3,8 = 초기+중간 구간 실패 → 레짐 미적응 또는 데이터 부족
```

| 실험 ID | 정의 | 게이트 | PASS 조건 |
|---------|------|--------|-----------|
| P2-A | Fold 1-3 기간 데이터 품질 점검 (결측률, 종목수) | missing_pct 출력 | < 5% |
| P2-B | `min_samples_per_fold=200` → `100` 완화 | degenerate_count | ≤ 2/10 |
| P2-C | Purged CV gap 5d → 10d 확대 (정보 유출 차단) | OOS stability | std < 1.5 |

**위험/부작용**: 샘플 완화 시 과적합 증가 가능 → P1 통과 후 실행
