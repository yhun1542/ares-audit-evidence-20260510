## 1. 우선순위 TOP 5 체크리스트

### ━━━ P1: Degenerate Fold 근본 원인 수정 ━━━

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | 4개 폴드가 퇴화 → OOS 결과 40% 신뢰 불가. 실제 모델이 아닌 노이즈 fitting 가능성 |
| **(b) 위험** | 수정 시 OOS mean 급락 가능 (진짜 실력 노출) |
| **(c) 실험** | 아래 참조 |
| **(d) PASS** | `degenerate_folds == []` AND `oos_min > -1.0%` |

```yaml
EXP-1A: fold_degeneracy_min_trades
  정의: 각 폴드에서 최소 거래 수 20회 강제
  게이트: degenerate_folds count ≤ 1
  관측: 폴드별 trade_count, hit_rate 분포

EXP-1B: fold_degeneracy_exposure_floor  
  정의: exposure_min ≥ 0.10 강제 (현재 0.0)
  게이트: exposure_min > 0.05 all folds
  관측: 폴드별 exposure 시계열, 0-exposure 일수

EXP-1C: fold_purge_embargo_audit
  정의: purge=5d, embargo=2d 적용 확인 (누수 점검)
  게이트: train/test 날짜 중복 = 0
  관측: 각 폴드 train_end vs test_start gap
```

### ━━━ P2: 비용 파이프라인 복구 ━━━

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | rebalance.csv 로딩 실패 → 슬리피지/수수료 미반영 상태 불명 |
| **(b) 위험** | 비용 이미 반영됐다면 중복 차감 위험 |
| **(c) 실험** | 아래 참조 |
| **(d) PASS** | `rebalance.csv` 정상 로드 AND 비용 컬럼 존재 |

```yaml
EXP-2A: cost_pipeline_repair
  정의: rebalance 로그 JSON→CSV 변환 스크립트 수정
  게이트: aub_rebalance_pinpoint.py 정상 실행
  관측: turnover, cost_bps 컬럼 값 분포

EXP-2B: cost_sensitivity_sweep
  정의: cost_bps ∈ [5, 10, 15, 20] 스윕
  게이트: OOS mean 변동 < 0.5pp per 5bps
  관측: cost vs return 선형 관계 확인
```

### ━━━ P3: MDD 계산 파이프라인 추가 ━━━

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | worst_mdd=None → 리스크 메트릭 부재, 운영 불가 |
| **(b) 위험** | MDD 계산 시점(일중 vs 종가) 불일치 가능 |
| **(c) 실험** | 아래 참조 |
| **(d) PASS** | `worst_mdd is not None` AND `worst_mdd < 15%` |

```yaml
EXP-3A: mdd_calculator_add
  정의: 폴드별 MDD 계산 함수 추가 (종가 기준)
  게이트: worst_mdd 값 출력
  관측: 폴드별 MDD 분포, 발생 시점

EXP-3B: mdd_regime_overlay
  정의: VIX > 25 구간 MDD 별도 계산
  게이트: high_vol_mdd < 1.5 * normal_mdd
  관측: 레짐별 MDD 비교
```

### ━━━ P4: Exposure 비대칭 정규화 ━━━

| 항목 | 내용 |
|------|------|
| **(a) 필요성** | exposure 0.0~0.84 → 0 exposure 구간 = 현금 drag 또는 신호 부재 |
| **(b) 위험** | 강제 exposure 시 저신뢰 구간 손실 증가 |
| **(c) 실험** | 아래 참조 |
| **(d) PASS** | `exposure_min ≥ 0.15` AND `oos_mean ≥ 3.0` |

```yaml
EXP-4A: exposure_floor_0.15
  정의: 최소 exposure 15% 강제 (동일 가중)
  게이트: exposure_min ≥ 0.15
  관측: 0-exposure 일수 변화, 수익 기여도

EXP-4B: exposure_confidence_scale
  정의: 신호 신뢰도 기반 exposure 스케일링 (0.2~0.8)
  게이트: exposure 표준편차 < 0.15
  관측: 신뢰도-수익 상관관계
```

| 항목 | 내용 |
|------|------|

| **(b) 위험** | 파라미터 과최적화 → OOS 열화 |
| **(c) 실험** | 아래 참조 |

```yaml
EXP-5A: fsa_scale_ablation

  게이트: 최적값 vs 양끝 차이 < 0.5pp
  관측: 폴드별 FSA 기여도

EXP-5B: hedge_ratio_stability
  정의: hedge ∈ [0.20, 0.25, 0.30] 비교
  게이트: MDD 개선 > 수익 손실
  관측: 헤지 발동 빈도, 비용
```

## 2. 성능 미변동 시 원인 분해 트리

```
성능 변동 없음
├─ [1] 트리거 미발동
│   └─ 점검: signal_count, rebalance_frequency
│   └─ 실험: 신호 임계값 0.5→0.3 낮춰서 발동 확인
│
├─ [2] 적용 미반영  
│   └─ 점검: config hash 변경 확인, 캐시 무효화
│   └─ 실험: --force-rebuild 플래그 실행
│
├─ [3] 노출 상쇄
│   └─ 점검: long/short 동시 보유로 net exposure ≈ 0
│   └─ 실험: gross vs net exposure 분리 로깅
│
├─ [4] 비용 흡수
│   └─ 점검: turnover 증가분 vs 비용 증가분
│   └─ 실험: cost=0 가상 실행 후 차이 확인
│
└─ [5] 레짐 불일치
    └─ 점검: 실험 기간 vs 챔피언 훈련 기간 VIX/금리 차이
    └─ 실험: 레짐 필터 적용 후 재실행
```
