### 4. 성능 정체 시 원인 분해 (Debugging Stagnation)

수치가 움직이지 않을 경우 아래 순서로 점검하십시오.

1.  **Trigger (트리거)**: 신호 자체가 발생하지 않음.
    *   *Check*: 지표(Indicator) 값이 `NaN`이거나 Threshold가 너무 높음(예: RSI > 95).
2.  **Apply (적용)**: 신호는 떴으나 제약조건(Constraint)에 걸림.
    *   *Check*: `exposure_max` 도달 여부, 현금 부족, 혹은 '1주 단위' 구매 불가(가격이 너무 비싼 주식).
3.  **Exposure (노출)**: 포지션은 잡았으나 시장 베타(Beta)에 묻힘.
    *   *Check*: Tech/Healthcare ETF(XLK, XLV)와 내 포트폴리오의 상관계수 확인. 0.9 이상이면 전략이 아니라 그냥 인덱스 추종 중인 것임.
4.  **Cost (비용)**: 잦은 매매로 비용이 수익을 잠식.
    *   *Check*: 회전율(Turnover) 확인. 주간 회전율이 200%를 넘으면 로직 수정 필요.
5.  **Regime (시장 국면)**: 현재 전략이 특정 국면(예: 저금리 상승장)에만 작동.
    *   *Check*: `degenerate_folds` 기간의 금리/변동성(VIX) 지표와 전략 성과를 대조.
