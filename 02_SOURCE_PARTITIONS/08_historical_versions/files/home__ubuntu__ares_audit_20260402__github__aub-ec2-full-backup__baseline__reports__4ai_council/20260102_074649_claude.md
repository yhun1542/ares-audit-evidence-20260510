### P1. 붕괴 폴드 원인 분해 (tuning_min = -1.42)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한지**
- tuning_min -1.42는 특정 폴드에서 **142% 손실** (레버리지? 올인?)
- 이게 실제 시장에서 발생하면 복구 불가 → 반드시 원인 파악 후 진행

**(b) 위험/부작용**
- 단순 폴드 제외 시 서바이버십 바이어스
- 해당 폴드가 "정상적 악재 구간"이면 전략 자체 문제

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 조건 | 기대 관측치 |
|----|-----------|-------------|-------------|
| P1-A | 붕괴 폴드 기간 추출 → 해당 구간 종목별 수익 분해 | 리포트 생성 완료 | 단일 종목 or 집중도 문제 식별 |
| P1-B | 붕괴 폴드에서 position sizing 로그 검증 | max_position > 30% 발견 | 사이징 버그 여부 확인 |
| P1-C | 동일 기간 Champion v5 수익 비교 | diff > 1.0 | 신규 로직이 원인 확정 |

**(d) PASS 조건**
```
붕괴 원인 식별 완료 AND 
(버그 수정 OR 해당 레짐 명시적 예외 처리 정의)
```

### P2. MDD-Return 트레이드오프 분리 검증
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요한지**
- Candidate: MDD 개선(-9.3%→-4.1%) but 수익 하락
- **방어 로직이 과잉**인지, **정당한 리스크 감소**인지 구분 필요

**(b) 위험/부작용**
- MDD 개선을 위해 exposure 자체를 줄였다면 → 단순 현금 비중 증가와 동치
- Sharpe 기준으로 재평가 필요

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 조건 | 기대 관측치 |
|----|-----------|-------------|-------------|
| P2-A | 양 전략 평균 exposure % 비교 | diff > 15%p | 현금 비중 차이로 MDD 개선 확인 |
| P2-B | exposure-normalized return 계산 | Candidate Sharpe < Champion | 방어 과잉 확정 |
| P2-C | MDD 구간만 exposure 조절 (adaptive) | lockbox_min > 0.8 AND mean 유지 | 타겟팅 방어 가능성 |

**(d) PASS 조건**
```
Sharpe(Candidate) >= Sharpe(Champion) * 0.95 
OR exposure 차이 < 10%p
```

│   ├─ 추가 수익 < 추가 거래비용?
│   ├─ 잦은 진입/청산으로 슬리피지 누적
│   └─ 측정: gross return vs net return diff
│

    ├─ 신규 로직이 특정 레짐에서만 작동?
    ├─ 테스트 기간에 해당 레짐 부재?
    └─ 측정: 레짐별 sub-period 성과 분리
