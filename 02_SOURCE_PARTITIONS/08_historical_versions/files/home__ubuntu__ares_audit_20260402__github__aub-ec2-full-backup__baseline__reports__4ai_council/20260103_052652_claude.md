## 📋 TOP 5 우선순위 액션 (48H)

### **P0: 파이프라인 무결성 복구**

#### (a) 왜 필요한지
- `rebalance.csv` 로드 실패 → 실제 매매 로직 검증 불가
- MDD=None → 리스크 게이트 작동 안 함
- 핸드오프(3.32) vs 진단(2.63) 괴리 → **어느 숫자가 진실인지 불명**

#### (b) 위험/부작용
- 수정 중 기존 로직 변경 위험
- 파일 경로 하드코딩 의존성 노출

#### (c) 실험 체크리스트

```
EXP-P0-1: 파이프라인 Sanity Check
├─ 정의: champion_v5_latest.json 직접 파싱, OOS 수치 재계산
├─ 게이트: |재계산값 - 핸드오프값| < 0.01
└─ 기대치: 불일치 시 누수 위치 특정

EXP-P0-2: Rebalance 로거 수리
├─ 정의: rebalance.jsonl 출력 경로 확인 & 포맷 검증
├─ 게이트: JSON 파싱 성공 + 최근 30일 레코드 존재
└─ 기대치: pinpoint 도구 정상 작동

EXP-P0-3: MDD 계산 강제 활성화
├─ 정의: backtest에 mdd_calculator hook 삽입
├─ 게이트: worst_mdd ≠ None, 값 < -0.25
└─ 기대치: 리스크 게이트 재가동
```

### **P1: Degenerate Fold 원인 분해**

#### (a) 왜 필요한지
- 4/10 폴드 퇴화 = **전략이 40% 시장 레짐에서 무력화**
- OOS 평균 신뢰도 급락 (유효 샘플 6개)

#### (b) 위험/부작용
- 폴드 제거 시 서바이버십 바이어스
- 레짐 필터 추가 시 복잡도 증가

#### (c) 실험 체크리스트

```
EXP-P1-1: 퇴화 폴드 레짐 프로파일링
├─ 정의: fold 1,2,3,8 기간의 VIX/금리/섹터 특성 추출
├─ 게이트: 공통 패턴 1개 이상 식별
└─ 기대치: "고금리+VIX<15" 등 레짐 태그 도출

EXP-P1-2: 폴드별 시그널 분포 히스토그램
├─ 정의: 퇴화 vs 정상 폴드의 시그널 분포 비교
├─ 게이트: KS-test p < 0.05 (분포 유의차)
└─ 기대치: 시그널 스케일링/클리핑 필요 여부 판단

EXP-P1-3: Degenerate 폴드 제외 시 성과 변화
├─ 정의: 6폴드만으로 OOS 재계산 (참고용, 채택 X)
├─ 게이트: Δ OOS Mean 리포트 (채택 기준 아님)
└─ 기대치: 과최적화 유혹 정량화
```

### **P2: OOS Mean 괴리 원인 추적 (누수 헌팅)**

#### (a) 왜 필요한지
- 3.32 vs 2.63 = **26% 괴리**는 누수/버그 시그널
- 실험 간 동일 데이터 사용 검증 필요

#### (b) 위험/부작용
- 누수 수정 시 성과 급락 가능 (진짜 성과 노출)

#### (c) 실험 체크리스트

```
EXP-P2-1: 데이터 해시 비교
├─ 정의: champion_v5 학습/테스트 데이터 MD5 vs 진단 데이터 MD5
├─ 게이트: 해시 일치
└─ 기대치: 불일치 시 데이터 버전 문제 확정

EXP-P2-2: Look-ahead 감사
├─ 정의: 시그널 생성 시점 vs 가격 참조 시점 타임스탬프 검증
├─ 게이트: signal_time < price_time 100%
└─ 기대치: T+0 가격 사용 누수 탐지

EXP-P2-3: Train/Test 경계 검증
├─ 정의: 각 폴드 train 마지막 날짜 < test 첫 날짜 확인
├─ 게이트: 모든 폴드 통과
└─ 기대치: 폴드 누수 제거
```

### **P3: 비용/슬리피지 현실화**

#### (a) 왜 필요한지
- 현재 비용 모델 미상 → 실제 수익률 과대 추정 가능
- exposure_max=0.84 → 빈번한 리밸런싱 예상

#### (b) 위험/부작용
- 비용 추가 시 성과 하락
- 슬리피지 추정치 오류 위험

#### (c) 실험 체크리스트

```
EXP-P3-1: 거래 비용 민감도
├─ 정의: 10bp/20bp/30bp 왕복 비용 적용 OOS 재계산
├─ 게이트: 30bp에서 OOS Mean > 1.5
└─ 기대치: 비용 임계점 파악

EXP-P3-2: 턴오버 측정
├─ 정의: 월간 평균 포트폴리오 턴오버 계산
├─ 게이트: 턴오버 < 100%/월
└─ 기대치: 과매매 여부 확인
```

## 🔬 성능 미변동 시 원인 분해 트리

```
성능 Δ ≈ 0
├─ [1] 트리거 미작동
│   ├─ 시그널 분포 변화 無 → 입력 피처 점검
│   └─ 임계값 도달 빈도 0 → 임계값 과격
│
├─ [2] 적용 실패  
│   ├─ 포지션 변경 명령 발생 but 실행 안 됨
│   └─ 코드 분기 오류 (if문 조건)
│
├─ [3] 노출 부족
│   ├─ exposure 변화 < 1% → 실질 베팅 없음
│   └─ 롱/숏 상쇄 → net exposure ≈ 0
│
├─ [4] 비용 상쇄
│   ├─ 그로스 수익 존재 but 비용 차감 후 0
│   └─ 슬리피지 > 기대 알파
│
└─ [5] 레짐 비활성
    ├─ 테스트 기간이 퇴화 레짐에 해당
    └─ VIX/금리 조건 미충족
```
