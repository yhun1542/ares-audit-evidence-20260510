## 2. 성능 미변동 원인 분해 (디버그 트리)

```
성능 불변
│
├─[1] 트리거 미발생
│   └─ 시그널 조건이 lockbox 기간에 거의 충족 안 됨
│       → 확인: 시그널 발생 count 로깅
│
├─[2] 트리거 → 적용 탈락
│   └─ 필터(유동성/변동성/섹터 cap)에서 탈락
│       → 확인: 필터별 탈락률
│
├─[3] 적용 → 노출 미미
│   └─ position size가 전체 자본의 1% 미만
│       → 확인: 평균 position size / 총 자본
│
├─[4] 노출 → 비용 상쇄
│   └─ 수익 < 거래비용
│       → 확인: gross return vs net return 차이
│
└─[5] 레짐 상쇄
    └─ bull 구간 수익 + bear 구간 손실 = 0
        → 확인: 월별/분기별 수익 breakdown
```

## 3. 48시간 실행 체크리스트

```bash
# ──────────────────────────────────────
# Hour 0-8: 진단 로깅 추가
# ──────────────────────────────────────
□ E1.1 시그널 발생/진입 로깅 코드 삽입
□ E3.1 cost 파라미터 문서화 (config 파일 확인)
□ E4.1 종목별 PnL 기여도 스크립트 작성

# ──────────────────────────────────────
# Hour 8-24: 데이터 수집 & 1차 분석
# ──────────────────────────────────────
□ E2.1 lockbox_min 발생 구간 날짜 추출
□ E5.1 월별 수익률-SPY 상관 계산
□ 로깅 결과 1차 리뷰 → 병목 식별

# ──────────────────────────────────────
# Hour 24-40: 실험 실행
# ──────────────────────────────────────
□ E2.3 regime=X 시 position cap 50% (tuning)
□ E3.2 cost×2 시나리오 lockbox 재평가
□ E5.2 SPY 200MA 룰 (tuning)

# ──────────────────────────────────────
# Hour 40-48: 결과 통합 & 다음 HANDOFF
# ──────────────────────────────────────
□ 각 실험 PASS/FAIL 판정
□ PASS 실험 → candidate로 lockbox 평가
□ HANDOFF 파일 갱신 + 다음 루프 명령어 생성
```
