## 1. 우선순위 TOP 5 패치

### PATCH-1: Fold-Robustness Gate 강화
```
[WHY]
- tuning_min = -1.42 → 14개 fold 중 최소 1개 치명적 실패
- 현재 게이트가 mean 중심이라 outlier fold 통과 허용

[RISK]
- 게이트 과도 → 모든 candidate FAIL
- 개선 후보 자체가 사라질 수 있음

[EXPERIMENTS]
EXP-1A: tuning_min ≥ 0.0 게이트 추가
EXP-1B: tuning_min ≥ 0.3 게이트 추가  
EXP-1C: CVaR(5%) ≥ 0.0 게이트 추가

[PASS 조건]
- 기존 champion 통과
- 붕괴 fold candidate 자동 REJECT 확인
- lockbox 성능 저하 없음 (mean ≥ 1.5)
```

### PATCH-2: MDD 상한 정규화
```
[WHY]
- Champion worst_mdd = -9.3% → 운영 시 심리적 이탈 유발
- MDD 제약 없이 수익만 추구 중

[RISK]
- MDD 제약 과도 시 수익률 급락
- 변동성 레짐에서 포지션 과소

[EXPERIMENTS]
EXP-2A: position_size *= max(0.5, 1 + (mdd_5d / 0.05))
EXP-2B: 연속 3일 DD > 3% 시 신규진입 1일 중단
EXP-2C: trailing_stop 5% → 4% 조정

[PASS 조건]  
- worst_mdd ≥ -6%
- lockbox_mean ≥ 1.4 (현재 대비 -20% 허용)
- tuning 분포 skew 개선
```

### PATCH-3: 비용 모델 현실화 점검

```
- lockbox_mean 하락폭 ≤ 15%
- 비용 반영 후에도 mean ≥ 1.3
```

```
- tuning_min ≥ 0.2
- 붕괴 fold 수익곡선 시각화 개선 확인
- 레짐 라벨 변경 시 다른 fold 악화 없음
```

## 2. 48h 자동 루프 정의

```yaml
# experiment_loop_20260102.yaml

cycle_hours: 24
max_cycles: 2

experiments:
  - id: EXP-1A
    script: gate_tuning_min_0.py
    gate: "tuning_min >= 0.0 AND lockbox_mean >= 1.5"
    expect: "붕괴 candidate REJECT"
    
  - id: EXP-2A  
    script: mdd_position_scale.py
    gate: "worst_mdd >= -0.06 AND lockbox_mean >= 1.4"
    expect: "MDD 개선 2%p+"
    
  - id: EXP-3A
    script: cost_slippage_010.py
    gate: "lockbox_mean >= 1.3"
    expect: "수익 하락 ≤15%"
    
  - id: EXP-4C
    script: regime_fold_audit.py
    gate: "tuning_min >= 0.2"
    expect: "붕괴 fold 레짐 라벨 식별"
    
  - id: EXP-5A
    script: concentration_cap_10.py
    gate: "single_stock_impact_mdd >= -0.04"
    expect: "집중도 리스크 감소"

promotion_rule: |
  IF all gates PASS:
    new_champion = best(lockbox_mean)
  ELIF partial PASS:
    INCONCLUSIVE += partial
  ELSE:
    REJECT all, revert to champion_v5
```

## 3. 성능 안 움직일 때 원인 분해 트리

```
성능 정체
│
├─ [1] 트리거 문제
│   └─ 신호 발생 빈도 확인: trades/month < 5 → 신호 과소
│   └─ 신호 정확도: win_rate 변화 없음 → 신호 품질 정체
│
├─ [2] 적용 문제  
│   └─ 신호 → 실제 진입 전환율 < 80% → 게이트/필터 과잉
│   └─ 진입 지연: entry_lag > 1d → 시장 선반영
│
├─ [3] 노출 문제
│   └─ 평균 포지션 크기 < 50% 자본 → 과소 노출
│   └─ 보유 기간 < 5d → 알파 수확 전 청산
│
├─ [4] 비용 문제
│   └─ 거래 회전율 > 200%/yr → 비용 잠식
│   └─ 실현 수익 vs 비용 비율 < 3:1 → 구조적 한계
│
└─ [5] 레짐 문제
    └─ 현재 레짐 = 전략 최악 레짐 → 일시적 정체
    └─ 레짐 분포 변화: 훈련기간 vs 테스트 불일치
```
