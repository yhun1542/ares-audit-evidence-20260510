## 2. 성능 불변 시 원인 분해 트리

```
성능 안 움직임
├── [트리거] 시그널이 발생 안 함
│   ├── 임계값 너무 높음 → 시그널 발생 빈도 로그 확인
│   └── 데이터 지연/누락 → 피처 freshness 점검
│
├── [적용] 시그널 → 주문 변환 실패
│   ├── 포지션 사이징 버그 → 목표 vs 실제 포지션 비교
│   └── 제약조건 충돌 → exposure/concentration 제한 로그
│
├── [노출] 포지션 있으나 수익 없음
│   ├── 방향 맞으나 보유기간 부족 → holding period 분석
│   └── 종목 선정 오류 → 섹터별 기여도 분해
│
├── [비용] 수익 있으나 비용이 상쇄
│   ├── 과다 리밸런싱 → turnover 분석
│   └── 슬리피지 과소추정 → 실제 체결가 vs 시뮬레이션
│
└── [레짐] 전략-시장 미스매치
    ├── 변동성 레짐 → VIX 구간별 성과 분해
    └── 섹터 로테이션 → Tech/HC 상대강도 분석
```
