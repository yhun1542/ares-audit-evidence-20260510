## 2. 성능 미변동 시 원인 분해 트리

```
성능 불변
│
├─ [1] 트리거 미발동
│   ├─ 시그널이 threshold 미달 → threshold 완화 실험
│   ├─ 레짐 필터가 항상 OFF → 레짐 판정 로직 점검
│   └─ 데이터 지연/누락 → 데이터 파이프라인 로그 확인
│
├─ [2] 적용 오류
│   ├─ 주문 생성됐으나 미체결 → 브로커 로그
│   ├─ Position sizing 0 → sizing 로직 버그
│   └─ 종목 필터에서 전부 제외 → universe 점검
│
├─ [3] 노출 부족
│   ├─ 현금 비중 과다 (>50%) → exposure 상한 확인
│   ├─ 헤지가 과도 → hedge ratio 점검
│   └─ 종목 수 < 목표 (8개 미달) → scoring 분포 확인
│
├─ [4] 비용 상쇄
│   ├─ 고빈도 리밸 → turnover 일별 체크
│   ├─ 슬리피지 과대 (유동성 낮은 종목) → volume 필터
│   └─ 세금 이벤트 → wash sale 등
│
└─ [5] 레짐 불일치
    ├─ 훈련기간 ≠ 현재 시장 구조 → 롤링 윈도우 축소
    ├─ 섹터 로테이션 발생 → 섹터 모멘텀 추가
    └─ 매크로 브레이크 (금리/달러) → 매크로 팩터 점검
```

**디버깅 우선순위**:
1. `트리거 미발동` → 가장 흔함, 로그로 5분 내 확인 가능
2. `비용 상쇄` → turnover 리포트로 10분 내 확인
3. `레짐 불
