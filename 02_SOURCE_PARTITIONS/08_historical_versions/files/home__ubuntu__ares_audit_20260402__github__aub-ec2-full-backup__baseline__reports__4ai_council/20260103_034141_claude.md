## 3. 성능 미변동 시 원인 분해 트리

```
성능 불변
├── [트리거 문제] 시그널이 발생 안 함
│   ├── 임계값 과다 → 연간 트리거 횟수 확인 (목표: 20~50회)
│   └── 데이터 지연 → 시그널 생성 시점 vs 가격 시점 검증
│
├── [적용 문제] 시그널 → 포지션 전환 실패
│   ├── 리밸런싱 빈도 부족 → 일별 vs 주별 비교
│   └── 포지션 캡/제약 과다 → 제약 완화 실험
│
├── [노출 문제] 포지션은 있으나 베타/팩터 상쇄
│   ├── 섹터 내 롱숏 상쇄 → 넷 익스포저 확인
│   └── 시장 베타 = 0 근처 → 방향성 부재
│
├── [비용 문제] 그로스 알파 < 비용
│   ├── 턴오버 과다 → 연간 회전율 400% 이하 목표
│   └── 슬리피지 과소 추정 → 비용 2x 실험
│
└── [레짐 문제] 전략이 현재 시장에 부적합
    ├── VIX > 25 구간 별도 분석
    └── 금리 상승기/하락기 구분 성과 체크
```
