[우선순위 진단]
**현재 상황은 '성능 개선' 단계가 아니라 '시스템 무결성 붕괴' 단계임.**
- `worst_mdd: None`은 백테스트 엔진 내 수익률 계산 로직이 NaN을 반환했거나 데이터가 누락되었음을 의미.
- `degenerate_folds: [1, 2, 3, 8]`은 전체 검증 구간의 40% 이상에서 전략이 수학적으로 실패(해를 못 찾거나 파산)했음을 시사.
- 로그 파일 로드 실패(`Errno 2`, `JSON decode error`)로 인해 원인 분석(Rebalance Pinpoint)조차 불가능.

### 1. 24~48시간 우선순위 TOP 5 제안

#### P1. [Infra] 로그/데이터 파이프라인 복구 (긴급)
- **Why:** `rebalance.csv` 로드 에러로 분석 도구가 무용지물임. 관측 불가능하면 개선 불가능.
- **Risk:** 로깅 오버헤드 증가 가능성.
- **Pass 조건:** Pinpoint 툴이 에러 없이 실행되고, Rebalance History가 출력될 것.

#### P2. [Logic] NaN/Inf 메트릭 방어 로직 주입 (MDD None 해결)
- **Why:** `worst_mdd: None`은 치명적 버그. 수익률 계산 시 0으로 나누기 혹은 데이터 결측 구간 존재.
- **Risk:** 잘못된 데이터를 0으로 처리하여 성능을 과대평가할 위험(Lookahead Bias).
- **Pass 조건:** `worst_mdd`가 유효한 음수 값으로 산출될 것.

#### P3. [Universe] Tech/Healthcare 유동성 필터 강화 (Degenerate Folds 해결 시도 1)
- **Why:** 폴드 붕괴는 대부분 거래 정지 종목, 초소형주, 또는 데이터 오류가 있는 티커를 매매하려다 발생.
- **Risk:** 유니버스 축소로 인한 기회비용.
- **Pass 조건:** Degenerate Folds 개수가 2개 이하로 감소.

#### P4. [Strategy] 변동성 기반 노출도 동적 제한 (Target Volatility)
- **Why:** Exposure Max 0.84가 특정 하락장(Degenerate Folds 구간)에서 MDD를 감당 못하고 터졌을 가능성.
- **Risk:** 상승장에서 수익률 저하.
- **Pass 조건:** OOS Min 값이 개선(-0.02 -> -0.01 이상)되거나 MDD 안정화.

#### P5. [Cost] 슬리피지/수수료 강제 주입 스트레스 테스트
- **Why:** 현재 OOS Mean 3.32는 비현실적. 비용 미반영(Cost Undercounting) 가능성 99%.
- **Risk:** 수익률 급락으로 기존 챔피언 폐기.
- **Pass 조건:** 비용 반영 후에도 Sharpe Ratio > 1.5 유지.

### 2. 실행 가능한 Patch/실험 (48시간 루프)

다음 명령형 체크리스트를 순차적으로 실행.

#### 실험 A: 데이터 무결성 및 로깅 포맷 표준화
1.  **실험 정의:**
    - 모든 Rebalance 로그를 `JSONL` 포맷으로 통일하고, 파일명에 타임스탬프 강제.
    - 백테스트 엔진에서 `returns.replace([np.inf, -np.inf], 0).fillna(0)` 처리 추가.
    - 데이터 로더에서 `Volume=0`인 구간이 3일 이상 지속되면 해당 티커 제외.
2.  **게이트:**
    - `python3 experiment_system/tools/aub_rebalance_pinpoint.py` 실행 시 Exit Code 0.
    - `worst_mdd` is not None.
3.  **기대 관측치:**
    - 로그 파싱 성공.
    - MDD 수치 확인 (아마도 -0.2 ~ -0.4 수준으로 현실화될 것).

#### 실험 B: 유니버스 정제 (Liquid Tech/Healthcare Only)
1.  **실험 정의:**
    - **Filter:** `Sector in ['Technology', 'Healthcare']` AND `AvgVolume(20d) > 10M USD`.
    - **Count:** 상위 시가총액 14개 고정 (ETF 제외).
    - **Constraint:** 개별 종목 비중 최대 20% 제한 (Hard Cap).
2.  **게이트:**
    - Degenerate Folds 목록에서 [1, 2, 3, 8] 중 2개 이상 제거.
3.  **기대 관측치:**
    - OOS Mean 하락(3.3 -> 1.5 수준) 그러나 신뢰도 상승.
    - Degenerate Folds 해결.

#### 실험 C: 하락장 방어 기제 (Regime Filter)
1.  **실험 정의:**
    - **Indicator:** `SPY` 200일 이평선 하회 시, 전체 Exposure를 기존의 50%로 강제 축소 (0.84 -> 0.42).
    - **Logic:** `if SPY_Close < SPY_MA200: target_weights *= 0.5`
2.  **게이트:**
    - OOS Min > -0.05 (Drawdown 방어).
3.  **기대 관측치:**
    - MDD가 개선되며, 남은 Degenerate Folds가 정상화됨.

### 3. 성능 정체(Stagnation) 시 원인 분해 트리거

성능 지표가 움직이지 않거나(Flatline), 이상 수치가 계속될 때 다음 순서로 디버깅.

1.  **Trigger (신호 발생 여부):**
    - "매매 시그널 자체가 생성되고 있는가?"
    - 확인: `prediction_score`의 표준편차가 0에 가까운지 체크 (Model Collapse).

2.  **Allocation (최적화기 작동 여부):**
    - "시그널은 있는데 비중이 0인가?"
    - 확인: 최적화 제약조건(Min Weight, Max Volatility)이 너무 타이트하여 해(Solution)가 `All Cash`로 수렴했는지 확인.

3.  **Execution (체결 거부):**
    - "주문은 나갔는데 데이터 문제로 취소되었는가?"
    - 확인: 백테스트 로그에서 `Order Rejected` 또는 `Delisted` 메시지 그렙(grep).

4.  **Cost (비용 잠식):**
    - "벌었는데 비용으로 다 나갔는가?"
    - 확인: `Gross Return` vs `Net Return` 괴리율 확인. 회전율(Turnover)이 일 20%를 초과하면 수수료 과다.

5.  **Regime (국면 불일치):**
    - "전략이 횡보장에서만 작동하는데 지금이 추세장인가?"
    - 확인: 시장(SPY/QQQ) 변동성과 전략 수익률 간의 상관관계(Rolling Correlation) 변화 관측.
