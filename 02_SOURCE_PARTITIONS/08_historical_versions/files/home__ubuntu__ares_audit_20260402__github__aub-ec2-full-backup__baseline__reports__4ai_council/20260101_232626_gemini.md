### 2. 세부 제안 (실행 가능한 Patch/실험)

#### 제안 A: [비용 현실화] Transaction Cost & Slippage Injection
*   **이유:** `exp_mrd_fsa`의 Lockbox Min 양수(0.33)는 비용 미반영 단타 매매일 확률 90% 이상. 실제 체결 오차 반영 시 마이너스 전환 가능성 높음.
*   **위험:** 모든 전략의 기대 수익률이 급락하여 '배포 불가' 판정될 수 있음(그러나 이는 진실임).
*   **실험 설계 (48h Loop):**
    1.  **실험 정의:** 기존 로직 유지하되, 매매 건당 `Spread 10bps + Comm 5bps` 강제 차감. 유동성 하위 20% 종목은 `30bps` 차감.
    2.  **게이트(Pass 조건):** 비용 반영 후에도 `Lockbox Sharpe > 1.0` AND `Worst MDD > -8%`.
    3.  **기대 관측치:** 기존 Candidate의 수익률 30~50% 감소 예상. 여전히 Champion보다 우위라면 승인.

#### 제안 B: [데이터 오염 제거] Strict Lag Enforcer
*   **이유:** 튜닝 때는 망가졌는데(-1.49), 락박스에서만 완벽한(0.33) 경우, 특정 피처가 미래 정보를 포함했을 가능성 큼.
*   **위험:** 주요 알파 팩터(예: 변동성 돌파 등)가 시점 문제로 무효화되어 전략 로직 자체가 붕괴될 수 있음.
*   **실험 설계 (48h Loop):**
    1.  **실험 정의:** 모든 OHLCV 및 보조지표 입력 데이터를 `shift(1)` 강제 적용. 당일 시가(Open) 진입 로직이라면 전일 종가 데이터만 참조하도록 코드 레벨 락(Lock) 설정.
    2.  **게이트(Pass 조건):** `Candidate Performance Decay < 20%` (수익률 하락폭이 20% 이내여야 함).
    3.  **기대 관측치:** 만약 수익률이 마이너스로 전환된다면 기존 모델은 폐기(Discard).

#### 제안 C: [유니버스 압축] Tech/Healthcare "Blue Chip" Only
*   **이유:** `exp_mrd_fsa`가 소형 바이오주의 급등락을 과최적화했을 가능성 차단. 서바이버십 바이어스 방지.
*   **위험:** 종목 풀이 좁아져(8~14개) 분산 효과 감소, MDD 일시 증가 가능.
