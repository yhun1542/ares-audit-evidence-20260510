## 2. 성능 미움직임 시 원인 분해 트리

```
성능 변화 없음
├── (1) 트리거 미작동
│   └── 체크: 신규 로직의 조건 충족 횟수 로깅 → 0회면 threshold 과격
│
├── (2) 적용되었으나 상쇄
│   └── 체크: 개선 구간 vs 악화 구간 분해 → 서로 +/- 상쇄 확인
│
├── (3) 노출 부족
│   └── 체크: 해당 로직 적용 가능 구간이 전체 기간의 <10%
│
├── (4) 비용이 효과 상쇄
│   └── 체크: 거래 횟수 증가분 × 비용 > 수익 개선분
│
└── (5) 레짐 불일치
    └── 체크: tuning 구간과 lockbox 구간의 레짐 분포 상이
```
