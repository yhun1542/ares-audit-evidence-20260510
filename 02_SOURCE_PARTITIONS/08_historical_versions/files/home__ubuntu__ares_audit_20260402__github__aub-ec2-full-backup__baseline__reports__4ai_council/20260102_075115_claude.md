## 우선순위 TOP 5 실행 패치

### PATCH 1: MDD 계측 누락 수정 (Critical)

**WHY**
- `worst_mdd: None` → 리스크 게이트 무력화 상태
- 실제 운영 시 drawdown 20%+ 발생해도 감지 불가

**RISK/SIDE-EFFECT**
- MDD 계산 방식(일간 vs 고점대비) 불일치 시 백테스트와 실운영 괴리
- 계산 부하 미미 (무시 가능)

**EXPERIMENTS**
| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 1a | `worst_mdd` 필드에 고점대비 MDD 계산 로직 삽입 | 빌드 통과 + 값 ≠ None | MDD 10~25% 범위 출력 |
| 1b | 전 fold MDD 분포 히스토그램 출력 | 모든 fold MDD ≤ 30% | 이상치 fold 식별 |

**PASS 조건**
```
worst_mdd IS NOT None AND worst_mdd ≤ 0.25
```

### PATCH 2: OOS Min 0.43 Fold 해부

**WHY**
- OOS Mean 1.88 대비 Min 0.43 → 특정 레짐에서 전략 붕괴
- 서바이버십 의심: "좋은 fold만 평균 끌어올림"

**RISK/SIDE-EFFECT**
- 해당 fold 제거 유혹 → 과최적화 함정
- 원인이 데이터 품질이면 허위 경보

**EXPERIMENTS**
| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 2a | Min fold 기간 추출 → 레짐 라벨링 (VIX>25 / 금리급등 / 섹터로테이션) | 라벨 1개 이상 부착 | 원인 후보 특정 |
| 2b | 해당 기간 exposure·종목 집중도 로그 | exposure < 30% 또는 단일종목 > 40%면 경고 | 집중 리스크 여부 |
| 2c | Min fold 제외 후 OOS Mean 재계산 | Mean 변동폭 < 0.3 | 제거 없이도 robust 확인 |

**PASS 조건**
```
원인 라벨 식별 AND 제거 없이 Mean 유지
```

### PATCH 3: 거래비용·슬리피지 반영 검증

**WHY**
- 현재 비용 미반영 시 실거래 Sharpe 0.3~0.5 하락 통상적
- Tech 대형주 슬리피지 낮지만, Healthcare 중소형 주의

**RISK/SIDE-EFFECT**
- 비용 과다 추정 → 매매 빈도 과소 (under-trading)
- 비용 과소 추정 → 실전 수익 괴리

**EXPERIMENTS**
| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 3a | 왕복 20bp 비용 삽입 후 OOS Mean 재계산 | OOS Mean ≥ 1.5 | 비용 후에도 edge 유지 |
| 3b | 연간 turnover 계산 | turnover ≤ 12x (월1회 리밸) | 과매매 아님 확인 |

**PASS 조건**
```
cost_adjusted_oos_mean ≥ 1.50 AND turnover ≤ 12
```

### PATCH 4: 레짐 필터 추가 실험

**WHY**
- OOS Min fold가 특정 레짐이면, 레짐 감지→현금 전환 로직 필요
- VIX 스파이크 / 금리 급등 구간 노출 축소

**RISK/SIDE-EFFECT**
- 레짐 정의 후행성 → 실시간 감지 지연
- 현금 전환 과다 시 상승장 수익 누락

**EXPERIMENTS**
| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 4a | VIX > 28 시 exposure 50% 강제 cap | OOS Min ≥ 0.7 | 최악 fold 개선 |
| 4b | 10Y 금리 20일 변동 > 50bp 시 Healthcare 비중 ↓30% | 섹터 MDD 개선 | Healthcare 단독 MDD ≤ 20% |

**PASS 조건**
```
oos_min ≥ 0.70 AND 레짐 필터 적용 fold에서 MDD ≤ 0.20
```

### PATCH 5: 홀드아웃 Fold 신선도 점검

**WHY**
- lane_hash / run_hash 존재하나 최신 데이터 반영 여부 불명
- 2024-2025 데이터 누락 시 레짐 변화 미반영

**RISK/SIDE-EFFECT**
- 데이터 업데이트 시 기존 파라미터 무효화 가능
- 갱신 주기 잦으면 오버헤드

**EXPERIMENTS**
| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| 5a | OOS fold 종료일 확인 → 최신일 기준 90일 이내 | 최신 fold 종료일 ≥ 2024-10-01 | 데이터 신선 |
| 5b | 2024-Q4 데이터 추가 후 walk-forward 1회 재실행 | OOS Mean 변동 < 0.3 | 안정성 확인 |

**PASS 조건**
```
latest_fold_end ≥ 2024-10-01 AND delta_oos_mean < 0.30
```
