## 3. 성능 정체 원인 분해 트리

```
lockbox 개선 無
├─ [트리거 문제] signal이 실제 미래 수익과 무관
│   └─ 검증: IC t-stat < 2 → signal 교체 필요
│
├─ [적용 문제] signal → position 변환 로직 오류
│   └─ 검증: signal 상위 decile vs 하위 decile 수익 차이 < 1%
│
├─ [노출 문제] position size가 conviction 미반영
│   └─ 검증: high-conviction 종목 weight < 평균 weight
│
├─ [비용 문제] 거래비용이 alpha 초과
│   └─ 검증: gross return - net return > 50% of alpha
│
└─ [레짐 문제] 특정 시장 환경에서만 작동
    └─ 검증: rolling 12M sharpe 표준편차 > 0.5
```
