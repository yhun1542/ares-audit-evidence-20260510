## 1. 우선순위 TOP 5 제안

### P1. Champion 과최적화 해부 (Critical)

**(a) 왜 필요한지**
- tuning(2.32) < lockbox(4.01) 역전은 일반적이지 않음
- tuning fold 내 특정 구간에서 과도한 손실 회피 → lockbox에서 우연히 맞았을 가능성

**(b) 위험/부작용**
- Champion 폐기 시 baseline 리셋 필요
- 검증 지연 24h+

**(c) 최소 실험**

| ID | 실험 | Gate |
|----|------|------|
| P1-A | Champion을 fold 1-10만으로 재학습, fold 11-14 OOS 테스트 | OOS mean > 1.5 AND MDD > -10% |
| P1-B | Candidate를 새 Champion으로 승격, 48h paper trade | Sharpe diff < 0.3 vs backtest |
| P1-C | Champion 파라미터 ±20% perturbation → 성능 분산 측정 | σ(returns) < 0.5 |

**(d) PASS 조건**
```
IF P1-A OOS_mean < 1.0 OR P1-C σ > 0.8:
    DEMOTE champion → archive/
    PROMOTE candidate → champion_v6
```

**(b) 위험/부작용**

**(c) 최소 실험**

|----|------|------|
| P2-A | 슬리피지 5bp + 커미션 0bp 적용 후 전체 재계산 | tuning_mean > 1.0 유지 |

**(c) 최소 실험**

## 2. 48h 자동 루프 스펙

```yaml
# experiment_batch_20260103.yaml
experiments:
  - id: P1-A
    script: tools/retrain_champion.py --folds 1-10 --oos 11-14
    gate: oos_mean > 1.5 AND oos_mdd > -0.10
    timeout: 4h
    
  - id: P2-A
    script: tools/cost_adjustment.py --slip 0.0005 --comm 0
    gate: tuning_mean > 1.0
    timeout: 1h
    
  - id: P3-A
    script: tools/regime_filter.py --vix-threshold 25 --cash-pct 0.5
    gate: fold14_mdd > -0.03
    timeout: 2h
    
  - id: P3-C
    script: tools/merge_modules.py --source candidate_macro --target champion
    gate: lockbox_min > 1.0
    timeout: 2h
    
  - id: P4-A
    script: tools/position_cap.py --max-single 0.15
    gate: sharpe_delta > -0.15
    timeout: 1h

on_all_pass:
  - promote best → champion_v6
  - archive current champion
  
on_any_fail:
  - log failure reason
  - continue remaining
```
