### [성능 정체 원인 분해 아이디어]

현재 성능이 움직이지 않는다면 다음 5가지 요소를 순차적으로 점검하십시오.

1.  **트리거(Trigger) 부재**: 시장 변동성이 낮아 '극단적' 조건(Deep Value, Crash 등)이 만족되지 않음 -> *Action: 진입 조건 완화.*
2.  **적용(Application) 실패**: 코드상 로직은 있으나, 자산 배분 가중치(Weight)가 0.001 미만으로 할당되어 실질적 영향 없음 -> *Action: 최소 가중치(Min Weight) 강제 설정.*
3.  **노출(Exposure) 상쇄**: 롱(Long) 시그널과 숏/헷지(Short/Hedge) 시그널이 동시에 발생하여 Net Exposure가 중립화됨 -> *Action: 시그널 우선순위(Priority) 지정.*
4.  **비용(Cost) 장벽**: 수익이 발생했으나 수수료/슬리피지 모델이 이를 모두 깎아먹음 -> *Action: 거래 횟수 제한 또는 지정가(Limit Order) 로직 시뮬레이션.*
5.  **레짐(Regime) 불일치**: 훈련 데이터의 레짐과 검증 데이터의 레짐이 정반대 -> *Action: 훈련 기간에 최근 6개월 데이터 가중치 부여 (Recency Bias 활용).*
