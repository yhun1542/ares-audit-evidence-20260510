## 2. 성능 미변동 원인 분해 트리 (디버깅용)

```
성능 안 움직임
├─ [트리거 문제] 시그널이 안 나옴
│   ├─ 조건 너무 strict → 완화 실험
│   └─ 데이터 피드 오류 → 최근 데이터 NaN 체크
│
├─ [적용 문제] 시그널 나와도 포지션 미반영
│   ├─ 자금 부족 (sizing 로직) → cash_buffer 점검
│   └─ 동시 시그널 충돌 → 우선순위 로직 점검
│
├─ [노출 문제] 포지션 잡혔으나 리턴 미발생
│   ├─ 레짐 미스매치 → 최근 6개월 시장 vs 전략 상관
│   └─ 보유 기간 너무 짧음 → holding period 늘리기 실험
│
├─ [비용 문제] 그로스 수익 있으나 비용에 먹힘
│   ├─ 슬리피지 과대 → 실제 체결 데이터 비교
│   └─ turnover 과다 → 필터 강화
│
└─ [레짐 문제] 전략 가정 레짐이 현재 없음
    ├─ 모멘텀 전략인데 choppy 장 → VIX/ADX 레짐 필터
    └─ 밸류 전략인데 그로스 장 → 스타일 로테이션 점검
```

## 3. 48시간 자동 루프 통합 스크립트

```bash
#!/bin/bash
# run_48h_patches.sh

set -e
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
LOG="baseline/reports/patch_log_${TIMESTAMP}.md"

echo "# 48h Patch Run - ${TIMESTAMP}" > $LOG

# PATCH-1: 폴드 진단
echo "## PATCH-1: Fold Inspector" >> $LOG
python3 tools/fold_inspector.py --champion baseline/champion_v5_20251231.json --metric tuning_min --dump-trades >> $LOG 2>&1

# PATCH-2: 비용 민감도
echo "## PATCH-2: Cost Sensitivity" >> $LOG
python3 tools/cost_sensitivity.py --champion baseline/champion_v5_20251231.json --slippage 0.002 >> $LOG 2>&1

# PATCH-3: 레짐 분해
echo "## PATCH-3: Regime Decompose" >> $LOG
python3 tools/regime_decompose.py --champion baseline/champion_v5_20251231.json --split yearly >> $LOG 2>&1

# PATCH-4: Attribution
echo "## PATCH-4: Attribution" >> $LOG
python3 tools/attribution.py --champion baseline/champion_v5_20251231.json --exclude-top 3 >> $LOG 2>&1

# PATCH-5: Signal Frequency
echo "## PATCH-5: Signal Frequency" >> $LOG
python3 tools/signal_frequency.py --champion baseline/champion_v5_20251231.json >> $LOG 2>&1

# 기존 autopilot 유지
python3 experiment_system/tools/aub_autopilot.py --registry experiment_system/config/module_registry.yaml --run --select-best
python3 experiment_system/tools/system_autopilot.py --spec experiment_system/config/system_candidates.yaml --run
python3 experiment_system/tools/aub_next_fix.py --registry experiment_system/config/module_registry.yaml --output baseline/reports/next_fix.md

echo "## COMPLETE" >> $LOG
```
