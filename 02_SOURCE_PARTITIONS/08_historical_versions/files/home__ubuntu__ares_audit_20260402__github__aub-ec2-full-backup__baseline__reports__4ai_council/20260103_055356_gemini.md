*   **(b) 위험:** 챔피언 모델이 즉시 폐기될 수 있음(성능 급락). 그러나 이는 '거짓 양성'을 제거하는 필수 과정.
*   **(c) 실행 실험 (Patch):**

    2.  **[EXP-DELAY-01]** Execution Delay 1-tick 강제 (Signal $t$ -> Trade $t+1$ Open).
    3.  **[EXP-SLIP-01]** Volatility 기반 Slippage 모델 적용 (ATR * 0.05 페널티 부과).

*   **(c) 실행 실험 (Patch):**
    1.  **[EXP-THRESH-LO]** 진입 임계값(Threshold) 20% 하향 조정 (예: 0.7 -> 0.56).
