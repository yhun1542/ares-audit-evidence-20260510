### 3. 성능 정체 원인 분해 (Diagnosis Tree)

성능이 움직이지 않거나 Degenerate 상태가 지속될 경우 다음 트리를 따라 점검:

1.  **트리거(Trigger) 부재:**
    *   *현상:* Tech/Healthcare 섹터가 횡보할 때 신호가 안 뜸.
    *   *해결:* 상대 모멘텀(Relative Momentum vs SPY) 대신 절대 모멘텀 혹은 평균 회귀(Mean Reversion) 로직 혼합 고려.
2.  **노출(Exposure) 제한:**
    *   *현상:* `Exposure Max`가 0.84로 제한적임. 현금을 너무 많이 들고 있음.
    *   *해결:* 시장 변동성(VIX 등)이 낮을 때 레버리지(1.0~1.2x) 허용 여부 점검 (단, 이번엔 Tech/Health 1배수 집중).
3.  **비용(Cost) 과다 평가:**
    *   *현상:* 잦은 리밸런싱으로 수수료가 수익을 갉아먹어 로직이 매매를 포기하게 최적화됨.
    *   *해결:* 리밸런싱 주기를 주간(Weekly) -> 월간(Monthly) 혹은 '임계치 기반(Threshold Rebalancing)'으로 변경.
4.  **레짐(Regime) 불일치:**
    *   *현상:* Fold 1,2,3,8이 하락장 혹은 급등락장임.
    *   *해결:* ETF(XLK, XLV)를 관측 지표로 삼아, 섹터 전체 하락 시 현금 비중 100%로 전환하는 'Regime Cut' 로직이 정상 작동하는지 확인(오히려 너무 빨리 도망가서 수익 기회를 놓치는 것일 수도 있음).
