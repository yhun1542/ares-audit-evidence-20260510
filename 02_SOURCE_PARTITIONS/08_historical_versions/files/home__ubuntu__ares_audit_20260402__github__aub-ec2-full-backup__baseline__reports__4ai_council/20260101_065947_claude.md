## 1. 우선순위 TOP-5 액션

### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### PATCH-1: 실험 적용 누수 점검 (Data Leakage Audit)
### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요**
- lockbox 결과가 Champion/Candidate 간 **byte-identical** → 실험 코드가 lockbox 경로에 실제 적용 안 됐을 가능성

**(b) 위험/부작용**
- 버그 발견 시 기존 모든 실험 결과 무효화 리스크
- 수정 후 전체 재실행 필요 (시간 비용)

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| L1 | `candidate.json`의 변경된 파라미터가 backtest 로그에 출력되는지 확인 | 로그에 파라미터 diff 존재 | diff 출력 or "적용 안 됨" 메시지 |
| L2 | lockbox fold 1개에 dummy 시그널(all-cash) 강제 주입 후 결과 변화 확인 | 결과가 기존과 **달라야** 함 | CAGR ≠ 1.793 |
| L3 | `hash(config)` → backtest 결과 매핑 테이블 생성, 중복 여부 확인 | 동일 config → 동일 결과 | 1:1 매핑 or 버그 탐지 |

**(d) PASS 조건**
```
L2에서 all-cash 주입 시 lockbox_mean이 1.0 ± 0.05로 변경되면 PASS
→ 적용 경로 정상 확인
```

### PATCH-2: 노출(Exposure) 부족 진단
### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**(a) 왜 필요**
- 실험이 적용되어도 **트리거 빈도가 너무 낮으면** 결과에 영향 無
- MRD/ARS/FSA 모듈이 lockbox 기간에 발동 안 됐을 수 있음

**(b) 위험/부작용**
- 노출 늘리면 과적합 리스크 증가
- 거래 비용/슬리피지 증가

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| E1 | 각 모듈별 트리거 횟수 로그 추가: `{module: count, dates: [...]}` | lockbox 기간 트리거 ≥ 10회 | 모듈별 count 출력 |
| E2 | FSA threshold 50%→30% 완화 후 트리거 증가 확인 | 트리거 2x 이상 증가 | count diff ≥ 2x |
| E3 | ARS 발동 조건 `-5%→-3%` 완화 후 결과 변화 | lockbox 결과 변동 | mean diff ≥ 0.02 |

**(d) PASS 조건**
```
E1에서 lockbox 기간 총 트리거 ≥ 50회 확인되면 노출 충분
→ 미달 시 E2/E3 실행
```

### PATCH-3: 비용 미반영 점검 (Cost Reality Check)

**(b) 위험/부작용**
- 비용 현실화 시 모든 전략 성능 하락

| ID | 실험 정의 | 게이트 | 기대 관측치 |

## 3. 성능 미동 원인 분해 트리

```
lockbox 결과 동일
├── [1] 트리거 문제
│   ├── 조건 미충족 (threshold 너무 높음)
│   └── 데이터 불일치 (indicator 계산 오류)
│
├── [2] 적용 문제
│   ├── config 로딩 실패 (경로/파싱 오류)
│   ├── 분기 로직 버그 (if 조건 오타)
│   └── 캐시 오염 (이전 결과 재사용)
│
├── [3] 노출 문제
│   ├── 발동 빈도 ≤ 5회/년 (통계적 무의미)
│   └── 포지션 크기 미미 (1% 미만 allocation)
│
├── [4] 비용/슬리피지
│   ├── 비용 미반영 (0bps 설정)
│   └── 시장 영향 미반영 (대형주 가정)
│
└── [5] 레짐/시장
    ├── lockbox 기간이 특수 (저변동/고변동 편중)
    └── 섹터 편향 (Tech만 상승장)
```
