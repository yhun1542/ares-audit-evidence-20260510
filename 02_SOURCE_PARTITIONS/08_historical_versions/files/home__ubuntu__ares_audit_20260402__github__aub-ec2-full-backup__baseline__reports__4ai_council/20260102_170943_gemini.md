현재 Champion(v5)은 Lockbox 성능(4.01)이 Tuning(2.32)보다 월등히 높아 **과최적화(Overfitting) 또는 특정 구간의 행운(Luck)**이 의심됩니다. 반면 Candidate(shadow)는 Tuning Min이 양수(+)로 방어력이 더 뛰어납니다. 다음 48시간은 **'수익률 챔피언의 검증'과 '섹터 편중 리스크 제어'**에 집중해야 합니다.

### 1. 24~48시간 우선순위 TOP 5 (명령형 체크리스트)

1.  **[검증] Champion v5 스트레스 테스트**: 슬리피지(Slippage) 2배, 수수료(Fee) 1.5배 적용 후에도 Tuning Min > -0.05 유지하는지 확인.
2.  **[로직] Tech/Bio 섹터 밸런싱 강제**: 포트폴리오(8~14종목) 구성 시 Tech와 Healthcare 비중이 최소 3:7 ~ 7:3 범위 내에 있도록 제약 조건 추가.
3.  **[신호] ETF 레짐 필터 도입**: `XLK`(Tech), `XLV`(Health)의 20일 이동평균 하회 시 해당 섹터 개별주 매수 금지(Cash 비중 확대).
4.  **[데이터] 서바이버십 바이어스 제거**: 최근 상장 폐지되거나 M&A된 바이오/테크 종목이 유니버스에 포함되어 백테스트 되었는지 점검(데이터 클리닝).
5.  **[비용] 회전율(Turnover) 캡 설정**: 일간 포트폴리오 교체율이 20%를 넘지 않도록 Penalty Term 추가 (과도한 리밸런싱 방지).

### 2. 제안별 실행 상세 (실험/게이트/관측)

#### 제안 A: ETF Trend Following Regime Filter (방어기제 강화)
*   **(a) 필요성**: Tech/Bio는 금리 및 투심에 민감. 개별 종목이 좋아 보여도 섹터 전체가 하락세면 확률이 낮음. ETF 매매는 안 하지만, 지표로 활용하여 '소나기'를 피해야 함.
*   **(b) 리스크**: 추세 전환 시그널이 늦어(Lagging), 반등 초입을 놓칠 수 있음(Whipsaw).
*   **(c) 실험 설계**:
    1.  `Exp_Regime_Tight`: XLK/XLV가 MA20 아래면 해당 섹터 비중 0% (All Cash).
    2.  `Exp_Regime_Loose`: XLK/XLV가 MA60 아래면 해당 섹터 비중 50% 축소.
    3.  `Exp_Regime_Relative`: XLK vs SPY 상대모멘텀이 음수면 Tech 비중 축소.
*   **(d) PASS 조건**:
    *   Fold14 MDD 개선 (기존 -0.039보다 0에 가깝게).
    *   Lockbox Min > 1.0 유지.

#### 제안 B: Cost & Slippage Stress Test (거품 제거)
*   **(a) 필요성**: Champion v5의 Lockbox 수익률(4.01)이 비현실적일 가능성 높음. 실제 체결 오차를 반영해 '진짜 알파'인지 확인 필요.
*   **(b) 리스크**: 모든 전략이 탈락하여 Champion이 공석이 될 수 있음 (그러나 이는 필요한 고통임).
*   **(c) 실험 설계**:
    1.  `Exp_Stress_HighFee`: 거래당 비용 10bp -> 20bp 상향.
    2.  `Exp_Stress_Lag`: 매수/매도 신호 발생 후 '다음 날 시가(Open)'가 아닌 '다음 날 종가(Close)' 혹은 'VWAP' 체결 가정.
    3.  `Exp_Vol_Penalty`: 변동성 상위 10% 종목(주로 바이오) 매매 시 슬리피지 2배 적용.
*   **(d) PASS 조건**:
    *   Tuning Mean이 1.5 이상 유지.
    *   Worst MDD가 -15%를 넘지 않음.

#### 제안 C: Dynamic Correlation Filtering (공멸 방지)
*   **(a) 필요성**: Tech와 Bio가 동시에 무너지는 날이 있음. 포트폴리오 내 종목 간 상관계수가 너무 높으면 분산 효과가 없음.
*   **(b) 리스크**: 상관계수가 낮은 종목을 찾다가 수익성 낮은 종목(Laggard)을 편입할 수 있음.
*   **(c) 실험 설계**:
    1.  `Exp_Corr_Cap`: 기존 보유 종목과 상관계수 0.7 이상인 신규 종목 매수 금지.
    2.  `Exp_Beta_Neutral`: 포트폴리오 가중 평균 베타가 1.2를 넘지 않도록 비중 조절.
*   **(d) PASS 조건**:
    *   Sharpe Ratio 상승 (변동성 대비 수익률 개선).
    *   Lockbox Min 값이 Candidate 수준(1.34)으로 접근.

### 3. 성능 정체 시 원인 분해 아이디어

만약 위 실험 후에도 성능(특히 Stability)이 개선되지 않는다면 다음 트리를 점검하십시오.

1.  **트리거(Trigger) 문제인가?**
    *   *증상*: 매매 횟수가 너무 적거나(주당 1회 미만), 너무 많음(일간 50% 교체).
    *   *해결*: 진입 임계값(Threshold)을 절대값이 아닌 '유동적 백분위(Percentile)'로 변경 (예: 상위 5% 점수 종목만 매수).

2.  **노출(Exposure) 문제인가?**
    *   *증상*: 수익 날 때는 찔끔, 손실 날 때는 왕창 (Skewness 문제).
    *   *해결*: 종목당 최대 비중(Max Weight)을 15% -> 10%로 축소하고, 현금 비중(Cash Buffer)을 항상 10% 이상 유지하도록 강제.

3.  **레짐(Regime) 불일치인가?**
    *   *증상*: 백테스트 기간 중 특정 연도(예: 2022년 하락장)에만 처참하게 깨짐.
    *   *해결*: 하락장 방어 로직(Trailing Stop)을 개별 종목 레벨이 아닌 '포트폴리오 전체 자산' 레벨에 적용 (Drawdown 5% 발생 시 강제 청산 후 3일 휴식).
