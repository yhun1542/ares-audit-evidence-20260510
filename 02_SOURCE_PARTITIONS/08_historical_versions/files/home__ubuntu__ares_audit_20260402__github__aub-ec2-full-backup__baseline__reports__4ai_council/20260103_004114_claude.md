## 1. 우선순위 TOP 5 액션

### P1. 계측 인프라 복구 (MUST-FIX)

**(a) 왜 필요한지**
- MDD=None, rebalance 로그 미존재 → 실제 리스크/비용 계산 불가
- OOS 수치 불일치(3.32 vs 2.63) → 어느 것이 진실인지 모름
- 이 상태에서 전략 실험은 의미 없음

**(b) 위험/부작용**
- 계측 추가 시 백테스트 속도 10~20% 저하
- 로그 포맷 변경 시 기존 분석 스크립트 호환성 깨짐

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P1-1 | `backtest.py`에 MDD 트래킹 추가, 폴드별 출력 | 10개 폴드 모두 MDD 숫자 출력 | worst_mdd ≠ None |
| P1-2 | rebalance 이벤트 JSONL 로거 삽입 | 파일 생성 + 파싱 성공 | `aub_rebalance_pinpoint.py` 정상 실행 |
| P1-3 | OOS 수치 소스 추적: handoff vs diagnoser 비교 | 둘 중 하나 버그 식별 | 단일 OOS 값 확정 |

**(d) PASS 조건**
```
✅ worst_mdd: float (not None)
✅ rebalance_pinpoint.py 정상 출력
✅ OOS Mean 단일값 확정 (delta < 0.01)
```

### P2. Degenerate Fold 원인 분해

**(a) 왜 필요한지**
- 40% 폴드 퇴화 = 모델이 특정 레짐에서 "포기" 상태
- 과최적화 vs 레짐 불일치 vs 시그널 자체 문제 구분 필요

**(b) 위험/부작용**
- 폴드별 분석은 시간 소모적
- 폴드 구조 변경 시 기존 결과와 비교 불가

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P2-1 | 퇴화 폴드(1,2,3,8) 기간 추출 → 시장 레짐 태깅 (VIX, SPY drawdown) | 레짐 레이블 생성 | 공통 패턴 유무 |
| P2-2 | 퇴화 폴드에서 exposure=0 비율 계산 | 수치 출력 | >80%면 시그널 부재, <50%면 손실 회피 |
| P2-3 | 정상 폴드(4,5,6,7,9,10) 파라미터 → 퇴화 폴드 적용 | OOS 비교 | 개선 시 과적합, 불변 시 레짐 문제 |

**(d) PASS 조건**
```
✅ 퇴화 원인 분류: {과적합 | 레짐불일치 | 시그널부재} 중 확정
✅ 최소 1개 폴드 퇴화 해제 (exposure > 0.3 & return > 0)
```

### P3. 비용/슬리피지 현실화 점검

**(a) 왜 필요한지**
- rebalance 빈도 미확인 상태 → 회전율 비용 반영 여부 불명
- 실제 운영 시 OOS 성능 급락 가능

**(b) 위험/부작용**
- 비용 상향 시 OOS 악화 → 심리적 저항
- 과도한 비용 가정은 유효 전략도 폐기

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P3-1 | 현재 비용 파라미터 추출 및 문서화 | 코드에서 값 확인 | cost_bps = ? |
| P3-2 | 비용 2배 시나리오 백테스트 | OOS 재계산 | OOS delta 측정 |
| P3-3 | 연간 회전율 계산 (P1-2 로그 활용) | turnover_annual 출력 | 실제 비용 = turnover × cost_bps |

**(d) PASS 조건**
```
✅ 비용 2배에서도 OOS > 1.5
✅ 연간 회전율 < 500% (과다 매매 아님)
```

### P4. Exposure 0 구간 분석

**(a) 왜 필요한지**
- exposure_min = 0.0 → 현금 100% 구간 존재
- 의도된 헷지인지, 시그널 실패인지 구분 필요

**(b) 위험/부작용**
- 현금 구간 제거 시 MDD 악화 가능
- 강제 노출은 레짐 무시 위험

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P4-1 | exposure=0 구간 날짜 추출 | 리스트 출력 | 시장 상황 대조 |
| P4-2 | 최소 노출 10% 강제 (floor=0.1) | OOS & MDD 비교 | 트레이드오프 측정 |

**(d) PASS 조건**
```
✅ exposure=0이 방어적 판단인 경우: 해당 구간 SPY < -5%
✅ 또는 floor=0.1에서 MDD 악화 < 5%p
```

## 2. 성능 불변 시 원인 분해 트리

```
성능이 안 움직인다
│
├─ [트리거] 시그널이 발생 안 함
│   ├─ 조건 너무 엄격 → threshold 완화 실험
│   └─ 입력 데이터 문제 → 피처 분포 점검
│
├─ [적용] 시그널 → 포지션 전환 실패
│   ├─ rebalance 주기 너무 김 → 빈도 확인
│   └─ 사이즈 로직 버그 → 단위 테스트
│
├─ [노출] 포지션은 있으나 너무 작음
│   ├─ max_exposure 제한 → 파라미터 확인
│   └─ 분산 제약 과다 → 제약 완화 실험
│
├─ [비용] 수익 < 비용
│   ├─ 회전율 과다 → 홀딩 기간 연장
│   └─ 비용 파라미터 비현실적 → 벤치마크 비교
│
└─ [레짐] 현재 시장에서 전략 무효
    ├─ 백테스트 기간 편향 → 롤링 윈도우 분석
    └─ 전략 전제 붕괴 → 펀더멘탈 재검토
```
