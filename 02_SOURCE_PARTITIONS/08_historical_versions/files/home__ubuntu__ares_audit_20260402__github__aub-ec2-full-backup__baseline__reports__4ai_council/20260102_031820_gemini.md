### 1. [긴급] Champion v5 서바이버십/선견 편향 검증
현재 `Champion_v5`의 Lockbox Minimum Return이 1.53으로 비정상적으로 높음. 이는 특정 Fold에서 손실이 전혀 없다는 의미로, 유니버스 구성 시점에서의 '생존 편향(Survivorship Bias)' 또는 '미래 데이터 참조(Look-ahead)'가 강력히 의심됨.

*   **배경:** 8~14개 종목이 현재 시점(2026년) 기준 우량주로만 고정되어 과거를 시뮬레이션했을 가능성 99%.
*   **리스크:** 실제 운영 시 상장폐지/급락 종목을 회피하지 못해 모델 붕괴.
*   **실험 정의:**
    1.  `Exp_Univ_Dynamic`: 유니버스 구성을 고정 리스트가 아닌, '매 월초 시가총액/거래량 상위' 로직으로 동적 변경하여 백테스트 재수행.
    2.  `Exp_Lag_Entry`: 시그널 발생 후 체결을 'Next Open'이 아닌 'Next Close' 또는 'Open + 5min'으로 강제 지연.
    3.  `Exp_Ticker_Shuffle`: Tech/Healthcare 내 임의의 10개 '패자 종목(하락세)'을 강제로 유니버스에 20% 섞어서 테스트.
*   **게이트(PASS 조건):**
    *   `v5` 대비 수익률 하락폭이 40% 이내일 것.
    *   Lockbox Min이 0.0 근처로 내려가더라도, Sharpe > 1.5 유지.
*   **기대 관측치:**
    *   수익률 대폭 하락 예상. 만약 하락하지 않는다면 로직 자체의 견고함 입증.

### 2. 비용 민감도 및 슬리피지 스트레스 테스트
Tech/Bio 섹터의 변동성을 고려할 때, 현재 모델이 비용을 과소평가하고 있을 가능성 점검.

*   **배경:** `candidate_mrd_fsa`가 수익은 낮아도 MDD가 우수한 점은 비용/슬리피지 현실화 시 역전될 수 있는 포인트임.
*   **리스크:** 실제 주문 시 호가 공백으로 인한 수익 급감.
*   **실험 정의:**
    1.  `Exp_Cost_2x`: 왕복 수수료+슬리피지를 기존 설정의 2배(예: 10bps -> 20bps)로 설정.
    2.  `Exp_Vol_Penalty`: ATR이 높은 구간(상위 20%)에서는 진입 비중을 0.5배로 축소하는 로직 추가 (`mrd_fsa`의 안정성 차용).
*   **게이트:**
    *   2배 비용 적용 후에도 Sharpe > 1.2 유지.
    *   Fold14 MDD가 -6%보다 악화되지 않을 것.
*   **기대 관측치:**
    *   `v5`의 회전율(Turnover)이 높다면 성능 붕괴 -> `mrd_fsa` 계열로 피벗 필요.

### 3. 섹터 편중 및 ETF 지표 디커플링 점검
Tech와 Healthcare는 금리/규제에 따라 디커플링되는 경향이 있음. ETF를 단순 지표로만 쓸 때의 괴리 확인.

*   **배경:** XLK(Tech)와 XLV(Healthcare)의 상관관계가 깨지는 구간에서 모델이 한쪽으로 쏠리는지 확인.
*   **리스크:** 특정 섹터 몰빵 후 급락 (MDD -7%가 여기서 발생했을 가능성).
*   **실험 정의:**
    1.  `Exp_Sector_Balancing`: 포트폴리오 내 Tech:Health 비중이 7:3 또는 3:7을 초과하지 않도록 하드 코딩 제약 추가.
    2.  `Exp_Macro_Filter`: SPY(S&P500)가 200일선 아래일 때, 현금 비중 최소 50% 강제 (Long-only 리스크 제어).
*   **게이트:**
    *   Worst MDD가 -5% 이내로 개선될 것.
    *   Lockbox Mean 수익률 희생이 20% 미만일 것.
*   **기대 관측치:**
    *   MDD 개선 효과가 뚜렷할 경우 `v5`에 해당 패치 즉시 적용.

### 4. 아키텍처 단순화 (Feature Selection)
Champion 모델이 과최적화되었을 가능성을 배제하기 위해 Feature 다이어트 수행.

*   **배경:** 현재 `v5`와 `candidate`의 괴리가 큼. `v5`가 노이즈를 학습했을 수 있음.
*   **리스크:** 라이브 트레이딩 시 모델의 예측력이 급격히 사라짐.
*   **실험 정의:**
    1.  `Exp_Top3_Features`: `v5`에서 중요도 하위 50% Feature를 제거하고 상위 3~5개로만 재학습.
    2.  `Exp_Param_Perturbation`: 주요 파라미터(기간, 임계값)에 ±10% 노이즈를 섞어서 100회 몬테카를로 시뮬레이션.
*   **게이트:**
    *   Feature 제거 후에도 `v5` 성능의 85% 이상 유지.
    *   파라미터 노이즈에 대해 성능 분산(Variance)이 낮을 것.
*   **기대 관측치:**
    *   복잡한 파생변수보다 단순 모멘텀/변동성 지표가 더 강건함을 확인.

### 5. `mrd_fsa` (Candidate) 로직의 Champion 이식
안정성이 높은 Candidate(`exp_mrd_fsa`)의 DNA를 Champion에 이식.

*   **배경:** `mrd_fsa`는 MDD 방어력이 좋음(-0.04). 이는 시장 하락기에 숏(Short) 혹은 현금화 로직이 우수함을 의미.
*   **리스크:** 이도 저도 아닌 모델이 될 수 있음.
*   **실험 정의:**
    1.  `Exp_Hybrid_V1`: 상승장(Bull) 판단 시 `v5` 로직, 하락/횡보장 판단 시 `mrd_fsa` 로직 스위칭.
    2.  `Exp_StopLoss_Tight`: `v5`에 `mrd_fsa`의 손절(Stop Loss) 또는 이익실현(Take Profit) 배수 적용.
*   **게이트:**
    *   Worst MDD < -0.05.
    *   Tuning Mean > 2.5 (두 모델의 중간값 이상).
*   **기대 관측치:**
    *   수익 곡선의 변동성이 줄어들며 우상향 각도 유지.

### [성능 정체 원인 분해 아이디어]

만약 위 실험 후에도 성능(Sharpe/MDD)이 개선되지 않거나 정체된다면 다음을 점검할 것.

1.  **트리거(Trigger)의 둔감화:**
    *   *현상:* 매매 횟수가 너무 적거나, 진입 시점이 너무 늦음.
    *   *액션:* ETF(XLK, XLV) 지표의 민감도(Lookback period)를 절반으로 줄여 반응 속도 테스트.
2.  **노출(Exposure)의 비대칭:**
    *   *현상:* 롱 포지션 수익을 숏 포지션 손실이 갉아먹음 (또는 그 반대).
    *   *액션:* Long-Only로 전환 시 성능 비교. Tech/Bio는 장기 우상향 편향이 강함.
3.  **레짐(Regime) 불일치:**
    *   *현상:* 현재 훈련 데이터의 마지막 구간이 횡보장인데, 모델은 추세추종을 고집함.
    *   *액션:* 최근 3개월 데이터에 가중치를 2배 부여하여 재학습(Fine-tuning) 테스트.
4.  **비용(Cost) 구조의 한계:**
    *   *현상:* 총 수익은 좋은데 건당 순이익이 마이너스.
    *   *액션:* 타겟 보유 기간(Holding Period)을 2배로 늘려 거래 비용 희석.
