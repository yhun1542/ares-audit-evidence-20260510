### 3. 성능 정체 원인 분해 아이디어

성능이 움직이지 않거나 Degenerate 상태가 지속될 경우 다음 체크리스트를 순서대로 수행:

1.  **Trigger (신호 발생):**
    *   ETF 지표(SPY, XLK, XLV)가 해당 폴드(1,2,3,8) 기간에 데이터가 존재하는가?
    *   진입 조건(`logic_A and logic_B`)이 너무 엄격하여(AND 조건 과다) `False`만 반환하는가? -> **Action:** OR 조건으로 분리하거나 Threshold 완화.

2.  **Application (주문 집행):**
    *   신호는 떴으나, `position_sizing` 로직에서 변동성 역가중(Volatility Inverse Weighting) 등의 이유로 할당량이 0에 수렴하는가?
    *   현금 비중(`cash_buffer`)이 100%로 강제되는 "Panic Mode" 로직이 오작동 중인가?

3.  **Exposure (유니버스):**
    *   선택된 8~14개 종목 중 해당 기간에 데이터가 `NaN`인 종목이 포함되어 전체 연산을 망가뜨리는가? -> **Action:** `.dropna()` 혹은 `ffill()` 전처리 강화.

4.  **Regime (시장 국면):**
    *   Fold 1,2,3,8이 하락장(Bear Market)인가?
    *   전략이 "Long Only"인데 하락장에서 숏/헷지 없이 현금 관망만 하여 거래가 없는가? -> **Action:** 현금 보유 시 소량의 인버스 ETF(옵셔널) 헤지 또는 Defensive Sector(Health) 비중 강제 상향.
