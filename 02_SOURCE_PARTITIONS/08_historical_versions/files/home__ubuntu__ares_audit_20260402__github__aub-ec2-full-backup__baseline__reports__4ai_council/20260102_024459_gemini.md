## 1. 24~48시간 우선순위 TOP 3 제안 (Checklist)

현재 Champion(v5)의 성과(Sharpe ~2.88)가 비정상적으로 높음. 이는 과최적화 혹은 비용 과소평가 가능성이 매우 큼. 반면 Candidate는 MDD 방어력은 좋으나 수익성이 부족함. 따라서 다음 48시간은 **'Champion의 현실성 검증'**과 **'Candidate의 방어 논리 이식'**에 집중하라.

1.  [ ] **Cost/Slippage Stress Test (비용 민감도 검증):** 현재 Champion 모델에 슬리피지/수수료 모델을 2배~3배 가중하여 재검증.
2.  [ ] **Hybrid Allocation (알파-리스크 분리):** Champion의 시그널(진입/청산)에 Candidate(mrd_fsa)의 포지션 사이징 로직 결합 실험.
3.  [ ] **Sector-Balance Constraint (섹터 쏠림 방지):** Tech와 Healthcare 종목 간 상관계수(Correlation) 패널티를 강화하여 포트폴리오 분산 효과 강제.

## 2. 제안별 실행 상세 (Experiment Definition)

### A. Cost/Slippage Stress Test (현실성 검증)
*   **(a) 필요성:** Lockbox Sharpe 2.88은 실거래에서 구현하기 힘든 수치임. 지정가(Limit) 체결 가정이나 스프레드 비용 누락 가능성 확인 필요.
*   **(b) 위험/부작용:** 챔피언 모델이 탈락(Fail)하여 Baseline이 후퇴할 수 있음(심리적 타격, 그러나 필수적 과정).
*   **(c) 실험 설계:**
    1.  **Exp_Cost_Linear:** 기본 수수료(bps)를 10bps -> 20bps로 상향.
    2.  **Exp_Cost_Impact:** 거래량 대비 주문 비중(Market Impact)에 따른 비선형 비용 모델 적용 ($Cost = \alpha \times Volume^{1.5}$).
    3.  **Exp_Execution_Delay:** 시그널 발생 후 `Open`이 아닌 `Close` 체결 혹은 `Next Open` 체결로 1틱 지연.
*   **(d) PASS 조건:**
    *   [ ] Delay/Cost 증가 후에도 Lockbox Sharpe > 1.5 유지.
    *   [ ] Turnover(회전율) 급증 없이 수익 곡선 우상향 유지.

### B. Hybrid Allocation (Champion Signal + Candidate Sizing)
*   **(a) 필요성:** Champion(v5)은 수익은 좋으나 MDD(-7%)가 Candidate(-4%)보다 큼. Candidate의 'MRD(Mean Reversion w/ Decay) FSA' 사이징이 변동성 제어에 효과적이므로 이를 이식.
*   **(b) 위험/부작용:** 사이징 로직 충돌로 인해 노출도(Exposure)가 극도로 낮아져(0.1 미만) 수익이 0에 수렴할 위험.
*   **(c) 실험 설계:**
    1.  **Exp_Hybrid_VolTarget:** Champion 시그널 사용 + 전체 포트폴리오 Volatility Target을 Candidate 수준(연 10~15%)으로 제한.
    2.  **Exp_Hybrid_Betting:** 종목별 승률(Win Rate) 기반 켈리 베팅(Kelly Criterion) 적용 (Candidate의 FSA 로직 차용).
*   **(d) PASS 조건:**
    *   [ ] MDD가 -5.5% 이내로 개선.
    *   [ ] Lockbox Return이 Champion의 80% 이상 방어.

### C. Tech/Healthcare Correlation Penalty (유니버스 건전성)
*   **(a) 필요성:** Tech와 Healthcare가 동시에 무너지는 거시경제 이벤트(금리 급등 등) 시, 8~14개 종목이 동반 하락하면 MDD가 통제 불능이 됨.
*   **(b) 위험/부작용:** 상관관계가 낮은 종목을 찾다가 유동성이 떨어지거나 모멘텀이 없는 '죽은 종목'을 편입할 위험.
*   **(c) 실험 설계:**
    1.  **Exp_Corr_Filter:** 유니버스 선정 시, Tech ETF(XLK)와 Healthcare ETF(XLV)와의 상관계수가 0.7 이상인 종목의 비중 축소.
    2.  **Exp_Sector_Cap:** 섹터별 최대 비중을 60%로 강제 (Tech 100% 쏠림 방지).
*   **(d) PASS 조건:**
    *   [ ] Worst MDD (Historical) 수치가 기존 대비 10% 이상 개선.
    *   [ ] Tech/Healthcare 비중이 최소 4:6 ~ 6:4 범위 내 유지.

## 3. 성능 정체 시 원인 분해 (Debugging Stagnation)

성과 지표(Sharpe/MDD)가 개선되지 않고 제자리걸음일 경우, 다음 순서로 원인을 트리거링하라.

1.  **Exposure Check (노출 부족):**
    *   *현상:* Sharpe는 유지되나 총 수익이 미미함.
    *   *진단:* 리스크 매니저가 변동성을 과대평가하여 현금 비중(Cash)만 90% 들고 있는가?
    *   *Action:* 최소 투자 비중(Min Weights) 강제 설정 테스트.

2.  **Cost Drag (비용 잠식):**
    *   *현상:* Gross Return은 좋으나 Net Return이 무너짐.
    *   *진단:* Tech/Bio 특성상 변동성이 커서 잦은 손절매(Whipsaw)가 발생하는가?
    *   *Action:* 진입/청산 임계값(Threshold)을 넓히거나(Desensitizing), Rebalancing 주기를 늦춤.

3.  **Regime Mismatch (국면 불일치):**
    *   *현상:* 특정 연도(예: 2022년 하락장)에만 MDD가 터지고 나머지는 평탄함.
    *   *진단:* 현재 전략이 Bull Market 전용인가?
    *   *Action:* 시장 지수(SPY/QQQ)가 200일선 아래일 때, `Short` 혹은 `Cash 100%` 로직이 작동하는지 확인.

4.  **Signal Decay (알파 소멸):**
    *   *현상:* 과거 데이터(In-sample)는 완벽하나 최근 데이터(Out-sample)에서 힘을 못 씀.
    *   *진단:* 모멘텀 팩터가 이미 시장에 널리 알려져 효율화되었는가?
    *   *Action:* 가격 데이터 외 거래량(Volume) 변동성이나 섹터 로테이션 지표 추가.
