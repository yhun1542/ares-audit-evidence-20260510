## 1. 우선순위 TOP-5 제안

### P1. Degenerate Fold 원인 분해 및 수정

**(a) 왜 필요한가**
- 4개 폴드 퇴화 → OOS 신뢰구간 50% 이상 손실
- 생존편향 위험: 정상 폴드만 집계 시 과대추정

**(b) 위험/부작용**
- 폴드 재설계 시 과거 실험과 비교 불가
- 샘플 수 늘리면 look-ahead 위험 증가

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P1-A | 퇴화 폴드 샘플 수 로깅: `min_samples >= 60` 강제 | 퇴화 폴드 ≤1 | 정상 폴드 9/10 |
| P1-B | Purged K-Fold → Combinatorial Purged 전환 | OOS mean 유지 ±5% | 폴드간 std ↓20% |
| P1-C | 폴드별 레짐 태깅 (bull/bear/sideways) | 레짐 커버리지 균등 | 각 레짐 2+ 폴드 |

**(d) PASS 조건**
```
degenerate_folds <= 1 AND oos_std < 1.5
```

### P2. MDD 게이트 복원 (Risk Guardrail)

**(a) 왜 필요한가**
- `worst_mdd: None` → 리스크 차단 없이 승격 가능
- 운영 시 치명적: -30% DD 전략도 통과

**(b) 위험/부작용**
- MDD 계산 로직 버그 시 전체 파이프라인 중단
- 너무 tight하면 모든 후보 탈락

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P2-A | MDD 계산 함수 단위테스트 추가 | 테스트 pass | mdd 값 정상 출력 |
| P2-B | 하드게이트: `worst_mdd > -0.15` | 게이트 작동 확인 | 위반 시 자동 reject |

**(d) PASS 조건**
```
worst_mdd != None AND worst_mdd > -0.20
```

---

### P3. Exposure 상한 과최적화 점검

**(a) 왜 필요한가**
- `exposure_max: 0.84` → 레버리지 없이 84% 집중
- 특정 구간 올인 후 MDD 폭발 패턴 의심

**(b) 위험/부작용**
- 상한 낮추면 수익률 동반 하락
- 섹터 집중도와 혼동 가능

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P3-A | `exposure_cap=0.60` 강제 | OOS mean ≥2.0 유지 | MDD 개선 ≥15% |
| P3-B | 노출도 vs 수익 scatter plot 생성 | 시각화 완료 | 비선형 구간 식별 |

**(d) PASS 조건**
```
exposure_max <= 0.65 AND oos_mean >= 2.5
```

### P4. 비용/슬리피지 현실화

**(a) 왜 필요한가**
- 현재 비용 모델 명시 없음 → 백테스트 과대추정 확률 높음

**(b) 위험/부작용**
- 과도한 비용 가정 시 전략 전멸
- 종목별 유동성 차이 미반영

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P4-A | 왕복 비용 10bp 적용 재실행 | OOS mean ≥2.0 | 수익 감소 <25% |
| P4-B | 회전율 연간 환산 로깅 | turnover ≤ 300% | 과매매 식별 |

**(d) PASS 조건**
```
cost_adjusted_oos_mean >= 2.0 AND annual_turnover <= 400%
```

### P5. OOS Mean vs Min 괴리 분석

**(a) 왜 필요한가**
- `oos_mean: 3.32` vs `oos_min: -0.026` → 분포 극심한 skew
- 단일 폴드 -2.6% 손실 vs 평균 +3.3% → 레짐 의존성 의심

**(b) 위험/부작용**
- 레짐 필터 추가 시 복잡도 증가
- 과거 데이터 레짐 태깅의 주관성

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| P5-A | 폴드별 VIX 평균 태깅 후 성과 분해 | 분석 완료 | VIX>25 폴드 식별 |
| P5-B | `oos_min > 0` 하드게이트 추가 | 게이트 작동 | 음수 폴드 전략 자동 reject |

**(d) PASS 조건**
```
oos_min >= 0.0 AND oos_mean/oos_std >= 1.5
```
