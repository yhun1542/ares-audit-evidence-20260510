### 2. 제안별 상세 실행 계획

#### 1) Degenerate Folds 해결 (진입 필터 완화)
*   **(a) 필요성**: 4개 Fold에서 거래가 없다는 것은 특정 시장 상황(폭락장 등)에서 로직이 아예 멈춘다는 뜻. 생존 편향(Survivorship Bias)의 전형.
*   **(b) 위험/부작용**: 필터를 풀면 잡주(Low cap)나 초고변동성 종목이 편입되어 MDD가 급증할 수 있음.
*   **(c) 실험 계획 (3-5 Experiments)**
    *   `EXP_RELAX_VOL`: 진입 금지 변동성 상한(Volatility Cap)을 기존 대비 1.5배로 상향.
    *   `EXP_LOWER_LIQ`: 최소 거래대금(Min Dollar Volume) 기준을 $10M -> $5M으로 하향.
    *   `EXP_MIN_WEIGHT`: 포트폴리오 내 최소 종목 수를 0 -> 4로 강제 설정하여 억지로라도 담게 유도.
*   **(d) PASS 조건**:
    *   `degenerate_folds` 개수가 0 또는 1 이하로 감소.
    *   `oos_min`이 -0.05 이상 유지 (폭락 방어).

#### 2) 비용 모델 현실화 (Slippage Stress)
*   **(a) 필요성**: OOS Mean 3.32는 비현실적. 실제 주문 집행 시 Tech/Bio 섹터의 호가 공백(Slippage) 반영 필수.
*   **(b) 위험/부작용**: 겉보기 수익률(Sharpe)이 급락하여 챔피언 모델이 탈락할 수 있음(그러나 이는 건강한 탈락임).
*   **(c) 실험 계획**
    *   `EXP_COST_BPS_10`: 거래 비용(Transaction Cost)을 10bps(0.1%)로 설정.
    *   `EXP_COST_BPS_20`: 거래 비용을 20bps(0.2%)로 설정 (Bio 종목 대응).
    *   `EXP_DELAYED_ENTRY`: 시그널 발생 후 '다음 날 시가(Open)'가 아닌 '다음 날 VWAP' 체결 가정.
*   **(d) PASS 조건**:
    *   비용 2배 적용 후에도 OOS Sharpe > 1.5 유지.
    *   회전율(Turnover)이 비용 증가에 비례하여 자연스럽게 감소하는지 확인.

#### 3) 섹터 밸런싱 강제 (Correlation Break)
*   **(a) 필요성**: 8~14개 종목이 모두 Tech로 쏠릴 경우, 나스닥 조정 시 계좌가 녹아내림. Healthcare(방어적 성격) 강제 편입 필요.
*   **(b) 위험/부작용**: 상승장에서 Tech 주도주를 놓쳐 알파가 감소할 수 있음.
*   **(c) 실험 계획**
    *   `EXP_BALANCE_5050`: 유니버스 내 Tech 50%, Healthcare 50% 강제 할당 후 랭킹 산출.
    *   `EXP_CAP_TECH_8`: Tech 종목 최대 보유 개수를 8개로 제한.
    *   `EXP_PAIR_HEDGE`: Tech 매수 시, Beta가 낮은 Healthcare 종목을 최하위 랭크라도 1개 강제 편입.
*   **(d) PASS 조건**:
    *   MDD가 기존 대비 10% 이상 개선.
    *   상관관계(Correlation)가 시장 지수(SPY/QQQ) 대비 0.8 이하로 하락.

### 3. 성능 정체 시 원인 분해 (Decomposition Check)

성능 지표가 움직이지 않을 때 다음 순서로 코드를 점검하십시오.

1.  **트리거(Trigger) 확인**: `rebalance_period`가 너무 길거나(예: 월간), `threshold`가 너무 높아 매매 자체가 발생하지 않는지? -> **일간(Daily) 체크로 변경 후 시그널 빈도 확인.**
2.  **적용(Execution) 확인**: 모델이 시그널을 보냈으나, `position_sizer` 단계에서 자산 배분(Weight)이 0.01 미만이라 잘려나가는지? -> **소수점 4자리까지 Weight 허용.**
3.  **노출(Exposure) 확인**: 현금 비중이 90% 이상 유지되는지? (Safe Haven 로직 오작동) -> **강제 Full Investment (Exposure 1.0) 실험으로 로직 검증.**
4.  **레짐(Regime) 불일치**: 훈련 데이터의 시장 국면(상승장)과 검증 데이터의 국면(횡보/하락장)이 달라서 모델이 '관망'만 하는지? -> **훈련 데이터 기간을 최근 6개월로 좁혀서 Overfit 유도 후 작동 여부 확인.**
