## 2. 우선순위 TOP-5 Patch 제안

### PATCH-1: Calmar-Weighted Ensemble (Champion + Candidate 합성)

**(a) 왜 필요한가**
- Champion: 고수익/고MDD, Candidate: 저수익/저MDD
- 단일 모델 선택보다 **Calmar 비율 기반 가중 평균**이 risk-adjusted 우위

**(b) 위험/부작용**
- 복잡도 증가 → 유지보수 비용
- 두 모델 상관관계 높으면 분산효과 無

**(c) 최소 실험**
| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| E1.1 | 50:50 단순 평균 | lockbox_mean > 2.5 AND worst_mdd > -5.5% | Sharpe 0.1+ 개선 |
| E1.2 | Calmar 비례 가중치 (Champion ~0.6) | 동일 | MDD 1%p 감소 |
| E1.3 | 롤링 120일 Calmar 동적 가중치 | 동일 + 회전율 < 150%/yr | 적응적 개선 |

**(d) PASS 조건**
```
lockbox_mean >= 2.5 AND worst_mdd >= -0.055 AND turnover <= 1.5
```

### PATCH-2: Regime Filter 추가 (VIX/금리 기반 노출 조절)

**(a) 왜 필요한가**
- worst_mdd -7%가 특정 레짐(금리급등/VIX 스파이크)에 집중 가능성
- 레짐별 노출 조절로 꼬리위험 절감

**(b) 위험/부작용**
- 레짐 정의 과최적화 위험
- 좋은 구간도 회피 → 수익 훼손

**(c) 최소 실험**
| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| E2.1 | VIX > 25 시 포지션 50% 축소 | worst_mdd > -5% | MDD 2%p 개선 |
| E2.2 | 2Y-10Y 역전 시 Tech 비중 -20% | lockbox_mean > 2.0 | 섹터 드로다운 감소 |
| E2.3 | 복합(VIX>25 OR 역전) 시 현금 30% | 둘 다 충족 | 안정성 확인 |

**(d) PASS 조건**
```
worst_mdd >= -0.05 AND lockbox_mean >= 2.2
```

### PATCH-3: Position Sizing 리팩터 (Equal → Vol-Parity)

**(a) 왜 필요한가**
- Tech(고변동) vs Healthcare(저변동) 동일 비중 시 실질 위험 불균형
- 변동성 역수 가중치로 위험 평준화

**(b) 위험/부작용**
- 저변동 종목 과대 노출 → 유동성 리스크
- 변동성 예측 오류 시 역효과

**(c) 최소 실험**
| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| E3.1 | 20일 실현변동성 역수 가중치 | worst_mdd > -6% | Sharpe +0.05 |
| E3.2 | 60일 변동성 + 1% 플로어 | 동일 | 극단 집중 방지 |
| E3.3 | 섹터별 Vol-Parity (종목은 동일) | lockbox_mean > 2.5 | 단순화 버전 |

**(d) PASS 조건**
```
sharpe_lockbox >= champion_sharpe AND worst_mdd >= -0.06
```

## 3. 성능 불변 시 원인 분해 트리

```
성능 안 움직임
├─ [트리거] 신호 자체가 발생 안 함?
│   └─ 점검: 일별 신호 발생 빈도, 최근 30일 트리거 횟수

│   └─ 점검: 포지션 변경 로그, 최소보유/cooldown 규칙 충돌
├─ [노출] 포지션은 바뀌었으나 시장 움직임과 무관?
│   └─ 점검: 포지션 방향 vs 실제 수익률 상관계수
├─ [비용] 수익은 나지만 비용에 잠식?
│   └─ 점검: gross return vs net return 차이, 슬리피지 추정
└─ [레짐] 현재 시장이 전략 blind spot?
    └─ 점검: 최근 60일 VIX/금리/섹터모멘텀 vs 학습구간 분포 비교
```
