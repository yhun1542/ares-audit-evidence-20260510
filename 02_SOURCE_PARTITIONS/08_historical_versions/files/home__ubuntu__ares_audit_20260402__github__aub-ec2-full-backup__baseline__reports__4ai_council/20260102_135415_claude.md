## 1. 우선순위 TOP 5 액션

### P1. 데이터/로그 무결성 복구 (BLOCKER)
```
왜: rebalance 로그 없이 비용/슬리피지 검증 불가 → 모든 OOS 수치 신뢰도 0
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **FIX-01** | `rebalance.jsonl` 생성 파이프라인 점검 + 재실행 | 파일 존재 & row > 100 | 종목별 거래 타임스탬프 출력 |
| **FIX-02** | OOS Mean 불일치 원인 추적 (1.88 vs 2.63) | delta < 0.05 | champion 해시 일치 확인 |
| **FIX-03** | `worst_mdd` 계산 로직 활성화 | MDD ≠ None | -15% ~ -40% 범위 내 |

**PASS 조건**: 3개 모두 통과 → P2 진행 가능

---

### P2. 비용/슬리피지 누수 점검
```
왜: 현재 OOS에 실거래 비용 미반영 가능성 → 과대 성과
위험: 비용 반영 시 OOS Mean 30~50% 하락 가능
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **COST-01** | 편도 10bp 슬리피지 적용 백테스트 | OOS Mean > 1.2 | 기존 대비 Δ 측정 |
| **COST-02** | 회전율(turnover) 측정: 월평균 % | turnover < 40%/월 | 과다회전 종목 리스트 |

**PASS 조건**: COST-01 OOS > 1.2 AND turnover < 40%

---

### P3. Survivorship Bias 검증
```
왜: 현재 종목풀이 "살아남은 종목"만 포함 시 OOS 왜곡
위험: 상장폐지/M&A 종목 누락 → +0.3~0.5 과대 추정
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **SURV-01** | 2020-2024 상폐/합병 Tech+HC 종목 리스트 대조 | 누락 종목 < 5개 | 누락 리스트 출력 |
| **SURV-02** | 누락 종목 포함 재백테스트 (가능 시) | OOS delta < 0.2 | 하락폭 측정 |

**PASS 조건**: 누락 < 5개 OR 포함 후 OOS delta < 0.2

---

### P4. 과최적화(Overfitting) 진단
```
왜: 9개 실험 후 개선 없음 → 파라미터 공간 소진 or 구조적 한계
위험: 추가 실험이 노이즈 피팅만 증가
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **OVER-01** | IS vs OOS 괴리 측정: (IS_mean - OOS_mean)/IS_mean | 괴리 < 30% | 현재 괴리율 % |
| **OVER-02** | 파라미터 수 vs fold 수 비율 | param/fold < 3 | 자유도 확인 |
| **OVER-03** | 랜덤 시드 3개 변경 재실행 | OOS std < 0.3 | 안정성 확인 |

**PASS 조건**: 괴리 < 30% AND seed 변경 std < 0.3

---

### P5. 레짐/노출 불균형 진단
```
왜: exposure 0.47~0.84 변동 → 특정 구간 과소/과다 노출 가능
위험: 상승장만 노출 높으면 하락장 MDD 급증
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| **REG-01** | VIX > 25 구간 exposure 분포 | exposure > 0.3 유지 | 공포장 회피 여부 |
| **REG-02** | 2022 하락장 단독 OOS | OOS > 0.8 | 방어력 측정 |

**PASS 조건**: 공포장 exposure > 0.3 AND 2022 OOS > 0.8

## 2. 성능 미개선 원인 분해 트리

```
OOS 변화 없음
├─ [트리거] 시그널 자체가 미발동
│   └─ 점검: 최근 6개월 시그널 발동 횟수
├─ [적용] 시그널 발동 → 포지션 미반영
│   └─ 점검: 시그널 vs 실제 보유 일치율
├─ [노출] 포지션 있으나 비중 미미
│   └─ 점검: 승리 트레이드 평균 비중 %
├─ [비용] 수익 < 거래비용
│   └─ 점검: 총수익 vs 총비용 비율
└─ [레짐] 해당 기간 전략 부적합 장세
    └─ 점검: 동일 기간 SPY 대비 상관관계
```

## 3. 48H 자동 루프 실행 순서

```bash
# Phase 1: 무결성 (0-8H)
□ FIX-01 → FIX-02 → FIX-03
  GATE: 3/3 PASS → Phase 2
  FAIL: 루프 중단, 수동 개입

# Phase 2: 비용/바이어스 (8-24H)  
□ COST-01 → COST-02 → SURV-01
  GATE: OOS_cost > 1.2 → Phase 3
  FAIL: 전략 근본 재설계 필요

# Phase 3: 안정성 (24-48H)
□ OVER-01 → OVER-03 → REG-02
  GATE: 괴리<30% & 2022 OOS>0.8
  PASS: 현 champion 유지, 실거래 준비
  FAIL: 앙상블/헤지 구조 변경 검토
```
