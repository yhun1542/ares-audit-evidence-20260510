### P1. Degenerate Fold 원인 분해 & 수정

**(a) 왜 필요한가**
- 4/10 fold가 degenerate = 해당 기간에 신호 0 or 포지션 0
- 이 상태로 live 전환 시 **특정 레짐에서 완전 무방비**
- OOS mean이 남은 6개 fold에서만 계산됨 → **서바이버십 바이어스**

**(b) 위험/부작용**
- 신호 임계값 낮추면 → 노이즈 트레이드 증가, 비용↑
- 강제 최소 exposure 설정 → 역풍 레짐에서 손실 확대

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| D1 | `signal_threshold` 0.5 → 0.3 | degenerate fold ≤ 1 | OOS mean ≥ 2.0 유지 |
| D2 | `min_position_pct` = 5% (현금 95% 상한) | exposure_min ≥ 0.05 | MDD 악화 ≤ 10%p |
| D3 | fold별 신호 발생 횟수 로깅 추가 | 로그 생성 확인 | 패턴 분석 가능 |

**(d) PASS 조건**
```
degenerate_folds ≤ 1 AND oos_mean ≥ 2.5 AND oos_min > -0.05
```

### P2. MDD/Drawdown 계측 파이프라인 복구

**(a) 왜 필요한가**
- `worst_mdd: None` → 리스크 블라인드 상태
- 과최적화 탐지 불가, position sizing 조정 근거 없음

**(b) 위험/부작용**
- 계산 로직 버그 시 잘못된 MDD로 조기 손절 유발
- 메모리 사용량 증가 (일별 equity curve 저장)

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| M1 | `equity_curve` 일별 저장 + peak drawdown 계산 | mdd ≠ None | 모든 fold에서 mdd 값 출력 |
| M2 | MDD > 25% 시 `FLAG_REVIEW` 자동 태깅 | 플래그 작동 | 위험 fold 자동 식별 |

**(d) PASS 조건**
```
worst_mdd is not None AND worst_mdd < 0.30
```

### P3. Rebalance Log 포맷 & 경로 정규화

**(a) 왜 필요한가**
- `rebalance_pinpoint.py` 실패 → **어떤 종목/타이밍에서 손실 발생했는지 추적 불가**
- 디버깅 불가 = 개선 불가

**(b) 위험/부작용**
- 로그 포맷 변경 시 기존 분석 스크립트 호환성 깨짐
- 파일 I/O 증가로 백테스트 속도 5-10% 저하 가능

**(c) 최소 실험**

| ID | 실험 정의 | 게이트 | 기대 관측치 |
|----|-----------|--------|-------------|
| R1 | rebalance.csv → rebalance.jsonl 통합, 경로 `artifacts/{run_hash}/` | 파일 존재 & 파싱 성공 | pinpoint 스크립트 정상 실행 |
| R2 | 스키마 검증 추가: `date, ticker, action, qty, price, cost` | validation pass | 누락 필드 0 |

**(d) PASS 조건**
```
aub_rebalance_pinpoint.py 정상 실행 AND 최소 100 rows 출력
```

**(b) 위험/부작용**

- 구현 복잡도 증가

**(d) PASS 조건**

## 2. 성능 미변동 시 원인 분해 트리

```
OOS Mean 변화 없음
│
├─ [1] 트리거 실패
│   └─ 신호 발생 횟수 동일한가? → signal_count diff
│
├─ [2] 적용 실패  
│   └─ 포지션 실제 변경됐나? → rebalance log row count
│
├─ [3] 노출 동일
│   └─ exposure 분포 변화? → exposure histogram diff
│
├─ [4] 비용 상쇄
│   └─ gross return ↑ but net ≈ → cost breakdown 확인
│
└─ [5] 레짐 불일치
    └─ 실험 기간 vs 평가 기간 시장 상태 다름 → regime overlap check
```

**체크 명령어 예시**:
```bash
# 트리거 확인
diff <(jq '.signal_count' base.json) <(jq '.signal_count' cand.json)

# 적용 확인
wc -l base_rebalance.jsonl cand_rebalance.jsonl

# 노출 확인
python3 -c "import json; d=json.load(open('cand.json')); print(d['exposure_histogram'])"
```
