## 📋 TOP 5 실행 체크리스트 (우선순위순)

### 1️⃣ Degenerate Fold 근본 수정
```
WHY: 4개 fold 퇴화 = 40% 데이터에서 시그널 0 → 과적합 거의 확정
RISK: fold 분할 로직 변경 시 기존 결과와 비교 불가
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `DEG-01` | fold별 exposure histogram 출력 추가 | 코드 실행 성공 | fold당 position_count > 50 |
| `DEG-02` | min_exposure_per_fold=0.05 강제 | degenerate ≤ 1 | OOS mean ≥ 2.0 유지 |
| `DEG-03` | purge gap 3d→5d 확대 | leakage 제거 확인 | fold 1,2 정상화 |

**PASS 조건**: `degenerate_folds ≤ 1 AND oos_min > 0.5`

---

### 2️⃣ Rebalance 로깅 파이프라인 복구
```
WHY: 비용 미반영 = 실제 수익 과대추정 (슬리피지+수수료 연 2-5% 누락)
RISK: 로깅 오버헤드로 백테스트 속도 저하
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `LOG-01` | rebalance.jsonl 스키마 검증 스크립트 | parse 100% 성공 | row_count > 0 |
| `LOG-02` | cost_bps=10 하드코딩 후 OOS 재계산 | 실행 완료 | oos_mean 하락폭 측정 |

**PASS 조건**: `rebalance_pinpoint.py 정상 실행 + cost 반영 OOS 산출`

---

### 3️⃣ MDD 계산 로직 활성화
```
WHY: worst_mdd=None → 리스크 조정 수익률 평가 불가 → 전략 비교 무의미
RISK: MDD 계산 시점 정의(일중/종가) 불일치
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `MDD-01` | equity curve에서 rolling max DD 계산 | MDD ≠ None | MDD ∈ [-0.30, -0.05] |
| `MDD-02` | Calmar ratio (CAGR/MDD) 추가 | 출력 확인 | Calmar > 1.0 |

**PASS 조건**: `worst_mdd 숫자값 출력 + Calmar ratio 계산`

---

### 4️⃣ OOS 분산 안정화 (Fold Weighting)
```
WHY: oos_min=-0.026 존재 = 특정 레짐에서 전략 붕괴
RISK: 가중치 조작 = 또 다른 과적합
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `VAR-01` | fold별 regime label(VIX>25) 부착 | 라벨링 완료 | 고변동 fold 식별 |
| `VAR-02` | oos_min fold 단독 분석 | 원인 특정 | 해당 fold 특성 문서화 |
| `VAR-03` | min fold 제외 후 OOS 재계산 (참고용) | - | 개선폭 = 진짜 취약점 크기 |

**PASS 조건**: `oos_std/oos_mean < 0.5 (CV < 50%)`

---

### 5️⃣ Exposure Cap 검증
```
WHY: exposure_max=0.84 → 레버리지 없이 84% 투자 = 합리적이나 검증 필요
RISK: exposure 계산 버그 시 실제 포지션 불일치
```

| 실험 ID | 정의 | 게이트 | 기대 관측치 |
|---------|------|--------|-------------|
| `EXP-01` | daily exposure vs holdings 교차검증 | 불일치 0건 | sum(weights) = exposure |
| `EXP-02` | exposure=0 구간 분석 | 빈도 확인 | cash 비중 20%+ 합리성 |

**PASS 조건**: `exposure 계산 로직 검증 완료`

## 🔬 성능 미변동 원인 분해 트리

```
OOS 변화 없음
├─ 트리거 미발동

│   └─ exposure 0 구간 과다 → cash_ratio 분석
├─ 비용 상쇄
│   └─ 거래 빈도 높아 수익=비용 → turnover 측정
└─ 레짐 불일치
    └─ 실험 기간 = 전략 약세 구간 → VIX overlay
```
