### 2. 제안별 상세 실행 계획

#### (1) `worst_mdd: None` 해결 및 무결성 검증
*   **Why:** MDD가 None이라는 것은 수익 곡선이 단조 증가(비현실적)하거나, 데이터 결측으로 계산이 중단된 상태. 리스크 관리 실패 상태임.
*   **Risk:** 버그 수정 후 성과 지표가 급락하여 현재 챔피언 폐기 가능성 높음.
*   **Experiments:**
    1.  `exp_fix_mdd_calc`: MDD 계산 함수에 예외 처리 추가(Div zero 방지) 및 초기 자본금 명시적 주입.
    2.  `exp_sanity_check_data`: 가격 데이터에 `NaN`이나 `0`이 포함된 구간 자동 Drop 후 백테스트 재구동.
*   **PASS 조건:** `worst_mdd`가 `None`이 아니며, -5% ~ -30% 사이의 현실적인 음수 값이 출력될 것.

#### (2) Rebalance Log 파이프라인 복구
*   **Why:** `AUB Rebalance Pinpoint` 실패로 인해 모델이 *왜* 매매했는지 블랙박스 상태. 디버깅 불가.
*   **Risk:** 로깅 오버헤드로 백테스트 속도 소폭 저하.
*   **Experiments:**
    1.  `exp_infra_jsonl`: 거래 로그 저장 방식을 `.csv`에서 `strict jsonl`로 변경 및 flush 주기 단축.
    2.  `exp_path_mapping`: `experiment_system`이 참조하는 상대 경로를 절대 경로로 하드코딩 매핑하여 `No such file` 에러 제거.
*   **PASS 조건:** `AUB Rebalance Pinpoint` 툴이 에러 없이 파싱을 완료하고 진단 리포트를 생성할 것.

#### (3) Degenerate Folds(1,2,3,8) 방어용 Regime Filter
*   **Why:** 특정 Fold(구간)에서 모델이 붕괴됨. Tech/Health 섹터 하락기에 롱 포지션을 강제했을 가능성.
*   **Risk:** 상승장에서 신호가 늦게 떠 수익 기회 상실(Lagging).
*   **Experiments:**
    1.  `exp_regime_xlk_xlv_ma`: XLK(기술), XLV(헬스)의 20일 MA > 60일 MA일 때만 진입 허용. (ETF는 매매 안 하고 지표로만 사용)
    2.  `exp_hard_stop_loss`: 개별 종목 일간 손실 -3% 도달 시 해당 Fold 내 5일간 매매 금지(Cool-down).
    3.  `exp_volatility_scaling`: VIX > 25 구간에서 전체 Exposure Max를 0.84 -> 0.4로 강제 축소.
*   **PASS 조건:** Degenerate Folds 중 최소 2개 이상이 정상 수익률 범주(-5% ~ +5% 연환산)로 복귀.

#### (4) 과최적화 제거: 비용 모델 가혹화
*   **Why:** OOS Mean 3.32는 HFT가 아닌 이상 비현실적. 실제 운영 시 슬리피지로 박살날 확률 99%.
*   **Risk:** 기존 챔피언 모델의 Sharpe Ratio가 1.0 이하로 급락할 수 있음.
*   **Experiments:**
    1.  `exp_cost_bps_10`: 편도 수수료+슬리피지를 10bps(0.1%)로 설정.
    2.  `exp_cost_bps_20`: 편도 수수료+슬리피지를 20bps(0.2%)로 설정.
*   **PASS 조건:** BPS 10 적용 후에도 Sharpe Ratio > 1.5, MDD < -20% 유지 시 유효 전략으로 인정.

*   **Why:** 2026년 기준 2025년 승자만 포함된 Static List일 가능성.
*   **Risk:** 유동성 낮은 바이오 잡주가 선택되어 MDD 폭증 가능성.
*   **Experiments:**
    1.  `exp_univ_dynamic_cap`: 매월 초 Tech/Healthcare 섹터 시총 상위 50위 중 변동성 하위 14개 선정.
    2.  `exp_univ_filter_vol`: 시총 상위 30위 중 최근 6개월 MDD가 -30%보다 양호한 종목 8개 선정.
*   **PASS 조건:** 2022년 하락장 포함 전체 기간 백테스트에서 생존(파산 없음) 및 벤치마크(QQQ/XLV) 대비 우위 확인.

### 3. 성능 정체 시 원인 분해 아이디어 (Debugging Tree)

성능 지표(OOS Mean 등)가 실험을 반복해도 움직이지 않을 경우 다음 순서로 점검:

1.  **Trigger Failure (신호 미발생):**
    *   *체크:* 진입 임계값(Threshold)이 너무 높아 거래가 `0`건인지 확인.
    *   *액션:* `Entry Threshold`를 강제로 50% 낮춰서 거래 횟수 폭증 유도 확인.

2.  **Exposure Clamping (노출 제한):**
    *   *체크:* `exposure_max: 0.83` 등의 설정이 실제 포지션 사이징을 짓누르고 있는지.
    *   *액션:* 레버리지/Exposure 제한을 1.0~1.2로 일시 해제.

3.  **Cost Masking (비용 잠식):**
    *   *체크:* 알파는 발생했으나 수수료가 이를 정확히 상쇄 중인지(PnL Flat).
    *   *액션:* 비용 0으로 설정 후 Raw Alpha 존재 여부 확인.

4.  **Regime Mismatch (국면 불일치):**
    *   *체크:* 현재 전략이 '추세추종'인데 테스트 데이터가 '횡보장(Choppy)'인지.
    *   *액션:* Fold 별 수익률을 시계열로 펼쳐 시장 지수(SPY/QQQ)와 상관관계 확인. Degenerate Fold가 횡보장과 겹치는지 대조.
