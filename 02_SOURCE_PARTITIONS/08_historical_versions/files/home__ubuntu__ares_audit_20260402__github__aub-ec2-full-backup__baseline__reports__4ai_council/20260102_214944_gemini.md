#### #2. [Logic] Degenerate Folds(1,2,3,8) 단순화
*   **(a) 필요성:** 4개 Fold가 망가졌다는 것은 특정 시장 상황(폭락장 등)에서 로직이 멈추거나, 데이터가 비어있음을 의미. 생존 편향(Survivorship Bias) 의심.
*   **(b) 위험/부작용:** 로직을 단순화하면 전체 `oos_mean`은 하락할 수 있음(그러나 신뢰도는 상승).
*   **(c) 실행 실험 (Loops):**
    1.  **실험 정의:** `No_Filter_Run` - Fold 1,2,3,8 구간에 대해 모든 진입 필터(Stoploss, Threshold)를 끄고 랜덤 진입 수행.
    2.  **게이트:** 해당 구간 데이터가 정상적으로 존재하는가? (거래 횟수 > 0)
    3.  **기대 관측치:** 만약 거래가 발생한다면 로직(필터) 문제, 발생 안 하면 데이터(Null) 문제.
*   **(d) PASS 조건:** Degenerate Folds 개수 0개 달성.

#### #3. [Risk] Tech/Health 하락장 방어 (ETF Regime Filter)
*   **(a) 필요성:** Tech/Healthcare 중심 포트폴리오는 섹터 전체 하락 시 방어력이 취약. Fold 파산 원인일 가능성 높음.
*   **(b) 위험/부작용:** 진입 기회 감소(False Negative)로 인한 수익률 저하.
*   **(c) 실행 실험 (Loops):**
    1.  **실험 정의:** `Regime_MA_Filter` - XLK(Tech) 또는 XLV(Health)가 200일 이평선 아래면 매수 금지.
    2.  **게이트:** 방어율(MDD 감소폭) > 수익률 감소폭.
    3.  **기대 관측치:** MDD가 획기적으로 줄고 Degenerate Fold가 생존 상태로 전환.
*   **(d) PASS 조건:** Worst MDD -20% 이내 방어.

#### #4. [Portfolio] 종목 쏠림 방지 (Weight Constrain)
*   **(a) 필요성:** `exposure_max: 0.83` 상태에서 특정 1-2개 종목에 몰빵했을 가능성. 8-14개 종목 분산 원칙 위배 가능성.
*   **(b) 위험/부작용:** 알파가 강한 종목의 비중을 깎아먹어 전체 수익률 저하.
*   **(c) 실행 실험 (Loops):**

    2.  **게이트:** 샤프 지수(Sharpe Ratio) 상승 여부.
    3.  **기대 관측치:** 변동성이 낮아지고 OOS Curve가 부드러워짐.
*   **(d) PASS 조건:** 개별 종목 비중 < 20%, Exposure 분산 확인.

#### #5. [Cost] 슬리피지/수수료 가중 테스트
*   **(a) 필요성:** OOS Mean 3.32는 비현실적. 실제 운영 리스크(슬리피지)가 반영 안 된 'Paper Profit'일 확률 99%.

    3.  **기대 관측치:** 수익률 급감하더라도 우상향 추세 유지 여부 확인.
