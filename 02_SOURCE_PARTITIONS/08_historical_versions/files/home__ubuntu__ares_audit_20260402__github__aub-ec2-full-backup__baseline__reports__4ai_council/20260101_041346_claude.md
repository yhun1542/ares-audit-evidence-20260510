## 3. 성과 미동 시 원인 분해 트리

```
성과가 안 움직인다
│
├─ [A] 트리거 미발동
│   └─ 점검: 신호 발생 빈도, 임계값 과다 여부
│   └─ 실험: threshold -20% 완화 후 관측
│
├─ [B] 적용 무효
│   └─ 점검: 신호→포지션 전환 로직 버그
│   └─ 실험: 특정 날짜 수동 트레이스
│
├─ [C] 노출 상쇄
│   └─ 점검: 롱/숏 비중이 상쇄되는가
│   └─ 실험: net_exposure 시계열 시각화
│
├─ [D] 비용 잠식
│   └─ 점검: 회전율 × 비용 > 알파
│   └─ 실험: 비용 0으로 재실행 비교
│
└─ [E] 레짐 비활성
    └─ 점검: 현재 구간이 전략 무효 구간
    └─ 실험: 과거 유사 레짐 추출 후 성과 비교
```
