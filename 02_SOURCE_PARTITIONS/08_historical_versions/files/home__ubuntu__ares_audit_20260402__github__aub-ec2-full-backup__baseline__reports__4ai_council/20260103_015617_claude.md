### P2. Degenerate Fold 원인 분해

```
WHY: 4/10 fold 퇴화 = 40% 기간에서 전략 미작동 → OOS 신뢰도 0
```

**체크리스트**
- [ ] Fold 1,2,3,8 의 날짜 범위 추출
- [ ] 해당 기간 exposure=0 인지 vs loss 큰지 구분
- [ ] 공통 레짐(변동성, 섹터 로테이션) 확인

**실험**
| ID | 정의 | 게이트 | 기대 관측치 |
|----|------|--------|-------------|
| P2-A | `fold_stats.json` 생성 - 각 fold별 {날짜, 거래수, exposure, return} | 파일 생성 | 퇴화 패턴 분류 |
| P2-B | 퇴화 fold에서 signal 분포 히스토그램 | 실행 완료 | signal=0 vs threshold 미달 구분 |
| P2-C | VIX>25 기간과 퇴화 fold 오버랩 계산 | 상관계수 | >0.5면 레짐 문제, <0.2면 로직 문제 |

## 🔬 성능 미작동 원인 분해 트리

```
OOS 개선 없음
├─ [트리거] Signal 생성 안 됨
│   └─ 확인: 일별 signal != 0 비율
├─ [적용] Signal → Position 변환 실패  
│   └─ 확인: signal 있는 날 position 변화 유무
├─ [노출] Position 있으나 exposure 낮음
│   └─ 확인: avg_position_size, cash_ratio
├─ [비용] 수익 < 거래비용
│   └─ 확인: gross_return vs net_return
└─ [레짐] 특정 시장 상황에서만 작동
    └─ 확인: 월별/분기별 수익 분포, VIX 상관
```
